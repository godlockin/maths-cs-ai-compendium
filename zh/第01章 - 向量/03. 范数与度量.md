# 度量与范数

> **一句话总结**：范数量的是单个向量的"大小"，度量量的是两个向量之间的"距离"；选对 L1/L2/L∞ 或余弦距离，直接决定 kNN、聚类、检索这些 ML 任务的效果。

*范数衡量一个向量的大小；度量衡量两个向量之间的距离。本文覆盖 L1、L2 和 L 无穷范数，欧几里得距离与余弦距离，以及为什么在 k 近邻 (k-Nearest Neighbors, kNN)、聚类和检索这些机器学习 (Machine Learning, ML) 任务里，选对距离函数至关重要。*

- 我们知道向量有大小和方向。但到底怎么衡量单个向量"有多大"，或者两个向量"离得多远"? 这就要请出**范数 (norm)** 和**度量 (metric)** 了。

- 标量里，我们知道 10 > 5，因为数值本身就把它量化好了；那向量怎么量化呢？答案是它的**范数**，它衡量单个向量的大小。

- 最熟悉的范数是**欧几里得范数 (Euclidean norm)** (L2)，其实就是我们早就见过的模长公式:

![formula](zh/images/formulas/formula-0d0e790b1f33.png)

- 但衡量大小的方式还有别的。想象你身处一个方格状街道的城市，你没法斜着穿过大楼，所以旅程的"长度"就是沿每条街走过的总街区数。这就是**曼哈顿范数 (Manhattan norm)** (L1):

![formula](zh/images/formulas/formula-7b96acb0712b.png)

- 或者你可能只在乎最大的那个分量，其它一概不管。这就是**最大范数 (Max norm)** (L 无穷):

![formula](zh/images/formulas/formula-f4faa9fdc1d0.png)

- 这三种都是**广义 Lp 范数 (general Lp norm)** 的特例:

![formula](zh/images/formulas/formula-75485098cfb6.png)

- 取 ![formula](zh/images/formulas/formula-a798dd128ab7.png) 得到欧几里得范数，取 ![formula](zh/images/formulas/formula-fa78c00babf5.png) 得到曼哈顿范数，当 ![formula](zh/images/formulas/formula-ffb3d79a5bef.png) 就得到最大范数。随着 ![formula](zh/images/formulas/formula-516b9783fca5.png) 增大，最大的那个分量占的分量越来越重，最终只有它说了算。

- 每一种范数都必须满足三条规则:

    - **非负性 (Non-negativity)**: ![formula](zh/images/formulas/formula-541dde63ca22.png)，且 ![formula](zh/images/formulas/formula-605322ab6459.png) 当且仅当 ![formula](zh/images/formulas/formula-4951344d9619.png)。大小永远不会是负的，只有零向量的大小是 0。

    - **齐次性 (Scaling)**: ![formula](zh/images/formulas/formula-15f5df69cdf9.png)。把一个向量放大两倍，它的大小也放大两倍。

    - **三角不等式 (Triangle inequality)**: ![formula](zh/images/formulas/formula-2e65d017221f.png)。抄近路永远不会比绕远路长。

- 现在，**度量**衡量的是两个向量*之间*的距离。可以把它理解成在问："这两个点离得多远?"

- 得到度量最简单的办法，是把范数作用在两向量之差上：![formula](zh/images/formulas/formula-46237b996ddf.png)。先把两个向量相减，再量剩下那个向量的大小。

- 用欧几里得范数就得到熟悉的**欧几里得距离 (Euclidean distance)**:

![formula](zh/images/formulas/formula-b32ac4929433.png)

- 用曼哈顿范数就得到**曼哈顿距离 (Manhattan distance)**，也就是每个坐标轴上差值的总和，就像数两个位置之间隔了多少个街区。

- 每一种度量都必须满足四条规则:

    - **非负性**: ![formula](zh/images/formulas/formula-2b7937ceed10.png)。距离永远不会是负的。

    - **同一性 (Identity)**: ![formula](zh/images/formulas/formula-474c3d2b3bee.png) 当且仅当 ![formula](zh/images/formulas/formula-f467ab2abb63.png)。距离为零意味着是同一点。

    - **对称性 (Symmetry)**: ![formula](zh/images/formulas/formula-fed64782551e.png)。从 A 到 B 的距离和从 B 到 A 的距离一样。

    - **三角不等式**: ![formula](zh/images/formulas/formula-22490b45e547.png)。直接走永远不会比绕道更长。

- 那么这两者是什么关系？范数量的是一个向量，度量量的是两个向量之间的差距。每个范数都会自然地导出一个度量 (量那个差)，但并不是每个度量都来自某个范数。

- 例如**汉明距离 (Hamming distance)** 数的是两个向量有多少个位置不同，它是合法的度量，但不来自任何范数。

- 在 ML 里，选对范数或度量很重要。

- L2 距离在求和之前会把每个差平方，所以某个特别大的差会主导结果。

- L1 距离把绝对差直接相加，每个差同等对待。跟 L2 比，单个大的差影响力更小。

## 编码练习 (在 CoLab 或 notebook 里做)

1. 对同一个向量计算 L1 和 L2 范数。试着改改里面的值，观察哪种范数对大分量更敏感，哪种对众多小分量更敏感。接着为逐渐增大的 ![formula](zh/images/formulas/formula-516b9783fca5.png) (比如 1、2、5、10、50、100) 计算 Lp 范数，看着它收敛到 L 无穷范数的值。
```python
import jax.numpy as jnp

v = jnp.array([3.0, -4.0, 1.0])

l1 = jnp.sum(jnp.abs(v))
l2 = jnp.sqrt(jnp.sum(v ** 2))

print(f"L1: {l1}, L2: {l2:.2f}")
```

2. 计算两个向量之间的欧几里得距离与曼哈顿距离。试着把两个向量拉近或推远，观察两种距离各自不同的反应。
```python
import jax.numpy as jnp

u = jnp.array([1.0, 2.0, 3.0])
v = jnp.array([4.0, 0.0, 1.0])

euclidean = jnp.sqrt(jnp.sum((u - v) ** 2))
manhattan = jnp.sum(jnp.abs(u - v))

print(f"Euclidean: {euclidean:.2f}, Manhattan: {manhattan}")
```

## 📌 本节要点

- **范数 (norm)**：衡量单个向量的"大小"，必须满足非负性、齐次性、三角不等式三条公理。
- **三种常见范数**: L1 (曼哈顿)、L2 (欧几里得)、L∞ (最大范数)，都是广义 Lp 范数在 ![formula](zh/images/formulas/formula-cd1c07c26f18.png) 时的特例。
- **度量 (metric)**：衡量两个向量之间的距离，必须满足非负性、同一性、对称性、三角不等式四条公理。
- **范数与度量的关系**：每个范数都能通过 ![formula](zh/images/formulas/formula-46237b996ddf.png) 导出度量，但反过来不成立 (如汉明距离是度量却不来自任何范数)。
- **L1 与 L2 的差异**: L2 因平方运算会被极端差主导，L1 对每个分量平权；选错会显著影响 kNN、聚类、检索的行为。
