# 向量积

> **一句话总结**：向量积把两个向量合成新的量——点积测方向对齐，叉积得垂直向量与面积，三重积则度量体积与共面性。

*向量积是衡量相似度和计算投影的基本操作。本节涵盖内积、点积、余弦相似度、叉积和外积——这些运算驱动着人工智能 (Artificial Intelligence, AI) 中的注意力机制、嵌入以及几何推理。*

- 我们已经见过如何相加、如何缩放向量。但两个向量能不能*相乘*呢？事实上乘法不止一种，每一种回答的是不同的问题。

- **内积 (inner product)** 是一个总的思路：一个函数，接收两个向量，产出一个数 (标量)。它是"向量相乘"的抽象蓝图。

- 任何内积都必须满足三条规则：

    - **正定性 (positive definiteness)**：![formula](zh/images/formulas/formula-c7fc53c8944d.png)，且当且仅当向量为零向量时取零。向量与自己相乘的结果永远非负。

    - **对称性 (symmetry)**：![formula](zh/images/formulas/formula-95a1e862a481.png)。顺序不影响结果。

    - **线性性 (linearity)**：![formula](zh/images/formulas/formula-d767722603f8.png)。对加法和缩放都满足分配律。

- 如果它们指向同一方向 (![formula](zh/images/formulas/formula-ff1572368539.png))，![formula](zh/images/formulas/formula-f80f903e5fe5.png)，点积取最大值。

- **余弦相似度 (cosine similarity)** 把点积同时除以两个向量的模长，做归一化：

- 到现在为止，点积接收两个向量、返回一个标量。**叉积 (cross product)** 反其道而行之，它接收两个向量，返回一个*新的向量*。

- 叉积 ![formula](zh/images/formulas/formula-356ac63c9781.png) 产生的向量同时垂直于 ![formula](zh/images/formulas/formula-29440a9c0f98.png) 和 ![formula](zh/images/formulas/formula-a35855f27c5b.png)：

![formula](zh/images/formulas/formula-1a8b3fadd9ab.png)

- 叉积只在 3D 里能用。点积在任意维度都成立，但叉积只属于三维空间。

- 叉积的模长等于两个向量张成的平行四边形的面积：

![formula](zh/images/formulas/formula-3f1eaff9f1b6.png)

- 注意这个规律：点积用的是 ![formula](zh/images/formulas/formula-3cf82d30457d.png)，叉积用的是 ![formula](zh/images/formulas/formula-8ce137676ac0.png)。点积衡量两个向量在方向上有多对齐，叉积衡量它们在方向上有多*不同*。

- 结果向量的方向遵循**右手法则 (right-hand rule)**：用右手四指从 ![formula](zh/images/formulas/formula-29440a9c0f98.png) 卷向 ![formula](zh/images/formulas/formula-a35855f27c5b.png)，大拇指指向的就是 ![formula](zh/images/formulas/formula-356ac63c9781.png) 的方向。

- 与点积不同，叉积**不满足交换律**：![formula](zh/images/formulas/formula-46fb7b709042.png)。交换顺序会翻转方向。

- 如果两个向量平行，它们的叉积是零向量 (因为 ![formula](zh/images/formulas/formula-d2f7c4b4af83.png))。没有面积，也就没有垂直方向。

- 那如果把三个向量用这两种积组合起来会怎样？这就引出了**三重积 (triple products)**。

- **标量三重积 (scalar triple product)** ![formula](zh/images/formulas/formula-6e7b0c4a3c68.png) 先对其中两个向量做叉积，再把结果和第三个向量做点积。输出是一个数，等于三个向量张成的平行六面体 (一个歪斜的 3D 立方体) 的体积。

- 如果标量三重积为零，三个向量就是**共面 (coplanar)** 的——它们全落在同一个平面上，围不出任何体积。

- 顺序可以循环轮换而不改变结果：![formula](zh/images/formulas/formula-d9dac76da219.png)。

- **向量三重积 (vector triple product)** ![formula](zh/images/formulas/formula-812fe654268b.png) 做两次叉积，返回一个向量。它可以用下面这个恒等式漂亮地展开：

## 编程练习 (用 CoLab 或 notebook)

1. 计算两个向量的点积，并用它求出两者之间的夹角。试着让它们正交、平行或反向，看看角度是怎么变的。
```python
import jax.numpy as jnp

a = jnp.array([1.0, 2.0, 3.0])
b = jnp.array([4.0, -1.0, 2.0])

dot = jnp.dot(a, b)
angle = jnp.arccos(dot / (jnp.linalg.norm(a) * jnp.linalg.norm(b)))

print(f"Dot product: {dot}")
print(f"Angle: {jnp.degrees(angle):.1f}°")
```

2. 计算两个 3D 向量的叉积，并通过验证结果与两个原向量的点积都为零，来确认它同时垂直于两者。
```python
import jax.numpy as jnp

a = jnp.array([1.0, 0.0, 0.0])
b = jnp.array([0.0, 1.0, 0.0])

cross = jnp.cross(a, b)

print(f"a x b = {cross}")
print(f"Perpendicular to a: {jnp.dot(cross, a) == 0}")
print(f"Perpendicular to b: {jnp.dot(cross, b) == 0}")
```

- **内积**：满足正定、对称、线性三条公理的通用"向量相乘"框架，输出为标量。
- **点积**：最常用的内积，代数上等于对应分量相乘再求和，几何上等于 ![formula](zh/images/formulas/formula-fdcd6c1ab71b.png).
- **投影**: ![formula](zh/images/formulas/formula-29440a9c0f98.png) 在 ![formula](zh/images/formulas/formula-a35855f27c5b.png) 方向上的"影子"，由点积除以 ![formula](zh/images/formulas/formula-1603dddbbc87.png) 再乘 ![formula](zh/images/formulas/formula-a35855f27c5b.png) 得到。
- **余弦相似度**：把点积归一化到 ![formula](zh/images/formulas/formula-b61210c8825b.png)，只看方向对齐、忽略长度，是嵌入比较的标配。
- **叉积**：只在 3D 定义，输出与两输入同时垂直的新向量，模长等于平行四边形面积，反交换、不结合。
