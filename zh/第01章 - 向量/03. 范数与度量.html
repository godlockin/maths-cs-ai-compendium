一句话总结：范数量的是单个向量的"大小"，度量量的是两个向量之间的"距离"；选对 L1/L2/L∞ 或余弦距离，直接决定 kNN、聚类、检索这些 ML 任务的效果。

范数衡量一个向量的大小；度量衡量两个向量之间的距离。本文覆盖 L1、L2 和 L 无穷范数，欧几里得距离与余弦距离，以及为什么在 k 近邻 (k-Nearest Neighbors, kNN)、聚类和检索这些机器学习 (Machine Learning, ML) 任务里，选对距离函数至关重要。

  • • 每一种范数都必须满足三条规则:
    • • 非负性 (Non-negativity): ，且 当且仅当 。大小永远不会是负的，只有零向量的大小是 0。
    • • 齐次性 (Scaling): 。把一个向量放大两倍，它的大小也放大两倍。
    • • 三角不等式 (Triangle inequality): 。抄近路永远不会比绕远路长。
  • • 现在，度量衡量的是两个向量之间的距离。可以把它理解成在问："这两个点离得多远?"
  • • 得到度量最简单的办法，是把范数作用在两向量之差上：。先把两个向量相减，再量剩下那个向量的大小。
  • • 用欧几里得范数就得到熟悉的欧几里得距离 (Euclidean distance):

  • • 用曼哈顿范数就得到曼哈顿距离 (Manhattan distance)，也就是每个坐标轴上差值的总和，就像数两个位置之间隔了多少个街区。
  • • 每一种度量都必须满足四条规则:
    • • 非负性: 。距离永远不会是负的。
    • • 同一性 (Identity): 当且仅当 。距离为零意味着是同一点。
    • • 对称性 (Symmetry): 。从 A 到 B 的距离和从 B 到 A 的距离一样。
    • • 三角不等式: 。直接走永远不会比绕道更长。
  • • 那么这两者是什么关系？范数量的是一个向量，度量量的是两个向量之间的差距。每个范数都会自然地导出一个度量 (量那个差)，但并不是每个度量都来自某个范数。
  • • 例如汉明距离 (Hamming distance) 数的是两个向量有多少个位置不同，它是合法的度量，但不来自任何范数。
  • • 在 ML 里，选对范数或度量很重要。
  • • L2 距离在求和之前会把每个差平方，所以某个特别大的差会主导结果。
  • • L1 距离把绝对差直接相加，每个差同等对待。跟 L2 比，单个大的差影响力更小。

import jax.numpy as jnp

📌 本节要点

  • • 范数 (norm)：衡量单个向量的"大小"，必须满足非负性、齐次性、三角不等式三条公理。
  • • 三种常见范数: L1 (曼哈顿)、L2 (欧几里得)、L∞ (最大范数)，都是广义 Lp 范数在 时的特例。
  • • 度量 (metric)：衡量两个向量之间的距离，必须满足非负性、同一性、对称性、三角不等式四条公理。
  • • 范数与度量的关系：每个范数都能通过 导出度量，但反过来不成立 (如汉明距离是度量却不来自任何范数)。
  • • L1 与 L2 的差异: L2 因平方运算会被极端差主导，L1 对每个分量平权；选错会显著影响 kNN、聚类、检索的行为。
