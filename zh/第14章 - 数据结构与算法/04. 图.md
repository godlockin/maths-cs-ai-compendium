# 图

> **一句话总结**: 图算法几乎全部归结为 BFS 与 DFS 两大遍历模式, 再叠加最短路 (Dijkstra)、拓扑排序、连通分量等变形, 掌握这两把钥匙就能破解绝大多数图题.

*图用来建模关系与连接: 社交网络、路网、依赖链. 本节覆盖图的表示、广度优先搜索 (Breadth-First Search, BFS)、深度优先搜索 (Depth-First Search, DFS)、最短路径、拓扑排序与连通分量, 以及主导图类面试题的遍历与寻路套路.*

- 图论的基础我们在第 12 章 (邻接矩阵、拉普拉斯、谱性质) 与第 13 章 (树、平面性、着色) 已经讲过. 这里聚焦**算法套路**: 如何在代码里遍历、搜索、优化图.

- 图的两大基本算法是 **BFS** 与 **DFS**. 几乎所有图题都能归约到二者之一, 可能带一点小改造. 把这两个吃透, 大部分图题都能解.

## 图的表示

- **邻接表 (adjacency list)**: 对每个节点存一份邻居列表. 空间 $O(|V| + |E|)$. 适合稀疏图 (大多数现实中的图都是稀疏的).

```python
# 无向图
graph = {
    0: [1, 2],
    1: [0, 3],
    2: [0, 3],
    3: [1, 2]
}

# 从边列表构造
def build_graph(n, edges):
    graph = {i: [] for i in range(n)}
    for u, v in edges:
        graph[u].append(v)
        graph[v].append(u)  # 有向图省略此行
    return graph
```

- **邻接矩阵 (adjacency matrix)**: $n \times n$ 的矩阵, 若边 $(i, j)$ 存在则 $A[i][j] = 1$. 空间 $O(|V|^2)$. 适合稠密图, 或需要 $O(1)$ 查询边是否存在的场景.

- **何时用哪种**: 绝大多数场景用邻接表. 只有图很稠密 ($|E| \approx |V|^2$) 或必须常数时间判断边是否存在时才用矩阵.

## 套路: BFS (广度优先搜索)

- BFS 借助队列**一层一层**地探索节点. 它是以下问题的首选:
    - **无权图**上的最短路径
    - 层序遍历
    - 找连通分量
    - 任何问"最少多少步"的问题

```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])

    while queue:
        node = queue.popleft()
        for neighbour in graph[node]:
            if neighbour not in visited:
                visited.add(neighbour)
                queue.append(neighbour)
```

- **关键**: 在**入队时**加入 `visited`, 而不是出队时. 如果出队才标记, 同一个节点可能被不同前驱多次入队, 既浪费时间, 也可能导致结果不对.

### 简单: 岛屿数量

- **问题**: 给定一个由 '1' (陆地) 和 '0' (水) 组成的二维网格, 数一共有多少座岛屿.

- **套路**: 遍历网格. 每遇到一个 '1', 就用 BFS/DFS 把所有相连的陆地都标记为已访问. 每一次 BFS 启动就是一座岛.

```python
from collections import deque

def num_islands(grid):
    if not grid:
        return 0

    rows, cols = len(grid), len(grid[0])
    count = 0

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                # BFS 标记整座岛
                queue = deque([(r, c)])
                grid[r][c] = '0'  # 标记已访问
                while queue:
                    cr, cc = queue.popleft()
                    for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                        nr, nc = cr + dr, cc + dc
                        if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == '1':
                            grid[nr][nc] = '0'
                            queue.append((nr, nc))

    return count
```

- **易错点**: `directions = [(0,1),(0,-1),(1,0),(-1,0)]` 这一套四连通邻居模式几乎所有网格题都会用到. 背下来. 需要八连通时再加上四个对角线.

- **易错点**: 直接改输入网格 (`grid[r][c] = '0'`) 可以省掉单独的 `visited` 集合. 面试里可以这么做, 但要说明代价 (会破坏输入).

### 中等: 腐烂的橘子

- **问题**: 新鲜橘子只要相邻的橘子烂了就会跟着烂. 求所有橘子都烂掉需要的最短时间 (若不可能则返回 -1).

- **套路**: 多源 BFS. 把所有初始就烂了的橘子同时塞进队列. BFS 的每一层就是一个时间步.

```python
from collections import deque

def oranges_rotting(grid):
    rows, cols = len(grid), len(grid[0])
    queue = deque()
    fresh = 0

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == 2:
                queue.append((r, c))
            elif grid[r][c] == 1:
                fresh += 1

    if fresh == 0:
        return 0

    time = 0
    while queue and fresh > 0:
        time += 1
        for _ in range(len(queue)):
            cr, cc = queue.popleft()
            for dr, dc in [(0,1),(0,-1),(1,0),(-1,0)]:
                nr, nc = cr + dr, cc + dc
                if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 1:
                    grid[nr][nc] = 2
                    fresh -= 1
                    queue.append((nr, nc))

    return time if fresh == 0 else -1
```

- **关键洞察**: 多源 BFS 把所有源头一起处理. 它给出的是到**任意**源头的最短距离, 恰好就是"最后一颗新鲜橘子多久会烂".

## 套路: DFS (深度优先搜索)

- DFS 尽可能往深处走, 走不动了再回溯. 它用栈 (显式栈, 或者靠递归的调用栈). DFS 是这些问题的首选:
    - 环检测
    - 拓扑排序
    - 连通分量
    - 回溯 / 穷举搜索
    - 带约束的路径搜索

```python
def dfs(graph, node, visited=None):
    if visited is None:
        visited = set()
    visited.add(node)
    for neighbour in graph[node]:
        if neighbour not in visited:
            dfs(graph, neighbour, visited)
```

### 中等: 课程表 (环检测)

- **问题**: 给定 $n$ 门课程与它们的先修关系, 判断能否修完所有课 (即是否存在循环依赖).

- **套路**: 在有向图里检测环. 用三种状态的 DFS: 未访问、进行中 (在当前 DFS 路径上)、已完成.

```python
def can_finish(num_courses, prerequisites):
    graph = {i: [] for i in range(num_courses)}
    for course, prereq in prerequisites:
        graph[course].append(prereq)

    # 0 = 未访问, 1 = 进行中, 2 = 已完成
    state = [0] * num_courses

    def has_cycle(node):
        if state[node] == 1:
            return True   # 回边 → 有环
        if state[node] == 2:
            return False  # 已完全探索过

        state[node] = 1  # 标记为进行中
        for neighbour in graph[node]:
            if has_cycle(neighbour):
                return True
        state[node] = 2  # 标记为已完成
        return False

    for course in range(num_courses):
        if has_cycle(course):
            return False
    return True
```

- **为什么要三种状态**: 只用两种状态 (访问过 / 没访问过) 区分不了"我正在探索这个节点"与"我已经探索完这个节点". 如果碰到一个**正在**被探索的节点 (状态 = 1), 就说明找到了环. 如果碰到已经**完全**探索完的节点 (状态 = 2), 那只是一条横叉边, 不是环.

### 中等: 课程表 II (拓扑排序)

- **问题**: 返回一个合法的修课顺序 (拓扑序).

- **套路 (Kahn 算法 —— 基于 BFS)**: 从没有入边 (入度为 0) 的节点开始. 处理它们, 再把邻居的入度减 1. 重复.

```python
from collections import deque

def find_order(num_courses, prerequisites):
    graph = {i: [] for i in range(num_courses)}
    indegree = [0] * num_courses

    for course, prereq in prerequisites:
        graph[prereq].append(course)
        indegree[course] += 1

    queue = deque([i for i in range(num_courses) if indegree[i] == 0])
    order = []

    while queue:
        node = queue.popleft()
        order.append(node)
        for neighbour in graph[node]:
            indegree[neighbour] -= 1
            if indegree[neighbour] == 0:
                queue.append(neighbour)

    return order if len(order) == num_courses else []  # 空结果 = 存在环
```

- **易错点**: 如果结果的节点数少于图的节点数, 就说明有环 (某些节点的入度一直没有降到 0).

## 最短路径

### Dijkstra 算法

- 从源点出发, 求它到所有其他节点的最短路径, 前提是图**非负权**. 用优先队列 (最小堆) 实现.

```python
import heapq

def dijkstra(graph, start):
    # graph: {node: [(neighbour, weight), ...]}
    dist = {node: float('inf') for node in graph}
    dist[start] = 0
    heap = [(0, start)]

    while heap:
        d, node = heapq.heappop(heap)
        if d > dist[node]:
            continue  # 过期条目

        for neighbour, weight in graph[node]:
            new_dist = d + weight
            if new_dist < dist[neighbour]:
                dist[neighbour] = new_dist
                heapq.heappush(heap, (new_dist, neighbour))

    return dist
```

- 时间复杂度: 用二叉堆时为 $O((|V| + |E|) \log |V|)$.

- **易错点**: `if d > dist[node]: continue` 这一行不能少. 少了就会去处理堆里的过期条目, 复杂度可能退化到 $O(|V|^2)$.

- **易错点**: Dijkstra 不适用于负权边. 一旦有负权, 贪心假设 (一个节点一旦"敲定"其距离就是最优) 就崩了. 这时改用 Bellman-Ford.

### 困难: 网络延迟时间

- **问题**: 给定 $n$ 个节点与有向带权边, 求从源点出发信号传到所有节点所需的时间. 若无法到达全部节点则返回 -1.

```python
def network_delay(times, n, k):
    graph = {i: [] for i in range(1, n + 1)}
    for u, v, w in times:
        graph[u].append((v, w))

    dist = dijkstra(graph, k)
    max_time = max(dist.values())
    return max_time if max_time < float('inf') else -1
```

## 强连通分量

- 在有向图里, **强连通分量 (Strongly Connected Component, SCC)** 是一个极大的节点集合, 集合内任意节点都能互相到达.

- **Kosaraju 算法**: (1) 在原图上做 DFS, 记录完成顺序. (2) 转置图 (所有边反向). (3) 按完成顺序的逆序在转置图上做 DFS. 第 3 步中的每一棵 DFS 树就是一个 SCC.

- **何时用**: 找循环依赖、2-SAT、把有向图缩成 SCC 的有向无环图 (Directed Acyclic Graph, DAG).

## 常见易错点汇总

| 易错点 | 例子 | 修法 |
|---------|---------|-----|
| 在出队时才标记 visited | 同一个节点被多次入队 | 入队时就标记 visited |
| 有向图里只用两种访问状态 | 分不清回边与横叉边 | 用三种状态: 未访问 / 进行中 / 完成 |
| Dijkstra 遇到负权 | 最短路径算错 | 改用 Bellman-Ford |
| 忘写 `if d > dist[node]: continue` | 处理堆里的过期条目 | 当前距离更差就跳过 |
| 网格越界检查 | 下标越界 | `0 <= nr < rows and 0 <= nc < cols` |
| 漏掉 time=0 的边界情况 | 腐烂橘子: 一开始就没有新鲜橘子 | 在 BFS 之前先判断 `fresh == 0` |
| 把有向图当无向图建 | 先修关系是单向的 | 只加一个方向的边 |

## 📌 本节要点

- **BFS 与 DFS**: 图算法的两大基石, 几乎所有图题都是二者的变体或组合.
- **邻接表 vs 邻接矩阵**: 稀疏图用邻接表 ($O(|V| + |E|)$), 稠密图或需 $O(1)$ 查边才用邻接矩阵 ($O(|V|^2)$).
- **BFS 入队即标记**: 一定在入队时加入 `visited`, 否则同一节点会被重复入队.
- **多源 BFS**: 把所有源头同时入队, 得到的是"到任意源头"的最短距离, 天然契合"所有目标最迟何时被覆盖"这类问题.
- **DFS 三态法**: 有向图环检测必须用未访问 / 进行中 / 已完成三种状态, 才能区分回边与横叉边.
- **拓扑排序 (Kahn 算法)**: 从入度为 0 的节点开始 BFS, 若最终结果节点数少于总数就说明有环.
- **Dijkstra 前提**: 只适用于**非负权图**; 处理过期堆条目要靠 `if d > dist[node]: continue` 那一行.
- **负权改用 Bellman-Ford**: 一旦有负权, Dijkstra 的贪心假设就失效.
- **强连通分量 (SCC)**: Kosaraju 算法用两遍 DFS 加一次图转置搞定, 常用于缩点为 DAG.
- **网格题 4 连通模板**: `[(0,1),(0,-1),(1,0),(-1,0)]` 是所有网格 BFS/DFS 题的公共模板, 务必背熟并配上越界检查.
