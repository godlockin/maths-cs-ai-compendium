## 三 · 教辅与拓展

### 3.1 教辅设计

7 类教辅 × 25 章 = 175 个教辅文件 + 25 个答案文件, 由核心译者团队手工编写。

- **单页 proposal**: 章节内容一览
- **闪卡**: 250+ 张 Q/A 速记
- **讲解稿**: 5500-6500 字 / 章的精讲
- **思维导图 / 信息图 / 复习大纲 / 阶段测试题**: 教学配套

### 3.2 前沿更新

- **P11**: 2026-07 最新模型更新 (GPT-5.6 / Gemini 3.5 / Claude 4.5)
- **P14**: Agent 记忆与自进化专题

- **P16**: Computer Use / Operator 实战专题

- **17 张原创 SVG**: 关键概念可视化
