# 第22章 · LLM Evaluation 方法学 · 总览

> **章节定位**: LLM 时代的"度量衡" — 从传统 NLP 指标到现代 Benchmark + LLM-as-Judge + Harness
> **章节字数**: ~8 节正文 / ~12 万字
> **配套教辅**: 本总览 + 各节精讲 + 评测代码示例
> **版本**: v1.0 (2026-07-31)

---

## 一 · 一句话总览

> **Eval = LLM 的"圣杯"**。没有好 Eval, 就没有 RLHF 的 Reward Model, 就没有可靠的 LLM-as-Judge, 就没有 Harness Engineering。**Eval 决定 LLM 走向**。
