## 三 · 关键概念 60+

### 3.1 面试心法
- STAR 法 (情境-任务-行动-结果)
- 8 步系统设计框架
- 离线-在线一致性
- 延迟 / 吞吐 / 成本三角
- 反向提问 (Reverse Questions)

### 3.2 系统设计
- 召回 / 精排 / 重排 (推荐三段式)
- 双塔模型 (Two-Tower)
- DLRM / DeepFM / DIN
- 冷启动策略
- 特征工程 / 特征存储
- 在线学习 (Online Learning)
- Multi-Armed Bandit
- 探索与利用 (Explore-Exploit)

### 3.3 反欺诈与风控
- 图神经网络 (GNN) 风控
- 异常检测 (Isolation Forest / AutoEncoder)
- 时序异常 (LSTM-AE)
- 标签稀缺 (PU Learning)
- 不平衡数据 (SMOTE / Focal Loss)
- 误杀 / 漏报权衡

### 3.4 LLM 系统
- RAG (检索增强生成)
- Vector DB / Embedding
- Hybrid Search (BM25 + Vector)
- Re-ranking (Cohere / BGE-reranker)
- Agent + Tool Use
- Prompt Caching
- KV Cache 优化
- 推理优化 (Speculative Decoding)

### 3.5 算法基础
- Top-K (堆 / 快选)
- Top-Frequent K (桶排序 / Trie)
- LRU / LFU (哈希 + 双向链表)
- Trie / Bloom Filter / HyperLogLog
- 并查集 / 红黑树 / B+ 树
- 二分 / 滑窗 / 前缀和
- BFS / DFS / 拓扑排序
- Dijkstra / Bellman-Ford
- 动态规划 (DP)
- 回溯 / 分治 / 贪心

### 3.6 行为面
- 项目 STAR 讲述
- 失败项目复盘 (Failure Story)
- 团队冲突 (Team Conflict)
- 技术分歧 (Technical Disagreement)
- 学习能力 (Learning Agility)
- Offer 谈判 (Salary Negotiation)
- RSU / 期权 / 签字费
- 跳槽时机
