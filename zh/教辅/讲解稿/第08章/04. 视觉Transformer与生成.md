## 导语（约 80 秒）

一辆自动驾驶汽车正接近十字路口。画面左下角有行人，右上角有红灯，中间还有一辆准备转弯的货车。卷积网络擅长从局部开始找边缘、纹理和轮廓，可系统最终必须回答一个全局问题：红灯约束哪条车道，行人与哪辆车可能发生冲突？

换到人脸识别也是一样。眼睛、鼻子、嘴巴各自只是局部纹理，真正决定身份的是它们之间的组合关系。再看 YOLO，检测头要同时利用小目标细节和大范围场景信息。于是研究者提出一个直接的问题：能不能把一张图切成许多小块，让每一块直接查看其他所有块，再决定该关注哪里？

这就是视觉 Transformer 的出发点。它把图像变成 Patch 序列，再用自注意力建立远距离关系。更进一步，图像块还可以与文本 Token 通过注意力交互，于是“戴红色头盔的人”不再只是字符串，而能指向画面里的具体区域。后半程我们还会看到，这套图文交互机制怎样进入潜扩散模型，让一句文字条件参与每一步图像去噪。

## 复习昨日与今日路线（约 45 秒）

上一节讲目标检测与分割：检测回答“物体在哪里”，分割回答“每个像素属于谁”。Faster R-CNN、YOLO 和 U-Net 都依赖多尺度视觉特征。问题是，普通卷积一次只看邻域，远处信息要经过很多层才能相遇。

## 核心概念一 · 图像怎样变成 Token（约 3 分钟）

**直觉。** 一张照片不能直接塞进原本处理单词序列的 Transformer。最直接的办法，是像切方格纸一样把图像切成小块，每块当作一个“视觉词”。

**定义。** 设输入图像为 $X\in\mathbb{R}^{H\times W\times C}$，其中 $H$ 是高度、$W$ 是宽度、$C$ 是通道数；Patch 边长为 $P$。不重叠切分后，Patch 数量为

$$N=\frac{HW}{P^2}.$$

每个 Patch 展平成长度 $P^2C$ 的向量，再乘可学习投影矩阵 $E\in\mathbb{R}^{P^2C\times D}$，得到 $D$ 维嵌入。符号表：$N$—Patch 数；$P$—Patch 边长；$D$—模型嵌入维度；$E$—本节的 Patch 投影矩阵，不表示期望算子。

**例子。** 对 $224\times224\times3$ 图像取 $P=16$，每边有 $224/16=14$ 块，所以 $N=14\times14=196$。每块展平长度为 $16\times16\times3=768$。若 $D=768$，投影后序列形状是 $196\times768$；再加一个分类 Token，形状变成 $197\times768$。这些数字都可用三步乘除直接验算。

**黑板动作。** 画一个 $4\times4$ 方格，把每个格子编号；再把方格拉成一排。格子空间位置没有自动保留，所以在每个嵌入上加位置向量。分类任务通常还在序列开头加入可学习的 `[CLS]` Token，最终用它的表示送入分类头。

**反例。** 如果只切块、投影，却完全不加位置编码，同一组 Patch 任意换序，模型无法仅靠自注意力区分“天空在上、道路在下”和“道路在上、天空在下”。内容没变，空间布局却变了。

**一句话总结。** ViT 的第一步不是做注意力，而是把二维图像可靠地改写成带位置信息的 Patch 序列。

**学生常问。** Patch 嵌入是不是一种卷积？是。它等价于卷积核大小为 $P$、步长为 $P$ 的卷积，只是随后把输出按序列读取。

## 核心概念二 · 自注意力怎样看全图（约 3 分钟）

**直觉。** CNN 像拿小窗口逐处观察；全局自注意力则允许每个 Patch 直接询问所有 Patch：“谁与我最相关？”红灯 Patch 可以直接关注车道，行人 Patch 可以直接关注车辆。

**定义。** 输入序列经过线性映射得到查询 $Q$、键 $K$、值 $V$。若序列长度为 $L=N+1$，每个头的键维度为 $d_k$，则

$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.$$

形状为：$Q,K\in\mathbb{R}^{L\times d_k}$，$V\in\mathbb{R}^{L\times d_v}$；$QK^\top\in\mathbb{R}^{L\times L}$，输出为 $L\times d_v$。这里深度学习中的张量指多维数组，不等同于数学上作为多重线性映射的张量。

**例子。** 暂时只看 3 个 Patch。某查询与三个键的缩放后分数是 $(2,1,0)$，softmax 权重约为 $(0.66524,0.24473,0.090031)$，三项相加为 1。若三个值是一维的 $(10,4,1)$，输出约为 $0.66524\times10+0.24473\times4+0.090031\times1=7.7214$。它不是挑一个块，而是按相关性加权汇总。

**黑板动作。** 画三个方块：红灯、车道、树。由红灯向车道画粗线，向树画细线。再写出 $L\times L$ 注意力矩阵，强调每一行都是一个查询对全体位置的权重。

**反例。** 很多人看到“全局”就以为代价固定。其实注意力矩阵有 $L^2$ 个元素。前面的 $N=196$ 时，Patch 间共有 $196^2=38,416$ 个分数；若 Patch 边长从 16 减到 8，$N$ 变为 $28^2=784$，分数变成 $784^2=614,656$，约为原来的 16 倍。空间分辨率每边翻倍，注意力工作量大约放大 16 倍。

**一句话总结。** 全局自注意力用一次矩阵运算连接远近区域，但代价随 Token 数量平方增长。

**学生常问。** 注意力图能不能直接当分割结果？通常不能。它能提示相关区域，却不等于经过像素级监督和校准的分割概率。

## 核心概念三 · ViT、DeiT 与 Swin 在解决什么（约 3 分钟）

**直觉。** ViT 展示了“少设规则、多从数据学习”的路线，但它吃数据、吃计算，而且分类用的单尺度序列不方便直接接检测与分割。DeiT 重点解决训练数据效率，Swin 重点解决计算量和多尺度特征。

**定义。** ViT 使用全局注意力和固定分辨率 Token。DeiT 加入强数据增强、正则化及知识蒸馏，并在 `[CLS]` Token 之外加入蒸馏 Token，让 Transformer 学习 CNN 教师的输出。Swin Transformer 则在局部窗口内做注意力，相邻层把窗口划分平移，再通过 Patch 合并形成层次结构。

**例子。** 假设特征图有 $56\times56=3,136$ 个 Token。全局注意力需比较约 $3,136^2=9,834,496$ 对位置。若窗口为 $7\times7$，每窗 49 个 Token，共 $3,136/49=64$ 个窗口，比较数为 $64\times49^2=153,664$，仅为全局方案的约 $1/64$。这里比较的是注意力分数数量，忽略通道投影等共同开销。

**黑板动作。** 先画四个不重叠窗口，下一层把网格向右下平移半窗。指出第一层分属不同窗口的两个相邻 Patch，到了第二层可能进入同一窗口，于是信息可以跨窗口流动。随后把相邻 $2\times2$ Patch 合并，画出分辨率减半、通道增加的金字塔。

**反例。** 如果窗口永远固定不动，各窗口会长期各算各的，边界两侧的信息难以交流。另一个反例是把 DeiT 简化成“更小的 ViT”；它的关键不是尺寸，而是训练策略和蒸馏机制提高数据效率。

**一句话总结。** DeiT 改善 ViT 的训练方法，Swin 攌造注意力范围与特征层级，二者解决的不是同一个问题。

**学生常问。** Swin 还是 Transformer 吗？是。核心运算仍是多头自注意力与前馈网络，只是注意力被限制在会平移的局部窗口中。

## 核心概念四 · 从视觉 Token 到图文生成（约 3 分钟）

**直觉。** 输入“戴红色头盔的骑车人”，模型需要把“红色”对应到颜色区域，把“头盔”对应到物体部件，把“骑车人”对应到主体。文本和图像必须在同一计算过程中交换信息。

**定义。** 交叉注意力中，图像特征提供查询 $Q$，文本 Token 提供键 $K$ 和值 $V$。每个图像位置都能根据相关性读取文字条件。潜扩散模型先用 VAE 编码器把像素图压到潜空间，再让去噪网络预测噪声；文本条件通过交叉注意力进入去噪网络。

扩散前向过程可直接写成

$$x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,\qquad \epsilon\sim\mathcal N(\mathbf 0,I).$$

符号表：$\beta_t$—第 $t$ 步噪声方差调度；$\alpha_t=1-\beta_t$—信号保留系数；$\bar\alpha_t=\prod_{s=1}^{t}\alpha_s$—累计信号保留系数；$\epsilon$—此处为标准高斯噪声，不表示数值精度或隐私预算；$I$—单位矩阵。

**例子。** 一张 $512\times512\times3$ 图像有 $786,432$ 个标量。空间下采样 8 倍、通道数为 4 的潜变量形状是 $64\times64\times4$，共 $16,384$ 个标量；前者是后者的 $786,432/16,384=48$ 倍。扩散在潜空间运行，因而显著减少主要去噪网络处理的空间数据量；不能把这个 48 倍直接宣称为端到端速度提升，因为还包含 VAE、注意力和硬件利用率。

**黑板动作。** 左边画文本 Token，右边画含噪潜变量网格；从每个网格位置连向若干词。再画“噪声 → 多步去噪 → 潜变量 → VAE 解码 → 图像”的流水线。

**反例。** 如果文本只在生成开始时压成一个向量，后续空间位置无法反复读取具体词语，细粒度属性容易丢失。另一个误区是说 VAE 直接负责生成最终语义；在潜扩散中，VAE主要负责压缩与还原，条件去噪模型承担从噪声形成内容的主体工作。

**一句话总结。** 多模态生成的关键机制，是让图像位置在去噪过程中持续读取文本 Token，而潜空间负责降低计算规模。

**学生常问。** 交叉注意力是不是把文字直接变成像素？不是。它产生条件化特征，像素最终由多步去噪和 VAE 解码共同形成。

## 一个走完全程的例子 · “红灯下的自行车”如何进入模型（约 2.5 分钟）

假设输入是一张 $224\times224\times3$ 的路口图像，并附带文本“红灯下的自行车”。

第一步，取 $16\times16$ Patch，得到 $14\times14=196$ 个视觉 Token。每个 Patch 展平为 768 维，再投影到模型维度。加入位置嵌入后，模型知道某块位于左上还是右下。

第二步，视觉自注意力建立图内关系。包含红灯的 Patch 会与车道、停止线产生较高权重；包含自行车轮廓的 Patch 会汇总相邻车架和骑行者信息。若做分类，`[CLS]` Token 汇总全图；若做检测或分割，则保留各位置特征交给任务头。

第三步，文本被分成“红灯”“下”“的”“自行车”等 Token。交叉注意力让图像位置读取这些词。红灯附近的视觉查询对“红灯”权重较高，自行车区域对“自行车”权重较高。这里的对应关系来自训练数据，不是人工写死的规则。

第四步，如果任务是文生图，系统从潜空间高斯噪声开始。去噪网络在每个时间步同时读取当前潜变量、时间步编码和文本条件，逐渐形成红灯、道路、自行车的布局。最后 VAE 解码器把 $64\times64\times4$ 潜变量还原为 $512\times512\times3$ 像素图。

好，到这里停一下。分类、定位与生成看似是三类任务，贯穿全程的对象却一致：视觉 Token 表示区域，自注意力建立图内关系，交叉注意力接入文本条件，任务头或解码器负责输出。

## 易错点回头看（约 85 秒）

1. **很多人以为 Patch 越小一定越好，其实是细节更多但计算急剧增加，因为 Patch 边长减半会让 Token 数变为 4 倍，全局注意力分数数量约变为 16 倍。**
2. **很多人以为 ViT 天生理解二维位置，其实位置必须显式注入，因为标准自注意力本身不会从 Token 排列自动知道上下左右。**
3. **很多人以为交叉注意力已经完成图文理解或图像生成，其实它只负责条件信息交换，因为最终预测还依赖视觉骨干、去噪网络、任务头或解码器。**

再补一个考试常见陷阱：Swin 的“滑动窗口”不是让一个窗口连续在图上卷动，而是相邻层采用错开的窗口划分。写成普通滑窗卷积，机制就答偏了。

## 与下节的钩子（约 30 秒）

一张图切成 Patch 后，Token 只在二维平面上排列；一段视频却多出时间轴，同一辆车会从第 1 帧移动到第 30 帧。下一节进入视频与 3D 视觉：我们要追踪跨帧变化，还要从二维观测恢复深度、相机姿态与三维结构。问题随之而来——当 Token 数量再乘上帧数，全局注意力还能承受吗？
