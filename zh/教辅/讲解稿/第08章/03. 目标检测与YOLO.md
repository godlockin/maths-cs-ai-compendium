## 导语（约 80 秒）

先抛一个数字。

**自动驾驶** 2024 年 L4 级: 一辆车一天产生约 **4 TB** 摄像头数据。**这数据要在 100ms 内处理完**才能实时避障 (100ms = 60 km/h 时车走 1.7m)。传统分类 CNN (Ch08 §02) 只回答"图里有什么"——目标检测要回答"**有什么 + 在哪 + 大小**", 输出**类别 + 边界框 (x, y, w, h)**。

YOLO (You Only Look Once, Redmon 2015) 把检测当**单次回归**——一张图一次前向传播, 输出所有边界框, **45 FPS** 实时 (VGG-16 仅 7 FPS)。今天 17 分钟讲清 4 件事: ① **IoU** (边界框重合度, 检测核心指标); ② **mAP** (平均精度均值); ③ **YOLO v1 单阶段检测** (45 FPS); ④ **YOLOv8/v9** (2023-2024 主流实时检测)。

## 核心概念一 · IoU (交并比)（约 3 分钟）

**直觉.** 两个边界框 $A, B$ 怎么算"重合度"？**交并比 (Intersection over Union, IoU)** = 交集面积 / 并集面积, 范围 [0, 1]。

**定义.**
$$\text{IoU}(A, B) = \frac{|A \cap B|}{|A \cup B|} = \frac{|A \cap B|}{|A| + |B| - |A \cap B|}$$

**例子.** 两框完全重合: IoU = 1; 完全不同 (不相交): IoU = 0; 半重合: IoU ≈ 0.5。

**用途.**
- **训练**: IoU 阈值 > 0.5 算 "正确检测" (TP), < 0.5 算"漏检" (FN)
- **NMS (非极大值抑制)**: 同一物体可能预测多个框, 保留 IoU 最高, 抑制 IoU > 0.5 的重叠框

**反例.** 用"中心点距离"代替 IoU — 远小近大同样距离, 无法刻画框形状。

**一句话总结.** IoU = 交集/并集, [0, 1], 检测核心指标, 阈值 0.5 分 TP/FN。

## 核心概念二 · mAP (mean Average Precision)（约 3 分钟）

**直觉.** 检测器给 100 个框, 实际只有 20 个真物体, mAP 综合衡量"前 N 个框里有多少真的"。

**定义.** AP (Average Precision):
- 按置信度排序所有预测框
- 计算每个 recall 下的最大 precision
- 积分 (现代用插值) 得 AP
- **mAP = 所有类 AP 的平均**

**例子.** COCO 数据集: mAP@0.5 (IoU 阈值 0.5) 与 mAP@0.5:0.95 (IoU 0.5-0.95 平均) 两个指标。

**YOLOv8** 在 COCO test-dev: mAP@0.5 = 73.0, mAP@0.5:0.95 = 53.9 — **SOTA 实时检测** (45+ FPS)。

**反例.** 报"准确率 90%" 而不报 mAP — **准确率掩盖了漏检**, 检测必须用 mAP。

**一句话总结.** mAP = 所有类 AP 平均, 综合 precision-recall, 配合 IoU 阈值 (COCO 标准 0.5-0.95)。

## 核心概念三 · YOLO 单阶段检测 (45 FPS)（约 3.5 分钟）

**直觉.** YOLO v1 (2015) 突破: 不像 Faster R-CNN 那样"先找区域再分类" (两阶段), **直接单次前向传播输出所有框**——把检测当**回归** (Ch06 §02 GD 同思路)。

**架构 (YOLO v1).**
- 输入 $448 \times 448$, CNN (类似 GoogLeNet) 提取特征
- 输出 $7 \times 7 \times 30$ 张量: 每格预测 2 个边界框 + 20 类概率 (Pascal VOC)
- 非极大值抑制 (NMS) 去除重叠

**损失函数 (3 部分).**
$$L = \lambda_{\text{coord}} \sum (x_i - \hat x_i)^2 + \lambda_{\text{obj}} \sum (C_i - \hat C_i)^2 + \sum (p_i(c) - \hat p_i(c))^2$$
- 坐标损失 (xywh)
- 置信度损失 (IoU)
- 类别损失 (softmax)

**数字.** YOLO v1: 45 FPS, mAP 63.4 (Pascal VOC 2007) — **比 Faster R-CNN 7 FPS/mAP 78 快 6 倍, 但 mAP 低 15 个百分点**。

**反例.** 用 YOLO v1 检测小目标 — 7×7 网格太粗, 小目标被同格大目标"吃掉"。

**一句话总结.** YOLO v1 = 单次前向传播 + 网格划分 + NMS, 45 FPS 实时, 但 mAP 略低 (后续 v3/v5 改进)。

## 核心概念四 · YOLOv8/v9 (2023-2024 主流)（约 3 分钟）

**直觉.** YOLOv8 (Ultralytics, 2023) 整合 YOLOv5/v7 优势 + **anchor-free** (不预设 anchor, 直接预测中心点) + **C2f 模块** (跨阶段部分卷积融合) + **TAL (Task-Aligned Assigner)**。

**架构 (YOLOv8n nano, 3.2M 参数).**
- Backbone: CSPDarknet + C2f
- Neck: PAN-FPN (Path Aggregation Network + Feature Pyramid Network)
- Head: anchor-free, 解耦 (decoupled) 分类 + 回归

**关键创新 (vs YOLO v5).**
- **Anchor-free**: 不用预设 anchor, 直接预测中心 + 宽高, 减少超参
- **C2f 模块**: 比 C3 更细粒度特征融合, 速度↑2% 准确率↑1%
- **TAL**: 任务对齐分配, 分类与回归联合优化, mAP 涨 1-2%

**数字.** YOLOv8n (3.2M): COCO mAP@0.5:0.95 = 37.3, **CPU 实时 100+ FPS**。YOLOv8x (68M): mAP = 53.9, **GPU 实时 280 FPS** (Tesla T4)。

**反例.** 仍用 anchor-based YOLOv5 — 2018 思路, anchor 超参调整累, 2023 起已被 anchor-free 替代。

**一句话总结.** YOLOv8 = anchor-free + C2f + TAL, 实时 100-280 FPS, 2024 年 SOTA 实时检测, 是工业部署默认。

## 一个走完全程的例子 · YOLOv8 端到端 5 行调用 (≤3 步可验)（约 2.5 分钟）

**场景.** 检测 COCO val2017 一张图, 输出所有物体框。

**第 1 步 · 加载模型.**
```python
from ultralytics import YOLO
model = YOLO("yolov8n.pt")  # 3.2M 参数预训练
```

**第 2 步 · 推理.**
```python
results = model("cat_dog.jpg", conf=0.25)  # 置信度阈值 0.25
for r in results:
    boxes = r.boxes  # xyxy + conf + cls
    for box in boxes:
        cls = model.names[int(box.cls)]  # 'cat' / 'dog'
        conf = float(box.conf)  # 0.0-1.0
        print(f"{cls} {conf:.2f} {box.xyxy}")
```

**第 3 步 · 数字验证.** CPU 推理: 80ms/张 (12.5 FPS), GPU (T4): 8ms/张 (**125 FPS**), 准确率 COCO val mAP@0.5 = 56.8。

**Ch07 §04 → Ch08 §03 完整链路**: Transformer attention → CNN → YOLO 检测 (单阶段 + anchor-free + 任务对齐)。

## 易错点回头看（约 80 秒）

1. **很多人以为 mAP 越高速度越快** — YOLOv8x mAP 53.9 比 YOLOv8n mAP 37.3 高 17 个百分点, **速度慢 5 倍** (80ms vs 16ms), 工程需权衡。
2. **很多人混用 mAP@0.5 vs mAP@0.5:0.95** — mAP@0.5 只看 IoU ≥ 0.5 算 AP, mAP@0.5:0.95 算 IoU 0.5-0.95 平均, **后者更严格** (YOLOv8x 在 0.5 是 73.0, 在 0.5:0.95 仅 53.9)。
3. **很多人误用 NMS** — NMS 阈值过低 (< 0.3) 漏检相邻物体, 过高 (> 0.7) 重复框。
