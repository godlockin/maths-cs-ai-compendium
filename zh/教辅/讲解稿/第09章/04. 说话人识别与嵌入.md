## 核心概念一 · 说话人识别 vs 验证（约 2 分钟）

**直觉.** 说话人识别有 2 类任务:
- **说话人验证 (Speaker Verification)**: **1:1 匹配**——"这段语音是张三说的吗?"
- **说话人识别 (Speaker Identification)**: **1:N 匹配**——"这段语音是 100 个候选人中的谁说的?"

**定义.**
- **注册 (Enrollment)**: 每个说话人录制几段语音, 提取嵌入存为**声纹模板**
- **测试 (Test)**: 给定新语音 + 候选模板, 计算相似度
- **阈值 (Threshold)**: 相似度 > 阈值 → 接受, < 阈值 → 拒绝

**指标.** EER (Equal Error Rate, 等错误率): **假接受率 = 假拒绝率** 时的错误率, EER 越低越好。
- 银行验证 EER < 0.01% (极严)
- 通用场景 EER < 2% (VoxCeleb SOTA)

**反例.** 用**准确率**作指标 — 1:1 验证场景假拒绝是真实负例, 准确率无意义。

**一句话总结.** 说话人验证 = 1:1 + EER, 识别 = 1:N + Top-K 准确率, 嵌入 + 评分是核心两步。

## 核心概念二 · x-vector 说话人嵌入（约 3.5 分钟）

**直觉.** 既然 ASR 编码器能学到语音内容, 我们**稍作修改**就能让它学到说话人身份。**x-vector (Snyder 2018)**: 用 TDNN (Time Delay NN) 编码 + 统计池化 + 全连接 → 512 维固定长度嵌入。

**架构.**
- **输入**: MFCC 特征 (Ch09 §01) 或 F-bank 滤波器组能量, 200 帧 ≈ 2 秒
- **帧级 (frame-level)**: 5 层 TDNN + ReLU + BN, 每层 512 维, 局部上下文
- **统计池化**: 均值 + 标准差 (Ch09 §01 池化), 变长 → 定长 (Ch06 §04 函数式同思路)
- **段级 (segment-level)**: 2 层全连接 (512 → 512), 输出 **512 维 x-vector**
- **Softmax**: 训练时用说话人 ID 作标签, 测试时**取前 512 维嵌入** (去掉 softmax)

**关键.** **统计池化**让变长输入 → 定长嵌入, 是 x-vector 的核心创新 (类似 Transformer 的 class token / RNN 的最后隐状态)。

**数字.** x-vector 512 维, VoxCeleb test EER **3.1%** (Snyder 2018) → ECAPA-TDNN (2021) EER **0.86%** → WavLM (2022, 微软) EER **0.43%**。

**反例.** 直接用 ASR 编码器当说话人嵌入 — 编码器学"说了什么", 不是"谁说", 需换 head + 用说话人 ID 微调。

**一句话总结.** x-vector = TDNN + 统计池化 (均值+标准差) + 全连接 = 512 维说话人嵌入, 共享 ASR 声学前端, 是 2018-2024 主流。

## 核心概念三 · PLDA 评分 (约 3 分钟)

**直觉.** 拿到两个 x-vector, 怎么判断"是不是同一个人"? 直接余弦相似度可以, 但**通道噪声** (麦克风/距离/背景) 会干扰。**PLDA (Probabilistic Linear Discriminant Analysis)** 把说话人差异和通道差异分开建模。

**定义.** PLDA 生成模型:
$$x = m + U y + \epsilon$$
- $x \in \mathbb{R}^{512}$: x-vector
- $m \in \mathbb{R}^{512}$: 全局均值
- $U \in \mathbb{R}^{512 \times r}$: 说话人子空间 (低秩, $r$ 远小于 512)
- $y \in \mathbb{R}^r$: 说话人身份 (隐变量, 多元高斯)
- $\epsilon \in \mathbb{R}^{512}$: 通道噪声 (隐变量, 高斯)

**对数似然比.**
$$\text{LLR} = \log \frac{P(x_1, x_2 | H_1)}{P(x_1 | H_0) P(x_2 | H_0)}$$
- $H_1$: 同一说话人
- $H_0$: 不同说话人

**训练:** EM 算法估计 $m, U$ 协方差; **测试:** 计算两 vector 的 LLR, > 阈值 → 接受。

**例子.** VoxCeleb 1:1 验证: 余弦相似度 EER 4.5%, PLDA EER 1.8% — **PLDA 比余弦好 60%**。

**反例.** 直接用余弦相似度, 不做 PLDA 校准 — 通道敏感, 跨麦克风 EER 退化 2-3 倍。

**一句话总结.** PLDA = 说话人 (低秩) + 通道 (噪声) 双子空间模型, LLR 评分, 比余弦相似度精准 60%。

## 核心概念四 · VoxCeleb 数据集与 SOTA (约 3 分钟)

**直觉.** 说话人识别数据稀缺, VoxCeleb (Nagrani 2017) 用 YouTube 视频挖掘——**真人说话, 真实噪声, 多语言, 多场景**。

**数字.** VoxCeleb2 (2018): **6112 个说话人, 1 百万+ 段音频** (中文/英文/印地/韩语/...), 是 x-vector 训练标配。

**SOTA 进展 (2018-2024).**
| 年份 | 系统 | VoxCeleb test EER |
|---|---|---|
| 2018 | x-vector + PLDA | 3.1% |
| 2020 | ECAPA-TDNN | 0.86% |
| 2021 | AASIST (抗欺骗) | 0.82% |
| 2022 | WavLM (微软) | 0.43% |
| 2024 | ERes2Net (阿里) | 0.32% |

**反例.** 在小数据集 (如 10 个说话人) 训练 x-vector — **EER > 20%**, 模型欠拟合; VoxCeleb 训好才能 fine-tune。

**一句话总结.** VoxCeleb 6K 说话人 1M 音频, SOTA EER 0.32-3.1%, 说话人识别 2018-2024 主要数据集。

## 一个走完全程的例子 · x-vector 5 行推理 (≤3 步可验)（约 2.5 分钟）

**场景.** 用 SpeechBrain 提取两段语音的 x-vector, 计算余弦相似度判别是否同说话人。

**第 1 步 · 加载模型.**
```python
from speechbrain.inference.speaker import EncoderClassifier
model = EncoderClassifier.from_hparams(source="speechbrain/spkrec-xvect-voxceleb")
```

**第 2 步 · 提取 x-vector.**
```python
emb1 = model.encode_batch(torch.tensor(audio1))  # (1, 512)
emb2 = model.encode_batch(torch.tensor(audio2))  # (1, 512)
```

**第 3 步 · 余弦相似度 + PLDA.**
```python
sim = torch.nn.functional.cosine_similarity(emb1, emb2).item()
# 同说话人: sim ≈ 0.85-0.95; 不同: 0.0-0.5
# PLDA 校准: score_plda = plda.score(emb1, emb2)
print(f"cosine sim: {sim:.3f}")
```

**Ch09 §04 完整链路**: ASR 编码器 → x-vector → PLDA → 阈值判别。

## 易错点回头看（约 80 秒）

1. **很多人混淆"识别"与"验证"** — 1:N 识别是开集分类, 1:1 验证是二分类, 指标不同 (Top-K vs EER)。
2. **很多人误用余弦相似度** — 跨麦克风/距离/语速, 余弦退化, **PLDA 校准必加**。
3. **很多人把 x-vector 当万能** — x-vector 训练需 VoxCeleb 大数据, 小数据 (10 人) 效果差, 需 fine-tune。
