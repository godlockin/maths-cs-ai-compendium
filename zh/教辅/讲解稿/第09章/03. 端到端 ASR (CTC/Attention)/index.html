    讲解稿 · 第 09 章 第 03 节 · 端到端 ASR (CTC/Attention)¶

    口播时长：约 18 分钟｜建议语速：中速，公式处停两拍｜字数：约 3900 字

    承 Ch09 §02 传统 ASR 流水线 (GMM-HMM / WFST) → Ch09 §03 端到端 ASR (CTC/Attention) → Ch09 §04 自监督预训练与大规模模型

    导语（约 80 秒）¶

    先抛一个真实场景。

    上个月我去银行办业务，柜台前放着一个电话客服机器人。我说："我信用卡上个月有三笔消费，第一笔是在京东买的笔记本电脑，第二笔是在美团点外卖，第三笔是在加油站刷卡。"机器人几乎同时在屏幕上把每一笔交易金额、日期、商户名称都打了出来，最后还问了一句："请问您要咨询的是否是与京东购物相关的那笔 8927 元订单？"——这句话我整段话里根本没出现过，是它自己从我说的"笔记本电脑"四个字里联想出来的。

    这段实时转写 + 实体抽取 + 跨句推理，背后是一台端到端 ASR 接一个语言模型，整段延迟不到 1 秒。换成 2015 年的老系统，这段话得先做 GMM-HMM 声学识别，再走 WFST 解码，再走单独的语义理解——三个独立模块串起来，延迟常常超过 3 秒，而且"京东"两个字经常被识别成"京东"或"景东"，最后一行字要人工核对。

    这中间 10 年的差距，靠的不是某一个神奇模块，而是把"声学 + 词典 + 语言学 + 解码"四个独立组件吞进一个神经网络。今天 18 分钟，我们用 6 件事讲清楚这件事怎么发生的：① 为什么传统流水线会被打穿；② CTC 怎么用一个特殊空白标记解决对齐难题；③ RNN-Transducer 怎么去掉 CTC 的条件独立性假设；④ 基于注意力的编码器-解码器 (LAS) 怎么走到另一条路；⑤ Conformer 怎么把卷积和注意力揉到一起；⑥ Whisper 与 wav2vec 2.0 怎么把规模推到一个新量级。讲完之后，你再听到 Siri、Whisper、讯飞、客服机器人这些名字，脑子里就不会只剩"AI 转写"四个字，而是一张完整的技术地图。

    复习昨日 & 今日路线（约 50 秒）¶

    §02 我们走了 ASR 的经典流水线：从梅尔频谱出发，GMM-HMM 给每一帧打 senone 分数，WFST 把 H、C、L、G 四个有限状态转换器组合成一张搜索图，最后用 Viterbi 找出最优词序列。每个组件单独训练、单独调优，能拆开 debug，工程师可以"知其然"——但天花板被每个模块的局部最优钉死了。DNN-HMM 把 GMM 换成深度神经网络，相对 WER 降了 20-30%，但 HMM 这层结构还是老套路。

    今天 §03 我们走另一条路：把声学、词典、语言学都吞进一个神经网络，端到端训练。重点讲清对齐这一根本难题——输入每秒几百帧，输出每秒几个字符，长度差几百倍，训练时它们之间怎么对齐？这条线拉通后，下一节 §04 我们再看 wav2vec 2.0 / HuBERT / Whisper / USM 怎么把自监督预训练和规模推上新的台阶。

    核心概念一 · CTC：空白字符解决对齐难题（约 3 分钟）¶

    直觉。 一段 3 秒的音频，按 10 ms 步长切梅尔帧，大约 300 帧。对应的转写是"你好"两个汉字，平均每个字读 0.4 秒，对应 40 帧。这意味着输入长度是输出长度的 7-15 倍。训练时我们只有"3 秒音频 + 文本"两个东西，中间的"哪个字符对应哪一段音频"完全不知道。

    传统做法是逼工程师标注 force alignment——把每一帧手工对应到一个音素。工程浩大，标注成本爆表。CTC (Connectionist Temporal Classification) 的核心想法是：别硬对齐了，让网络在每个时刻任意输出字符或空白，最后把所有"能坍缩到正确转写"的路径概率加起来。

    定义。 - CTC (Graves et al., 2006) 在字符表之外引入一个特殊的空白标记 (blank, 通常记为 -)。 - 网络在每个时刻从 (V+1) 个 token (V 个字符 + 1 个空白) 里挑一个。 - 一个输出序列 π = (π_1, π_2, ..., π_T) 经过两步坍缩得到转写 y：(1) 合并连续重复字符；(2) 删除所有空白。例如 --cc-aa-t-- 坍缩成 cat。 - 标签序列 y 的概率定义为：

    \[P(\mathbf{y} | \mathbf{x}) = \sum_{\boldsymbol{\pi} \in \mathcal{B}^{-1}(\mathbf{y})} \prod_{t=1}^{T} p(\pi_t | \mathbf{x})\]

    其中 B 是上述多对一映射，B⁻¹(y) 是所有坍缩到 y 的合法路径集合。

    例子。 假设 T=5，目标是 "cat"。能坍缩到 "cat" 的合法路径包括 --cat、c-cat、ca-t-、-c-at 等等——只要 c 后能再跟一个 c (重复不合并)、a、t 各自被空白隔开或处于不重复位置。CTC 前向-后向算法用动态规划在 O(T·|y|) 时间内把这种指数级求和算完——和 Ch05 HMM 前向-后向同一套路。

    反例。 直接把 CTC 输出当最终转写，不做任何处理，会得到 cccaatt 这种重复字符——必须先 collapse 再删 blank。反例二：用"不加 blank 的多对多映射"替代 CTC，结果某些字符永远无法被识别 (例如目标 aa，但网络每个时刻只允许 1 个字符，无 blank 隔开时无法表达)。CTC 加 blank 不是装饰，是数学上让"任意长度对齐到任意长度转写"成立的最小补丁。

    一句话总结。 CTC 用 blank + 路径求和把对齐问题从"必须知道"换成"可以不知道"，代价是做了条件独立性假设：每个时刻的输出互相独立，学不到"q 后必跟 u"这种依赖。

    核心概念二 · RNN-Transducer：去掉条件独立假设（约 3 分钟）¶

    直觉。 CTC 假设"每个时刻的字符独立"——但语言不是独立的。CTC 解码时得外挂一个语言模型才能修这个缺陷。RNN-Transducer (RNN-T, Graves 2012) 的核心想法是：直接在网络里加一个"预测网络"模拟语言模型，让每个输出条件依赖之前的输出，干净利落。

    定义。 RNN-T 三个组件： 1. 编码器 (encoder)：从左到右处理音频特征 (通常是 LSTM 或 Conformer 堆叠)，输出 h_t^enc。 2. 预测网络 (prediction network)：自回归 RNN，喂入已发射的标签，输出 h_u^pred。 3. 联合网络 (joint network)：把两个表示组合，算出下一个 token 的分布 (含 blank)：

    \[p(y | t, u) = \text{softmax}\!\left(W \cdot \tanh\!\left(W_\text{enc} \mathbf{h}_t^\text{enc} + W_\text{pred} \mathbf{h}_u^\text{pred} + b\right)\right)\]

    u 是已发射的标签个数，t 是当前编码时刻。联合网络在二维网格 (t, u) 上做前向-后向，复杂度 O(T·U)。

    关键机制：RNN-T 允许每个时刻发射零个或多个标签——发非 blank 就在当前 t 继续发下一个字符，发 blank 就前进到 t+1 但 u 不变。这套机制让 RNN-T 天生流式：编码器从左到右扫音频，预测网络增量式产出字符，无需等完整音频。

    例子。 Google Pixel 手机内置的 ASR 用 RNN-T 架构。原因很直接：你对手机说"Hey Google"，手机必须在 300 ms 内给出反应，不能等整段话说完。CTC + 后挂 LM 也能流式，但 LM 是独立模块；RNN-T 把 LM 折进网络，端到端训练得到更紧的联合优化。

    反例。 以为 RNN-T 只是"CTC + 一个 RNN"——错。CTC 输出条件独立 (Ch09 §03 概念一已讲)，RNN-T 通过预测网络显式建了 token 间依赖，等式右边的 W_pred · h_u^pred 这一项承载了"上一个字符是什么"的信息。代价是计算图变大 (二维网格)、训练慢，所以 RNN-T 训练通常需要大 batch + 混合精度 + 分布式。

    一句话总结。 RNN-T = CTC 的路径求和 + 预测网络的语言建模，是当前端侧流式 ASR 的主流架构。

    核心概念三 · LAS：基于注意力的另一条路（约 2.5 分钟）¶

    直觉。 CTC 与 RNN-T 都属于"逐帧 → 序列"的范式。另一条路完全不同：把整段音频一次性编码成一个特征序列，再用注意力机制让解码器自己挑要看哪几帧。这就是 LAS (Listen, Attend and Spell, Chan et al., 2016)。

    定义。 LAS 三组件： 1. Listener (编码器)：金字塔式双向 LSTM，每一层把相邻隐藏状态拼接做 8 倍下采样，整段音频压缩成一个较短的编码器隐藏状态序列。 2. Attention：每一步解码时，对所有编码器状态算注意力权重，合成上下文向量——和 Ch07 Transformer 的注意力是同一套机制，只是去掉了因果掩码 (因为解码时可以看完整音频)。 3. Speller (解码器)：自回归 LSTM，依赖上下文向量 + 已生成字符，逐个生成字符。

    例子。 解码第 3 个字符时，注意力权重集中在音频的 1.2-1.5 秒处——对应第 3 个音素的声学位置。解码到第 4 个字符时，权重又跳到 1.5-1.7 秒——这种"软对齐"是注意力在 ASR 里的最直观体现。Ch07 §04 Transformer 详细讲过注意力，LAS 几乎可以看成"Transformer 编码器 + RNN 解码器"的混合体。

    反例。 以为 LAS 也能流式——不行。LAS 编码器用双向 LSTM，解码时要看完整编码序列才能算注意力。给 LAS 强做流式 (例如一边录音一边补 LSTM 隐藏状态) 会丢未来上下文，精度断崖下降。LAS 是离线高精度场景的首选，RNN-T 是流式场景的首选，Conformer 编码器常被两者共用。

    一句话总结。 LAS 把 ASR 重新表述为 seq2seq + 注意力，精度强但需完整音频，是离线批处理 ASR 的代表。

    核心概念四 · Conformer：卷积 + 注意力的马卡龙三明治（约 2.5 分钟）¶

    直觉。 LSTM 编码器捕获局部时序模式能力强，但难建模长程依赖。Transformer 自注意力强，但 O(T²) 复杂度让长音频爆显存。Conformer (Gulati et al., 2020) 的洞察是：两者不是竞争关系，是互补关系——卷积擅长捕捉局部 n-gram 模式，自注意力擅长建模全局依赖。

    定义。 一个 Conformer 块是马卡龙式四模块： 1. 前馈模块 (半步)：带残差的前馈网络，残差权重取 1/2。 2. 多头自注意力模块：标准 Transformer 自注意力 + 相对位置编码。 3. 卷积模块：逐点卷积 → GLU 门控 → 1D 深度可分卷积 → BatchNorm → Swish 激活 → 逐点卷积。 4. 前馈模块 (半步)：与模块 1 相同。

    输出：y = LayerNorm(x + 1/2·FFN₁ + MHSA + Conv + 1/2·FFN₂)。前后两个半步 FFN + 中间 Attention + Conv，是经验上试出来的最佳排列。

    例子。 一段 30 秒的音频，Conformer-L 编码器大约 100M 参数。给定一句话的 WER，Conformer 比纯 Transformer 编码器降约 10-15%，比纯 LSTM 编码器降约 15-20%。CTC + Conformer 或 RNN-T + Conformer 已成为 2020 年后所有主流商用 ASR 的默认搭配。

    反例。 以为 Conformer 是"加了卷积的 Transformer"——错。结构上 Conformer 把卷积嵌在自注意力之后、第二个 FFN 之前，且两个 FFN 各只取半步残差。这种沙漏式设计不是为了叠参数，是为了让梯度流更平滑——你可以把它理解成 ResNet 残差思路在 Transformer 上的延伸。NVIDIA NeMo 工具包的 Fast Conformer 进一步把自注意力前的输入做 8 倍下采样，让长音频 (数分钟) 训练成为可能。

    一句话总结。 Conformer = FFN + Attention + Conv + FFN 的四模块三明治，是当前 ASR 编码器的默认骨干。

    核心概念五 · Whisper 与 wav2vec 2.0：规模压倒架构（约 2.5 分钟）¶

    直觉。 当你有了 Conformer 编码器、CTC 或注意力解码器，剩下能榨的精度空间在哪？答案是训练数据规模。Whisper (Radford et al., 2023) 在 680,000 小时弱监督数据上训练；wav2vec 2.0 (Baevski et al., 2020) 用 53,000 小时无标注数据做预训练。这两个量级是 §02 GMM-HMM 时代训练数据量的 100-1000 倍。

    定义。 - Whisper：标准编码器-解码器 Transformer。输入 80 通道对数梅尔频谱 (25 ms 窗、10 ms 步长)，解码器用字节级 BPE 自回归生成 token。多任务：单一模型同时做转写、翻译、语种识别、时间戳预测，用解码器提示里的特殊 token 切换。 - wav2vec 2.0：自监督预训练框架。特征编码器 (多层 1D CNN) 把音频波形压成 20 ms 帧率的潜在向量；量化模块用乘积量化把潜在向量离散化；Transformer 上下文网络在遮盖预测任务上做对比学习 (InfoNCE 损失)：

    \[\mathcal{L} = -\log \frac{\exp(\text{sim}(\mathbf{c}_t, \mathbf{q}_t) / \kappa)}{\sum_{\tilde{\mathbf{q}} \in Q_t} \exp(\text{sim}(\mathbf{c}_t, \tilde{\mathbf{q}}) / \kappa)}\]

    预训练后加 CTC 头，用 10 分钟标注数据微调就能逼近当时最佳水平。

    例子。 Whisper large-v3 在多个英语测试集上 WER 低于 Parakeet 同尺寸模型——但前提是测试集分布接近训练集 (网络视频字幕)。换到医学口述、客服电话、会议录音这种域外数据，Whisper 仍比 Conformer-CTC 基线强约 30-50%，说明规模带来的不是"记忆训练集"，而是泛化能力。

    反例。 以为"模型越大越好"——错。Whisper large 在 CPU 上跑一次实时率 RTF ≈ 0.3 (慢于实时)，无法流式；Moonshine (Useful Sensors, 2024) 模型不到 30M 参数，专门为边缘部署设计，速度 5-10× 于 Whisper 但精度低 2-5%。架构和数据规模不是银弹，部署约束决定选型。

    一句话总结。 Whisper 走"大数据 + 标准 Transformer + 多任务"路线；wav2vec 2.0 走"自监督预训练 + 少量微调"路线——两者殊途同归，把 ASR 精度推上新台阶。

    一个走完全程的例子 · "你好世界"端到端识别（约 2.5 分钟）¶

    场景：一段 1 秒的 16 kHz 音频，内容是普通话"你好世界"。我们追踪这 1 秒音频从一个神经网络里走过的完整路径，最终在屏幕上打出汉字。

    步骤 1：特征提取 (Ch09 §01) - 16 kHz × 1 秒 = 16000 个采样点。 - 25 ms 窗 (400 个采样点)、10 ms 步长 (160 个采样点) 切梅尔帧，得到约 100 帧的 80 通道对数梅尔频谱。 - 形状：(100, 80) 的张量。

    步骤 2：编码 (Conformer-L) - Conformer-L 编码器下采样 4 倍 → 输出 25 个时间步，每步 512 维向量。 - 形状：(25, 512)。 - 这一步把所有"声学细节"压缩成"语义粒度的表示"，相当于 §02 WFST 里声学模型 + 三音素聚类 + senone 评分三个步骤的全部功能。

    步骤 3：CTC 头 + 贪心解码 - 一个线性层把 512 维投影到 (V+1) 维 (V 是汉字词表大小 + 1 个 blank)。 - 每个时刻取概率最大的 token → 一个 (25,) 的整数序列。 - Collapse：合并连续重复 + 删 blank → 4 个汉字。 - 输出："你好世界"。 - 这一步等价于 §02 里 Viterbi 解码 + 词典查找 + 语言模型排序的合并版本。

    步骤 4 (RNN-T 变体)：联合解码 - 如果换成 RNN-T，预测网络从 "你好世界" 已发射部分生成 h_u^pred。 - 联合网络在 (t=25, u=4) 的二维网格上算最终概率。 - 流式版本可以每收到一帧就更新输出。

    对比 §02 经典流水线： - 经典版：MFCC 提取 → GMM-HMM 算 senone 后验 → WFST 图搜索 → 输出。 - 端到端版：梅尔频谱 → Conformer 编码 → CTC/RNN-T/LAS 解码 → 输出。 - 模块数从 5 个降到 2 个，工程维护量减少约 60%，但每个模块的可解释性大幅下降——调试 Conformer 的内部激活比 debug WFST 图难得多。

    Ch05 HMM 前向-后向 → Ch06 DNN-HMM → Ch07 注意力 → Ch09 §03 CTC/RNN-T/LAS 完整链路：从概率图模型的动态规划到深度神经网络，从独立组件到端到端联合训练，每一步都在简化工程复杂度、提升上限精度。

    易错点回头看（约 80 秒）¶

    1. 很多人以为 CTC 输出就是最终转写——其实是塌缩后的结果。CTC 输出的原始序列包含大量重复和 blank，必须做"合并连续重复 + 删 blank"两步处理。例如 -n-n-i-i-h-h-a-a-o-o 才是合法路径，塌缩后才是"nihao"。直接当最终输出会得到一串没意义的字符。

    2. 很多人以为 RNN-T 只是"CTC 加了一个 RNN"——错在没理解条件独立的破除。CTC 的输出条件独立 (Ch05 概率论里我们讲过 i.i.d. 假设)，所以学不到"q 后必跟 u"这种依赖。RNN-T 的预测网络显式建模 token 间依赖，等式右边的 W_pred · h_u^pred 才是精髓。

    3. 很多人以为 Whisper 是架构突破——其实是规模突破。Whisper 用的是标准 Transformer 编码器-解码器，没有架构创新。它强在 680,000 小时弱监督数据 + 多任务训练 + 大 batch 训练稳定性。把同样的架构放到 1000 小时数据上，精度和 Conformer-CTC 基线拉不开差距。

    与下节的钩子（约 30 秒）¶

    本节讲完"端到端 ASR 三大架构 (CTC / RNN-T / LAS) + Conformer 编码器 + Whisper 大数据范式"，但有一个问题没解决：带标注数据从哪来？ 普通话、英语这种高资源语言还好，越南语、藏语、孟加拉语这种低资源语言，标注数据可能不到 100 小时。

    下一节 §04 我们讲自监督预训练怎么破解这个困局：wav2vec 2.0 用 53,000 小时无标注音频做预训练，HuBERT 简化训练流程，Whisper 用网络爬来的弱监督数据，USM 把规模拉到 1200 万小时跨 300+ 种语言。最后我们再回到第 10 章多模态，看看语音和视觉怎么联合训练。
