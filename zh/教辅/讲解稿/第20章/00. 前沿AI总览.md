## 三 · 章节主线 (5 段)

### 第 1 段 · 量子机器学习 (10 分钟)

#### 3.1.1 量子基础

**Qubit**: 0/1 叠加态
$$|\psi\rangle = \alpha|0\rangle + \beta|1\rangle, \quad |\alpha|^2 + |\beta|^2 = 1$$

**测量**: 概率塌缩到 0 或 1, 概率 $|\alpha|^2$ / $|\beta|^2$。

**纠缠**: 多 qubit 关联, 不可分割。

#### 3.1.2 量子门

- Hadamard (H): 创建叠加
- CNOT: 纠缠
- Pauli (X/Y/Z): 单 qubit 操作

#### 3.1.3 VQE (变分量子特征求解器)

```python
from qiskit import QuantumCircuit
from qiskit.algorithms import VQE

# 参数化电路
qc = QuantumCircuit(2)
qc.ry(theta[0], 0)
qc.ry(theta[1], 1)
qc.cx(0, 1)

# 经典优化 theta
vqe = VQE(ansatz=qc, optimizer=...)
result = vqe.compute_minimum_eigenvalue(hamiltonian)
```

适用: 小分子基态, 量子化学。

#### 3.1.4 QAOA (量子近似优化)

解决组合优化 (MaxCut, TSP), 量子-经典混合。

#### 3.1.5 硬件现状 (2024)

| 平台 | Qubit | 状态 |
|------|-------|------|
| IBM Condor | 1121 | 2023 |
| Google Willow | 105 | 2024 (纠错) |
| Quantinuum H2 | 56 | 高保真 |
| IonQ | 32 | 离子阱 |

量子优越性: 仍争议, 实际应用受限。

### 第 2 段 · 神经形态计算 (10 分钟)

#### 3.2.1 核心思想

模拟大脑神经元脉冲 (spike), 事件驱动, 低功耗。

#### 3.2.2 SNN vs ANN

| 维度 | ANN | SNN |
|------|-----|-----|
| 激活 | 连续 (ReLU) | 脉冲 (spike) |
| 时间 | 同步 | 异步 |
| 功耗 | 高 (300W GPU) | 极低 (mW) |
| 硬件 | GPU/TPU | 神经形态芯片 |

#### 3.2.3 主要硬件

- **SpiNNaker** (曼彻斯特大学): 百万核
- **Intel Loihi 2**: 100 万 neuron / 芯片
- **IBM TrueNorth**: 54 亿晶体管
- **清华天机芯**: 异构融合

#### 3.2.4 SNN 工具栈

- Nengo (高层)
- Norse (PyTorch)
- snnTorch (PyTorch)

```python
import snntorch as snn
lif = snn.Leaky(beta=0.95)
# spike forward
spk, mem = lif(cur, mem)
```

#### 3.2.5 应用

- 边缘 AI (低功耗)
- 时序信号 (语音, EEG)
- 机器人感知

未来: SNN LLM 推理, 节能 100×。

### 第 3 段 · 太空数据中心 (8 分钟)

#### 3.3.1 三优势

| 优势 | 说明 |
|------|------|
| **24h 太阳能** | ~1361 W/m² (AM0) |
| **真空散热** | 无对流, 但辐射强 |
| **低重力** | 对流弱, 但减轻结构 |

#### 3.3.2 挑战

- **辐射**: 宇宙线, 需加固
- **发射**: ~$3000/kg (SpaceX Falcon)
- **维护**: 远程, 不可达
- **通信**: LEO 延迟 4-10 ms

#### 3.3.3 代表项目

- **Google Project Suncatcher** (2027): 卫星太阳能 AI
- **Starcloud**: 2025 发射 H100
- **Axiom Space**: 商业空间站
- **Lumen Orbit**: 月球轨道

#### 3.3.4 商业化路径

- 2024-2027: 原型
- 2027-2030: 商业化
- 2030+: 大规模太空算力

#### 3.4.5 应用

### 第 5 段 · 脑机接口 (10 分钟)

#### 3.5.1 BCI 三种采集

| 方式 | 侵入度 | 信噪比 | 应用 |
|------|--------|--------|------|
| **侵入** | 电极植入 | 高 | 瘫痪, Neuralink |
| **半侵入 (ECoG)** | 颅内表面 | 中 | 医疗, 癫痫 |
| **非侵入 (EEG)** | 头皮 | 低 | 消费, 游戏 |

#### 3.5.2 Neuralink

- 2024 临床, 瘫痪患者
- 高通道 (1024 电极)
- 双向 (读 + 写)
- 风险: 手术, 感染

#### 3.5.3 Synchron

- 血管电极, 不开颅
- 已临床, 安全
- 低通道

#### 3.5.4 Meta BCI

非侵入 EEG, 实时解码文本, 2024 论文。

#### 3.5.5 解码算法

- CNN: EEG 视觉化
- RNN/LSTM: 时序
- Transformer: 多模态

```python
# 简化 EEG → 文本
eeg = ... # (B, C, T)
embed = CNN(eeg)
intent = Transformer(embed)
text = LLM.generate(intent)
```

#### 3.5.6 应用

- 医疗: 瘫痪患者交流
- 增强: 健康人增强认知
- 科研: 大脑机制
