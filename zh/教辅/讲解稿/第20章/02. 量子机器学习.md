## 二 · 量子计算基础

### 2.1 Qubit

**经典比特**: 0 或 1
**量子比特** |ψ⟩ = α|0⟩ + β|1⟩, |α|² + |β|² = 1

### 2.2 三大特性

- **叠加 (Superposition)**: 同时是 0 和 1
- **纠缠 (Entanglement)**: 多 qubit 相关
- **测量**: 概率塌缩 (只能用一次)

### 2.3 常用门

| 门 | 作用 | 类似 |
|----|------|------|
| **X (NOT)** | |0⟩↔|1⟩ | 经典 NOT |
| **H (Hadamard)** | 创建叠加 | — |
| **CNOT** | 受控翻转 | — |
| **T / S / R** | 相位旋转 | — |

## 三 · 主流量子算法

### 3.1 Shor (1994)

**整数分解**: 指数级加速
- 经典: O(exp(n^(1/3)))
- Shor: O(n³)

**应用**: 破解 RSA / Diffie-Hellman

### 3.2 Grover (1996)

**无序搜索**: √N 加速
- 经典: O(N)
- Grover: O(√N)

**应用**: NP 问题的暴力搜索加速

### 3.3 HHL (2009)

**线性方程组 Ax=b**:
- 条件数 κ 适当时指数级加速
- 应用: 主成分分析 / 推荐系统

### 3.4 VQE (2014)

**变分量子特征求解器**:
- 找分子基态
- 量子-经典混合
- 化学 / 材料发现

### 3.5 QAOA (2014)

**量子近似优化**:
- 组合优化 (MaxCut / TSP)
- 多项式加速

## 四 · 量子 ML

### 4.1 QSVM (量子 SVM)

- 用量子核函数
- 量子态空间 → 经典分类
- 实验性, 规模受限

### 4.2 QNN (量子神经网络)

- 参数化量子电路 (PQC)
- 训练用经典优化器
- 可类比经典 NN

### 4.3 QGAN (量子 GAN)

- 生成 + 判别都用量子电路
- 小规模实验

### 4.4 量子嵌入

- 经典数据 → 量子态
- **振幅编码 / 角度编码 / 基础编码**

## 六 · 何时实用?

### 6.1 时间表

```
2024-2030 (NISQ):
  - 100-1000 qubits
  - 演示性优势
  - 适合: 化学模拟 / 组合优化
  - 应用: 演示 / 培训

2030-2040 (Early FTQC):
  - 1万-100万物理 qubits
  - 容错早期
  - 适合: Shor 准备 (破解 RSA 倒计时)

2040+ (FTQC):
  - 百万 qubits
  - 真正量子加速
  - 应用: 密码学 / AI / 模拟
```

### 6.2 后量子密码学 (PQC)

**担心**: 量子破解现有加密
**应对**: NIST 已标准化 PQC 算法
- **ML-KEM (Kyber)**: 密钥交换
- **ML-DSA (Dilithium)**: 数字签名
- **SLH-DSA (SPHINCS+)**: 哈希签名

## 七 · 工具

### 7.1 Qiskit (IBM)

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(2, 2)
qc.h(0)        # H 门
qc.cx(0, 1)    # CNOT
qc.measure([0, 1], [0, 1])

# 在 IBM Quantum 真实硬件跑
from qiskit_ibm_runtime import QiskitRuntimeService
service = QiskitRuntimeService()
backend = service.least_busy(operational=True, simulator=False)
job = backend.run(qc)
result = job.result()
```
