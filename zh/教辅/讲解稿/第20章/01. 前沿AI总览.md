## 三 · 章节主线 (5 段)

### 第 1 段 · 量子机器学习 (10 分钟)

#### 3.1.1 量子计算基础

**Qubit** = 量子比特, 状态: |ψ⟩ = α|0⟩ + β|1⟩, |α|² + |β|² = 1

**关键概念**:
- **叠加 (Superposition)**: 同时处于 |0⟩ 和 |1⟩
- **纠缠 (Entanglement)**: 多 qubit 相关
- **测量**: 概率塌缩到经典态

#### 3.1.2 量子算法

| 算法 | 加速 | 适用 |
|------|------|------|
| **Shor** | 指数 | 大数分解 (破解 RSA) |
| **Grover** | √N | 搜索 |
| **HHL** | 指数 (条件) | 线性方程组 |
| **VQE** | 多项式 | 分子基态 |
| **QAOA** | 多项式 | 组合优化 |

#### 3.1.3 量子 ML

**核心思想**: 用量子电路做 ML
- **QSVM**: 量子核 SVM
- **QNN**: 量子神经网络
- **QGAN**: 量子 GAN

**挑战**:
- **NISQ 时代**: 噪声 + 几十 qubit
- **退相干**: 100 μs - 1 ms
- **错误率**: 1% / gate (容错需要 1e-10)

#### 3.1.4 当前生态

- **IBM**: 1121 qubit Condor (2023)
- **Google**: 70 qubit Bristlecone / Sycamore
- **IonQ / Rigetti / PsiQuantum**: 商用

### 第 2 段 · 神经形态计算 (10 分钟)

#### 3.2.1 什么是神经形态

**类比**: 用**模拟生物神经元**的硬件跑 AI
- 传统: 数字 + 冯诺依曼 (CPU/GPU)
- 神经形态: 模拟 + 事件驱动 (SpiNNaker / Loihi)

#### 3.2.2 脉冲神经网络 (SNN)

**核心**: 第三代神经网络, 用**脉冲 (spike)** 传递信息
- 时序编码
- 事件驱动 (省电)
- 生物可信

**代表模型**: 
- **LIF (Leaky Integrate-and-Fire)**
- **STDP (Spike-Timing-Dependent Plasticity)**

#### 3.2.3 主要芯片

| 芯片 | 出品 | 神经元数 |
|------|------|----------|
| **SpiNNaker** | Manchester | 1M cores |
| **Loihi** | Intel | 128K / chip |
| **TrueNorth** | IBM | 1M neurons / chip |
| **Akida** | BrainChip | 1.2M neurons |

#### 3.2.4 应用

- **边缘 AI** (低功耗 1W)
- **时序信号** (音频 / EEG)
- **机器人感知**

### 第 3 段 · 太空数据中心 (10 分钟)

#### 3.3.1 动机

**地面数据中心问题**:
- **能耗**: 占全球 1-2%, 持续增长
- **散热**: 冷却耗能 ~40%
- **土地**: 紧缺 + 远离用户

**太空优势**:
- **太阳能**: 24/7 无限
- **真空散热**: -270°C 天然冷源
- **阳光遮挡**: 轨道间隔离

#### 3.3.2 现状 (2024-2026)

- **Starcloud-1** (2025): 首颗 GPU 卫星
- **Axiom Space**: 商业空间站 + GPU
- **Google / Microsoft / Amazon**: 探索轨道 DC

#### 3.3.3 挑战

- **发射成本**: $1k-10k / kg (SpaceX 降 10×)
- **辐射**: GPU 单粒子翻转
- **维护**: 不可上门
- **通信**: 地面-卫星延迟 4-40 ms

#### 3.3.4 商业化时间表

```
2025-2027: PoC (1-10 颗, 验证)
2028-2030: 集群 (100+, 商用)
2030+: 大规模 (1000+, 主流)
```

### 第 4 段 · 去中心化 AI (10 分钟)

#### 3.4.1 动机

**集中化问题**:
- 数据在 Big Tech, 隐私风险
- 训练成本高, 小公司无法参与
- 模型被 3-4 家垄断

**去中心化方案**:
- **数据**: 用户私有 (联邦学习)
- **算力**: 闲置 GPU (io.net / Render)
- **模型**: 分布式推理 (Bittensor / Akash)

#### 3.4.2 联邦学习

**FedAvg (Google 2017)**:
```
Server: 发全局模型
Clients: 本地训练 → 上传模型
Server: 加权平均 → 更新全局模型
```

**挑战**:
- **通信**: 大模型传输贵
- **异构**: 设备能力不同
- **隐私**: 梯度泄露信息 (差分隐私)

#### 3.4.3 去中心化训练

- **BitTorrent 风格**: P2P 分片
- **Hivemind (Petals)**: 协作推理
- **Prime Intellect**: 去中心化训练

#### 3.4.4 模型市场

- **HuggingFace Hub**: 开源模型
- **Replicate / Modal**: API 市场
- **Bittensor**: 区块链激励

### 第 5 段 · 脑机接口 (10 分钟)

#### 3.5.1 三大流派

| 流派 | 方法 | 代表 |
|------|------|------|
| **侵入式** | 电极插入 | Neuralink / BrainGate |
| **半侵入** | 颅骨表面 | Synchron / Paradromics |
| **非侵入** | 头皮 EEG | OpenBCI / Kernel |

#### 3.5.2 Neuralink (2016-2026)

**核心**: 1024 通道电极, 机器人手术植入
**进展**:
- 2024: 首例人体植入 (Noland Arbaugh)
- 2025: 多例患者, 鼠标控制 + 文字输入

**应用**:
- 瘫痪患者恢复运动
- ALS 患者交流
- (未来) 健康人增强

#### 3.5.3 BCI 技术栈

```
电极 (sensor) → 信号处理 (DSP) → 特征提取 (ML) → 解码 (DL) → 控制 (机器人/文字)
```

**核心难题**:
- **信号噪声**: SNR 低
- **个体差异**: 每人不同
- **电极衰减**: 几年后失效
- **带宽**: 当前 < 100 bps

#### 3.5.4 伦理与监管

- **思维隐私**: 脑数据最私密
- **身份认同**: 增强 vs 改变自我
- **公平性**: 谁先用上?
- **军事化**: 武器化风险
