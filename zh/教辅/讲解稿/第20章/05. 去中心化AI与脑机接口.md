## 第一部分 · 去中心化 AI

### 一 · 一句话总览

> **去中心化 AI = 数据 + 算力 + 模型 全部去中心**。**联邦学习 + 区块链 + P2P** 三件套, 让 AI 不被 Big Tech 垄断。

---

### 二 · 集中化 AI 问题

- **数据**: Big Tech 垄断 (Google / Meta)
- **算力**: NVIDIA 主导 GPU
- **模型**: 3-4 家闭源 (GPT / Claude / Gemini)
- **小公司 / 个人**: 难以参与

### 三 · 三大去中心化方向

#### 3.1 数据去中心化 (联邦学习)

**FedAvg (Google 2017)**:
```
Server 发全局模型
       ↓
Clients 本地训练 (数据不出)
       ↓
Clients 上传模型 (非数据)
       ↓
Server 加权平均
```

**挑战**:
- **通信**: 大模型频繁同步贵
- **异构**: 设备能力差异
- **隐私**: 梯度仍可能泄露 (差分隐私)

**代表**:
- **Flower** (Linux Foundation)
- **PySyft** (OpenMined)
- **FATE** (微众银行)

#### 3.2 算力去中心化

**闲置 GPU 聚合**:
- **io.net**: 100K+ GPU 网络
- **Render**: 3D 渲染网络
- **Akash**: 通用算力市场

**关键问题**:
- **验证**: 工作是否真做了? (Proof of Work / TEE)
- **带宽**: 大模型传输
- **延迟**: 跨洲调度

#### 3.3 模型去中心化

**模型市场**:
- **HuggingFace Hub**: 开源模型 (主流)
- **Replicate / Modal**: API 市场
- **Bittensor**: 区块链 + 模型质量激励

**P2P 推理**:
- **Petals (BigScience)**: 协作推理
- **Prime Intellect**: 去中心化训练
- **Nous Research**: Hermes 模型

---

### 四 · 代表项目

| 项目 | 特色 |
|------|------|
| **Bittensor** | 区块链 + 模型激励 |
| **io.net** | 100K GPU 网络 |
| **Render Network** | 渲染 + AI |
| **Akash** | 通用算力市场 |
| **Gensyn** | ML 训练去中心化 |
| **Prime Intellect** | 去中心化训练 |
| **HuggingFace** | 开源模型市场 |

---

### 五 · 挑战

- **质量**: 节点性能不一
- **信任**: 算力结果是否可信
- **监管**: KYC / 合规
- **经济**: 代币激励长期可持续

## 第二部分 · 脑机接口 (BCI)

### 六 · 一句话总览

> **BCI = 大脑 ↔ 机器直连**。**Neuralink / Synchron / Kernel** 三大流派,**2024-2026 进入人体临床**。**短期医疗, 长期增强**。

---

### 七 · 三大流派

| 流派 | 方法 | 信号质量 | 创伤 |
|------|------|----------|------|
| **侵入式** | 电极插入皮层 | 高 | 大 |
| **半侵入** | 颅骨表面 (ECoG) | 中 | 中 |
| **非侵入** | 头皮 (EEG) | 低 | 无 |

### 八 · Neuralink (2016-2026)

**进展时间线**:
- 2016: 公司成立
- 2020: 猪 demo
- 2021: 猴玩 Pong
- 2024-01: 首例人体植入 (Noland Arbaugh)
- 2024-2025: 多患者 + 文字输入

**技术**:
- 1024 通道柔性电极
- R1 手术机器人
- N1 芯片

**能力**:
- 鼠标控制
- 文字输入 (> 30 wpm)
- 视频 / 照片浏览

### 九 · Synchron (Stentrode)

**特点**:
- 血管植入 (无需开颅)
- 已多国临床
- FDA Breakthrough Device

### 十 · 其他玩家

- **BrainGate** (Brown Univ): 老牌, 学术
- **Precision Neuroscience**: Layer 7 薄电极
- **Blackrock Neurotech**: Utah Array
- **Kernel**: 非侵入 fNIRS
- **OpenBCI**: 开源 EEG
- **Paradromics**: 高通道

### 十一 · BCI 5 大应用

| 应用 | 现状 |
|------|------|
| **瘫痪患者运动** | ✅ 已实现 (Neuralink) |
| **ALS 交流** | ✅ 已实现 |
| **视觉假体** | ⚠️ 实验 (Second Sight 已退) |
| **听觉增强** | ⚠️ 实验 |
| **健康人增强** | ❌ 10-20 年 |

### 十二 · 关键技术

#### 12.1 电极

- **Utah Array**: 100 通道硬电极
- **Michigan Probe**: 线性
- **Neuralink 柔性电极**: 1024 通道
- **ECoG**: 皮层表面

#### 12.2 信号处理

```
原始信号 (kHz) → 滤波 → 特征提取 → 解码 (DL) → 控制指令
```

#### 12.3 解码算法

- **线性回归**: 简单, 但有限
- **LSTM**: 时序
- **Transformer**: 多通道
- **LFADS** / **Cebra**: 神经表征学习

### 十三 · 伦理与监管

#### 13.1 5 大伦理

- **思维隐私**: 脑数据最私密
- **身份认同**: 增强 vs 改变自我
- **公平**: 谁先用上 (富人?)
- **军事化**: DARPA 主导担忧
- **撤销权**: 能否"卸载"?

#### 13.2 监管

- **FDA**: 美国医疗器械
- **NMPA**: 中国药监
- **CE**: 欧盟
- **伦理委员会**: 临床试验必须

### 十四 · 时间表

```
2024-2025: 瘫痪患者首批商用 (Neuralink / Synchron)
2026-2028: 多患者 + 多应用
2028-2030: 视觉假体 / 听觉增强
2030+: 健康人增强 (伦理辩论)
2040+: 通用 AI 接口? (科幻但可想象)
```
