## 三 · 脉冲神经网络 (SNN)

### 3.1 第三代神经网络

| 代 | 模型 | 信息载体 |
|----|------|----------|
| 1 | Perceptron | 二进制 |
| 2 | CNN/RNN | 连续值 |
| **3** | **SNN** | **脉冲 (spike)** |

### 3.2 LIF 模型

**Leaky Integrate-and-Fire**:
```
du/dt = -(u - u_rest) / τ + I(t)
当 u > u_threshold → fire spike, u = u_reset
```

```python
import torch
import torch.nn as nn

class LIFNeuron(nn.Module):
    def __init__(self, tau=20.0, v_threshold=1.0):
        super().__init__()
        self.tau = tau
        self.v_threshold = v_threshold
        self.v = None
    
    def forward(self, I):
        if self.v is None:
            self.v = torch.zeros_like(I)
        self.v = self.v + (I - self.v) / self.tau
        spike = (self.v >= self.v_threshold).float()
        self.v = self.v * (1 - spike)
        return spike
```

### 3.3 STDP 学习

**Spike-Timing-Dependent Plasticity**:
- 前突触脉冲**先于**后突触 → 权重增加
- 后突触**先于**前突触 → 权重减少
- **生物可信**

### 3.4 SNN 编码

- **频率编码**: 脉冲数 = 信息
- **时序编码**: 脉冲时间 = 信息
- **群体编码**: 多神经元组合
