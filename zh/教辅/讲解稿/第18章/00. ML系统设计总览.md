### 第 1 段 · 系统设计基础 (10 分钟)

#### 3.1.1 CAP 定理

分布式系统三选二:

| 维度 | 含义 |
|------|------|
| **C**onsistency | 一致性, 所有节点同时看到相同数据 |
| **A**vailability | 可用性, 每个请求都响应 |
| **P**artition tolerance | 分区容忍, 网络分区仍能工作 |

实际 P 必须, 选择 C+A。

**代表**:
- CP: ZooKeeper, HBase, etcd
- AP: Cassandra, DynamoDB, S3

#### 3.1.2 扩展性

- **垂直**: 加 CPU/内存, 单机有限
- **水平**: 加机器, 主流

#### 3.1.3 一致性模型

| 类型 | 含义 | 例子 |
|------|------|------|
| 强一致 | 立即看到写入 | ZooKeeper |
| 最终一致 | 异步传播 | DynamoDB |
| 因果一致 | 因果关系可见 | 部分分布式 DB |

#### 3.1.4 一致性哈希

```python
# 简版
def get_node(key, nodes, ring_size=2**32):
    h = hash(key) % ring_size
    for node in sorted(nodes, key=lambda n: hash(n) % ring_size):
        if hash(node) % ring_size >= h:
            return node
    return nodes[0]
```

增删节点只影响 1/节点数 比例的数据。

### 第 3 段 · 大规模基础设施 (10 分钟)

#### 3.3.1 流处理: Kafka

```
Producer → Kafka Broker (Topic) → Consumer
```

- 高吞吐: ~1M msg/s
- 持久化: 日志存储
- 顺序: 分区内有序

适用: 日志收集, 事件流, 实时计算。

#### 3.3.2 批处理: Spark

```python
df = spark.read.parquet("s3://bucket/data")
result = df.filter(df.age > 18).groupBy("city").count()
```

RDD/Dataset API, 内存计算, 比 MapReduce 快 100×。

#### 3.3.3 数据湖: Iceberg / Delta / Hudi

| 特性 | Iceberg | Delta | Hudi |
|------|---------|-------|------|
| Schema 演进 | ✓ | ✓ | ✓ |
| 时间旅行 | ✓ | ✓ | ✓ |
| 增量 ETL | ✓ | ✓ | ✓ |
| 社区 | Apache | Databricks | Uber |

适用: 海量数据 + ML 训练 + 增量更新。

#### 3.3.4 Lambda vs Kappa

**Lambda**: 批 + 流双链路, 复杂但稳健。
**Kappa**: 纯流, Kafka + Flink, 历史靠重放。

### 第 4 段 · ML 系统设计 (12 分钟)

#### 3.4.1 核心组件

```
Data Lake → Feature Store → Train → Model Registry → Serve
                                    ↓
                                  Monitoring → Drift Detection → Retrain
```

#### 3.4.2 Feature Store

```python
# Feast 风格
features = store.get_online_features(
    features=["user:age", "user:city", "item:category"],
    entity_rows=[{"user_id": 1, "item_id": 100}]
).to_dict()
```

在线 + 离线一致性, 跨团队共享。

代表:
- **Feast**: 开源主流
- **Tecton**: 商业
- **Hopsworks**: 学术

#### 3.4.3 数据漂移

| 类型 | 检测 |
|------|------|
| Covariate shift ($P(X)$) | PSI, KS |
| Prior shift ($P(Y)$) | 类别分布 |
| Concept shift ($P(Y|X)$) | 模型精度 |

PSI 公式:
$$PSI = \sum (P_{\text{new}} - P_{\text{ref}}) \ln \frac{P_{\text{new}}}{P_{\text{ref}}}$$

阈值: < 0.1 轻微, > 0.2 严重。

#### 3.4.4 模型 Registry

```python
import mlflow

mlflow.register_model(
    model_uri="runs:/abc/model",
    name="recommendation_v1"
)
```

工具: MLflow, DVC, W&B。

#### 3.4.5 A/B Test

```python
# 用户分流
user_hash = hash(user_id) % 100
if user_hash < 50:
    return model_v1.predict(x)  # 对照
else:
    return model_v2.predict(x)  # 实验
```

关键: 随机分流, 统计显著性 (p < 0.05), 长期指标。

#### 3.4.6 回流闭环

```
用户行为 → Kafka → 数据湖 → 训练 → 模型更新
```

自动化 retrain 是 ML 平台的核心。

## 四 · 易错点 (5 条)

1. **CAP**: 三选二, P 必须, 实际 C+A。
2. **Feature Store schema**: 必须严格一致。
3. **A/B test**: 流量分流要随机, 样本足够。
4. **数据漂移**: 不止 covariate, 还有 prior / concept。
5. **回流闭环**: 自动化是关键, 不是手动。
