## 一 · 一句话总览

> **并发 vs 并行**: 并发 = 多任务交替 (单核可), 并行 = 同时执行 (需多核)。AI 大模型训练 = GPU 并行 (CUDA SIMT) + 多卡并行 (DDP) + 多机并行 (FSDP/Megatron)。

---

## 二 · 心智模型

- **并发**: 一心多用 (打电话 + 查邮件)
- **并行**: 多双手同时干 (工厂流水线)

AI 训练 = 大规模并行。

## 三 · 章节主线 (5 段)

### 第 1 段 · 同步原语 (8 分钟)

#### 3.1.1 互斥锁 (Mutex)

确保只有一个线程进入临界区。

```python
import threading

lock = threading.Lock()
counter = 0

def increment():
    global counter
    with lock:  # 自动获取/释放
        for _ in range(100000):
            counter += 1

threads = [threading.Thread(target=increment) for _ in range(4)]
for t in threads: t.start()
for t in threads: t.join()
print(counter)  # 应为 400000
```

#### 3.1.2 信号量 (Semaphore)

允许 N 个线程同时进入 (N 元信号量)。

```python
import threading
sem = threading.Semaphore(3)  # 3 个槽

def access(i):
    sem.acquire()
    print(f"Thread {i} accessing")
    sem.release()
```

#### 3.1.3 条件变量

线程等待某条件成立。

```python
cv = threading.Condition()

with cv:
    while not condition:
        cv.wait()
    # 处理
    cv.notify_all()
```

#### 3.1.4 原子操作

硬件级不可中断。Python `queue.Queue` 内部用原子 + 锁。

#### 3.1.5 常见并发问题

| 问题 | 现象 | 解 |
|------|------|-----|
| **竞态** | 数据不一致 | 锁 |
| **死锁** | 互相等待 | 排序 / 超时 |
| **活锁** | 不断让步 | 随机退避 |
| **饥饿** | 长期得不到 | 公平调度 |
| **优先级反转** | 高优先级等低优先级 | 优先级继承 |

### 第 2 段 · GPU 与 CUDA (10 分钟)

#### 3.2.1 CUDA 编程模型

```
Host (CPU)            Device (GPU)
┌────────┐            ┌────────────┐
│ Serial │            │ Parallel   │
│  Code  │  ────→     │  Kernels   │
└────────┘            └────────────┘
```

#### 3.2.2 Thread 层次

| 层级 | 大小 | 说明 |
|------|------|------|
| **Thread** | 1 | 单线程 |
| **Warp** | 32 | 调度单位 |
| **Block** | 32-1024 | 含多 warp |
| **Grid** | 多 block | 整个 kernel 启动 |

索引:
```cuda
int idx = blockIdx.x * blockDim.x + threadIdx.x;
```

#### 3.2.3 向量加法 kernel

```cuda
__global__ void vecAdd(float* a, float* b, float* c, int n) {
    int idx = blockIdx.x * blockDim.x + threadIdx.x;
    if (idx < n) c[idx] = a[idx] + b[idx];
}

// Host 启动
int n = 1000000;
int threads = 256;
int blocks = (n + threads - 1) / threads;
vecAdd<<<blocks, threads>>>(a, b, c, n);
```

#### 3.2.4 内存层级

| 类型 | 作用域 | 速度 |
|------|--------|------|
| **Register** | Thread | 极快 |
| **Shared** | Block | 快 (~100× global) |
| **Local** | Thread | 慢 (实际在 global) |
| **Global** | 全 Grid | 慢 (但大) |
| **Constant** | 全 Grid | 缓存读 |

```cuda
__global__ void matmul(float* a, float* b, float* c, int n) {
    __shared__ float tile[16][16];  // 共享内存
    int bx = blockIdx.x, by = blockIdx.y;
    int tx = threadIdx.x, ty = threadIdx.y;

    // 加载 tile 到共享内存
    tile[ty][tx] = a[(by * 16 + ty) * n + bx * 16 + tx];
    __syncthreads();

    // 计算
    float sum = 0;
    for (int k = 0; k < n; k++) {
        sum += tile[ty][k] * tile[k][tx];
    }
    c[(by * 16 + ty) * n + bx * 16 + tx] = sum;
}
```

### 第 3 段 · 分布式并行 (10 分钟)

#### 3.3.1 Amdahl 定律

$$S(n) = \frac{1}{(1-p) + p/n}$$

$p$ = 可并行比例。即使 $p = 0.95$, 100 核加速 ≤ 16×。

#### 3.3.2 并行策略

| 策略 | 切什么 | 适用 |
|------|--------|------|
| **数据并行 (DP)** | 切 batch | 模型小, 数据多 |
| **模型并行 (MP)** | 切模型 | 模型大, 单卡装不下 |
| **流水线 (PP)** | 切深度 | 深层网络 |
| **张量并行 (TP)** | 切单层 | 大 hidden |

#### 3.3.3 集合通信

| 操作 | 含义 |
|------|------|
| **AllReduce** | 同步到所有 (梯度) |
| **Reduce** | 同步到主节点 |
| **Broadcast** | 主→从 |
| **AllGather** | 每节点拿全量 |
| **Reduce-Scatter** | 每节点拿分片 |

#### 3.3.4 NCCL

NVIDIA Collective Communications Library, GPU 优化的集合通信。

```python
import torch.distributed as dist

# 初始化
dist.init_process_group(backend='nccl')

# AllReduce
tensor = torch.randn(1024, device='cuda')
dist.all_reduce(tensor, op=dist.ReduceOp.SUM)
```

#### 3.3.5 PyTorch DDP

```python
import torch
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP

# 启动: torchrun --nproc_per_node=4 train.py

dist.init_process_group(backend='nccl')
local_rank = int(os.environ['LOCAL_RANK'])
torch.cuda.set_device(local_rank)

model = Model().to(local_rank)
model = DDP(model, device_ids=[local_rank])

# 训练 loop 同普通
```

#### 3.3.6 FSDP / ZeRO

切模型参数到多卡, 每卡只持有 1/N 参数。

```
ZeRO-1: 优化器状态分片
ZeRO-2: 加梯度分片
ZeRO-3: 加参数分片 (类似 FSDP)
```

70B 模型 ~140 GB (FP16) → 8 卡 ZeRO-3 每卡 ~17 GB。

## 四 · 易错点 (5 条)

1. **Python GIL**: 多线程对 CPU 密集任务无效, 用 `multiprocessing`。
2. **CUDA 同步**: GPU 操作默认异步, 必须 `torch.cuda.synchronize()` 才计时准确。
3. **AllReduce 是同步**: DDP 每次 backward 后等所有节点就绪, 网络慢 = 训练慢。
4. **NCCL 端口冲突**: 多任务同节点需不同 `MASTER_PORT`。
5. **FSDP checkpoint**: 必须用 `state_dict_type`, 直接保存失效。
