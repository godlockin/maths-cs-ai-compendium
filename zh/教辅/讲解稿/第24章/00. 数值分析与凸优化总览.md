## 三 · 关键概念 50+

### 3.1 数值基础
- IEEE 754 (FP32 / FP16 / bfloat16)
- 机器精度 (machine epsilon)
- 浮点误差 (舍入 / 截断)
- 条件数 (Condition Number)
- 数值稳定性
- Kahan 求和 / Compensated Summation
- Softmax Trick (max subtraction)

### 3.2 线性代数
- 矩阵分解 (LU / QR / SVD / Cholesky)
- 特征值 / 特征向量
- 稀疏矩阵 (CSR / COO / ELL)
- Conjugate Gradient (CG)
- GMRES / BiCGSTAB
- 预条件子 (Jacobi / ILU / AMG)

### 3.3 凸优化基础
- 凸集 / 凸函数
- 凸包 / 凸锥
- 强凸 / 平滑
- Lipschitz 常数
- 共轭函数
- Moreau 包络

### 3.4 对偶与 KKT
- Lagrange 乘子
- 对偶问题
- 弱对偶 / 强对偶
- Slater 条件
- KKT 条件
- 互补松弛
- Fenchel-Rockafellar

### 3.5 二阶方法
- Newton 方法
- Quasi-Newton (BFGS / L-BFGS / SR1)
- Trust Region
- Line Search (Armijo / Wolfe)
- 自然梯度 (Natural Gradient)
- Fisher 信息矩阵
- K-FAC / Shampoo
- 信赖域 (Trust Region)

### 3.6 约束优化
- 内点法 (Interior Point)
- 投影梯度 (Projected Gradient)
- Frank-Wolfe 算法
- 序列二次规划 (SQP)

### 3.7 分布式优化

- AllReduce / Parameter Server
- 联邦学习 (FedAvg)
- 弹性平均 (Elastic Averaging)
- 拜占庭鲁棒 (Byzantine-Robust)
