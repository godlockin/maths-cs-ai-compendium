## 三 · 章节主线 (5 段)

### 第 1 段 · C++ 与 ML 框架基础 (10 分钟)

#### 3.1.1 为什么 AI 框架用 C++

Python 慢, 性能关键用 C++/CUDA。PyTorch 栈:

- **Python API**: 用户友好
- **ATen (C++)**: Tensor 操作核心
- **autograd**: 自动微分
- **cuDNN / cuBLAS**: GPU 加速

#### 3.1.2 SIMD 原理

**SIMD = Single Instruction Multiple Data**: 一条指令同时操作多个数据。

e.g., AVX-512 一次算 16 个 FP32, 理论 16× 加速 (实际受内存限制)。

#### 3.1.3 SIMT 原理

**SIMT = Single Instruction Multiple Threads**: GPU 上 32 个 thread (warp) 同指令, 但每 thread 有独立数据。

类比: SIMD 像 16 个工人做同一动作; SIMT 像 32 个学生做同一作业。

### 第 2 段 · 硬件基础与 Roofline (10 分钟)

#### 3.2.1 内存层级

| 层级 | 延迟 | 带宽 |
|------|------|------|
| 寄存器 | < 1 ns | TB/s |
| L1/L2 | ~1-30 ns | TB/s |
| DRAM | ~100 ns | 50 GB/s |
| HBM (GPU) | ~400 ns | 3 TB/s |

#### 3.2.2 Roofline 模型

$$P = \min(\pi_{\text{peak}}, I \times B_{\text{mem}})$$

| $I$ | 含义 |
|-----|------|
| 计算强度 (ops / byte) | 算法特性 |

两类 kernel:
- **计算受限** (compute-bound): $I$ 高, matmul
- **带宽受限** (memory-bound): $I$ 低, attention, embedding

#### 3.2.3 内存墙

CPU / GPU 算力增长 > 内存带宽增长。

LLM 推理就是 memory-bound — 加载 70 GB 权重, GPU 带宽 3 TB/s → 至少 23 ms。

#### 3.2.4 Flash Attention 思路

不存中间 $O(n^2)$ attention matrix, 分块计算 → 减少 IO。

### 第 3 段 · CPU SIMD: AVX 与 NEON (10 分钟)

#### 3.3.1 x86 AVX

| 指令集 | 宽度 | 寄存器 |
|--------|------|--------|
| SSE | 128 | XMM |
| AVX | 256 | YMM |
| AVX-512 | 512 | ZMM (32 个) |

```cpp
#include <immintrin.h>

void vec_add(float* a, float* b, float* c, int n) {
    for (int i = 0; i < n; i += 8) {
        __m256 va = _mm256_load_ps(a + i);
        __m256 vb = _mm256_load_ps(b + i);
        __m256 vc = _mm256_add_ps(va, vb);
        _mm256_store_ps(c + i, vc);
    }
}
```

`gcc -mavx2 -O3` 启用 AVX2。

#### 3.3.2 ARM NEON

128 bit, 16 个 Q 寄存器。

```cpp
#include <arm_neon.h>

void vec_add(float* a, float* b, float* c, int n) {
    for (int i = 0; i < n; i += 4) {
        float32x4_t va = vld1q_f32(a + i);
        float32x4_t vb = vld1q_f32(b + i);
        float32x4_t vc = vaddq_f32(va, vb);
        vst1q_f32(c + i, vc);
    }
}
```

Apple Silicon + 手机普遍用。

#### 3.3.3 FMA

Fused Multiply-Add: `a*b+c` 一条指令, 提升精度 + 性能。

### 第 4 段 · GPU CUDA 编程 (12 分钟)

#### 3.4.1 编程模型

```
Host (CPU) → launch kernel<<<grid, block>>>(...) → Device (GPU)
```

```cuda
__global__ void matmul(float* A, float* B, float* C, int M, int N, int K) {
    int row = blockIdx.y * blockDim.y + threadIdx.y;
    int col = blockIdx.x * blockDim.x + threadIdx.x;
    if (row < M && col < N) {
        float sum = 0;
        for (int k = 0; k < K; k++) {
            sum += A[row * K + k] * B[k * N + col];
        }
        C[row * N + col] = sum;
    }
}

// Host
dim3 block(16, 16);
dim3 grid((N + 15) / 16, (M + 15) / 16);
matmul<<<grid, block>>>(A, B, C, M, N, K);
```

#### 3.4.2 内存层级

| 类型 | 速度 | 用途 |
|------|------|------|
| Register | 极快 | 局部变量 |
| Shared | 快 (~100ns) | block 内通信 |
| L1/L2 | 中 | cache |
| Global (HBM) | 慢 | 主存 |

```cuda
__shared__ float tile[16][16];
// 加载
tile[ty][tx] = A[row * K + k * 16 + tx];
__syncthreads();
// 通信
sum += tile[ty][k] * tile[k][tx];
```

#### 3.4.3 优化技巧

| 优化 | 做法 |
|------|------|
| **coalesced** | 32 thread 访问连续 128 字节 |
| **bank conflict** | shared mem 分 32 bank |
| **occupancy** | 调整 block 大小 |
| **tensor core** | 用 mma 指令 |

### 第 5 段 · Triton / TPU / RISC-V / Vulkan (8 分钟)

#### 3.5.1 Triton

OpenAI 推出的 Python-like DSL:

```python
import triton
import triton.language as tl

@triton.jit
def vec_add(A, B, C, N, BLOCK: tl.constexpr):
    pid = tl.program_id(0)
    offsets = pid * BLOCK + tl.arange(0, BLOCK)
    a = tl.load(A + offsets, mask=offsets < N)
    b = tl.load(B + offsets, mask=offsets < N)
    tl.store(C + offsets, a + b, mask=offsets < N)
```

优势: Python 简洁 + 自动优化 + 性能接近 CUDA。

#### 3.5.2 TPU

Google 自研, 脉动阵列 (systolic):

```
数据从左流入, 从上流入, 一周期算 128×128 矩阵乘
```

| 代 | FLOPS | 内存 |
|----|-------|------|
| v3 | 123 TFLOPS | 32 GB HBM |
| v4 | 275 TFLOPS | 32 GB |
| v5e | 197 TFLOPS | 16 GB |

适用: 大模型训练 (Gemini, PaLM)。

#### 3.5.3 RISC-V

开放 ISA, 中国 + 美国生态。

- V 扩展: 128-2048 bit 向量
- 厂商: SiFive, 平头哥玄铁
- AI 应用: 边缘部署 (Llama.cpp 量化)

#### 3.5.4 Vulkan Compute

跨平台 GPU API:

```glsl
#version 450
layout(local_size_x = 64) in;
layout(set = 0, binding = 0) buffer A { float data[]; };

void main() {
    uint idx = gl_GlobalInvocationID.x;
    data[idx] *= 2.0;
}
```

优势: Windows / Linux / Android / macOS (via MoltenVK) 统一。

## 四 · 易错点 (5 条)

1. **AVX 宽度**: AVX-2 是 256, AVX-512 是 512, 别混。
2. **CUDA warp**: 32 thread 固定, block 32-1024。
3. **shared memory bank**: 32 bank, 同 bank 冲突。
4. **Triton 不万能**: 极端优化仍需 CUDA。
5. **量化精度**: INT4 节省内存但损失精度。
