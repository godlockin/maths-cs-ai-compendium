## 导语 (约 90 秒)

先讲一个 2026 年最反直觉的行业新闻。

2025 年 9 月, OpenAI 发布 Sora 2, 分辨率、时长、物理合理性全面跃升, 还配了一个信息流形态的 Sora app, 生成视频第一次有了消费级社交产品。结果不到一年, **2026-04-26 产品下线, 2026-09-24 API 关闭**。媒体披露的原因包括日均约 100 万美元的亏损、下载下滑, 以及和 Disney 谈好的 200 多个角色授权、10 亿美元投资意向告吹。

这是本节最重要的一课: **生成媒介的产品成败, 不只取决于模型质量**。算力成本、版权治理、商业模式, 任何一项都能致命。也正因为如此, 本节出现的所有"第一梯队"名单, 都是按月过期的快照——听这一节, 请把注意力放在方法和趋势上, 把型号当作锚点而不是知识本体。

这一节讲 5 件事: ① 图像生成的三代同堂; ② 2026-11 最新增补; ③ 视频生成从"能动"到"可控可拍"; ④ Sora 落幕的教材级教训; ⑤ 五大技术趋势与选型口诀。

## 一 · 图像生成: 三代同堂的 2026 (约 3.5 分钟)

### 1.1 第一代: 扩散 UX 时代 (2022-2023)

Stable Diffusion XL、DALL·E 3、Midjourney v5-v6。交互形态是"写咒语 → 抽卡": 写一段提示词, 抽几十张挑一张。它仍是教科书范式, §04 讲的潜空间扩散就是这一代的底座, 但已经不是体验前沿。

### 1.2 第二代: 指令编辑时代 (2024-2025)

三个标志性事件。

**GPT-4o 原生图像生成 (2025-03)**: 图像生成第一次被放进自回归多模态 LLM——不是外挂一个扩散模型, 而是 LLM 直接"画", 自回归加扩散解码器混合。核心突破是**指令式编辑**和**文字渲染**: "把这张图的猫换成狗, 其余别动"第一次变得可靠。

**FLUX 系 (Black Forest Labs)**: 流匹配工业化的样板。FLUX.1 Kontext (2025-05) 把上下文编辑做成模型能力; FLUX.2 (2025-11) 统一生成与编辑, 一度是开源阵营的画质天花板。请记住"一度"两个字, 第二节会讲它怎么被自家继任者取代。

**Google Nano Banana / Gemini 原生图像 (2025-08 起)**: 招牌能力是**角色一致性**, 多轮对话里同一个人物不变; 2025-11 的 Nano Banana Pro 把生成拉进 4K 和"图形设计可用"区间。

中国梯队同处第一梯队: 字节 Seedream 4.0 (2025-09) 到 Seedream 5.0 (2026-02), 代际以季度计; 阿里 Qwen-Image (2025-08, 开源) 的中文文字渲染是显著长板。

### 1.3 2026 关键词: 一致性经济

生成单张好看的图已经是 commodity。付费能力集中在三件事: **跨轮一致性** (同一角色/产品/场景反复出现)、**精准排版** (海报级文字)、**编辑可靠性** (改一处不动全局)。这恰好是多模态 LLM 原生生成相对独立扩散工具的结构性优势, 和 §05 的统一架构论互相呼应。

## 三 · 视频生成: 从"能动"到"可控可拍" (约 4 分钟)

### 3.1 Sora 2 的落幕与教材级教训

Sora 2 (2025-09/10 至 2026-04-26) 定义过品类: cameos 功能把真人形象授权给生成场景, 也引发"人格权 vs 生成媒介"的治理讨论——这是第 21 章的议题。OpenAI 2026-03-24 发博客宣布停运, 官方理由是聚焦机器人与生产力。

教材视角拆三层: **算力成本** (第 16/18 章的推理经济学)、**版权治理** (第 21 章)、**商业模式** (订阅收入撑不住日均百万美元亏损)。Sora 退场后, 开源接力反而提速。

### 3.2 Veo 3: 音画一体的里程碑

Google DeepMind 的 Veo 3 (2025-05 起) 首次做到**同步音轨生成**: 对话口型、音效、环境音一起出, 不是画完再配音。"视频 + 声音一体生成"从此成为旗舰标配。Veo 3.1 (2025-10) 补音画同步、Ingredients-to-Video 与 4K。

### 3.3 中国梯队与开源主力

可灵 Kling 是商业化最快的一档, 3.0 在 2026-01 全量、04 月上原生 4K, 注册用户约 6000 万; 海螺 (MiniMax)、Vidu (生数)、通义万相同处第一梯队。开源侧, 阿里 **Wan 2.1/2.2 以 Apache 2.0 开源**, 是开源视频生成主力; Wan 2.5 起转闭源商业 API。

### 3.4 开源接力的两个代表

**MiniMax H3** (2026-07-31 发布、08 月开源权重): Sora 2 停运后"闭源标杆退役、开源接力"的最佳注脚。底座是 33B 稠密单流 Omni Transformer, 文本/图像/视频/音频统一上下文; 视频侧差异化是**原生立体声**, 把 Veo 3 开创的音画一体带进开源阵营。支持 4-15 秒、24fps、默认 768p, 带精确时间戳切点的多镜头叙事。

**LTX-2.5** (Lightricks, 2026): 开源阵营的"效率极", 消费级硬件可跑——官方教程给出 Apple Silicon 留 15GB 空闲内存即可本地运行, 单次前向生成多镜头场景。

## 四 · 五大技术趋势 (约 2.5 分钟)

把产品名剥掉, 剩下的理论骨架全部连着 §04/§05:

1. **DiT + 全量缩放**成为视频底座, 训练算力比同参数 LLM 更烧;
2. **流匹配/整流**逐步替换 DDPM 采样, 少步数 (5-20 步) 成为标配;
3. **自回归 + 扩散混合**: 时间维自回归、空间维扩散, 统一了"长视频"与"高画质"的矛盾;
4. **音视频联合生成**, 本质是联合 token 化 (§03 的延伸);
5. **世界模型接管可控性**: 相机轨迹、物体交互级控制来自第 20 章世界模型的动作条件化——视频生成与世界模型的边界正在变模糊。

## 五 · 选型口诀与定位建议 (约 1.5 分钟)

2026-11 口径的选型口诀:

- 学理论: §04 的扩散/流匹配数学加 §05 的统一架构观, 到 2026 仍是全部产品的骨架, 没有过时;
- 开源可控: FLUX 系 / Wan 系, 全模态音画一体加开源权重选 MiniMax H3, 消费级本地选 LTX-2.5;
- 一致性编辑: Gemini 原生图像 / Nano Banana 2.1;
- 影视管线: Runway Gen-4.5 / Veo 3.1 / Kling 4.0;
- 中文文字渲染: 优先中国梯队;
- **新项目勿选 Sora 系**, 产品与 API 均已关闭。
