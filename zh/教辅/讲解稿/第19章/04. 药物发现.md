## 三 · 分子生成

### 3.1 表示

| 表示 | 例子 | 优点 |
|------|------|------|
| **SMILES** | `CC(=O)Oc1ccccc1C(=O)O` | 紧凑 |
| **分子图** | Graph | 拓扑清楚 |
| **3D 坐标** | xyz | 物理性质 |

### 3.2 生成模型

#### RNN / Transformer
- SMILES 序列生成
- 代表: **MolGPT** / **CHEMBERTa**

#### Graph VAE / GAN
- JT-VAE / MolGAN
- 分子图直接生成

#### Diffusion
- **DiffDock**: 3D 分子对接 (结合 pose 预测)
- **DiffMol**: 3D 分子生成

#### RL
- **REINVENT**: 奖励 = 活性
- **MolDQN**: Deep Q-Network

### 3.3 实战: REINVENT

```python
from reinvent.models import Mol2Mol

agent = Mol2Mol(
    pretrained_model="reinvent.prior",
    scoring_function="qed",  # 药物相似性
    learning_rate=0.0001,
)
new_molecules = agent.run(num_steps=1000)
```

### 4.3 实战

```python
from rdkit import Chem
from chemprop import predict

mol = Chem.MolFromSmiles("CC(=O)Oc1ccccc1C(=O)O")
props = predict(
    model_path="admet_model.pt",
    smiles=[Chem.MolToSmiles(mol)],
)
print(props)  # {'qed': 0.85, 'logP': 1.19, 'hERG': 0.05}
```

## 八 · 实战: 端到端示例

```python
import datamol as dm
from molfeat.trans.fp import FPVecTransformer
from sklearn.ensemble import RandomForestClassifier

# 1. 数据
mols = dm.data.freesolv().sample(1000)
smiles = mols["smiles"].tolist()
labels = (mols["expt"] < -5).astype(int).tolist()  # 溶解度阈值

# 2. 特征 (分子指纹)
fp = FPVecTransformer(kind="ecfp", length=2048)
X = fp(smiles)

# 3. 训练
model = RandomForestClassifier(n_estimators=100).fit(X, labels)

# 4. 生成新分子 (用 GPT-3 化学版)
candidates = ["CCO", "CCN", "CC(=O)O"]  # 简化
X_new = fp(candidates)
predictions = model.predict_proba(X_new)
```
