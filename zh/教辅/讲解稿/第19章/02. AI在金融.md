## 一 · 一句话总览

> **金融 AI = 数据 + 模型 + 合规**。4 大场景: **信用风控 / 量化交易 / 反欺诈 / 智能投顾**, 每个都有专属技术栈和监管要求。

---

## 二 · 信用风控

### 2.1 业务场景

- 个人信贷 (花呗 / 借呗)
- 信用卡审批
- 企业贷款
- 房贷 / 车贷

### 2.2 建模流程

```
申请数据 → 特征工程 (百维) → XGBoost → SHAP 解释 → 决策 (拒 / 通过 / 人工)
```

### 2.3 关键特征

- **基本信息**: 年龄 / 学历 / 收入 / 婚姻
- **信用历史**: 还款记录 / 逾期 / 负债率
- **行为**: APP 登录 / 消费 / 浏览
- **社交**: 通讯录 / 关系图

### 2.4 模型演进

| 年代 | 模型 | 优点 |
|------|------|------|
| 2000s | Logistic 回归 | 解释性好 |
| 2010s | XGBoost / LightGBM | 精度高 |
| 2020s | 深度模型 (DeepFM / DLRM) | 特征交叉自动 |
| 2024+ | LLM 特征 + Graph | 多模态 + 关系 |

### 2.5 评估指标

- **AUC**: 综合排序能力
- **KS**: 坏样本区分度
- **Lift**: Top decile 捕获率
- **PSI**: 特征稳定性

## 三 · 量化交易

### 3.1 策略类型

| 类型 | 持仓 | 模型 |
|------|------|------|
| **高频 (HFT)** | 秒级 | 订单流 + 微结构 |
| **统计套利** | 天级 | 协整 / 配对 |
| **趋势跟踪** | 周级 | 时间序列 |
| **多因子** | 月级 | 因子合成 |

### 3.2 ML 应用

**特征工程**:
- 技术指标 (MA / RSI / MACD)
- 基本面 (PE / PB / ROE)
- 情绪 (新闻 / 研报 / 社交)
- 另类数据 (卫星图像 / 信用卡)

**模型**:
- **XGBoost**: 多因子合成主流
- **LSTM / Transformer**: 时序预测 (Informer / AutoFormer)
- **RL (PPO)**: 组合优化
- **LLM**: 情绪分析 / 研报摘要

### 3.3 关键挑战

- **过拟合**: 大量噪声 + 非平稳
- **回测陷阱**: 前视偏差 / 幸存者偏差
- **延迟**: 微秒级 (FPGA / 专用硬件)
- **合规**: 市场操纵 / 内幕交易

### 3.4 业绩归因

- **IC (Information Coefficient)**: 预测 vs 实际相关系数
- **Sharpe Ratio**: 风险调整收益
- **Max Drawdown**: 最大回撤
- **Capacity**: 策略容量

## 四 · 反欺诈

### 4.1 欺诈类型

- **盗卡**: 偷来的信用卡
- **套现**: 信用卡 → 现金
- **伪卡**: 复制卡片
- **账户接管 (ATO)**: 盗用账号
- **团伙**: 多人串通

### 4.2 GNN 风控

**构图**:
```
用户 - 设备 - IP - 卡号 - 商户
```

**模型**: GAT / GraphSAGE / HAN
- 捕获**团伙欺诈** (多个账户共用设备)
- 邻居节点信息聚合

**优势**:
- 单笔交易看不出, 关联图暴露
- 新欺诈模式自动学习

### 4.3 时序异常

- **LSTM-AE**: 重构误差异常
- **Transformer**: 时序模式
- **Isolation Forest**: 无监督异常

### 4.4 决策系统

```
交易 → 规则引擎 (硬规则) → ML 模型 (概率) → 决策引擎
                                                ├─ 通过
                                                ├─ 拒
                                                └─ 二次验证 (短信/人脸/电话)
```

## 五 · 智能投顾 (Robo-Advisor)

### 5.1 业务

- 用户画像 (风险偏好 / 期限 / 目标)
- 资产配置 (股票 / 债券 / 现金 / 大宗)
- 自动调仓
- 风险监控

### 5.2 关键技术

- **现代投资组合理论 (MPT)**: Markowitz 均值方差
- **Black-Litterman**: 加入主观观点
- **风险平价 (Risk Parity)**: 等风险贡献
- **强化学习**: 动态调仓

### 5.3 LLM 应用

- 财报分析 + 摘要
- 研报问答
- 客户沟通
- 监管报告

## 六 · 大模型在金融

### 6.1 BloombergGPT (2023)

- **专用金融 LLM**, 50B 参数
- 金融任务 SOTA
- Bloomberg 数据训练 (非公开)

### 6.2 FinGPT

- 开源金融 LLM
- LoRA 微调
- 实时数据更新

### 6.3 落地场景

- **研报摘要**: 100 页 PDF → 1 页
- **情感分析**: 新闻 / 公告 → 多空
- **客户客服**: 7×24 自动回复
- **合规审查**: 文档自动检查
- **代码生成**: SQL / Python 报表

## 七 · 监管与合规

### 7.1 主要法规

- **GDPR / 个人信息保护法**
- **巴塞尔协议** (银行资本充足率)
- **MiFID II** (欧盟金融工具市场)
- **反洗钱 (AML) / KYC**

### 7.2 AI 合规要求

- **可解释**: SHAP / LIME (监管要求)
- **公平**: 性别 / 种族无偏 (反歧视)
- **审计**: 决策可追溯
- **稳健**: 抗对抗样本

### 7.3 Model Risk Management (MRM)

- 模型验证 (Validation)
- 模型监控 (Monitoring)
- 模型治理 (Governance)
- **文档**: Model Card / Model Risk Card

---

## 八 · 一句话总结

> **金融 AI = 数据密集 + 模型复杂 + 强监管**。4 大场景各有技术栈: 风控靠 XGBoost + GNN, 量化靠时序 + RL, 反欺诈靠 GNN + 时序, 投顾靠 MPT + LLM。**模型可解释 + 合规审计 + 数据安全 = 金融 AI 三件套**。
