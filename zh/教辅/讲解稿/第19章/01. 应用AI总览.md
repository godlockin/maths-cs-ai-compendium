## 三 · 章节主线 (5 段)

### 第 1 段 · 金融 AI (10 分钟)

#### 3.1.1 金融 AI 4 大场景

| 场景 | 关键模型 | 难点 |
|------|----------|------|
| **信用风控** | XGBoost / LSTM | 不平衡 / 解释 |
| **量化交易** | Transformer / RL | 低延迟 / 过拟合 |
| **反欺诈** | GNN / 图 | 标签稀缺 / 团伙 |
| **智能投顾** | LLM + RAG | 监管 / 合规 |

#### 3.1.2 信用风控建模

**典型 pipeline**:
```
申请数据 → 特征工程 (上百维) → XGBoost → SHAP 解释 → 决策
```

**关键挑战**:
- **数据不平衡** (违约 ~3%): SMOTE / Focal Loss
- **概念漂移**: PSI 监控, 周期性重训
- **解释性**: SHAP / LIME (监管要求)

#### 3.1.3 量化交易

**核心**: 预测短期价格 → 低买高卖
**模型演进**:
- 传统: ARIMA / GARCH
- ML: XGBoost / LightGBM
- DL: LSTM / Transformer (Informer / AutoFormer)
- RL: PPO / DDPG

**关键**: **延迟** (毫秒级) + **回测** (避免过拟合)

#### 3.1.4 反欺诈 GNN

**构图**: 用户 - 设备 - IP - 卡号
**模型**: GAT / GraphSAGE
**优势**: 捕获**团伙欺诈** (多账户共用设备)

### 第 2 段 · 蛋白质 AI (10 分钟)

#### 3.2.1 蛋白质结构预测

**AlphaFold 2 (DeepMind 2020)**:
- 输入: 氨基酸序列
- 输出: 3D 坐标
- CASP14: GDT-TS 92.4 (接近实验精度)

**AlphaFold 3 (2024)**: 蛋白质 + 核酸 + 小分子复合体

#### 3.2.2 蛋白质设计

**RFdiffusion (Baker Lab 2023)**:
- 类别: Diffusion Model
- 输入: 期望性质 (结合位点)
- 输出: 新氨基酸序列

**Chroma (Generate Biomedicines 2023)**:
- 类比: 蛋白质界的 Stable Diffusion

#### 3.2.3 蛋白质语言模型

**ESM-2 / ESMFold (Meta 2022-2023)**:
- 15B 参数 Transformer
- 一次前向完成"序列 → 结构"

### 第 3 段 · 药物发现 (10 分钟)

#### 3.3.1 药物发现 5 大阶段

```
Target (靶点) → Hit (苗头) → Lead (先导) → Optim (优化) → Candidate (候选)
```

#### 3.3.2 分子生成

**主流模型**:
- **RNN / Transformer**: SMILES → 分子
- **Graph VAE**: 分子图生成
- **Diffusion (DiffDock)**: 3D 分子对接
- **RL (REINVENT)**: 奖励 = 活性

#### 3.3.3 ADMET 预测

**ADMET**: 吸收 / 分布 / 代谢 / 排泄 / 毒性
- 传统: 湿实验, 慢 + 贵
- AI: 预测, 快 + 省
- 模型: GraphGym / ChemBERTa

#### 3.3.4 AlphaFold 改变行业

- 缩短靶点发现从 2-5 年 → 几周
- 节省数十亿美元
- Insilico Medicine 已用 AI 找到新靶点 + 候选药

### 第 4 段 · 智能体系统 (10 分钟)

#### 3.4.1 智能体 vs 普通应用

| 维度 | 普通应用 | 智能体 |
|------|----------|--------|
| **决策** | 规则 | LLM |
| **行动** | 固定 | 工具调用 |
| **适应** | 静态 | 学习 |

#### 3.4.2 AutoGPT / BabyAGI (2023)

**架构**: 任务分解 → 工具调用 → 反思 → 循环
**局限**: 容易循环 / token 消耗大

#### 3.4.3 SWE-Agent (Princeton 2024)

**任务**: 修复 GitHub Issue
**架构**: 
- Repo 检索 (ripgrep)
- 代码编辑 (Editor)
- 测试运行 (pytest)
**SWE-Bench**: 解决率 12-20% (SOTA 2024-2025)

#### 3.4.4 Devin (Cognition 2024)

**任务**: 端到端软件开发
**能力**: 规划 + 编码 + 调试 + 部署
**争议**: 演示夸张, 真实能力待评估

### 第 5 段 · 医疗 AI (10 分钟)

#### 3.5.1 医疗 AI 5 大场景

1. **影像诊断**: X 光 / CT / MRI (CNN / ViT)
2. **电子病历 (EHR)**: 时序 + NLP (Med-BERT / Med-PaLM)
3. **药物**: Ch19 §03
4. **手术机器人**: 达芬奇 + 强化学习
5. **健康管理**: 可穿戴 + LLM

#### 3.5.2 Med-PaLM (Google 2023)

**专长**: 医学问答 (USMLE 达 60%+)
**训练**: 医学文献 + 临床案例

#### 3.5.3 医疗 AI 挑战

- **数据隐私** (HIPAA / GDPR)
- **数据不平衡** (罕见病)
- **可解释性** (临床决策必须解释)
- **监管** (FDA / NMPA 审批)
- **责任归属** (误诊谁负责)
