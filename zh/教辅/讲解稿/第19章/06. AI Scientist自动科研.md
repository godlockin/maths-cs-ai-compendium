## 二 · 5 阶段闭环

```
想法 (Idea) → 文献 (Lit) → 实验 (Exp) → 写作 (Write) → 反思 (Reflect)
   ↑                                                          ↓
   └──────────────  下次迭代  ←──────────────────────────────┘
```

### 2.1 阶段 1: 想法生成

- 文献综述找空白
- 跨学科联想
- 生成 10 个候选, 排序选 top-3

### 2.2 阶段 2: 文献调研

- Semantic Scholar / OpenAlex 检索
- LLM 总结
- 提取关键引用

### 2.3 阶段 3: 实验设计 + 执行

- 写代码 + 跑实验
- Jupyter / Docker / Modal
- 收集结果

### 2.4 阶段 4: 论文撰写

- LaTeX + 图表 + 引用
- 标准 NeurIPS / ICML 格式
- 自动生成

### 2.5 阶段 5: 自动反思

- LLM-as-Judge
- 模拟审稿
- 决定下一轮想法

## 六 · 实战案例 (P15 详细代码)

### Sakana AI Scientist v2

```python
from sakana_ai_scientist import AIScientist

scientist = AIScientist(
    idea="On the Robustness of LoRA in Diffusion Models",
    budget=15.0,  # USD
)
paper = scientist.run(stages=["literature", "experiment", "writing", "review"])
```

### Google AI Co-Scientist

```python
from google_ai_co_scientist import CoScientist

co = CoScientist()
hypotheses = co.generate(
    goal="Find new therapeutic targets for cancer",
    num_hypotheses=10,
    debate_rounds=3,
)
```
