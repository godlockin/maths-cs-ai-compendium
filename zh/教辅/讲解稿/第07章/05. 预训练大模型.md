## 核心概念一 · 自回归语言模型 (约 3 分钟)

**直觉。** 你打 "今天天气很", 手机会预测下一个字是 "好"。语言模型 (Language Model) 的核心就是**给定前文, 预测下一个 token**——一句话就是 token 序列的概率 $P(x_1, x_2, \ldots, x_n) = \prod_t P(x_t | x_{<t})$。

**定义。** **自回归 (autoregressive)** 模型:
$$P(x_t | x_{<t}) = \text{softmax}(W_o \cdot h_t), \quad L = -\sum_t \log P(x_t | x_{<t})$$
- $h_t$ 第 $t$ 步隐藏状态 (Transformer 编码前 $t$ 个 token 后的输出)
- $W_o$ 输出投影矩阵, 把隐藏状态映射到词表大小
- $\text{softmax}$ 归一化到概率分布
- $L$ 训练目标: 负对数似然 (NLL) = 交叉熵, 越小越好
- **困惑度 (perplexity)**: $\text{ppl} = \exp(L/n)$ (Ch05 §05 信息论承接), ppl=10 表示模型平均在 10 个候选中选

**例子。** GPT-2 small (124M 参数) 在 WikiText-103 测试集 perplexity = 29.4, GPT-2 large (1.5B) = 17.5——**模型越大, ppl 越低, 越"不困惑"**。这是 Ch05 §05 LLM 评估的数学基础。

**反例。** 把 perplexity 当"模型准确率"——**ppl 是困惑度, 越低越好**; 与准确率 (accuracy) 含义不同, 二者不可换算。

**一句话总结。** 自回归 LM = 给定前文预测下个 token, 训练目标 = 负对数似然, 评估指标 = perplexity = exp(L/n)。

## 核心概念二 · GPT vs BERT vs T5 (约 3.5 分钟)

**直觉。** Transformer 有 3 种用法:
- **Decoder-only** (GPT 系列): 单向 attention, 适合生成
- **Encoder-only** (BERT 系列): 双向 attention, 适合理解
- **Encoder-Decoder** (T5/BART): 编码 + 解码, 适合翻译/摘要

**定义。**
- **GPT (decoder-only)**: 用**因果 mask** (causal mask), 第 $t$ 位置只能看前 $t-1$ 个 token, 不能看未来
  - 注意力矩阵上三角 mask 掉
  - 训练: $L = -\sum_t \log P(x_t | x_{<t})$ (自回归)
  - 应用: 文本生成 (ChatGPT, GPT-4, LLaMA, Qwen)
- **BERT (encoder-only)**: 双向 attention, 第 $t$ 位置能看所有位置
  - 训练: $L = L_{\text{MLM}} + L_{\text{NSP}}$ (掩码语言模型 + 下一句预测)
  - 应用: 文本理解/分类/检索, 不擅长生成
- **T5 (encoder-decoder)**: 编码器双向看, 解码器单向生成
  - 训练: 把所有任务统一成"输入文本 → 输出文本" (翻译/摘要/QA 同一格式)
  - 应用: 翻译/摘要, Google 主力

**例子。** 2024 年 LLM 主流是 GPT/LLaMA/Qwen 等 **decoder-only**:
- **为什么 decoder-only 主导?** 三阶段训练 (Ch06 §05 流水线) 中 RLHF-PPO (Ch06 §05 沉淀) 适合生成任务
- **为什么不用 BERT?** Encoder 双向看全句, 训练时已"偷看未来", 不适合"接龙"生成
- **为什么不用 T5?** 翻译/摘要场景已被 ChatGPT 类通用模型替代

**反例.** 用 BERT 做对话生成——它没训练过"自回归接龙", 输出会卡顿重复。

**一句话总结.** GPT (decoder-only, 因果 mask, 接龙) = LLM 主流; BERT (encoder-only, 双向, 理解) = 检索/分类; T5 (encoder-decoder) = 翻译/摘要。

## 核心概念三 · 指令微调 SFT (约 3 分钟)

**直觉.** 预训练 LLM 是"续写引擎": 你问"法国的首都是", 它会续写"美国, 加拿大..."因为训练语料里有大量对比句。**指令微调 (Supervised Fine-Tuning, SFT)** 用 (指令, 回答) 对微调, 让模型学会"按指令回答"。

**定义.** SFT 数据集:
$$D_{\text{SFT}} = \{(x_i, y_i)\}_{i=1}^N$$
- $x_i$ 用户指令 (如 "法国的首都是什么?")
- $y_i$ 期望回答 (如 "巴黎")
- 损失: $L_{\text{SFT}} = -\sum_i \log P(y_i | x_i, \theta)$ (用预训练模型继续训练)

**例子.** Alpaca 数据集 (52K 条), Self-Instruct (175K 条), FLAN (1.8M 条):
- **小数据, 大效果**: LLaMA-7B 用 5K 指令微调, 就能在 HumanEval 代码任务涨 14 个百分点
- **RLHF 前置**: SFT 模型是 RLHF 奖励模型的起点, 没有 SFT 直接 RLHF 容易训崩
- **数据 vs 模型规模**: Chinchilla 缩放律 (Ch06 §05 沉淀): 20 token/参数; Alpaca 52K 条 ≈ 13M tokens, 配 7B 模型刚好

**反例.** 期望 SFT 让模型"更聪明"——**SFT 只调格式, 不补知识**。要补知识用 RAG (检索增强生成) 或继续预训练 (continued pre-training)。

**一句话总结.** SFT = (指令, 回答) 对微调, 调的是"按指令回答"格式, 不是知识深度。

## 核心概念四 · RLHF (基于人类反馈的强化学习) (约 3 分钟)

**直觉.** SFT 后, 模型"会回答"但可能"乱回答"——**有毒、偏见、不真实**。RLHF 用人类偏好训练**奖励模型 (Reward Model, RM)**, 再用 Ch06 §05 PPO 微调 LLM, 让模型**对齐人类价值观**。

**定义. RLHF 三阶段**:
1. **SFT** (Ch07 §05 §3): 训练"会回答"的模型 $\pi_{\text{SFT}}$
2. **奖励建模**: 人类对同一指令的多个回答排序 (A > B > C), Bradley-Terry 模型拟合
   $$L_{\text{RM}} = -\log\sigma(r(x, y_w) - r(x, y_l))$$
   $y_w$ 偏好的, $y_l$ 不偏好的, $r(\cdot)$ 标量奖励
3. **PPO 微调** (Ch06 §05): 用 RM 评分, PPO 最大化期望奖励
   $$L_{\text{RLHF}} = -E_{(x,y)\sim\pi_\theta}[\log\pi_\theta(y|x)\cdot r(x,y)] - \beta\text{KL}(\pi_\theta\|\pi_{\text{SFT}})$$
   - 第一项: 拉高 RM 高分回答
   - 第二项: KL 散度惩罚, 不让模型偏离 SFT 太远 (避免 reward hacking)

**例子.** InstructGPT (ChatGPT 前身, OpenAI 2022):
- SFT: 13K 条人类示范
- RM: 33K 条人类排序
- PPO: 1.3 万亿 token 继续训练
- 数字: **人类偏好胜率 85.1% (SFT 模型 vs PPO 模型)**, 有毒输出降 25%
- 数字: 训练成本 $0.4M FLOPs 标注 + $0.05M GPU, 比从头训练便宜 100×

**反例.** 期望 RLHF 让模型"变聪明"——**RLHF 只调行为, 不补知识**。RLHF 失败模式: reward hacking (模型学会钻 RM 漏洞而非真改善), 需 KL 散度约束 (Ch05 §05 沉淀) 防漂移。

**一句话总结.** RLHF = SFT + RM 训练 + PPO 微调, 把人类偏好灌进 LLM, 核心是**奖励模型 + PPO + KL 散度防漂移**三件套。

## 一个走完全程的例子 · LLaMA-7B 三阶段训练 (约 2.5 分钟)

**场景.** Meta 2023 年发布 LLaMA-7B, 用 1 万亿 token 训练, 之后用 5K Alpaca 指令数据 SFT, 不用 RLHF。

**第 1 步 · 预训练 (1T tokens).**
$$L = -\sum_{i=1}^{1T} \log P(x_i | x_{<i})$$
- 用 AdamW, lr=3e-4, $\beta_1=0.9, \beta_2=0.95$, weight_decay=0.1
- 4096 块 A100, 训练 21 天

**第 2 步 · SFT (5K 指令).**
$$L_{\text{SFT}} = -\sum_{i=1}^{5K} \log P(y_i | x_i)$$
- 5K 指令 vs 1T 预训练 — **不到 0.0005% 数据量**
- 数字: LLaMA-7B 在 MMLU (57 题多任务) 涨 4 个百分点, HumanEval (代码) 涨 14 个百分点

**第 3 步 · 评估.**
- perplexity: 5.7 (越小越好, 业界 SOTA 5-10)
- MMLU 5-shot: 35.1%, HumanEval 0-shot: 14.0%

**Ch07 §05 完整链路.** GPT 训练目标 (§1) → GPT 架构 (§2) → SFT (§3) → RLHF (§4) → 一气贯通 ChatGPT 全栈。

## 易错点回头看（约 80 秒）

1. **很多人以为 perplexity 越低模型越"聪明"** — **ppl 是困惑度, 越低只代表"对下个 token 预测越准"**, 与任务表现 (HumanEval 准确率) 不直接相关。
2. **很多人以为 SFT 让模型"理解"指令** — **SFT 只调格式** (question → answer), 知识在预训练里, SFT 不增加知识。
3. **很多人以为 RLHF 让模型"更对齐人类"** — **RLHF 只调"说出来的内容"**, 不保证"想的内容", reward hacking 时可能学会伪装。
