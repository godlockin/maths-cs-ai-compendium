    第23章 · AI Agent 与工具使用 · 总览¶

    章节定位: LLM 从"对话"到"行动"的范式跃迁 — Agent + 工具 + 协议 + 记忆 + 自进化 章节字数: ~10 节正文 / ~16 万字 配套教辅: 本总览 + 10 节精讲 + P14/P16 实战专题 版本: v1.0 (2026-07-31)

    一 · 一句话总览¶

    AI Agent = LLM + 工具 + 规划 + 记忆 + 反思。2024 是 MCP 协议年, 2025 是 Operator / Multi-Agent / 记忆系统年, 2026 进入"工业化部署"。
