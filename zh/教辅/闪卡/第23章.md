# 第23章 · AI Agent 与工具使用 · 闪卡

---

## 一 · Agent 基础 (8 张)

**Q1**: 什么是 AI Agent?
**A1**: 能感知环境 + 决策 + 行动的自主系统。LLM Agent = LLM 作为推理引擎 + 工具调用 + 规划。

**Q2**: Agent 核心循环 (Perception-Action Loop)?
**A2**: ① 观察 → ② 思考 → ③ 决策 → ④ 行动 → ⑤ 观察新状态 → 循环。

**Q3**: Agent vs LLM 的核心区别?
**A3**: LLM 只能"说", Agent 能"做"。Agent = LLM + 工具 + 规划 + 记忆 + 反思。

**Q4**: ReAct 是什么?
**A4**: Reason + Act。**推理步骤**与**行动步骤**交替, 让 Agent 既思考又行动。Yao et al. 2022。

**Q5**: Tree of Thoughts (ToT) 是什么?
**A5**: 把推理组织为**树**, 每个节点是中间思考, BFS/DFS 探索, 投票选最优分支。

**Q6**: Reflexion 的核心思想?
**A6**: Agent 失败后**生成反思文本**, 存入长期记忆, 下次尝试时调用反思。Shinn 2023。

**Q7**: Plan-and-Execute 模式?
**A7**: ① Planner 把任务拆成子任务 → ② Executor 依次执行。**节省 LLM 调用**, 但规划错误时难纠错。

**Q8**: LATS (Language Agent Tree Search) 是什么?
**A8**: 把 MCTS + LLM 结合, **搜索**最优行动序列, 用环境反馈当 reward。

## 二 · 工具与协议 (10 张)

**Q9**: OpenAI Function Calling 是什么?
**A9**: 让 LLM 输出**结构化 JSON**, 调用外部函数。GPT-4 2023-06 首发。

**Q10**: Toolformer 是什么?
**A10**: 让 LLM **自己决定**何时调用 API (在预训练时通过 self-supervision 学习), 2023 Meta。

**Q11**: Gorilla 是什么?
**A11**: UC Berkeley 微调的 **Tool LLM**, 在 1600+ API 上训练, 超越 GPT-4 在工具选择上。

**Q12**: MCP (Model Context Protocol) 是什么?
**A12**: Anthropic 2024-11 发布的**标准协议**, 让 LLM 接入任何工具/数据源, "USB-C for AI"。

**Q13**: MCP 三大组件?
**A13**: **Resources** (文件/数据) + **Tools** (函数调用) + **Prompts** (模板)。MCP Server 暴露这些。

**Q14**: A2A (Agent-to-Agent) 协议?
**A14**: Google 2025 发布的**Agent 间通信协议**, 让不同框架的 Agent 互联。

**Q15**: ANP (Agent Network Protocol) 是什么?
**A15**: 开源 Agent 网络协议, 基于 DID (Decentralized Identifier), 让 Agent 在去中心化网络发现彼此。

**Q16**: ACP (Agent Communication Protocol) 是什么?
**A16**: IBM 主导的 Agent 通信协议, 强调**语义互操作**, 类似 FIPA ACL。

**Q17**: MCP 与 OpenAI Function Calling 区别?
**A17**: **MCP** 是标准协议 (跨厂商), **Function Calling** 是 OpenAI 专有 API。MCP 可被 Claude/Gemini 等支持。

**Q18**: JSON Mode vs Function Calling?
**A18**: **JSON Mode** 强制输出 JSON; **Function Calling** 输出特定 schema 的参数。Function Calling 更结构化。

## 三 · 记忆 (8 张)

**Q19**: Agent 5 大记忆类型?
**A19**: ① **短期** (Stack/Redis) ② **长期** (Vector DB) ③ **情节** (时序) ④ **语义** (KG/RAG) ⑤ **程序** (技能库)。

**Q20**: Mem0 是什么?
**A20**: 通用 LLM 记忆中间件, **Extract + Dedupe + Update + Forget** 4 步, 2024 行业标准。

**Q21**: MemGPT 核心思想?
**A21**: 借鉴 OS **虚拟内存**, Agent 内存分主存 (context) + 虚存 (无限外部存储), 通过 Recall/Archival 管理。UC Berkeley 2023。

**Q22**: Letta 与 MemGPT 关系?
**A22**: Letta 是 MemGPT 团队 2024 创立的商业公司, 开源 Letta 框架 = MemGPT v2。

**Q23**: HippoRAG 是什么?
**A23**: 模仿**人脑海马体索引**的 RAG, RAG + KG + PageRank, 比传统 RAG 准确率 +20%。OSU NeurIPS 2024。

**Q24**: LangMem 是什么?
**A24**: LangChain 2025 的长期记忆 SDK, 支持**用户偏好 / 情节 / 程序**三类记忆。

**Q25**: Episodic Memory 如何实现?
**A25**: 时序 DB (TimescaleDB) + 事件 schema, 或带时间戳的向量记录。

**Q26**: 程序记忆 (Procedural Memory) 是什么?
**A26**: Agent 的**技能库**, Voyager 风格。技能 = (代码 + 描述 + 测试用例), 成功时自动添加。

## 四 · 自进化 (8 张)

**Q27**: Self-RAG 核心创新?
**A27**: LLM 生成 **Retrieve / IsRel / IsSup / IsUse** 4 个特殊 token, 决定是否检索 + 答案是否基于检索 + 答案是否有用。ICLR 2024。

**Q28**: Voyager 3 大创新?
**A28**: ① **技能库** (描述+代码); ② **迭代提示** (成功经验写入); ③ **自动课程** (难度递进)。NeurIPS 2023。

**Q29**: Constitutional AI 的核心?
**A29**: Anthropic 2022, 用 **20 条宪法**让 LLM 自评 + 修正 + RLAIF 微调。

**Q30**: AlphaEvolve 是什么?
**A30**: DeepMind 2025, AI **自动改进算法**的框架, 已改进 Gemini 训练速度 +1%, 发现矩阵乘法新算法。

**Q31**: Darwin Godel Machine 是什么?
**A31**: 2025 提出的 **AGI 自进化架构**, 模型可以**修改自己的代码**, 通过安全测试验证。

**Q32**: AI Scientist (Sakana AI) 5 阶段?
**A32**: 想法生成 → 文献调研 → 实验设计 → 论文撰写 → 自动反思。首篇自动写 ICLR 论文。

**Q33**: Loop Engineering 是什么?
**A33**: 把 5 大循环 (OS / RL / Agent / DevOps / Control) **工程化**, 让 LLM 持续自我改进。

**Q34**: Self-Improvement vs Self-Training?
**A34**: **Self-Improvement** 部署中持续学习 (Reflexion); **Self-Training** 离线自己生成数据再训练 (Self-Instruct)。

## 五 · Computer Use / Operator (6 张)

**Q35**: Anthropic Computer Use 发布?
**A35**: 2024-10, Claude 直接控制 macOS/Linux 桌面, OSWorld 14.9% (人类 76%)。

**Q36**: OpenAI Operator v1?
**A36**: 2025-01, 浏览器自主操作, GPT-4o 驱动, Operator SDK。

**Q37**: Operator v2 升级?
**A37**: 2025-09, **全 OS** (桌面+浏览器+移动), 1M context, 沙盒 + 权限控制。

**Q38**: OSWorld 基准?
**A38**: CMU 2024, 724 真实 OS 任务, 跨 Win/macOS/Linux。当前 SOTA Claude 4.5 ~38%, 人类 76%。

**Q39**: WebArena 基准?
**A39**: CMU 2024, 812 真实网页任务 (GitLab/Reddit/购物), 当前 SOTA Operator v2 ~58%, 人类 78%。

**Q40**: Browser-Use 是什么?
**A40**: 开源 Computer Use Agent, GitHub 8 万星, 支持 GPT-4 / Claude / Gemini。
