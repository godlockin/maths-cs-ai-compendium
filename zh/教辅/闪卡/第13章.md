## 卡片 1（🟢 定义）

**Q**: 集合 $S$ 的幂集 $|\mathcal{P}(S)|$ 大小?

**A**: $|\mathcal{P}(S)| = 2^{|S|}$。每个元素可选在或不在子集中。
**来源**: 01. 离散数学 §集合

## 卡片 2（🟢 定义）

**Q**: 排列 $P(n, k)$ 公式?

**A**: $P(n, k) = \frac{n!}{(n-k)!}$。$P(5, 3) = 60$。有序。
**来源**: 01. 离散数学 §集合

## 卡片 3（🟢 定义）

**Q**: 组合 $C(n, k)$ 公式?

**A**: $C(n, k) = \binom{n}{k} = \frac{n!}{k!(n-k)!}$。$C(5, 3) = 10$。无序。
**来源**: 01. 离散数学 §集合

## 卡片 4（🟢 定义）

**Q**: 大 O 记号定义?

**A**: $T(n) = O(f(n))$ 当 $\exists c > 0, n_0: T(n) \leq c f(n), \forall n \geq n_0$。上界。
**来源**: 01. 离散数学 §复杂性理论

## 卡片 5（🟢 定义）

**Q**: 大 Ω 记号?

**A**: $T(n) = \Omega(f(n))$ 下界。$T(n) = \Theta(f(n))$ 紧界。
**来源**: 01. 离散数学 §复杂性理论

## 卡片 6（🟢 定义）

**Q**: 鸽巢原理?

**A**: $n$ 个鸽巢, $n+1$ 只鸽子, 至少一巢有 ≥ 2 只。
**来源**: 01. 离散数学 §证明技巧

## 卡片 7（🟢 定义）

**Q**: 命题逻辑符号?

**A**: $\land$ 与, $\lor$ 或, $\neg$ 非, $\to$ 蕴含, $\leftrightarrow$ 等价。
**来源**: 01. 离散数学 §命题逻辑

## 卡片 8（🟢 定义）

**Q**: 数学归纳法两步?

**A**: (1) 基础: $P(1)$ 成立; (2) 归纳: $P(k) \to P(k+1)$。
**来源**: 01. 离散数学 §证明技巧

## 卡片 9（🟢 定义）

**Q**: P 类问题定义?

**A**: 多项式时间内可解。$P \subseteq NP$。
**来源**: 01. 离散数学 §复杂性理论

## 卡片 10（🟢 定义）

**Q**: NP 完整问题举例?

**A**: SAT, 旅行商 (TSP), 团问题 (Clique), 子集和。互为多项式归约。
**来源**: 01. 离散数学 §复杂性理论

## 卡片 11（🟢 定义）

**Q**: 默写 CPU 时间公式。

**A**: $T_{\text{CPU}} = IC \times CPI \times T_{\text{cycle}}$。IC 指令数, CPI 每指令周期, $T_{\text{cycle}}$ 周期时间。
**来源**: 02. 计算机架构 §CPU 架构

## 卡片 12（🟢 定义）

**Q**: 冯诺依曼架构组件?

**A**: CPU (ALU + CU) + 内存 + 总线 + 输入/输出。存储程序 (stored-program)。
**来源**: 02. 计算机架构 §CPU 架构

## 卡片 13（🟢 定义）

**Q**: 内存层级 (从快到慢)?

**A**: 寄存器 (~0.3 ns) → L1 (~1 ns) → L2 (~4 ns) → L3 (~10 ns) → DRAM (~50-100 ns) → SSD (~10-100 μs) → HDD (~5-10 ms)。口径与正文 §02 存储层级一致。
**来源**: 02. 计算机架构 §存储层级

## 卡片 14（🟢 定义）

**Q**: 缓存命中率公式?

**A**: $h = N_{\text{hit}} / N_{\text{total}}$。教学演算 (L1=1ns、L2=4ns): 95% 命中时平均访问 $0.95\times1 + 0.05\times4 = 1.15$ ns。
**来源**: 02. 计算机架构 §存储层级

## 卡片 15（🟢 定义）

**Q**: 流水线 CPI 公式?

**A**: $\text{CPI}_{\text{pipeline}} = \text{CPI}_{\text{ideal}} + N_{\text{stall}}/N_{\text{inst}}$。
**来源**: 02. 计算机架构 §流水线

## 卡片 16（🟢 定义）

**Q**: DRAM 与 SRAM 区别?

**A**: SRAM 快但贵 (寄存器缓存), DRAM 慢但密 (主存)。SRAM 用触发器, DRAM 用电容刷新。
**来源**: 02. 计算机架构 §存储层级

## 卡片 17（🟢 定义）

**Q**: CPU vs GPU 核心差异?

**A**: CPU 少核 (8-64) 高频率, 控制逻辑复杂; GPU 多核 (数千) 低频率, SIMT 适合并行。
**来源**: 04. 并发与并行 §并行编程模型

## 卡片 18（🟢 定义）

**Q**: GPU FLOPS 公式?

**A**: $\text{FLOPs} = N_{\text{SM}} \times \text{cores/SM} \times F \times 2$。H100 SXM 稠密 FP16 张量算力约 989 TFLOPS (~1000, 稀疏约 2 倍)。
**来源**: 04. 并发与并行 §并行编程模型

## 卡片 19（🟢 定义）

**Q**: 内存墙 (Memory Wall)?

**A**: CPU 算力增长 >> 内存带宽增长, 性能被内存带宽限制。
**来源**: 02. 计算机架构 §存储层级

## 卡片 20（🟢 定义）

**Q**: SIMT 是什么?

**A**: Single Instruction Multiple Threads — GPU 同一指令, 多数据流 (NVIDIA 术语)。
**来源**: 04. 并发与并行 §并行编程模型

## 卡片 21（🟢 定义）

**Q**: 进程 vs 线程差别?

**A**: 进程独立地址空间, 线程共享。线程轻量 (~1 MB stack), 进程重 (~10 MB)。
**来源**: 03. 操作系统 §进程 / §线程

## 卡片 22（🟢 定义）

**Q**: 进程地址空间布局?

**A**: 从低到高: 代码段 → 数据段 → 堆 (向上长) → 栈 (向下长)。共享库, 内核区。
**来源**: 03. 操作系统 §内存管理

## 卡片 23（🟢 定义）

**Q**: 虚拟内存如何工作?

**A**: MMU 翻译虚拟地址 → 物理地址; 页表 VA → PA; TLB 缓存页表项。
**来源**: 03. 操作系统 §内存管理

## 卡片 24（🟢 定义）

**Q**: Page fault 是什么?

**A**: 访问不在内存的页, OS 从磁盘换入 (ms 级)。
**来源**: 03. 操作系统 §内存管理

## 卡片 25（🟢 定义）

**Q**: 死锁四条件?

**A**: (1) 互斥, (2) 占有并等待, (3) 不剥夺, (4) 循环等待。
**来源**: 04. 并发与并行 §死锁

## 卡片 26（🟢 定义）

**Q**: 调度算法?

**A**: FCFS (先来先服务), SJF, RR (时间片), CFS (Linux 完全公平)。
**来源**: 03. 操作系统 §CPU 调度

## 卡片 27（🟢 定义）

**Q**: 文件系统 inode 是什么?

**A**: 索引节点, 存储文件元数据 (权限/时间戳/数据块指针)。ext4 inode = 256 B。
**来源**: 03. 操作系统 §文件系统

## 卡片 28（🟢 定义）

**Q**: 中断与异常区别?

**A**: 中断异步 (外设), 异常同步 (除 0 / 缺页)。
**来源**: 02. 计算机架构 §I/O、中断与 DMA

## 卡片 29（🟢 定义）

**Q**: 系统调用是什么?

**A**: 用户态 → 内核态的入口。`fork`, `exec`, `read`, `write` 等。
**来源**: 03. 操作系统 §系统调用与内核态

## 卡片 30（🟢 定义）

**Q**: fork vs exec?

**A**: fork 复制当前进程, exec 替换为新程序。`fork+exec` 是经典组合。
**来源**: 03. 操作系统 §进程

## 卡片 31（🟢 定义）

**Q**: 默写 Amdahl 公式。

**A**: $S(n) = \frac{1}{(1-p) + p/n}$。$p$ 可并行比例。
**来源**: 04. 并发与并行 §扩展律

## 卡片 32（🟢 定义）

**Q**: 互斥锁 (mutex) 与信号量 (semaphore)?

**A**: mutex 二值 (一个线程进入), semaphore 计数 (N 个线程)。
**来源**: 04. 并发与并行 §同步原语

## 卡片 33（🟢 定义）

**Q**: 死锁 vs 活锁 vs 饥饿?

**A**: 死锁 = 互相等待 (永久); 活锁 = 不断让步 (忙等); 饥饿 = 某些线程长期得不到资源。
**来源**: 04. 并发与并行 §死锁

## 卡片 34（🟢 定义）

**Q**: MapReduce 两阶段?

**A**: map: $(k, v) \to \text{list}(k', v')$; reduce: $(k', \text{list}(v')) \to \text{list}(v'')$。
**来源**: 拓展卡 (Ch13 正文未直接覆盖) · 挂靠 04. 并发与并行 §并行编程模型

## 卡片 101（🟢 定义）

**Q**: Loop Engineering 的一句话定义?

**A**: Loop Engineering = 5 大循环模式 + 9 类失败检测 + 闭环设计原则。任何“重复执行”系统 (OS/RL/Agent/DevOps/Control) 都要给循环配上“缰绳”, 防止无限循环、死锁与漂移。
**来源**: 03A. Loop Engineering 综述 §一 · 一句话总览

## 卡片 102（🟢 定义）

**Q**: 5 大 Loop 分别是什么? 周期量级?

**A**: OS Loop (ms-s, 调度器)、RL Loop (s-min, PPO/SAC)、Agent Loop (s-min, LangGraph)、DevOps Loop (min-day, Airflow)、Control Loop (ms-s, PID)。频率从 1000Hz 到每天数次跨 8 个数量级。
**来源**: 03A. Loop Engineering 综述 §四 · 5 大 Loop 对照矩阵

## 卡片 103（🟢 定义）

**Q**: OS Loop 的组成与致命失败?

**A**: 含调度循环、中断循环、时钟循环、IO 循环 (epoll/select/IOCP); 典型失败为优先级反转、饥饿、死锁、活锁、调度抖动, 最致命的是死锁。
**来源**: 03A. Loop Engineering 综述 §三 · 章节主线

## 卡片 104（🟢 定义）

**Q**: RL Loop 与 Agent Loop 的关键区别?

**A**: RL Loop 靠环境奖励更新策略参数 (PPO/SAC), 致命失败是策略崩溃; Agent Loop 靠 LLM 推理 + 工具调用完成任务 (LangGraph), 致命失败是无限循环。前者“学参数”, 后者“调工具”。
**来源**: 03A. Loop Engineering 综述 §四 · 5 大 Loop 对照矩阵

## 卡片 105（🟢 定义）

**Q**: DevOps Loop 与 Control Loop 怎么对照?

**A**: DevOps Loop 周期 min-day、每天 1-100 次 (Airflow/CI-CD), 致命失败是状态丢失; Control Loop 周期 ms-s、10-1000Hz (PID), 致命失败是震荡。一慢一快, 都靠闭环反馈纠偏。
**来源**: 03A. Loop Engineering 综述 §四 · 5 大 Loop 对照矩阵

## 卡片 106（🟢 定义）

**Q**: 9 类共同失败模式可分哪几族?

**A**: 终止族 (无限循环、死锁、活锁)、漂移族 (漂移、稳态误差)、稳定性族 (超调、震荡、响应慢)、可观测族 (观测黑盒), 共 9 类。
**来源**: 03A. Loop Engineering 综述 §五 · 9 类共同失败模式

## 卡片 107（🟢 定义）

**Q**: 无限循环与死锁各自怎么防?

**A**: 无限循环 = 循环没有终止条件, 防御是 max_iter 硬上限; 死锁 = 多方互相等待, 防御是超时 + 资源排序 (破坏循环等待)。
**来源**: 03A. Loop Engineering 综述 §五 · 9 类共同失败模式

## 卡片 108（🟢 定义）

**Q**: 控制论三病 (超调/震荡/稳态误差) 与防御?

**A**: 超调 = 走过头 → 限幅; 震荡 = 输出不稳定 → 滤波; 稳态误差 = 终点偏差消不掉 → 积分项消除。调参层面分别对应: 超调降 P、震荡加 D、稳态误差加 I (03A §3.5.4)。
**来源**: 03A. Loop Engineering 综述 §五 · 9 类共同失败模式

## 卡片 109（🟢 定义）

**Q**: Loop Engineering 的 5 大工程原则?

**A**: 可终止 (terminable, 任何循环必须有终点)、可观测 (observable, 状态可见)、可回退 (recoverable, 失败可回滚)、可限速 (rate-limited, 防失控)、可校准 (calibratable, 周期校准)。
**来源**: 03A. Loop Engineering 综述 §六 · 工程原则

## 卡片 110（🟢 定义）

**Q**: “可终止”原则在 Agent Loop 怎么落地?

**A**: 给 Agent 的推理-行动循环设 max_iter 硬上限与单步超时, 超限即熔断并回退到人工或安全默认动作; 对应失败模式表里的“无限循环 → max_iter”。
**来源**: 03A. Loop Engineering 综述 §六 · 工程原则
