## 卡片 1（🟢 定义）

**Q**: 图 (Graph) 的数学定义?

**A**: $G = (V, E)$, 其中 $V$ 是节点集, $E \subseteq V \times V$ 是边集。无向图对称, 有向图不要求。
**来源**: 02. 图论 §图的表示

## 卡片 2（🟢 定义）

**Q**: 邻接矩阵 $A$ 的元素含义?

**A**: $A_{uv} = 1$ 当 $(u,v) \in E$, 否则 $0$。对称当无向。
**来源**: 02. 图论 §图的表示

## 卡片 3（🟢 定义）

**Q**: 节点度 (degree) 定义?

**A**: $d_v = \sum_{u \in V} A_{uv}$, 即 $v$ 的邻居数。
**来源**: 02. 图论 §图的表示

## 卡片 4（🟢 定义）

**Q**: 拉普拉斯矩阵 $L$ 定义?

**A**: $L = D - A$, 其中 $D$ 是度矩阵 (对角)。实对称半正定。
**来源**: 02. 图论 §拉普拉斯矩阵

## 卡片 5（🟢 定义）

**Q**: 归一化拉普拉斯怎么定义? 特征值范围?

**A**: $\hat{L} = I - D^{-1/2} A D^{-1/2}$ (即 $D^{-1/2} L D^{-1/2}$)。特征值落在 $[0, 2]$, GCN 直接用其中的对称归一化邻接 $D^{-1/2}AD^{-1/2}$。
**来源**: 02. 图论 §图拉普拉斯矩阵

## 卡片 6（🟢 定义）

**Q**: Weisfeiler-Lehman (WL) 测试定义?

**A**: 节点邻居集合哈希比较,迭代确定两图是否同构。GIN 与 WL 等价。
**来源**: 02. 图论 §WL 测试

## 卡片 7（🟢 定义）

**Q**: 几何深度学习 (GDL) 如何统一 CNN、Transformer 与 GNN?

**A**: 五大几何域各有对称群与对应架构: 网格→CNN (平移等变)、集合→DeepSets (置换不变)、序列→RNN/Transformer、图→GNN (节点置换等变)、流形→内在算子。一句话: CNN 是网格图上的 GNN, Transformer 是完全图上的 GNN, DeepSets 是无边图上的 GNN。
**来源**: 01. 几何深度学习 §五大几何域

## 卡片 8（🟢 定义）

**Q**: SO(3) 与 SE(3) 区别?

**A**: SO(3) = 三维旋转群; SE(3) = 旋转 + 平移 (3D 刚体变换群)。
**来源**: 01. 几何深度学习 §对称群

## 卡片 9（🟢 定义）

**Q**: GCN 用于直推 (transductive) 还是归纳 (inductive)?

**A**: 直推, 因为聚合依赖全图 $A$。GraphSAGE 支持归纳(邻居采样)。
**来源**: 03. 图神经网络 §归纳与直推

## 卡片 10（🟢 定义）

**Q**: GNN 的 over-smoothing 指什么?

**A**: 多层 GNN 后所有节点表示趋同, 失去区分度。
**来源**: 03. 图神经网络 §过平滑

## 卡片 11（🟢 定义）

**Q**: 默写 GCN 卷积公式。

**A**: $H^{(l+1)} = \sigma(\tilde D^{-1/2} \tilde A \tilde D^{-1/2} H^{(l)} W^{(l)})$; $\tilde A = A + I$。
**来源**: 03. 图神经网络 §GCN

## 卡片 12（🟢 定义）

**Q**: 默写 GraphSAGE 聚合公式。

**A**: $h_v^{(l+1)} = W \cdot [\text{CONCAT}(h_v^{(l)}, \text{AGG}(\{h_u^{(l)}\}))]$; AGG ∈ {MEAN, MAX, LSTM}。
**来源**: 03. 图神经网络 §GraphSAGE

## 卡片 13（🟢 定义）

**Q**: 默写 GIN 公式。

**A**: $h_v^{(l+1)} = \text{MLP}((1+\epsilon) h_v + \sum_{u \in \mathcal{N}(v)} h_u)$。 $\epsilon$ 可学习。
**来源**: 03. 图神经网络 §GIN

## 卡片 14（🟢 定义）

**Q**: 默写 GAT 注意力系数。

**A**: $\alpha_{ij} = \frac{\exp(\text{LeakyReLU}(\mathbf{a}^\top [Wh_i \| Wh_j]))}{\sum_k \exp(\text{LeakyReLU}(\mathbf{a}^\top [Wh_i \| Wh_k]))}$。
**来源**: 04. 图注意力网络 §GAT

## 卡片 15（🟢 定义）

**Q**: 默写 Graphormer 的结构编码。

**A**: 注意力分数: $\alpha_{ij} = (h_i W_Q)(h_j W_K)^T/\sqrt{d_k} + b_{\mathrm{spd}(i,j)} + b_{\mathrm{edge}}$; 最短路距离偏置与边偏置加在注意力分数上, 中心性 (度数) 编码则加到节点输入嵌入, 两者位置不同。
**来源**: 04. 图注意力网络 §Graphormer

## 卡片 16（🟢 定义）

**Q**: 默写 READOUT 排序不变性。

**A**: $h_G = \sum_{v \in V} h_v^{(L)}$ (SUM) 或 $h_G = \text{MAX}_{v} h_v^{(L)}$。排列不变。
**来源**: 03. 图神经网络 §READOUT

## 卡片 17（🟢 定义）

**Q**: 默写 SchNet 的距离相关消息。

**A**: $m_{j\to i} = h_j \odot W_{\mathrm{filter}}(\mathrm{RBF}(d_{ij}))$; 原子间距离先经径向基函数展开, 再生成连续滤波器, 只用不变量故自动旋转平移不变。
**来源**: 05. 3D 图网络 §SchNet

## 卡片 18（🟢 定义）

**Q**: 默写 PointNet 全局特征。

**A**: $h_G = \text{MAX}_{v \in V} \text{MLP}(h_v)$。Max 实现排列不变。
**来源**: 05. 3D 图网络 §PointNet

## 卡片 19（🟢 定义）

**Q**: 默写 PageRank 收敛。

**A**: $p_v^{(t+1)} = \frac{1-d}{N} + d \sum_{u \to v} \frac{p_u^{(t)}}{d_u^{\text{out}}}$; 收敛当 $\|p^{(t+1)} - p^{(t)}\| < \epsilon$。
**来源**: 02. 图论 §PageRank

## 卡片 20（🟢 定义）

**Q**: 默写 PageRank 与 GNN 的关系。

**A**: PageRank 是一种特殊 GNN: $\text{AGG}$ = 邻接归一化求和, $h_v$ = 标量, 多次迭代 = K 层 GNN。
**来源**: 02. 图论 §PageRank

## 卡片 21（🟢 定义）

**Q**: GCN vs GraphSAGE vs GIN 三大模型对比?

**A**: | 维度 | GCN | SAGE | GIN |
|------|-----|------|-----|
| 聚合 | 加权平均 | MEAN/MAX/LSTM | Sum |
| 表达力 | 中 | 中 | 最高 (WL 最优) |
| 归纳 | 否 | 是 | 是 |
| 应用 | 节点分类 | 大图 | 分子 |
**来源**: 03. 图神经网络 §模型对比

## 卡片 22（🟢 定义）

**Q**: GAT vs GCN 注意力优势?

**A**: GAT 给不同邻居不同权重,适应异质图; GCN 等权。
**来源**: 04. 图注意力网络 §GAT

## 卡片 23（🟢 定义）

**Q**: Graphormer vs GAT 区别?

**A**: - GAT: 每边系数, 局部注意力
- Graphormer: 全连接 + 空间/中心性编码 (距离 bias, 度编码)
**来源**: 04. 图注意力网络 §Graphormer

## 卡片 24（🟢 定义）

**Q**: 谱图卷积与空间图卷积区别?

**A**: - 谱: 用 Laplacian 特征分解 $L = U \Lambda U^\top$, 卷积=$U g(\Lambda) U^\top$
- 空间: 直接在图上聚合, 不用 Laplacian
**来源**: 03. 图神经网络 §谱与空间卷积

## 卡片 25（🟢 定义）

**Q**: PointNet 与 PointNet++ 区别?

**A**: PointNet 单层 max; PointNet++ 多层 max + KNN 分层聚合, 类似 CNN 金字塔。
**来源**: 05. 3D 图网络 §PointNet++

## 卡片 26（🟢 定义）

**Q**: GNN 在推荐系统的核心逻辑?

**A**: 用户-商品-店铺多类型异构图,RGCN/HAN 编码, 输出嵌入向量, dot product 预测评分。
**来源**: 应用案例 §推荐系统

## 卡片 27（🟢 定义）

**Q**: GNN 怎么做交通预测?

**A**: 路网建模为图: 路口是节点、路段是带权边 (距离/通行时间); 时空 GCN 在图结构上聚合邻接路口流量, 再结合时间序列预测车速与拥堵。
**来源**: 02. 图论 §真实世界的图

## 卡片 28（🟢 定义）

**Q**: GNN 在药物发现里怎么用?

**A**: 分子图以原子为节点、化学键为边, 节点特征含元素类型/电荷, 经 GIN 等消息传递编码后做分子性质 (毒性、溶解度) 虚拟筛选; 3D 场景则用 SchNet/等变网络。
**来源**: 03. 图神经网络 §任务类型; 05. 3D 图网络 §应用

## 卡片 29（🟢 定义）

**Q**: AlphaFold 各代用了 GNN 吗?

**A**: AlphaFold 2 (2021) 主力是 Evoformer——注意力加三角更新, 并非严格意义的消息传递 GNN; AlphaFold 3 (2024, Nature) 转向扩散模块迭代精修原子坐标, 覆盖蛋白-DNA-RNA-配体全复合物。几何/图推理思想贯穿其中, 但不能简单说 "AF3 用 GNN 替代 Transformer"。
**来源**: 05. 3D 图网络 §蛋白质结构 (2026-09 增补)

## 卡片 30（🟢 定义）

**Q**: 通用大语言模型和 GNN 是什么关系?

**来源**: 04. 图注意力网络 §2024-2026 补记

## 卡片 64（🟢 定义）

**Q**: 谱图卷积与空间图卷积的耗时差? (与卡片 24 的定义配对)

**A**: 谱路线要对 $L$ 做特征分解, 代价 $O(n^3)$ 加 $O(n^2)$ 卷积; 空间路线只遍历邻接边, 单层 $O(|E|d)$。大图一律走空间/多项式近似 (GCN 的一阶 Chebyshev 化简正是为此)。

## 卡片 71（🟢 定义）

**Q**: 写一个 PyG 两层 GCN 的 Cora 节点分类骨架。

**A**: ```python
import torch
import torch.nn.functional as F
from torch_geometric.datasets import Planetoid
from torch_geometric.nn import GCNConv

dataset = Planetoid(root='/data/Cora', name='Cora')
data = dataset[0]

class GCN(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = GCNConv(dataset.num_features, 64)
        self.conv2 = GCNConv(64, dataset.num_classes)
    def forward(self, data):
        x, edge_index = data.x, data.edge_index
        x = F.relu(self.conv1(x, edge_index))
        x = F.dropout(x, training=self.training)
        return F.log_softmax(self.conv2(x, edge_index), dim=1)
```
**来源**: 代码实战 §PyG GCN
