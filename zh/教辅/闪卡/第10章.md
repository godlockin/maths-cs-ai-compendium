# Ch10 多模态学习 · 102 张闪卡 (Anki 格式转构建器格式)

## 卡片 1（🟢 定义）

**Q**: 什么是**多模态学习 (Multimodal Learning)**?

**A**: 把不同模态 (vision, language, audio, video, structured data) 的数据组合起来,学到比单模态更丰富、更鲁棒的表征。例如 CLIP 把图像和文本投影到共享的 512/768 维空间,实现图文检索和零样本分类。
**提示**: Ch10 §01 核心定义 (来源: 基础概念卡)

## 卡片 2（🟢 定义）

**Q**: **模态 (Modality)** 在机器学习中指什么?

**A**: 一种独立的信息通道。最常见: 图像 (像素网格)、文本 (token 序列)、音频 (波形/频谱)、视频 (帧序列)、结构化数据 (表格/图)。
**提示**: 多模态 ≠ 多任务;模态侧重数据形式 (来源: 基础概念卡)

## 卡片 3（🟢 定义）

**Q**: **早期融合 (Early Fusion)** vs **晚期融合 (Late Fusion)**?

**A**: - **早期**: 不同模态原始/低层特征直接拼接 `$x_{\text{fused}} = [x_{\text{img}}; x_{\text{txt}}]$`,优点细粒度交互,缺点维度大、需学对齐
- **晚期**: 各模态独立编码 → 末期分数融合 `$\hat y = \alpha\hat y_1 + (1-\alpha)\hat y_2$`,优点可复用单模态预训练,缺点学不到低层交互
- **中层** (主流): Q-Former / cross-attention 在中层交互
**提示**: Tradeoff: 表达力 vs 训练成本 (来源: 基础概念卡)

## 卡片 4（🟢 定义）

**Q**: **跨模态注意力 (Cross-modal Attention)** 的 Q/K/V 各来自哪个模态?

**A**: 取决于任务:
- **图生文** (captioning): Q=文本(解码器), K/V=图像
- **文生图** (diffusion): Q=latent, K=文本, V=文本
- **VQA**: Q=文本, K/V=视觉;或 Q=视觉, K/V=文本
- 一般: Q 来自目标模态 (要生成的), K/V 来自条件模态
**提示**: Transformer cross-attn 的本质 (来源: 基础概念卡)

## 卡片 5（🟢 定义）

**Q**: 列出 3 种主流多模态融合时间点策略的缺点各 1 条。

**A**: 1. Early: 输入维度爆炸,VLM 中拼接到 LLM 上下文长度超限
2. Late: 学不到低层跨模态信号;下游任务剪枝有损
3. Middle (Q-Former): 引入了 lossy compression,可能丢失细节
**提示**: 实际工程中混合策略

--- (来源: 基础概念卡)

## 卡片 6（🟡 公式）

**Q**: **CLIP** 是如何训练的?

**A**: 在大规模 batch 的图文对:
1. 图像经 ViT-L 编码 → 投影到共享空间 (ViT-L/14 为 768 维)
2. 文本经 Transformer 编码 → 同维
3. 在 N×N 相似度矩阵上,对角线为正例,其他为负例
4. 对称 InfoNCE 损失 (双向),温度 τ=0.07 与权重一起学
数据集 WIT-400M (WebImageText, 4 亿图文对)。
**提示**: OpenAI, Radford et al., ICML 2021 (来源: CLIP & 对比学习)

## 卡片 7（🟡 公式）

**Q**: **InfoNCE 损失**公式?

**A**: $$L_i = -\log \frac{\exp(s(z_i, z_i^+)/\tau)}{\sum_{j=1}^N \exp(s(z_i, z_j)/\tau)}$$
其中 $s$ 是余弦相似度,$\tau$ 是温度参数 (CLIP 默认 0.07)。
**提示**: 双向 = 文本侧同样计算 (来源: CLIP & 对比学习)

## 卡片 8（🟡 公式）

**Q**: **τ (温度参数)** 在 InfoNCE 中的作用?

**A**: - τ 越小 → 分布越尖 → 训练越难但学到的表征越细粒度
- τ 越大 → 越均匀 → 训练稳但表征粗糙
- CLIP τ=0.07 偏小;ALIGN (Google) 用 τ=1/100 ≈ 0.01
**提示**: 超敏感超参;SigLIP 用 sigmoid 损失消除 τ (来源: CLIP & 对比学习)

## 卡片 9（🟡 公式）

**Q**: **CLIP 零样本分类**怎么做?

**A**: 给定类别集 {猫, 狗, 鸟...}:
1. 构造 prompt: "a photo of a {class}" 模板 (如"一只{class}")
2. 文本编码器得每个类的嵌入 $T_y$
3. 图像编码器得图片嵌入 $z_v$
4. $\hat y = \arg\max_y \cos(z_v, T_y)$
ImageNet 76.2% 准确率(ResNet-50 baseline 是 76.0% 监督训练)。
**提示**: prompt 工程可提升到 80%+ (来源: CLIP & 对比学习)

## 卡片 10（🟡 公式）

**Q**: **SigLIP** 是怎么改进 CLIP 的?

**A**: 用 **sigmoid 损失**取代 softmax:
- 不需要 N² 关系矩阵
- 每对图文独立打分
- 允许小 batch(几千) 也能稳定
- 性能与 CLIP 相当,效率高 10x
**提示**: Google 2023, Zhai et al. (来源: CLIP & 对比学习)

## 卡片 11（🟡 公式）

**Q**: **图文检索 (Image-Text Retrieval)** 的 Recall@k 指标?

**A**: 给定图片,模型在 N 张文本中选最匹配;前 k 个有正确答案的比例。
- MS-COCO 5K 测试集 R@1: CLIP ≈ 65%, SigLIP ≈ 70%, Florence-2 ≈ 78%
- R@5 / R@10 更高
**提示**: Recall 越高表示检索越准 (来源: CLIP & 对比学习)

## 卡片 12（🟡 公式）

**Q**: **负样本 (Negative Samples) 数量**如何影响 InfoNCE?

**A**: 负样本越多,模型学到的"区分"越细粒度。
- N=128 → ImageNet ≈ 60%
- N=8192 → ≈ 75%
- N=32768 → ≈ 76.2%
边际收益递减,所以 SigLIP 用 sigmoid 损失在小 batch 即可模拟。
**提示**: CLIP 训练一次需要数百块 GPU

--- (来源: CLIP & 对比学习)

## 卡片 13（🟡 直觉）

**Q**: **VLM (Vision-Language Model)** 与 **CLIP** 的核心区别?

**A**: - CLIP: 双编码器,只学对齐,不生成
- VLM: 把视觉信息融合进 LLM,可对话、可生成、可推理
**提示**: VLM = CLIP + 生成能力 (来源: VLM 视觉语言模型)

## 卡片 14（🟡 直觉）

**Q**: **LLaVA** 如何把视觉信息接入 LLM?

**A**: 1. ViT 编码图像 → patch embeddings (e.g., 256 tokens × 1024 维)
2. 线性投影 $W \in \mathbb{R}^{1024 \times d_{\text{LLM}}}$ 把每 patch 降到 LLM 维度
3. 作为 "image token" 拼到 prompt 中
4. LLM 正常处理,生成文字回应
**提示**: 简单粗暴但有效 (来源: VLM 视觉语言模型)

## 卡片 15（🟡 直觉）

**Q**: **Q-Former (BLIP-2 关键组件)** 的工作原理?

**A**: - 32 个 learnable query tokens (Q)
- Cross-attention Q 与 ViT 输出 (K, V)
- 三任务训练:ITC (对比) + ITM (匹配) + ITG (生成)
- 输出 32×768 压缩表达到 LLM
**提示**: Salesforce 2023 (来源: VLM 视觉语言模型)

## 卡片 16（🟡 直觉）

**Q**: **视觉指令微调 (Visual Instruction Tuning)** 的工作流?

**A**: 1. 用 GPT-4V 当 oracle,基于图像生成 (Q, A) 对 (e.g., 158K 样本)
2. 这些 instruction-following 数据微调 LLaVA (Vicuna)
3. 学到 "看图回答问题" 能力
**提示**: Liu et al., NeurIPS 2023 (来源: VLM 视觉语言模型)

## 卡片 17（🟡 直觉）

**Q**: **Qwen-VL 多阶段训练**的三阶段?

**A**: 1. **阶段 1**: 视觉编码器 + Q-Former + LLM 解冻,数据集图文对 1.4B, 训对齐
2. **阶段 2**: LLM 解冻,Q-Former 冻结,多任务微调
3. **阶段 3**: 解冻所有,指令微调 + RLHF
**提示**: 阿里达摩院 2023 (来源: VLM 视觉语言模型)

## 卡片 18（🟡 直觉）

**Q**: **VQA (Visual Question Answering)** 任务的准确率?

**A**: - VQAv2 test-dev 标准: 闭集 4 选项,人类 ≈ 95%,LLaVA-1.5 ≈ 80%
- OK-VQA 开放问答: GPT-4V ≈ 60% (2024 口径), LLaVA-1.5 ≈ 50%
**提示**: VQA 准确率随模型 scale 提升

## 卡片 19（🟡 公式）

**Q**: **VQ-VAE** 的三大组件及作用?

**A**: 1. **编码器** $E$: 图像 $x$ → 连续特征 $z_e \in \mathbb{R}^{h \times w \times d}$
2. **量化器**: 把 $z_e$ 在 codebook $\mathcal{C}$ 中找最近邻 → 离散 $z_q$
3. **解码器** $D$: 把 $z_q$ 重建成 $\hat x$
**提示**: 关键创新: 用离散 token 当下游任务输入 (来源: VQ-VAE 视觉分词)

## 卡片 20（🟡 公式）

**Q**: **VQ 量化**的数学表达?

**A**: $$z_q = z_k, \quad k = \arg\min_{j \in [1..K]} \|z_e - z_j\|_2$$
codebook $\mathcal{C} = \{z_1, ..., z_K\}$,通常 $K=8192$,每个 $z_k \in \mathbb{R}^d$。
**提示**: 最近邻查找,代码 index 而非连续向量 (来源: VQ-VAE 视觉分词)

## 卡片 21（🟡 公式）

**Q**: **Codebook Collapse** 是什么?怎么防?

**A**: - **症状**: 部分 codebook entry 永远不被选中(利用率低)
- **原因**: 训练初期对某 entry 偏好,Adam 把它和编码器一起"训死"
- **缓解**:
  1. EMA 更新 codebook(不让梯度直接动)
  2. Code 重启:长期不用的 entry 重置为当前 batch 的 $z_e$
  3. Gumbel-Softmax:加 noise 增加随机性
**提示**: 是 VQ 训练最常见坑 (来源: VQ-VAE 视觉分词)

## 卡片 22（🟡 公式）

**Q**: **直通估计 (Straight-Through Estimator, STE)** 在 VQ 中怎么用?

**A**: - 量化操作 $\arg\min$ 不可微,反向梯度被截断
- STE hack: 前向用 $z_q$,反向时把梯度原样代理给 $z_e$
$$\frac{\partial L}{\partial z_e} \approx \frac{\partial L}{\partial z_q}$$
**提示**: 简单粗暴但有效 (来源: VQ-VAE 视觉分词)

## 卡片 23（🟡 公式）

**Q**: **VQ-GAN 损失**的组成部分?

**A**: $$L = \underbrace{\|x - \hat x\|_1}_{\text{重建}} + \lambda_1 \underbrace{\|F(x) - F(\hat x)\|_1}_{\text{感知}} + \lambda_2 \underbrace{\|z_e - \text{sg}[z_q]\|_2^2}_{\text{commit}} + \underbrace{L_{\text{GAN}}}_{\text{对抗}}$$
分别保证像素相似、感知相似、codebook 用上、视觉真实。
**提示**: VQ-VAE + PatchGAN 判别器 (来源: VQ-VAE 视觉分词)

## 卡片 24（🟡 公式）

**Q**: **DALL-E dVAE** 把 256×256 图变成多少 token?

**A**: - 256×256×3 → 经 dVAE 编码 → 32×32=1024 个 latent
- 量化到 8192 个 codebook entry
- 最终 1024 个 token 进入 transformer 训练
**提示**: 把图像像文字一样喂给 GPT (来源: VQ-VAE 视觉分词)

## 卡片 25（🟡 公式）

**Q**: **VAR (Visual AutoRegressive)** 与扩散模型相比的差异?

**A**: - 传统扩散: 在 latent 加噪 → 学去噪
- VAR: next-scale prediction,从低分辨率到高分辨率逐级自回归
- VAR 更像 LLM 自回归 (类比文字 token)
- ImageNet 256 FID: VAR ≈ 1.0,SD 2.1 ≈ 8
**提示**: 字节跳动 + 北大, NeurIPS 2024

--- (来源: VQ-VAE 视觉分词)

## 卡片 26（🟡 直觉）

**Q**: **Stable Diffusion** 为什么叫 "Stable"?相比 DDPM 改进?

**A**: - DDPM: 像素空间扩散 (256×256×3),千步迭代慢
- LD (Latent Diffusion): 加 VAE 把图像压到 latent 4×64×64,扩散在 latent 跑
- 速度提升 ~50x
**提示**: Stability AI + LMU Munich, CVPR 2022 (来源: 跨模态生成 (Stable Diffusion))

## 卡片 27（🟡 直觉）

**Q**: **扩散前向**公式?

**A**: $$x_t = \sqrt{\bar\alpha_t} x_0 + \sqrt{1 - \bar\alpha_t} \epsilon, \quad \bar\alpha_t = \prod_{s=1}^t \alpha_s$$
其中 $\epsilon \sim \mathcal{N}(0, I)$,$\alpha_t$ 是超参 schedule,通常 1000 步。
**提示**: 方差递增地加噪 (来源: 跨模态生成 (Stable Diffusion))

## 卡片 28（🟡 直觉）

**Q**: **扩散训练损失**是什么?

**A**: $$L_{\text{simple}} = \mathbb{E}_{t, x_0, \epsilon, c} \left[\|\epsilon - \epsilon_\theta(x_t, t, c)\|^2\right]$$
预测噪声 $\epsilon$,c 是条件(文本嵌入)。L1 也用但 L2 更稳。
**提示**: 训练时随机采 t (来源: 跨模态生成 (Stable Diffusion))

## 卡片 29（🟡 直觉）

**Q**: **CFG (Classifier-Free Guidance)** 公式?

**A**: $$\hat\epsilon = (1 + w) \epsilon_\theta(x_t, t, c) - w \epsilon_\theta(x_t, t, \emptyset)$$
- $c$=条件嵌入
- $\emptyset$=无条件 (空文本或 null token)
- w=7.5 对齐最强,多样性下降
- w=1 退化为普通条件生成
**提示**: 没有 classifier, 所以叫 classifier-free (来源: 跨模态生成 (Stable Diffusion))

## 卡片 30（🟡 直觉）

**Q**: **Stable Diffusion UNet 中** 文本如何注入?

**A**: - 文本经 CLIP ViT-L/14 → 77×768 嵌入
- UNet 每个 spatial block 加 **cross-attention 层**:
  - Q: latent feature (256×256×4 flatten)
  - K, V: 文本嵌入
- 文本经多层 cross-attn 注入到所有分辨率层
**提示**: cross-attn 是文生图的核心机制 (来源: 跨模态生成 (Stable Diffusion))

## 卡片 31（🟡 直觉）

**Q**: **Stable Diffusion 推理**从噪声到图像的步骤?

**A**: 1. $x_T \sim \mathcal{N}(0, I)$ 采纯噪声
2. 循环 $t = T, T-1, ..., 1$:
   - 用 $\epsilon_\theta(x_t, t, c)$ 预测噪声
   - CFG: $\hat\epsilon = (1+w)\epsilon_c - w\epsilon_\emptyset$
   - 用 DDPM/DDIM scheduler 更新 $x_{t-1}$
3. VAE 解码 $x_0 \to$ 像素图像
**提示**: 50 步 DDIM 即可生成 (来源: 跨模态生成 (Stable Diffusion))

## 卡片 32（🟡 直觉）

**Q**: **DALL-E 3** vs **Stable Diffusion** 关键差异?

**A**: - SD: open-source,生图直接用 CLIP 文本嵌入
- DALL-E 3: 用 GPT-4V 重写用户的简短 prompt 成详细描述 (e.g., 用户说"猫",GPT 重写"一只在阳光下的橙色虎斑猫,坐姿警觉...")
- 然后用 T5-XXL 编码后给扩散模型
**提示**: GPT-4V 重写提升对齐,但 prompt engineering 不灵活 (来源: 跨模态生成 (Stable Diffusion))

## 卡片 33（🟡 直觉）

**Q**: **ControlNet** 工作原理?

**A**: 1. 复制 SD UNet 的可训练副本 (zero convolutions 初始权重)
2. 给定空间条件(Canny 边缘、深度图、姿态点) 单独编码
3. 加到 UNet 各层 zero convolutions 输出 → 类似残差
4. 训练时 SD UNet 冻结,副本 + zero conv 训练
**提示**: 张吕敏, Lvmin Zhang, 2023 (来源: 跨模态生成 (Stable Diffusion))

## 卡片 34（🟡 直觉）

**Q**: **FID (Fréchet Inception Distance)** 怎么算?

**A**: $$\text{FID} = \|\mu_r - \mu_g\|^2 + \text{Tr}\left(\Sigma_r + \Sigma_g - 2 (\Sigma_r \Sigma_g)^{1/2}\right)$$
- 用 Inception-v3 提取 2048 维特征
- 真实图和生成图分别算 $\mu, \Sigma$
- FID 越低越好
**提示**: ImageNet 256 ImageNet FID 排行: VAR ≈ 1.0, SD3 ≈ 8, DALL-E 3 ≈ 5.6

--- (来源: 跨模态生成 (Stable Diffusion))

## 卡片 35（🟡 直觉）

**Q**: **GPT-4o** 相对 GPT-4V 的核心改进?

**提示**: OpenAI, 2024-05 (来源: 统一多模态架构)

## 卡片 39（🟡 直觉）

- Janus 用 **解耦编码器**: 理解的 SigLIP + 生成的 (变分或扩散编码器)

**提示**: DeepSeek, 2024 (来源: 统一多模态架构)

2. **属性幻觉**: 物体属性错误(颜色/形状)
3. **关系幻觉**: 物体之间空间/数量关系错误
**提示**: MMHal-Bench 评测,GPT-4o 幻觉率约 7%

## 卡片 47（🔴 反例）

**Q**: VQ-VAE 量化代码

**A**: ```python
import torch
import torch.nn.functional as F

class VectorQuantizer(torch.nn.Module):
    def __init__(self, num_embeddings=8192, embedding_dim=256):
        super().__init__()
        self.codebook = torch.nn.Embedding(num_embeddings, embedding_dim)

    def forward(self, z_e):
        # z_e: (B, C, H, W) -> (B*H*W, C)
        z_flat = z_e.permute(0, 2, 3, 1).reshape(-1, z_e.shape[1])
        # 距离矩阵
        d = (z_flat.pow(2).sum(-1, keepdim=True)
             - 2 * z_flat @ self.codebook.weight.t()
             + self.codebook.weight.pow(2).sum(-1))
        # 最近邻索引
        idx = d.argmin(-1)
        z_q = self.codebook(idx).view(z_e.shape)
        # 直通估计
        z_q = z_e + (z_q - z_e).detach()
        return z_q, idx
```
**提示**: VQ-VAE 核心量化代码

## 卡片 66（🟡 公式）

**Q**: 默写 **跨模态注意力**公式。

**A**: $$\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{Q K^\top}{\sqrt{d_k}}\right) V$$
Q 来自目标模态,K/V 来自条件模态。$d_k$ 为 K 维度,用于缩放。
**提示**: 这是 VLM 投影/SD cross-attn/GPT-4o 跨模态的统一公式 (来源: 公式速查)

## 卡片 67（🟡 公式）

**Q**: 默写 **VQ 量化**公式。

**A**: $$z_q = z_k, \quad k = \arg\min_j \|z_e - z_j\|_2$$
codebook $\mathcal{C}=\{z_1,...,z_K\}$。
**提示**: VQ-GAN/VQ-VAE/dVAE/DALL-E 都用 (来源: 公式速查)

## 卡片 68（🟡 公式）

**Q**: 默写 **InfoNCE** 损失。

**A**: $$L_i = -\log\frac{\exp(s(z_i,z_i^+)/\tau)}{\sum_{j=1}^N \exp(s(z_i,z_j)/\tau)}$$
**提示**: CLIP/ALIGN/MOCO/SimCLR 都用 (来源: 公式速查)

## 卡片 69（🟡 公式）

**Q**: 默写 **扩散前向**与 **CFG**。

**A**: - 前向: $x_t = \sqrt{\bar\alpha_t} x_0 + \sqrt{1-\bar\alpha_t} \epsilon$
- CFG: $\hat\epsilon = (1+w)\epsilon_\theta(x_t,t,c) - w\epsilon_\theta(x_t,t,\emptyset)$
**提示**: 这两行是 SD/Imagen/Sora/DALL-E 3 的核心 (来源: 公式速查)

**Q**: 默写 **VQ-GAN 损失**四项。

**A**: $L = L_{\text{recon}} + \lambda_1 L_{\text{percept}} + \lambda_2 L_{\text{commit}} + L_{\text{GAN}}$
**提示**: 4 项分别保证像素/感知/codebook 用上/视觉真实
