## 卡片 1（🟢 定义）图像数字化

**Q**: 图像在计算机中如何表示?
**A**: 三维张量 $(H, W, C)$: $H$ 高度, $W$ 宽度, $C$ 通道 (灰度 1, RGB 3)。MNIST 28×28×1, ImageNet 224×224×3, 4K 3840×2160×3。
**提示**: 像素 = 0-255 或 0-1 数值。
**来源**: 01.图像基础 §定义

## 卡片 2（🟢 公式）2D 卷积公式

**Q**: 2D 卷积数学定义?
**A**: $(I * K)[i, j] = \sum_{m=0}^{k-1} \sum_{n=0}^{k-1} I[i+m, j+n] \cdot K[m, n]$
输出尺寸: $O = \lfloor (I - K + 2P) / S \rfloor + 1$ (P padding, S stride)
**提示**: 互相关 cross-correlation, 工程上等价卷积。
**来源**: 01.图像基础 §公式

---

## 卡片 3（🟢 公式）池化

**Q**: 2×2 max pooling 数学?
**A**: $P[i, j] = \max_{(m, n) \in [0,2)^2} I[2i+m, 2j+n]$
**例子**: 4×4 输入, stride 2 → 2×2 输出, 每值 = 对应 2×2 块最大值
**提示**: max pool 默认; avg pool 平滑; global avg pool 整图一个值
**来源**: 01.图像基础 §公式

---

## 卡片 4（🟡 公式）批归一化 BN

**Q**: BN 公式?
**A**: $\hat x_i = (x_i - \mu_B) / \sqrt{\sigma_B^2 + \epsilon}$, $y_i = \gamma \hat x_i + \beta$
$\mu_B, \sigma_B^2$ 小批均值/方差; $\gamma, \beta$ 可学习; $\epsilon = 10^{-5}$ 防除零
**提示**: 训练用 batch 统计, 推理用全局滑动平均
**来源**: 01.图像基础 §公式

## 卡片 5（🟢 反例）深度=参数更多?

**Q**: 152 层的 ResNet-152 一定比 22 层的 GoogLeNet 参数多吗? 准确率呢?
**A**: 参数确实多得多: ResNet-152 约 60.2M (6020 万), GoogLeNet 仅 680 万 (6.8M), 前者约 9 倍; 但 ResNet-152 top-5 错误率 3.57% vs GoogLeNet 6.7%, 深 130 层反而更准。**关键是残差连接**: 无残差时 50 层网络训练准确率可能仅 50%, 深度反成负担。
**提示**: 层数与参数量不成正比, 残差才是深度可训练的前提。
**来源**: 02.卷积网络 §反例

## 卡片 6（🟢 公式）3×3 vs 5×5 参数对比

**Q**: 5×5 卷积 (64→64) 参数量 vs 两个 3×3 堆叠?
**A**: 5×5: $5 \times 5 \times 64 \times 64 = 102,400$
两个 3×3: $2 \times 3 \times 3 \times 64 \times 64 = 73,728$
节省 28% 参数 + 多 1 个 ReLU
**提示**: VGG-16 全部用 3×3
**来源**: 02.卷积网络 §公式

## 卡片 7（🟢 定义）ResNet 残差块

**Q**: 残差块数学?
**A**: $y = \mathcal{F}(x, \{W_i\}) + x$, $\mathcal{F}$ 残差映射
- 让网络学 $\mathcal{F}(x) = H(x) - x$, 输出 $F(x) + x$
- 梯度直接通过恒等路径反传
**提示**: 当维度不匹配, 用 $W_s x$ 投影
**来源**: 02.卷积网络 §定义

人类水平 5.1%, **2015 ResNet 首次超越**
**提示**: 6 年暴跌 25 个百分点
**来源**: 02.卷积网络 §数字

## 卡片 9（🟡 定义）IoU 交并比

**Q**: 两个边界框 IoU 公式?
**A**: $\text{IoU}(A, B) = \dfrac{|A \cap B|}{|A \cup B|} = \dfrac{|A \cap B|}{|A| + |B| - |A \cap B|}$
- $\in [0, 1]$, 1 = 完全重合
- 训练: 阈值 > 0.5 算 TP, < 0.5 算 FN
**提示**: NMS 用 IoU > 0.5 抑制重叠框
**来源**: 03.目标检测与分割 §定义

---

## 卡片 10（🟡 定义）mAP 计算

**Q**: mAP 平均精度均值?
**A**: AP = 按置信度排序所有预测, 计算每个 recall 下的最大 precision, 积分得 AP
mAP = 所有类 AP 的平均
mAP@0.5 (IoU ≥ 0.5 算) vs mAP@0.5:0.95 (IoU 0.5-0.95 平均, 更严格)
**提示**: COCO 标准 0.5:0.95
**来源**: 03.目标检测与分割 §定义

---

## 卡片 11（🟡 公式）YOLOv8 损失

**Q**: YOLOv8 损失 3 部分?
**A**: $L = L_{\text{cls}} + L_{\text{box}} + L_{\text{mask}}$
- $L_{\text{cls}}$ 分类 (focal loss)
- $L_{\text{box}}$ 框回归 (CIoU loss)
- $L_{\text{mask}}$ 分布焦点损失 (DFL)
**提示**: anchor-free 直接预测中心点 + 宽高
**来源**: 03.目标检测与分割 §公式

## 卡片 12（🟡 反例）准确率当检测指标?

**Q**: 报"准确率 90%"代替 mAP 检测?
**A**: 错! 准确率掩盖漏检, **必须报 mAP**。检测输出 100 框, 实际 20 物体, mAP 综合衡量前 N 框里真物体比例。
**提示**: 准确率 vs mAP 是不同指标
**来源**: 03.目标检测与分割 §反例

YOLOv8x (68M): COCO mAP 53.9
**提示**: 精度换速度: nano 比 xlarge 快数倍, mAP 低约 17 个百分点 (37.3 vs 53.9)
**来源**: 03.目标检测与分割 §数字

## 卡片 14（🟢 公式）Dice 系数

**Q**: Dice 系数公式?
**A**: $\text{Dice} = \dfrac{2|P \cap G|}{|P| + |G|} = \dfrac{2 \sum p_i g_i}{\sum p_i + \sum g_i}$, $L_{\text{Dice}} = 1 - \text{Dice}$
- 类别不平衡稳定 (vs IoU)
- 解决肿瘤/小目标
**提示**: Dice 比 IoU 公式分母多 1 倍
**来源**: 03.目标检测与分割 §公式

---

## 卡片 15（🟡 公式）IoU 转 Dice

**Q**: IoU 0.5 对应 Dice 多少?
**A**: $\text{Dice} = \frac{2 \cdot \text{IoU}}{1 + \text{IoU}} = \frac{2 \times 0.5}{1.5} \approx 0.67$
反之 Dice = 0.8 → IoU = 0.67
**提示**: Dice 永远 ≥ IoU, 在小目标上更稳定
**来源**: 03.目标检测与分割 §公式

## 卡片 17（🟡 定义）Mask R-CNN

**Q**: Mask R-CNN 架构?
**A**: Backbone ResNet-101 + FPN → RPN 候选框 → 检测头 (类别+框) + **Mask 头 (14×14 RoIAlign → 28×28 二值掩码)**
$L = L_{\text{cls}} + L_{\text{box}} + L_{\text{mask}}$
**提示**: COCO 37.1 mAP (2017 实例分割 SOTA)
**来源**: 03.目标检测与分割 §定义

**A**: ISBI 细胞追踪 2015 错误率 3% (vs SOTA 25%)
**提示**: 跳跃连接 concat 让浅层位置细节传回解码器

## 卡片 19（🟡 公式）ViT Patch 切分

**Q**: ViT 如何把图像当 token?
**A**: $H \times W$ 图像切成 $N$ 个 $P \times P$ patch, $N = HW/P^2$
- $P=16, H=W=224 \Rightarrow N = 196$ tokens
- 加 [class] token + 位置编码, 送入 Transformer Encoder
**提示**: patch 展平 + Linear Projection 当 token embedding (等价 stride=P 卷积)
**来源**: 04.视觉 Transformer 与生成 §公式

## 卡片 20（🟡 数字）ViT 性能

**Q**: ViT 在 ImageNet 超越 CNN 的成绩归哪个型号?
**A**: **ViT-H/14 (632M 参数) 经 JFT-300M 预训练**后 ImageNet top-1 达 88.55%, 超越 BiT 88.0%; 不是 ViT-L/16 (304M) 的成绩。ViT-B/16 为 86M 参数。
**提示**: 型号-数据-成绩三者一起记: 反超 CNN 的前提是超大数据预训练 (2021)。
**来源**: 04.视觉 Transformer 与生成 §数字

## 卡片 21（🟡 公式）CLIP 对比损失

**Q**: CLIP 损失?
**A**: $\mathcal{L} = -\dfrac{1}{N} \sum_i \log \dfrac{\exp(\text{sim}(I_i, T_i)/\tau)}{\sum_j \exp(\text{sim}(I_i, T_j)/\tau)}$
- 图像-文本对 (4 亿对)
- $\tau$ 温度参数, 对角线为正样本
**提示**: 对比学习, 拉近正样本对推远负样本
**来源**: 04.视觉 Transformer 与生成 §公式

---

## 卡片 22（🟡 反例）CLIP 是图像模型?

**Q**: CLIP 是图像模型?
**A**: 错! CLIP 是**文本-图像联合表征**模型, **核心是 zero-shot 迁移** (用文本 prompt 引导分类), 不是传统图像分类。
**提示**: 联合 embedding 空间
**来源**: 04.视觉 Transformer 与生成 §反例

---

## 卡片 23（🟡 公式）CLIP zero-shot 流程

**Q**: CLIP zero-shot 推理流程?
**A**: 给定测试图 $I$, 编码 $f_I(I)$
对 $K$ 类名 prompt $T_k$ 编码 $f_T(T_k)$
预测 $\hat y = \arg\max_k \text{sim}(f_I(I), f_T(T_k))$
**提示**: 0 训练样本, 仅靠文本 prompt
**来源**: 04.视觉 Transformer 与生成 §公式

**Q**: DETR 与 YOLO 区别?

## 卡片 26（🟢 定义）颜色空间三兄弟

**Q**: HSV / YCbCr / LAB 各适合什么任务?
**A**: HSV 把色相与亮度分开, 颜色分割只需阈值化色相; YCbCr 分亮度 Y 与色度 Cb/Cr, 人眼对色度不敏感可子采样, 是 JPEG/视频编码基础; LAB 的数值距离对应人眼感知差异, 用于感知均匀的颜色比较。
**提示**: RGB 适合采集显示, 处理任务按需换空间。
**来源**: 01.图像基础 §定义

## 卡片 27（🟢 定义）针孔相机模型

**Q**: 三维点如何投影到像素?
**A**: 针孔模型下世界点 $(X,Y,Z)$ 先经外参 (旋转 $R$ + 平移 $t$) 变相机坐标, 再按焦距 $f$ 透视投影到像素平面; 外参描述相机位姿, 内参 (焦距/主点) 描述成像几何。
**提示**: 双目视觉与 SLAM 的几何都建在这一投影上。
**来源**: 01.图像基础 §定义

## 卡片 28（🟡 反例）中值滤波 vs 均值滤波

**Q**: 椒盐噪声该用哪种滤波?
**A**: 中值滤波: 取邻域中位数替换像素, 对离群黑白点稳健且保住边缘; 均值滤波会把噪声摊平成模糊。高斯滤波按距离加权, 适合高斯噪声而非椒盐。
**提示**: 噪声类型决定滤波器, 不是一个高斯走天下。
**来源**: 01.图像基础 §反例

## 卡片 29（🟡 定义）Canny 边缘检测四步

**Q**: Canny 流程?
**A**: ①高斯模糊去噪 ②Sobel 算梯度幅值与方向 ③非极大值抑制细化边缘 ④双阈值 + 滞后连接 (强边缘保留, 与之相连的弱边缘保留)。
**提示**: 输出单像素宽边缘, 经典视觉流水线标准答案。
**来源**: 01.图像基础 §定义

## 卡片 30（🟡 公式）Harris 角点检测

**Q**: Harris 角点响应函数?
**A**: 结构张量 $M=\sum W\begin{pmatrix}I_x^2 & I_xI_y\\ I_xI_y & I_y^2\end{pmatrix}$: 两特征值都大=角点, 一大一小=边缘, 都小=平坦; 响应 $R=\det(M)-k\cdot\text{trace}(M)^2$, $k$ 常取 0.04-0.06, $R$ 显著为正即角点。
**提示**: 不用显式算特征值, 一个标量 $R$ 搞定。
**来源**: 01.图像基础 §公式

## 卡片 31（🟢 数字）LeNet 与 AlexNet

**Q**: 两个里程碑的参数量与创新?
**A**: LeNet-5 (1998) 两卷积 + 三全连接, 仅 6 万参数, 证明学出的滤波器胜过手工特征; AlexNet (2012) 五卷积 + 三全连接, 6000 万参数, 靠 ReLU + Dropout + 数据增强 + GPU 拿下 ImageNet。
**提示**: 14 年间参数量涨千倍, 深度学习由 GPU 引爆。
**来源**: 02.卷积网络 §数字

## 卡片 32（🟡 公式）VGG 3×3 堆叠

**Q**: 为何两个 3×3 替代一个 5×5?
**A**: 感受野相同 (两层 3×3 覆盖 5×5), 参数 $2\times3^2=18$ 对 $5^2=25$ 省 28%, 还多一次 ReLU 非线性; VGG-16 全用 3×3, 共 1.38 亿参数。
**提示**: 小核堆叠是 VGG 留给后世的设计范式。
**来源**: 02.卷积网络 §公式

## 卡片 33（🟢 定义）Inception 与 1×1 瓶颈

**Q**: GoogLeNet 如何以小博大?
**A**: Inception 模块把 1×1/3×3/5×5 卷积并行再拼接, 让网络自选尺度; 大核前先用 1×1 卷积降通道 (瓶颈) 削计算。22 层仅 680 万参数, 比 VGG 的 1.38 亿少约 12 倍且准确率更高。
**提示**: 1×1 卷积 = 跨通道融合 + 降维利器。
**来源**: 02.卷积网络 §定义

---

## 卡片 34（🟡 定义）ResNet 瓶颈块

**Q**: ResNet-50 及以上为何用瓶颈块?
**A**: 三层卷积: 1×1 缩通道 → 3×3 空间处理 → 1×1 扩回, 比两层 3×3 便宜且支持更深网络; 残差维度不匹配时用 $W_s x$ 投影。ResNet-152 达 60.2M 参数、top-5 错误率 3.57%。
**提示**: 残差连接解决退化问题, 瓶颈结构解决算力问题。
**来源**: 02.卷积网络 §定义

---

## 卡片 35（🟡 公式）深度可分离卷积

**Q**: MobileNet 省多少计算?
**A**: 标准卷积 $k^2 C_{\text{in}} C_{\text{out}}$; 拆成逐通道深度卷积 $k^2 C_{\text{in}}$ + 1×1 逐点卷积 $C_{\text{in}}C_{\text{out}}$, 3×3 时约省 9 倍。MobileNet-V2 再加倒残差块: 先扩通道再深度卷积再投影, 扩张比常取 6。
**提示**: 移动端 CNN 的标准件。
**来源**: 02.卷积网络 §公式

---

## 卡片 36（🟡 公式）EfficientNet 复合缩放

**Q**: 复合缩放怎么配?
**A**: 深度/宽度/分辨率按同一系数 $\phi$ 一起放: $\text{depth}=\alpha^\phi$, $\text{width}=\beta^\phi$, $\text{res}=\gamma^\phi$, 约束 $\alpha\cdot\beta^2\cdot\gamma^2\approx 2$; 网格搜索得 $\alpha=1.2,\beta=1.1,\gamma=1.15$, $\phi$ 每加 1 FLOPs 约翻倍, B0-B7 依次放大。
**提示**: 单缩宽度或深度都会边际递减, 三维同缩才最优。
**来源**: 02.卷积网络 §公式

---

## 卡片 37（🟡 定义）锚框 anchor box

**Q**: RPN 每个位置预测几个锚框?
**A**: 3 尺度 × 3 长宽比 = 9 个锚框/位置; 网络对每个锚框出物体性分数 + 坐标偏移量 (宽高取对数保证为正), 回归只在合理起点框上做小幅调整, 不预测绝对坐标。
**提示**: anchor-based 的超参主要就是尺度与长宽比。
**来源**: 03.目标检测与分割 §定义

## 卡片 38（🟡 数字）R-CNN 家族演进

**Q**: 两阶段检测器如何一步步加速?
**A**: R-CNN (2014) 选择性搜索约 2000 候选, 每个单独跑 CNN, 极慢; Fast R-CNN 整图只跑一次 CNN + RoI 池化共享特征; Faster R-CNN 用 RPN 直接在特征图上出候选, 候选生成并入 GPU 端到端。
**提示**: 主线是把重复 CNN 计算一步步共享掉。
**来源**: 03.目标检测与分割 §数字

## 卡片 39（🟢 定义）非极大值抑制 NMS

**Q**: NMS 做什么?
**A**: 同一物体常出多个重叠框; NMS 按类别独立执行: 留置信度最高的框, 把与它 IoU 超阈值 (常 0.5) 的其他框丢弃, 迭代至全部处理完。
**提示**: NMS 是后处理, 不参与梯度训练。
**来源**: 03.目标检测与分割 §定义

---

## 卡片 40（🟡 反例）RetinaNet 与 focal loss

**Q**: 单阶段检测器为何被背景样本淹没?
**A**: 绝大多数锚框对应背景, 简单负样本占满损失梯度; RetinaNet 用 focal loss $\text{FL}(p_t)=-\alpha_t(1-p_t)^\gamma\log p_t$, $\gamma=2$ 时易分负样本权重被压到 0.01, 让稀有正样本主导梯度。
**提示**: $\gamma=0$ 即退回普通交叉熵。
**来源**: 03.目标检测与分割 §反例

## 卡片 41（🟢 定义）分割三类 + COCO 规模

**Q**: 语义/实例/全景分割区别? COCO 多大?
**A**: 语义分割每像素一个类 (两辆车同标签); 实例分割每个物体出独立掩码; 全景分割合一, stuff (天空/道路) 只给语义、thing (车/人) 给实例 ID。COCO 全量约 33 万图、150 万实例、80 类; 常用 train2017 切分 11.8 万张, 两个口径别混。
**提示**: 检测输出框, 分割输出像素级标签图。
**来源**: 03.目标检测与分割 §定义

## 卡片 42（🟡 定义）DeiT 知识蒸馏

**Q**: DeiT 怎么不用 JFT 也能训好 ViT?
**A**: 强数据增强 + 随机深度/标签平滑/Dropout, 再加知识蒸馏: 预训练 CNN 老师出软标签, ViT 学生在 [ CLS] token 之外加蒸馏 token 专门拟合老师, 仅 ImageNet 即可训练。
**提示**: 蒸馏把大数据需求替换成一个老师网络。
**来源**: 04.视觉 Transformer 与生成 §定义

## 卡片 43（🟡 公式）Swin 窗口注意力

**Q**: Swin 如何把注意力代价降到线性?
**A**: 不做全局 $O(N^2)$ 注意力, 只在局部窗口 (如 7×7 patch) 内自注意力; 相邻层窗口错开半个窗宽, 建立跨窗连接; 再经 patch 合并构造层次化特征图, 可直接接 Faster R-CNN/U-Net 检测分割头。
**提示**: ViT 治平方开销, Swin 同时治层次结构缺失。
**来源**: 04.视觉 Transformer 与生成 §公式

## 卡片 44（🟡 定义）自监督视觉四剑客

**Q**: SimCLR / MoCo / BYOL / DINO 区别?
**A**: SimCLR 同图两增强视图 + NT-Xent 损失, 依赖大 batch; MoCo 用动量队列存负样本, 键编码器 EMA 更新 ($m=0.999$), 不依赖大 batch; BYOL 去掉负样本, 在线网预测 EMA 目标网输出; DINO 把自蒸馏用到 ViT, 无分割监督注意力图却自动分出物体。
**提示**: DINOv2 扩到 1B 参数/1.42 亿图, DINOv3 (2025-08) 到 7B/约 17 亿图。
**来源**: 04.视觉 Transformer 与生成 §定义

## 卡片 45（🟡 定义）MAE 掩码自编码

**Q**: MAE 为何预训练省 4 倍计算?
**A**: 随机遮住 75% 的 patch, 编码器只处理可见 patch, 轻量解码器结合可学习掩码 token 重建全图像素; BEiT 同族但预测 dVAE 离散视觉 token 而非像素, 对应 BERT 的 MLM。
**提示**: 高掩码率可行是因为图像空间冗余远高于文本。
**来源**: 04.视觉 Transformer 与生成 §定义

## 卡片 46（🟡 公式）扩散模型与流匹配

**Q**: DDPM 与流匹配路线差在哪?
**A**: DDPM 走随机 SDE: 前向 $T=1000$ 步逐步加高斯噪 ($\beta$ 从 $10^{-4}$ 线性升到 0.02), 反向网络预测噪声 $\epsilon_\theta$, DDIM 确定性采样可压到 50 步; 流匹配直接回归确定性 ODE 速度场, 5-20 步即可采样, Stable Diffusion 3 / Flux 已换此路线。
**提示**: 潜扩散先用 VAE 把图下采样 8 倍, 再在潜空间去噪。
**来源**: 04.视觉 Transformer 与生成 §公式

## 卡片 47（🟡 公式）光流约束与 Lucas-Kanade

**Q**: 光流约束方程是什么? LK 怎么解?
**A**: 亮度恒定假设给出 $I_x u + I_y v + I_t = 0$, 一个方程两个未知数 $(u,v)$; Lucas-Kanade 假设小窗口 (如 5×5) 内光流恒定, 25 个方程超定, 最小二乘求解。深度学习 RAFT (2020) 用 4D 相关体积 + GRU 迭代精修, 至今是标准光流骨干。
**提示**: 光流是像素级 2D 位移场, 不是目标框。
**来源**: 05.视频与 3D 视觉 §公式

## 卡片 48（🟢 定义）视频理解三条路线

**Q**: 双流 / 3D 卷积 / TimeSformer 各自思路?
**A**: 双流网络把 RGB 帧 (外观) 与光流栈 (运动) 两路末端融合; 3D 卷积 (C3D/I3D) 把滤波器扩到时间维, I3D 从 2D 预训练权重 "膨胀" 初始化; TimeSformer 把时空注意力拆成时间注意力 + 空间注意力轮流做, 复杂度 $O(T^2N^2)\to O(T^2+N^2)$。VideoMAE 借视频时间冗余用 90-95% 掩码率做自监督。
**提示**: Kinetics-400 是动作识别标准基准 (400 类、约 30 万段视频)。
**来源**: 05.视频与 3D 视觉 §定义

## 卡片 49（🟡 定义）多目标跟踪 SORT 系

**Q**: SORT / DeepSORT / ByteTrack 怎么跟踪?
**A**: SORT = 逐帧检测 + 卡尔曼滤波 (线性运动预测) + 匈牙利算法 (IoU 代价一对一匹配); DeepSORT 加 CNN 外观嵌入, 遮挡后靠余弦距离重识别; ByteTrack 不丢弃低置信度检测, 先匹配高置信轨迹再救低置信目标, 找回模糊遮挡物体。
**提示**: 跟踪 = 检测 + 数据关联, 不是另起炉灶。
**来源**: 05.视频与 3D 视觉 §定义

## 卡片 50（🟡 数字）3D 视觉三件套

**Q**: 双目 / NeRF / 3DGS 的核心数字?
**A**: 双目深度 $z=fb/d$, 视差 $d$ 与深度反比, 立体匹配退化为沿水平扫描线的一维搜索; NeRF 用 MLP 学 5D 辐射场, 每条射线采样上百点做体渲染, 单场景训练数小时; 3D 高斯泼溅光栅化可达 100+ FPS, 质量追平 NeRF 且实时。AR/VR 要求双眼 90+ FPS、端到端延迟低于 20 ms。
**提示**: NeRF 慢在每条射线上百万次 MLP 求值。
**来源**: 05.视频与 3D 视觉 §数字
