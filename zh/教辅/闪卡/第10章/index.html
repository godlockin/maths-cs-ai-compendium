    Ch10 多模态学习 · 闪卡 (Anki 导出格式)¶

    使用方式: 复制到 Anki -> 字段 1 = front, 字段 2 = back, 字段 3 (notes) = 自定义注释。 大约 100 张卡,涵盖 5 节核心概念、关键术语、公式、典型代码片段。 推荐创建 Deck: Ch10 多模态学习

    Section A: 基础概念卡¶

    Card 1¶

    Front: 什么是多模态学习 (Multimodal Learning)? Back: 把不同模态 (vision, language, audio, video, structured data) 的数据组合起来,学到比单模态更丰富、更鲁棒的表征。例如 CLIP 把图像和文本投影到共享 256 维空间,实现图文检索和零样本分类。 Notes: Ch10 §01 核心定义

    Card 2¶

    Front: 模态 (Modality) 在机器学习中指什么? Back: 一种独立的信息通道。最常见: 图像 (像素网格)、文本 (token 序列)、音频 (波形/频谱)、视频 (帧序列)、结构化数据 (表格/图)。 Notes: 多模态 ≠ 多任务;模态侧重数据形式

    Card 3¶

    Front: 早期融合 (Early Fusion) vs 晚期融合 (Late Fusion)? Back: - 早期: 不同模态原始/低层特征直接拼接 $x_{\text{fused}} = [x_{\text{img}}; x_{\text{txt}}]$,优点细粒度交互,缺点维度大、需学对齐 - 晚期: 各模态独立编码 → 末期分数融合 $\hat y = \alpha\hat y_1 + (1-\alpha)\hat y_2$,优点可复用单模态预训练,缺点学不到低层交互 - 中层 (主流): Q-Former / cross-attention 在中层交互 Notes: Tradeoff: 表达力 vs 训练成本

    Card 4¶

    Front: 跨模态注意力 (Cross-modal Attention) 的 Q/K/V 各来自哪个模态? Back: 取决于任务: - 图生文 (captioning): Q=文本(解码器), K/V=图像 - 文生图 (diffusion): Q=latent, K=文本, V=文本 - VQA: Q=文本, K/V=视觉;或 Q=视觉, K/V=文本 - 一般: Q 来自目标模态 (要生成的), K/V 来自条件模态 Notes: Transformer cross-attn 的本质

    Card 5¶

    Front: 列出 3 种主流多模态融合时间点策略的缺点各 1 条。 Back: 1. Early: 输入维度爆炸,VLM 中拼接到 LLM 上下文长度超限 2. Late: 学不到低层跨模态信号;下游任务剪枝有损 3. Middle (Q-Former): 引入了 lossy compression,可能丢失细节 Notes: 实际工程中混合策略

    Section B: CLIP & 对比学习¶

    Card 6¶

    Front: CLIP 是如何训练的? Back: 在大规模 batch (N=32768) 的图文对: 1. 图像经 ViT-L 编码 → 256 维 (投影后) 2. 文本经 Transformer 编码 → 256 维 3. 在 N×N 相似度矩阵上,对角线为正例,其他为负例 4. 对称 InfoNCE 损失 (双向),Adam, lr=5e-4, 32 epoch 数据集 WIT-400M (WebImageText, 4 亿图文对)。 Notes: OpenAI, Radford et al., ICML 2021

    Card 7¶

    Front: InfoNCE 损失公式? Back: $\(L_i = -\log \frac{\exp(s(z_i, z_i^+)/\tau)}{\sum_{j=1}^N \exp(s(z_i, z_j)/\tau)}\)$ 其中 \(s\) 是余弦相似度,\(\tau\) 是温度参数 (CLIP 默认 0.07)。 Notes: 双向 = 文本侧同样计算

    Card 8¶

    Front: τ (温度参数) 在 InfoNCE 中的作用? Back: - τ 越小 → 分布越尖 → 训练越难但学到的表征越细粒度 - τ 越大 → 越均匀 → 训练稳但表征粗糙 - CLIP τ=0.07 偏小;ALIGN (Google) 用 τ=1/100 ≈ 0.01 Notes: 超敏感超参;SigLIP 用 sigmoid 损失消除 τ

    Card 9¶

    Front: CLIP 零样本分类怎么做? Back: 给定类别集 {猫, 狗, 鸟...}: 1. 构造 prompt: "a photo of a {class}" 模板 (如"一只{class}") 2. 文本编码器得每个类的嵌入 \(T_y\) 3. 图像编码器得图片嵌入 \(z_v\) 4. \(\hat y = \arg\max_y \cos(z_v, T_y)\) ImageNet 76.2% 准确率(ResNet-50 baseline 是 76.0% 监督训练)。 Notes: prompt 工程可提升到 80%+

    Card 10¶

    Front: SigLIP 是怎么改进 CLIP 的? Back: 用 sigmoid 损失取代 softmax: - 不需要 N² 关系矩阵 - 每对图文独立打分 - 允许小 batch(几千) 也能稳定 - 性能与 CLIP 相当,效率高 10x Notes: Google 2023, Zhai et al.

    Card 11¶

    Front: 图文检索 (Image-Text Retrieval) 的 Recall@k 指标? Back: 给定图片,模型在 N 张文本中选最匹配;前 k 个有正确答案的比例。 - MS-COCO 5K 测试集 R@1: CLIP ≈ 65%, SigLIP ≈ 70%, Florence-2 ≈ 78% - R@5 / R@10 更高 Notes: Recall 越高表示检索越准

    Card 12¶

    Front: 负样本 (Negative Samples) 数量如何影响 InfoNCE? Back: 负样本越多,模型学到的"区分"越细粒度。 - N=128 → ImageNet ≈ 60% - N=8192 → ≈ 75% - N=32768 → ≈ 76.2% 边际收益递减,所以 SigLIP 用 sigmoid 损失在小 batch 即可模拟。 Notes: CLIP 训练一次需要数百块 GPU

    Section C: VLM 视觉语言模型¶

    Card 13¶

    Front: VLM (Vision-Language Model) 与 CLIP 的核心区别? Back: - CLIP: 双编码器,只学对齐,不生成 - VLM: 把视觉信息融合进 LLM,可对话、可生成、可推理 Notes: VLM = CLIP + 生成能力

    Card 14¶

    Front: LLaVA 如何把视觉信息接入 LLM? Back: 1. ViT 编码图像 → patch embeddings (e.g., 256 tokens × 1024 维) 2. 线性投影 \(W \in \mathbb{R}^{1024 \times d_{\text{LLM}}}\) 把每 patch 降到 LLM 维度 3. 作为 "image token" 拼到 prompt 中 4. LLM 正常处理,生成文字回应 Notes: 简单粗暴但有效

    Card 15¶

    Front: Q-Former (BLIP-2 关键组件) 的工作原理? Back: - 32 个 learnable query tokens (Q) - Cross-attention Q 与 ViT 输出 (K, V) - 三任务训练:ITC (对比) + ITM (匹配) + ITG (生成) - 输出 32×768 压缩表达到 LLM Notes: Salesforce 2023

    Card 16¶

    Front: 视觉指令微调 (Visual Instruction Tuning) 的工作流? Back: 1. 用 GPT-4V 当 oracle,基于图像生成 (Q, A) 对 (e.g., 158K 样本) 2. 这些 instruction-following 数据微调 LLaVA (Vicuna) 3. 学到 "看图回答问题" 能力 Notes: Liu et al., NeurIPS 2023

    Card 17¶

    Front: Qwen-VL 多阶段训练的三阶段? Back: 1. 阶段 1: 视觉编码器 + Q-Former + LLM 解冻,数据集图文对 1.4B, 训对齐 2. 阶段 2: LLM 解冻,Q-Former 冻结,多任务微调 3. 阶段 3: 解冻所有,指令微调 + RLHF Notes: 阿里达摩院 2023

    Card 18¶

    Front: VQA (Visual Question Answering) 任务的准确率? Back: - VQAv2 test-dev 标准: 闭集 4 选项,人类 ≈ 95%,LLaVA-1.5 ≈ 80% - OK-VQA 开放问答: GPT-4V ≈ 60%,LLaVA-1.5 ≈ 50% Notes: VQA 准确率随模型 scale 提升

    Section D: VQ-VAE 视觉分词¶

    Card 19¶

    Front: VQ-VAE 的三大组件及作用? Back: 1. 编码器 \(E\): 图像 \(x\) → 连续特征 \(z_e \in \mathbb{R}^{h \times w \times d}\) 2. 量化器: 把 \(z_e\) 在 codebook \(\mathcal{C}\) 中找最近邻 → 离散 \(z_q\) 3. 解码器 \(D\): 把 \(z_q\) 重建成 \(\hat x\) Notes: 关键创新: 用离散 token 当下游任务输入

    Card 20¶

    Front: VQ 量化的数学表达? Back: $\(z_q = z_k, \quad k = \arg\min_{j \in [1..K]} \|z_e - z_j\|_2\)$ codebook \(\mathcal{C} = \{z_1, ..., z_K\}\),通常 \(K=8192\),每个 \(z_k \in \mathbb{R}^d\)。 Notes: 最近邻查找,代码 index 而非连续向量

    Card 21¶

    Front: Codebook Collapse 是什么?怎么防? Back: - 症状: 部分 codebook entry 永远不被选中(利用率低) - 原因: 训练初期对某 entry 偏好,Adam 把它和编码器一起"训死" - 缓解: 1. EMA 更新 codebook(不让梯度直接动) 2. Code 重启:长期不用的 entry 重置为当前 batch 的 \(z_e\) 3. Gumbel-Softmax:加 noise 增加随机性 Notes: 是 VQ 训练最常见坑

    Card 22¶

    Front: 直通估计 (Straight-Through Estimator, STE) 在 VQ 中怎么用? Back: - 量化操作 \(\arg\min\) 不可微,反向梯度被截断 - STE hack: 前向用 \(z_q\),反向时把梯度原样代理给 \(z_e\) $\(\frac{\partial L}{\partial z_e} \approx \frac{\partial L}{\partial z_q}\)$ Notes: 简单粗暴但有效

    Card 23¶

    Front: VQ-GAN 损失的组成部分? Back: $\(L = \underbrace{\|x - \hat x\|_1}_{\text{重建}} + \lambda_1 \underbrace{\|F(x) - F(\hat x)\|_1}_{\text{感知}} + \lambda_2 \underbrace{\|z_e - \text{sg}[z_q]\|_2^2}_{\text{commit}} + \underbrace{L_{\text{GAN}}}_{\text{对抗}}\)$ 分别保证像素相似、感知相似、codebook 用上、视觉真实。 Notes: VQ-VAE + PatchGAN 判别器

    Card 24¶

    Front: DALL-E dVAE 把 256×256 图变成多少 token? Back: - 256×256×3 → 经 dVAE 编码 → 32×32=1024 个 latent - 量化到 8192 个 codebook entry - 最终 1024 个 token 进入 transformer 训练 Notes: 把图像像文字一样喂给 GPT

    Card 25¶

    Front: VAR (Visual AutoRegressive) 与扩散模型相比的差异? Back: - 传统扩散: 在 latent 加噪 → 学去噪 - VAR: next-scale prediction,从低分辨率到高分辨率逐级自回归 - VAR 更像 LLM 自回归 (类比文字 token) - ImageNet 256 FID: VAR ≈ 1.0,SD 2.1 ≈ 8 Notes: 字节跳动 + 北大, NeurIPS 2024

    Section E: 跨模态生成 (Stable Diffusion)¶

    Card 26¶

    Front: Stable Diffusion 为什么叫 "Stable"?相比 DDPM 改进? Back: - DDPM: 像素空间扩散 (256×256×3),千步迭代慢 - LD (Latent Diffusion): 加 VAE 把图像压到 latent 4×64×64,扩散在 latent 跑 - 速度提升 ~50x Notes: Stability AI + LMU Munich, CVPR 2022

    Card 27¶

    Front: 扩散前向公式? Back: $\(x_t = \sqrt{\bar\alpha_t} x_0 + \sqrt{1 - \bar\alpha_t} \epsilon, \quad \bar\alpha_t = \prod_{s=1}^t \alpha_s\)$ 其中 \(\epsilon \sim \mathcal{N}(0, I)\),\(\alpha_t\) 是超参 schedule,通常 1000 步。 Notes: 方差递增地加噪

    Card 28¶

    Front: 扩散训练损失是什么? Back: $\(L_{\text{simple}} = \mathbb{E}_{t, x_0, \epsilon, c} \left[\|\epsilon - \epsilon_\theta(x_t, t, c)\|^2\right]\)$ 预测噪声 \(\epsilon\),c 是条件(文本嵌入)。L1 也用但 L2 更稳。 Notes: 训练时随机采 t

    Card 29¶

    Front: CFG (Classifier-Free Guidance) 公式? Back: $\(\hat\epsilon = (1 + w) \epsilon_\theta(x_t, t, c) - w \epsilon_\theta(x_t, t, \emptyset)\)$ - \(c\)=条件嵌入 - \(\emptyset\)=无条件 (空文本或 null token) - w=7.5 对齐最强,多样性下降 - w=1 退化为普通条件生成 Notes: 没有 classifier, 所以叫 classifier-free

    Card 30¶

    Front: Stable Diffusion UNet 中 文本如何注入? Back: - 文本经 CLIP ViT-L/14 → 77×768 嵌入 - UNet 每个 spatial block 加 cross-attention 层: - Q: latent feature (256×256×4 flatten) - K, V: 文本嵌入 - 文本经多层 cross-attn 注入到所有分辨率层 Notes: cross-attn 是文生图的核心机制

    Card 31¶

    Front: Stable Diffusion 推理从噪声到图像的步骤? Back: 1. \(x_T \sim \mathcal{N}(0, I)\) 采纯噪声 2. 循环 \(t = T, T-1, ..., 1\): - 用 \(\epsilon_\theta(x_t, t, c)\) 预测噪声 - CFG: \(\hat\epsilon = (1+w)\epsilon_c - w\epsilon_\emptyset\) - 用 DDPM/DDIM scheduler 更新 \(x_{t-1}\) 3. VAE 解码 \(x_0 \to\) 像素图像 Notes: 50 步 DDIM 即可生成

    Card 32¶

    Front: DALL-E 3 vs Stable Diffusion 关键差异? Back: - SD: open-source,生图直接用 CLIP 文本嵌入 - DALL-E 3: 用 GPT-4V 重写用户的简短 prompt 成详细描述 (e.g., 用户说"猫",GPT 重写"一只在阳光下的橙色虎斑猫,坐姿警觉...") - 然后用 T5-XXL 编码后给扩散模型 Notes: GPT-4V 重写提升对齐,但 prompt engineering 不灵活

    Card 33¶

    Front: ControlNet 工作原理? Back: 1. 复制 SD UNet 的可训练副本 (zero convolutions 初始权重) 2. 给定空间条件(Canny 边缘、深度图、姿态点) 单独编码 3. 加到 UNet 各层 zero convolutions 输出 → 类似残差 4. 训练时 SD UNet 冻结,副本 + zero conv 训练 Notes: 张吕敏, Lvmin Zhang, 2023

    Card 34¶

    Front: FID (Fréchet Inception Distance) 怎么算? Back: $\(\text{FID} = \|\mu_r - \mu_g\|^2 + \text{Tr}\left(\Sigma_r + \Sigma_g - 2 (\Sigma_r \Sigma_g)^{1/2}\right)\)$ - 用 Inception-v3 提取 2048 维特征 - 真实图和生成图分别算 \(\mu, \Sigma\) - FID 越低越好 Notes: ImageNet 256 ImageNet FID 排行: VAR ≈ 1.0, SD3 ≈ 8, DALL-E 3 ≈ 5.6

    Card 47¶

    Front: VQ-VAE 量化代码 Back: 

    import torch
import torch.nn.functional as F

class VectorQuantizer(torch.nn.Module):
    def __init__(self, num_embeddings=8192, embedding_dim=256):
        super().__init__()
        self.codebook = torch.nn.Embedding(num_embeddings, embedding_dim)

    def forward(self, z_e):
        # z_e: (B, C, H, W) -> (B*H*W, C)
        z_flat = z_e.permute(0, 2, 3, 1).reshape(-1, z_e.shape[1])
        # 距离矩阵
        d = (z_flat.pow(2).sum(-1, keepdim=True)
             - 2 * z_flat @ self.codebook.weight.t()
             + self.codebook.weight.pow(2).sum(-1))
        # 最近邻索引
        idx = d.argmin(-1)
        z_q = self.codebook(idx).view(z_e.shape)
        # 直通估计
        z_q = z_e + (z_q - z_e).detach()
        return z_q, idx
    Notes: VQ-VAE 核心量化代码

    Card 66¶

    Front: 默写 跨模态注意力公式。 Back: $\(\text{Attn}(Q, K, V) = \text{softmax}\left(\frac{Q K^\top}{\sqrt{d_k}}\right) V\)$ Q 来自目标模态,K/V 来自条件模态。\(d_k\) 为 K 维度,用于缩放。 Notes: 这是 VLM 投影/SD cross-attn/GPT-4o 跨模态的统一公式

    Card 67¶

    Front: 默写 VQ 量化公式。 Back: $\(z_q = z_k, \quad k = \arg\min_j \|z_e - z_j\|_2\)$ codebook \(\mathcal{C}=\{z_1,...,z_K\}\)。 Notes: VQ-GAN/VQ-VAE/dVAE/DALL-E 都用

    Front: 默写 InfoNCE 损失。 Back: $\(L_i = -\log\frac{\exp(s(z_i,z_i^+)/\tau)}{\sum_{j=1}^N \exp(s(z_i,z_j)/\tau)}\)$ Notes: CLIP/ALIGN/MOCO/SimCLR 都用

    Section S: 开放题¶

    Card 96¶

    Front: 设计题: 给你 1000 张猫/狗图片和 1000 句 "a photo of a cat/dog",你怎么训一个零样本分类器? Back: 1. 用 CLIP 预训练编码器,冻结 2. 用图文对训一个投影层到 256 维共享空间 (LinearProjection) 3. 推理时算 \(\cos(z_v, z_t)\) 4. 或者: fine-tune CLIP (更慢但更好) Notes: 经典监督学习 vs 对比学习 tradeoff

    Front: 辩论题: 多模态是不是 LLM 的终结? Back: - 反方: LLM 会演化为多模态 (GPT-4o 已经如此) - 正方: 多模态有自己的独立架构和挑战 (实时性、视觉分词等) - 现实: 两者汇流,统一架构可能胜出 Notes: 前沿思考
