## 三 · 简答题 (6 题)

### 16 CNN vs ViT 归纳偏置

- CNN 内置局部连接 + 权重共享 (平移不变), 小数据即可训练。
- ViT 只靠全局自注意力, 无空间先验, 需 JFT-300M 级大数据才超越 CNN; DeiT 用 CNN 蒸馏可仅靠 ImageNet 训好。
- 混合架构 (CoAtNet、EfficientFormer) 组合两者, 是工程主流。

### 17 手算 3×3 卷积

- valid padding 输出尺寸 $(5-3)+1=3$。
- 水平 Sobel 核 $[[-1,0,1]]$ 三行堆叠, 中列权重为 0, 输出中列恒为 0。
- 中心 3×3 亮块的完整响应为 $[[2,0,-2],[3,0,-3],[2,0,-2]]$, 符号标出垂直边缘方向。

### 18 IoU 与 NMS

- NMS 按类别独立执行: 留置信度最高框, 抑制与其 IoU 超阈值 (默认 0.5) 的重叠框。
- 阈值 <0.3 易吞掉相邻物体 (漏检), >0.7 易留重复框。
- NMS 是推理后处理, 不参与梯度训练。

### 19 Dice 为何抗类别不平衡

- BCE 按像素平均, 99% 背景时模型全预测背景即得 99% 准确率, 但 Recall=0。
- Dice $=2|P\cap G|/(|P|+|G|)$ 直接优化重叠度, 10 像素肿瘤与 100 像素正常组织对损失的贡献同尺度。
- 工程上常用 Dice + BCE 联合损失, 兼顾稳定与平衡。

### 20 ViT 为什么需要大数据集

- ViT 没有 CNN 的局部性/平移等变先验, 所有空间关系都要从数据学。
- 纯 ImageNet (约 128 万图) 训 ViT-Base 输给 ResNet-50; ViT-H/14 (632M) 经 JFT-300M (3 亿图) 预训练才达 ImageNet top-1 88.55%, 超 BiT 88.0%。
- 两条出路: 超大数据预训练, 或 DeiT 式 CNN 知识蒸馏。

### 21 YOLOv8 anchor-free vs YOLOv5 anchor-based

- anchor-based (YOLOv5): k-means 聚类预设锚框, 需按数据集调 anchor 尺寸与数量。
- anchor-free (YOLOv8): 直接回归中心点 + 宽高, 省掉锚框超参, 对未见尺寸泛化更好, 精度略升 1-2 个百分点。
- 代价: 中心点热峰回归对标注噪声更敏感; 新项目优先 YOLOv8, 老生态可延续 YOLOv5。

## 四 · 编程题 (4 题)

### 22 5×5 Sobel 卷积

期望输出 (valid, 3×3):

```
tensor([[ 2.,  0., -2.],
        [ 3.,  0., -3.],
        [ 2.,  0., -2.]])
```

核只对左右列差分: 亮块左边缘得正、右边缘得负, 中间行经三行亮块求和幅值最大 (3)。

### 23 YOLOv8n 检测

无固定数值答案 (随图片/权重版本变化)。标准输出为每行一个检出框:

```
cat: 0.92
dog: 0.85
```

conf<0.25 的框已被过滤; 无检测时无输出。考核点: Results → r.boxes → box.cls/box.conf → model.names 的取值链路。

### 24 U-Net + Dice Loss

- `loss` 为 (0,1) 标量, 随机初始化下典型区间 0.5-0.9; 输入随机故无固定值。
- `loss.backward()` 后 `model.enc.weight.grad` 等梯度被填充即链路正确。
- $\epsilon=10^{-6}$ 保证预测与真值同时为空时不除零。

