## 三 · 简答 (6 题)

### 16 三种融合策略
早期融合拼原始特征，细粒度交互强但难对齐异质数据、算力大；晚期融合各模态独立到预测层再组合，简单可复用但缺低层交互；中期融合先各自编码再在中段交叉注意力/投影合并，是 Flamingo/LLaVA 的主流选择，平衡模块化与交互。

### 17 InfoNCE 与大 batch
$(K+1)$ 路分类，正样本相似度（除 τ）压过 $K$ 个负样本；是互信息下界，负样本越多下界越紧。大 batch 提供更多 in-batch 负样本，CLIP 因此用超大批；SigLIP 用逐位 sigmoid 摆脱全局 softmax 的跨设备通信。

### 18 码本坍塌
只有少数条目被反复使用、其余"死掉"。缓解：EMA 更新码本、码本重启/复活、Gumbel-Softmax 软量化；另可加大 commitment β、加量化熵正则。

### 19 SD 推理流程
文本→CLIP/T5 条件嵌入；潜空间采 $x_T\sim\mathcal N(0,I)$；$t{:}T{\to}1$ 用 UNet 预测噪声、CFG 组合 $\hat\epsilon=(1+w)\epsilon_c-w\epsilon_\varnothing$（w≈7.5）、DDPM/DDIM 更新（DDIM 20-50 步）；VAE 解码潜变量回像素。

### 20 三种视觉接入方案
LLaVA 线性/MLP 投影最简单、量化友好但占上下文；Q-Former 32 query 压缩 + 三任务预训练、质量高但重；Perceiver Resampler 64 token + 门控交叉注意力注入冻结 LM、支持交错少样本但训练最复杂。端侧偏好 LLaVA 式投影。

### 21 一致性与音画一体
单张画质已商品化；付费能力转向跨轮/跨镜头角色场景一致（影视电商刚需）与音画同步生成（Veo 3 开创、MiniMax H3 开源接力）。两者都是"统一多模态架构"对"独立扩散工具"的结构性优势；Sora 2 停运说明成本、版权、商业模式同样决定成败。

## 四 · 编程 (2 题)

### 22 对称 InfoNCE
```python
def clip_loss(image_embeds, text_embeds, tau=0.07):
    image_embeds = F.normalize(image_embeds, dim=-1)
    text_embeds = F.normalize(text_embeds, dim=-1)
    logits = image_embeds @ text_embeds.t() / tau
    targets = torch.arange(logits.shape[0], device=logits.device)
    return (F.cross_entropy(logits, targets) + F.cross_entropy(logits.t(), targets)) / 2
```

### 23 视频镜头描述管线
镜头切分（帧间差异/PySceneDetect）→ 关键帧抽取 → VLM 逐镜头描述（Qwen3-VL/InternVL3.5）→ 可选 ASR 合并对白 → 区间-描述列表。2026 年的 Qwen3-VL 支持数小时视频 + 秒级定位，可省去显式切分直接输出带时间戳描述。
