## 三 · 简答 (5 题)

### 3.1 NISQ 时代

**Noisy Intermediate-Scale Quantum**:
- 100-1000 qubits
- 错误率高 (~1e-3)
- 退相干短 (100 μs)
- **实用有限**, 但化学/优化可演示

### 3.2 神经形态优势

| 维度 | 传统 | 神经形态 |
|------|------|----------|
| 功耗 | 100-700W | 0.1-10W |
| 延迟 | ms | μs |
| 稀疏 | 不友好 | 天然 |
| 学习 | 离线 | 在线 STDP |

### 3.3 太空 DC 优势

- **24/7 太阳能**: 1.36 kW/m², 无昼夜
- **真空散热**: -270°C 背景
- **无限土地**: 轨道空间

**挑战**: 抗辐射 + 维修 + 成本 + 通信

### 3.4 联邦学习 3 大挑战

1. **通信**: 大模型频繁同步贵
2. **异构**: 设备能力差异
3. **隐私**: 梯度泄露信息

**解决方案**: 压缩 / 差分隐私 / 加密聚合

### 3.5 BCI 5 大应用

1. 瘫痪患者运动 (Neuralink 2024 实现)
2. ALS 交流
3. 视觉假体 (实验)
4. 听觉增强 (实验)
5. 健康人增强 (10-20 年)

### 4.1 Qiskit 量子电路

```python
from qiskit import QuantumCircuit

qc = QuantumCircuit(2, 2)
qc.h(0)        # Hadamard
qc.cx(0, 1)    # CNOT → Bell state
qc.measure([0, 1], [0, 1])
print(qc.draw())
```

### 4.2 LIF 神经元

```python
class LIFNeuron:
    def __init__(self, tau=20.0, v_th=1.0):
        self.tau = tau
        self.v_th = v_th
        self.v = 0
    
    def step(self, I):
        self.v += (I - self.v) / self.tau
        if self.v >= self.v_th:
            spike = 1
            self.v = 0
        else:
            spike = 0
        return spike
```
