## 三 · 简答 (5 题)

### 3.1 中心极限定理

**答**: 独立同分布随机变量 X₁, X₂, ..., Xₙ, 当 n 足够大时:
```
(X̄ - μ) / (σ/√n) ~ N(0, 1)
```
**意义**:
- 解释为什么正态分布普遍
- 大数定律 + 概率论核心
- 假设检验的理论基础
**n 多大**: 通常 n ≥ 30 就足够

### 3.2 p 值解读

**p 值**: 在 H0 成立时, 观测到当前(或更极端)结果的概率。
**误用**: p 值 ≠ H0 为真的概率 ≠ 效应大小
**正确解读**:
- p < 0.05: 拒绝 H0 (常用阈值, 但有争议)
- p < 0.01: 强证据
- p ≥ 0.05: 不拒绝 H0 (不等于"接受")

### 3.3 t 检验 vs z 检验

**z 检验**: 已知总体标准差 σ, 用标准正态
**t 检验**: σ 未知, 用样本标准差 s, 用 t 分布
- 大样本 (n≥30) 时 t ≈ z
- t 分布肥尾, 小样本更保守

### 3.4 多重比较问题

**问题**: 检验 20 个假设, 每个 α=0.05, 至少 1 个假阳率 ≈ 64%
**解决**:
- **Bonferroni**: α/n = 0.0025 (保守)
- **FDR (Benjamini-Hochberg)**: 控制期望假阳比例, 较宽松
- **Holm-Bonferroni**: 逐步 Bonferroni, 比 Bonferroni 有力

### 3.5 Bootstrap

**原理**: 有放回抽样, 用样本分布估计总体分布
**步骤**:
1. 从样本有放回抽样 n 个, 得到 B 个 bootstrap 样本
2. 对每个样本算统计量
3. 用 B 个统计量的分布估计置信区间

**优点**: 不需要分布假设
**缺点**: 计算量大, 小样本仍有偏

## 四 · 编程 (2 题)

### 4.1 t 检验

```python
from scipy import stats
import numpy as np

group_a = np.random.normal(5, 1, 100)
group_b = np.random.normal(5.5, 1, 100)

t, p = stats.ttest_ind(group_a, group_b)
print(f"t={t:.3f}, p={p:.4f}")
```

### 4.2 Bootstrap 置信区间

```python
import numpy as np

data = np.random.exponential(2, 100)
B = 1000
means = [np.mean(np.random.choice(data, size=len(data))) for _ in range(B)]
ci_lower, ci_upper = np.percentile(means, [2.5, 97.5])
print(f"95% CI: [{ci_lower:.3f}, {ci_upper:.3f}]")
```
