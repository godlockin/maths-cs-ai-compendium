## 三 · 简答 (5 题, 每题 6 分)

### 16. 总体分布 / 样本分布 / 抽样分布 (含 mini-batch SGD 对应)

**答**: 总体分布描述单个观测值的整体规律 (如全部用户点击次数); 样本分布是一次抽到的数据集的经验分布 (如一次抽的 64 条记录); 抽样分布是同一统计量在重复抽样中的分布 (如各批梯度估计的波动)。
mini-batch SGD 中: 全部训练数据 ≈ 总体; 一次 mini-batch ≈ 样本; 不同 batch 梯度估计的波动 ≈ 抽样分布。

### 17. p 值 / CI / 显著性陈述纠错

**答**: 1、2、3 错误; 4 正确。
1 应为: $p=0.03$ 表示假定 $H_0$ 为真时, 观察到当前或更极端结果的概率为 0.03。
2 应为: 重复抽样按同一方法构造区间, 约 95% 的区间会覆盖固定总体参数。
3 应为: $p>0.05$ 只是证据不足以拒绝 $H_0$, 不等于证明 $H_0$ 为真。

### 18. A/B 测试结论与统计显著 ≠ 业务重要

**答**: $H_0:p_A=p_B$, $H_1:p_A\ne p_B$。$\alpha=0.05$ 下 $p=0.0059<0.05$, 拒绝 $H_0$, B 与 A 转化率差异统计显著 (样本中 B 高 4 个百分点)。
但业务上还需评估: 4 个百分点的实际价值与成本、实验时长、随机分配质量、多指标筛选与可复现性 — 显著不等于值得上线。

### 19. CI vs PI 计算 + Bayesian credible interval 解释差异

**答**: $SE=10/\sqrt{100}=1$, $CI=100\pm1.96=[98.04,\ 101.96]$;
预测标准误 $10\sqrt{1+1/100}\approx10.0499$, $PI=100\pm1.96\times10.0499\approx[80.30,\ 119.70]$。
PI 覆盖未来个体, 除均值估计误差外还含个体噪声, 故更宽, 二者不可混用。
Bayesian credible interval 给的是"给定数据与先验后, 参数落入区间的后验概率为 95%"; 频率 CI 只承诺重复抽样覆盖率, 二者解释不同。

### 20. 正态对数似然 / Fisher 信息 / 样本均值梯度

**答**:
1. $\ell(\mu)=-\frac{1}{2\sigma^2}\sum_i(x_i-\mu)^2+C$; 得分 $\nabla_\mu\ell=\frac{\sum_i(x_i-\mu)}{\sigma^2}$; $I_n(\mu)=n/\sigma^2$。
2. $n=8,\sigma=2$: $I_n(\mu)=8/4=2$。
3. $f(\mathbf{x})=\bar x=\frac1n\mathbf{1}^\top\mathbf{x}$: 梯度 (列向量) $\nabla_{\mathbf{x}}f=\frac1n\mathbf{1}\in\mathbb{R}^{n\times1}$; Jacobian (行向量) $J_f=\frac1n\mathbf{1}^\top\in\mathbb{R}^{1\times n}$。

## 四 · 编程 (2 题, 每题 10 分)

### 21. CLT 数值验证 (指数总体, n=30)

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(2024)

n = 30
reps = 50_000

# 指数总体：均值 mu=1，方差 sigma^2=1
samples = rng.exponential(
    scale=1.0,
    size=(reps, n),
)

# 每一行对应一次 n=30 的抽样
sample_means = samples.mean(axis=1)

emp_mean = sample_means.mean()
emp_se = sample_means.std(ddof=1)
emp_skew = stats.skew(sample_means, bias=False)

levels = np.array([0.025, 0.5, 0.975])

# 经验分位数
empirical_quantiles = np.quantile(sample_means, levels)

# CLT 理论近似：Normal(mu, sigma^2/n)
theoretical_se = 1.0 / np.sqrt(n)
normal_quantiles = stats.norm.ppf(
    levels,
    loc=1.0,
    scale=theoretical_se,
)

print(f"empirical mean = {emp_mean:.4f}")
print(f"empirical SE   = {emp_se:.4f}")
print(f"normal SE      = {theoretical_se:.4f}")
print(f"sample-mean skewness = {emp_skew:.4f}")
print(
    "empirical quantiles =",
    np.round(empirical_quantiles, 4),
)
print(
    "normal quantiles    =",
    np.round(normal_quantiles, 4),
)
```

**要点**: 经验标准误 $0.1834$ 接近理论值 $1/\sqrt{30}=0.1826$; 经验分位数与 $N(1,1/30)$ 理论分位数接近; 样本均值偏度降至约 $0.376$ (远小于指数总体的偏度), 呈现趋近正态的数值证据。

### 22. 构造第一主成分沿 $(1,1)$ 方向的二维数据 (PCA + 相关)

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(7)

# 自造场景：
# t 是共同变化因素，两个特征都随 t 增大而增大
t = rng.normal(loc=0.0, scale=1.0, size=1000)
noise = rng.normal(loc=0.0, scale=0.2, size=(1000, 2))

X = np.column_stack((t, t)) + noise

# 中心化
X_centered = X - X.mean(axis=0)

# rowvar=False：每一列是一个特征
covariance = np.cov(
    X_centered,
    rowvar=False,
    ddof=1,
)

# 协方差矩阵是对称矩阵，eigh 返回升序特征值
eigenvalues, eigenvectors = np.linalg.eigh(covariance)

# 最大特征值对应第一主成分
first_direction = eigenvectors[:, -1]

# 统一符号方向，避免特征向量整体取负
if first_direction.sum() < 0:
    first_direction = -first_direction

target_direction = np.array([1.0, 1.0]) / np.sqrt(2)
cosine = float(first_direction @ target_direction)

correlation, p_value = stats.pearsonr(
    X[:, 0],
    X[:, 1],
)

print("covariance =")
print(np.round(covariance, 4))
print("first direction =", np.round(first_direction, 4))
print(
    "cosine with (1,1)/sqrt(2) =",
    f"{cosine:.4f}",
)
print(
    f"Pearson r = {correlation:.4f}, "
    f"p-value = {p_value:.3e}",
)
```

**要点**: 两个特征由共同变量 $t$ 驱动, 协方差为正, 第一主成分方向 $\approx(0.708,0.706)^\top$, 与 $(1,1)^\top/\sqrt2$ 的余弦相似度约为 1; Pearson $r\approx0.958$。注意高相关不等于因果。
