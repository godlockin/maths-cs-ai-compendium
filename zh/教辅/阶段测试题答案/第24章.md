## 三 · 简答题答案 (5 题)

### 3.1 Mixed Precision Training
**为什么**: 权重/激活/梯度用 FP16(省内存 + 快 Tensor Core),但**主副本 FP32**(避免精度损失)。
**技术**:
- **Loss Scaling**: loss × scale(典型 65536),防止 FP16 梯度下溢
- **GradScaler**: 检测 inf/nan,动态调整 scale
- **关键算子**(Loss/Softmax/BN)FP32 计算

### 3.2 优化器对比
- **SGD**: 简单,泛化好,慢,需手动调 lr;**适合 CNN/RL**
- **Adam**: 自适应,快,泛化略差,默认首选;**适合 Transformer**
- **L-BFGS**: 二阶近似,收敛快但内存大,需小 batch;**适合小数据集 / 经典 ML**
- **Shampoo**: 二阶 preconditioner,加速 2-3×;**适合大模型**

### 3.3 SVM 对偶与 KKT
**原始**: min (1/2)||w||² s.t. yᵢ(w·xᵢ+b)≥1。
**Lagrangian**: L = (1/2)||w||² - Σαᵢ[yᵢ(w·xᵢ+b)-1]。
**对 w, b 求偏导 = 0**: w = Σαᵢyᵢxᵢ, Σαᵢyᵢ = 0。
**代入得对偶**: max Σαᵢ - (1/2)ΣΣαᵢαⱼyᵢyⱼ(xᵢ·xⱼ) s.t. αᵢ≥0。
**KKT 互补松弛**: αᵢ[yᵢ(w·xᵢ+b)-1]=0, 即 yᵢ(w·xᵢ+b)>1 时 αᵢ=0(非支持向量),=1 时 αᵢ≥0(**支持向量**)。

### 3.4 DDP vs FSDP
- **DDP**: 每 worker 完整模型 + AllReduce 梯度。**内存 = 模型 + 优化器**。通信 1 次/步
- **FSDP**: 模型/优化器/梯度都分片。**内存 ≈ (模型+优化器)/world_size**。通信 2-3 次/步
- **选 DDP**: 模型 < 1.5B,显存够
- **选 FSDP**: 模型 > 7B,单卡放不下(等价 ZeRO-3)

### 3.5 Catastrophic Cancellation
**典型场景**:
- **Softmax 溢出**: exp(1000) = inf → 全 0
- **CrossEntropy**: log(0) = -inf
- **梯度消失**: 梯度小到 fp16 无法表示(下溢)
- **SVD 退化**: 矩阵太病态

**避免**:
- **Softmax 减 max**: e^(xᵢ-max) / Σe^(xⱼ-max)
- **CrossEntropy 内部 log_softmax**
- **用 bfloat16**(更大动态范围)替代 FP16
- **Loss Scaling** + GradScaler

## 四 · 编程题答案 (2 题)

### 4.1 数值稳定 Softmax
```python
import numpy as np

def softmax_stable(x):
    x = np.array(x)
    x_shifted = x - np.max(x)  # 关键: 减 max
    exp_x = np.exp(x_shifted)
    return exp_x / np.sum(exp_x)
```

### 4.2 DDP 训练循环
```python
import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP

def train_ddp(rank, world_size, model, optimizer):
    # 1. 初始化进程组
    dist.init_process_group("nccl", rank=rank, world_size=world_size)
    torch.cuda.set_device(rank)
    model = model.to(rank)
    ddp_model = DDP(model, device_ids=[rank])
```
