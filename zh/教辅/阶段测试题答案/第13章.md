## 三 · 简答（6 题，每题 5 分）

**16** 反证：假设 $H(P,x)$ 存在，构造 $D$ 对 $(D,D)$ 跑 $H$ 并反着做（说停机就死循环、说死循环就停机），$H(D,D)$ 自相矛盾，故 $H$ 不存在（图灵 1936）。后果：完美死锁检测器/病毒扫描器/优化编译器都不存在，工程上只能启发式近似，不能保证对所有输入正确。

**17** 算力增速远快于内存带宽与访存改善，GPU “算得比数据喂得快”；LLM 每生成一个 token 就要把权重逐层读一遍，70B 模型 FP16 权重约 140 GB（INT8 量化后约 70 GB），单批下耗时由读取主导，故 memory-bound。缓解：顺序访问吃空间局部性、大批摊薄延迟、混合精度/量化翻倍有效带宽、计算与 I/O 重叠。

**18** 进程：独立地址空间、隔离强、切换/IPC 贵，场景 = 浏览器多标签页隔离崩溃；线程：进程内共享堆与文件描述符、仅栈独立、切换轻，共享数据需同步原语，场景 = Web 服务器线程池并发请求共享连接池。

**19** OS Loop（调度器）→ 死锁；RL Loop（PPO/SAC）→ 策略崩溃；Agent Loop（LangGraph）→ 无限循环；DevOps Loop（Airflow）→ 状态丢失；Control Loop（PID）→ 震荡。五组全对满分。

**20** 并发 = 多任务交替推进（单核可做，结构属性）；并行 = 多执行单元同一瞬间真同时（需多核，硬件属性）。GIL 使同一时刻仅一个线程跑 Python 字节码，CPU 密集只能多进程绕开；Python 3.13（2024-10）引入实验性 free-threaded 构建，PEP 779 下 3.14（2025-10）起官方支持（可选、非默认，单线程开销 5-10%）。

**21** 手动（C/C++）：原始速度与硬件级控制，代价是释放后使用/重复释放/泄漏靠人防；GC（Java/Go/Python）：自动回收不可达对象，代价是停顿与运行时开销（ZGC/Go 并发 GC 已亚毫秒），引用泄漏仍可能；Rust 所有权：编译期借用检查杜绝悬垂指针与数据竞争、无 GC 开销，代价是学习曲线。
