## 三 · 简答题答案 (5 题)

### 3.1 Goodhart's Law 与 Reward Hacking
**Goodhart's Law**: "当度量变成目标,它就不再是好度量"。
**LLM 表现**: RM 喜欢长回答 → 模型生成冗长空话(高 RM 低质量)。
**检测**: 同时跟踪 RM 分数和人类/语义质量评分,当两者相关性低即 reward hacking。

### 3.2 RLHF / DPO / GRPO 对比
- **RLHF**: RM + PPO,训练慢 + 不稳定
- **DPO**: 闭式解,无 RM,一次 SFT
- **GRPO**: 组内相对优势,无 Critic,适合 Reasoning

### 3.3 Mechanistic Interpretability vs Explainability
**Mechanistic** = 逆向工程网络找到具体电路;**Explainability** = 后处理生成解释。前者更难但更根本(Anthropic 2024 蓝图),后者更通用但不可信(SHAP 不反映模型真实推理)。

### 3.4 PRM vs ORM
**ORM**: 只评最终答案对错;**PRM**: 评每一步推理是否正确。数学/代码题需要多步推理,中间错一步就全错,ORM 难以归因,PRM 可精确归因并针对性训练。DeepSeek-R1 / o1 用 PRM 在 AIME 上大幅提升。

### 3.5 LLM 4 层安全防护
1. **输入层**: Prompt 检测 + 长度限制 + 内容审查
2. **检索层**: RAG 内容过滤
3. **模型层**: Safety Fine-tuning + Constitutional AI
4. **输出层**: 二次 LLM 审查 + 关键词过滤 + 人工兜底

## 四 · 编程题答案 (2 题)

### 4.1 Reward Hacking 检测器
```python
def detect_reward_hacking(reward_history, quality_history):
    if len(reward_history) < 10:
        return False
    import numpy as np
    r = np.array(reward_history[-20:])
    q = np.array(quality_history[-20:])
    correlation = np.corrcoef(r, q)[0, 1]
    recent_r_slope = np.polyfit(range(len(r)), r, 1)[0]
    recent_q_slope = np.polyfit(range(len(q)), q, 1)[0]
    return recent_r_slope > 0.1 and recent_q_slope < -0.05 and correlation < 0.3
```

### 4.2 Jailbreak 检测
```python
import re

JAILBREAK_PATTERNS = [
    r"忽略之前",
    r"假装你是",
    r"你现在是DAN",
    r"jailbreak",
]

def detect_jailbreak(prompt: str) -> bool:
    prompt_lower = prompt.lower()
    for pattern in JAILBREAK_PATTERNS:
        if re.search(pattern, prompt_lower, re.IGNORECASE):
            return True
    if len(re.findall(r"[A-Za-z0-9+/=]{50,}", prompt)) > 0:
        return True
    return False
```
