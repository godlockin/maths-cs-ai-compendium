## 三 · 简答 (5 题)

### 3.1 信用风控关键挑战

- **数据不平衡**: 违约 3% → SMOTE / Focal Loss
- **概念漂移**: PSI 监控, 周期性重训
- **解释性**: SHAP / LIME (监管)
- **公平**: 性别 / 种族无偏

### 3.2 GNN 风控

**构图**: 用户 - 设备 - IP - 卡号
**优势**: 捕获团伙欺诈 (多账户共用设备)
**模型**: GAT / GraphSAGE / HAN

### 3.3 AlphaFold 2 核心

**架构**: Evoformer (MSA + 配对) + Structure Module
**性能**: CASP14 GDT 92.4 (实验级)
**影响**: 缩短靶点发现从 5 年 → 几周

### 3.4 药物发现 5 阶段

Target (靶点) → Hit (苗头) → Lead (先导) → Optimize (优化) → Candidate (候选)
传统耗时: 2 年 + 2 年 + 3 年 + 2 年 + 临床 5+ 年

### 3.5 AI Scientist 5 阶段

```
想法 → 文献 → 实验 → 写作 → 反思 → (下轮想法)
```

### 4.1 XGBoost 信用评分

```python
import xgboost as xgb
from sklearn.model_selection import train_test_split

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

model = xgb.XGBClassifier(
    n_estimators=100, max_depth=4, learning_rate=0.1,
    scale_pos_weight=10,  # 不平衡
)
model.fit(X_train, y_train)
print(f"AUC: {model.score(X_test, y_test)}")
```
