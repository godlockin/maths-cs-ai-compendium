## 三 · 简答 (5 题)

### 3.1 SIMD vs SIMT

**SIMD**: 单指令多数据, 1 个指令操作多个数据 (CPU AVX)
**SIMT**: 单指令多线程, 32 个线程 (warp) 同步执行 (GPU)

### 3.2 Memory Coalescing

**核心**: 连续线程访问连续内存 → 1 次 transaction
```
线程 0-31 访问 addr[0..127] → 1 个 128B 事务 ✓
线程 0-31 访问 addr[0, 32, 64, ...] → 32 个事务 ✗
```

### 3.3 Shared Memory Bank Conflict

**Shared memory 分 32 bank**
- 同 bank 不同地址 → conflict (串行)
- 不同 bank → 并行
**例子**: `sm[tid][0]` for tid 0..31 → 全 bank 0 → 31 个 conflict
**解决**: padding / 重新布局

### 3.4 Tensor Core 加速

**矩阵乘硬件加速**:
- A100 TF32: 156 TFLOPS
- H100 FP8: 3.3 PFLOPS
**API**: `mma.sync` / WMMA / CUTLASS

### 3.5 Triton vs CUDA

| 维度 | Triton | CUDA |
|------|--------|------|
| 语言 | Python | C++ |
| 学习 | 低 | 高 |
| 性能 | 80-95% SOTA | 100% |
| 适用 | 算子 | 极致优化 |

## 四 · 编程 (2 题)

### 4.1 AVX-512 向量加法

```cpp
#include <immintrin.h>

void vec_add_avx512(const float *a, const float *b, float *c, int n) {
    for (int i = 0; i < n; i += 16) {
        __m512 va = _mm512_loadu_ps(a + i);
        __m512 vb = _mm512_loadu_ps(b + i);
        _mm512_storeu_ps(c + i, _mm512_add_ps(va, vb));
    }
}
```

### 4.2 Triton Softmax

```python
import triton
import triton.language as tl

@triton.jit
def softmax_kernel(out_ptr, in_ptr, n_cols, BLOCK: tl.constexpr):
    row = tl.program_id(0)
    offsets = tl.arange(0, BLOCK)
    mask = offsets < n_cols
    x = tl.load(in_ptr + row * n_cols + offsets, mask=mask, other=-float('inf'))
    x = x - tl.max(x, axis=0)
    e = tl.exp(x)
    tl.store(out_ptr + row * n_cols + offsets, e / tl.sum(e, axis=0), mask=mask)
```
