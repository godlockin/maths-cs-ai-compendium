## 三 · 简答 (5 题)

### 3.1 链式法则

**答**: 复合函数求导法则
```
d/dx f(g(x)) = f'(g(x)) × g'(x)
```
**ML 应用**: 反向传播(Backpropagation)的基础。每个神经元都是复合函数,链式法则让梯度高效传播。

### 3.2 多元函数极值

**必要条件**: ∇f(x*) = 0 (梯度为 0)
**充分条件**: ∇f(x*) = 0 且 Hessian 正定 → 极小值
**鞍点**: ∇f = 0 但 Hessian 不定, 在某些方向是极大, 某些方向是极小。

### 3.3 梯度下降

**算法**:
```
x_{t+1} = x_t - α × ∇f(x_t)
```
**变种**:
- SGD: 用单个样本的梯度
- Batch GD: 用全部样本
- Mini-batch: 折中(主流)
- Momentum: 引入动量加速
- Adam: 自适应学习率

**收敛性**: 凸函数 O(1/k), 强凸函数 O(ρ^k) 线性收敛。

### 3.4 凸 vs 非凸

**凸**: 局部最优 = 全局最优, 易优化
**非凸**: 多个局部最优, 深度学习都是非凸

**深度学习虽非凸**, 但实践中:
- 随机初始化 + SGD 通常能找到"好的"局部最优
- 过参数化时损失景观更平滑
- 现代架构 (Transformer) 损失景观较友好

### 3.5 反向传播

**核心**: 链式法则的高效实现
**前向**: 算 Loss
**反向**: 从 Loss 开始, 用链式法则算每个参数的梯度

**计算复杂度**: 与前向传播同阶 O(n), 不需要 O(n²)
**关键**: 计算图 + 自动微分

## 四 · 编程 (2 题)

### 4.1 梯度下降

```python
import numpy as np

def gradient_descent(grad_fn, x0, lr=0.1, n_steps=100):
    x = x0
    for _ in range(n_steps):
        x = x - lr * grad_fn(x)
    return x

# 例子: f(x) = x^2
grad = lambda x: 2 * x
x_min = gradient_descent(grad, x0=10.0, lr=0.1, n_steps=100)
print(f"x_min: {x_min}")  # ~0
```

### 4.2 PyTorch 自动微分

```python
import torch

x = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)
y = (x ** 2).sum()
y.backward()
print(x.grad)  # [2, 4, 6]
```
