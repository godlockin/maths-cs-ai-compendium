## 一、选择题 (10 题, 每题 4 分, 共 40 分)

### 1. C
**解析**: 向量与向量的乘法(点积)交换律不是向量空间公理; 向量空间只涉及"加法"和"标量乘法"两种运算, 共 10 条公理(2 封闭 + 4 加法 + 4 标量乘法)。C 描述的是内积的性质, 不属于向量空间定义本身。
**来源**: §1.1 十条公理段

### 2. C
**解析**: $0.5 \times 3 = 1.5 \notin \mathbb{Z}$, 用实数标量缩放整数向量后结果跑出集合, 违反标量乘法封闭性。加法封闭性其实是满足的(整数 + 整数 = 整数)。
**来源**: §1.1 反例段

### 3. B
**解析**: 子空间必须包含零向量, 因此必须过原点。偏离中心的直线不含 $\mathbf{0}$, 不是子空间。
**来源**: §1.1 子空间段

### 4. A
**解析**: $\|\mathbf{a}\|_2=\sqrt{3^2+(-4)^2}=\sqrt{25}=5$。
**来源**: §1.2 模长公式 / §1.3 L2 范数

### 5. C
**解析**: $\|\mathbf{v}\|_1=|3|+|{-4}|+|1|=8$; $\|\mathbf{v}\|_2=\sqrt{9+16+1}=\sqrt{26}$ (A 项的 25 是漏开平方的结果); $\|\mathbf{v}\|_\infty=\max(3,4,1)=4$。
**来源**: §1.3 L1/L2/L∞ 范数

### 6. C
**解析**: $\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$, 点积为零(且两向量非零)当且仅当 $\cos\theta=0$, 即 $\theta=90°$ 正交。
**来源**: §1.4 点积几何解释

### 7. C
**解析**: 叉积**反交换**: $\mathbf{a}\times\mathbf{b}=-(\mathbf{b}\times\mathbf{a})$; 交换顺序会翻转方向。其余三项均为叉积的正确性质。
**来源**: §1.4 叉积性质

### 8. B
**解析**: L2 因先平方后开方, **单一极大差**会主导整体距离; L1 对每个分量平权反而稀释极端项; $L_\infty$ 只看单个最大分量, 忽略其他信息。当"想让离群维度主导"就选 L2。
**来源**: §1.3 L1 vs L2 差异

### 9. B
**解析**: 令 $P=\begin{bmatrix}1&-1\\1&1\end{bmatrix}$, 求 $P\mathbf{x}=(3,2)^\top$, 解得 $\mathbf{x}=(2.5,-0.5)$。验证: $2.5(1,1)-0.5(-1,1)=(3,2)$。
**来源**: §1.5 咖啡馆基变换例子

### 10. B
**解析**: 一般基的坐标要用 $P^{-1}$ 的**行**(即对偶基)去测。只有当基满足单位正交($P^{-1}=P^\top$)时, 对偶基才恰好等于原基, 直接点积才成立。标准基是特例。
**来源**: §1.5 正交陷阱段

## 二、填空题 (5 题, 每题 4 分, 共 20 分)

### 11. $\sqrt{29}$
**解析**: $\sqrt{9+4+16}=\sqrt{29}\approx 5.39$。
**来源**: §1.2 模长公式

### 12. $\dfrac{\mathbf{a}}{\|\mathbf{a}\|}$
**解析**: 归一化后模长为 1, 仅保留方向信息。
**来源**: §1.2 单位向量

### 13. $\left(\sum_{i=1}^{n}|v_i|^p\right)^{1/p}$; 最大范数($L_\infty$)
**解析**: 随 $p$ 增大, 最大分量占比越来越重, 极限只剩最大分量。
**来源**: §1.3 广义 Lp 范数

### 14. $\dfrac{\mathbf{a}\cdot\mathbf{b}}{\|\mathbf{a}\|\|\mathbf{b}\|}$; $[-1,\ 1]$
**解析**: 归一化点积, 剥离长度只保留方向对齐信息, 广泛用于文档/嵌入相似度。
**来源**: §1.4 余弦相似度

### 15. $\delta_{ij}$; $I$ (单位矩阵)
**解析**: 尺子 $i$ 在基向量 $i$ 上读 1、在其他基向量上读 0; 单位矩阵就是 Kronecker δ 的表格化。
**来源**: §1.5 对偶基校准段

## 三、简答题 (5 题, 每题 6 分, 共 30 分)

### 16. 子空间为什么必须过原点
**答案**:
- 直觉: 子空间必须继承原空间的加法与标量乘法运算, 且封闭。
- 公式: 对任意 $\mathbf{v}\in U$, 标量乘法封闭性要求 $0\cdot\mathbf{v}=\mathbf{0}\in U$; 因此零向量必须在子空间内, 即子空间必须过原点。

**解析**: 关键钥匙是"取标量 $c=0$", 直接强制零向量存在。
**来源**: §1.1 子空间段

### 17. 范数与度量的联系、区别与反例
**答案**:
- **联系**: 每一个范数都能通过 $d(\mathbf{u},\mathbf{v})=\|\mathbf{u}-\mathbf{v}\|$ 导出一个度量。
- **区别**: 范数量单个向量的"大小"; 度量量两个向量的"距离"。范数需满足 3 条公理(非负、齐次、三角), 度量需满足 4 条(非负、同一性、对称、三角)。
- **反例**: **汉明距离**(计数两个向量分量不同的位置数)是合法度量, 但它不来自任何范数——因为它不满足范数导出度量应具备的齐次缩放性 $d(c\mathbf{u}, c\mathbf{v})=|c|\,d(\mathbf{u},\mathbf{v})$。

**解析**: 判别钥匙是齐次缩放性: 范数导出的度量必须满足该等式, 汉明距离对整体缩放不敏感, 故不可能由范数导出。
**来源**: §1.3 范数与度量关系段

### 18. 点积与叉积的几何对比
**答案**:
- **点积**: $\mathbf{a}\cdot\mathbf{b}=\|\mathbf{a}\|\|\mathbf{b}\|\cos\theta$, 衡量方向"多对齐", 输出标量, 任意维可用。
- **叉积**: $\|\mathbf{a}\times\mathbf{b}\|=\|\mathbf{a}\|\|\mathbf{b}\|\sin\theta$, 衡量方向"多不同"(所张平行四边形面积), 输出与两输入同时垂直的新向量, 仅 3D 定义。
- **代数性质**: 点积交换, 叉积反交换 $\mathbf{a}\times\mathbf{b}=-(\mathbf{b}\times\mathbf{a})$; 平行向量点积 $\ne 0$, 叉积 $=\mathbf{0}$。

**解析**: 点积用 $\cos\theta$ 把方向对齐度压成一个标量; 叉积用 $\sin\theta$ 把方向偏离度张成一个面积向量, 一个量"同"、一个量"异", 正好互补。
**来源**: §1.4 点积/叉积段

### 19. 为什么直接点积读不出一般基下的坐标
**答案**:
- 以 $\mathbf{v}=(3,2)$ 为例, $\mathbf{b}_1\cdot\mathbf{v}=1\cdot 3+1\cdot 2=5$, 而真正的坐标应为 $2.5$——恰好是 2 倍关系, 因为 $\|\mathbf{b}_1\|^2=2$。
- 一般基的坐标必须用**对偶基**(即 $P^{-1}$ 的行)去读, 此例 $\mathbf{b}_1^\ast=(0.5,0.5)$, $\mathbf{b}_1^\ast\cdot\mathbf{v}=2.5$ 才对。
- "用基向量自己做点积即得坐标"这个捷径**仅在基是单位正交(orthonormal)时成立**——此时 $P^{-1}=P^\top$, 对偶基恰好等于原基。标准基就是特例。

**解析**: 一般基既当"尺子"又带长度, 直接点积的读数被 $\|\mathbf{b}_1\|^2=2$ 放大; 只有单位正交基下基向量长度为 1 且互相垂直, 对偶基等于原基, 捷径才成立。
**来源**: §1.5 正交陷阱段

### 20. 高维数据住在低维子空间的两个场景
**答案**:
- **场景 1**: 图像数据。$28\times 28$ 手写数字 = $\mathbb{R}^{784}$, 但同一数字类别的样本聚集在远低于 784 维的子空间; PCA 找出主方向后可将维数压缩至几十维。
- **场景 2**: 文本嵌入。词向量维度 512+, 但语义相近的词/句只占其中极低维的语义子流形; 用于检索、聚类。
- **过原点的问题**: 实际数据点通常不过原点, 但预处理中总会**先做中心化(减去均值)**, 让数据云的中心平移到 $\mathbf{0}$, 之后 PCA 等基于子空间的方法即可安全使用; sklearn 的 `PCA` 内部也会自动中心化数据。
- (评估维度) 好的答案会指出: 若不中心化, PCA 找到的将是仿射空间的主方向, 而不是几何意义上正确的方差主轴。

**解析**: 中心化把数据云整体平移到原点, 仿射空间问题就此降为向量子空间问题, 所以"过原点"约束在标准预处理之后自然满足, 不构成实际障碍。
**来源**: §1.1 子空间段 + §1.5 基变换/PCA 提示

## 四、编程题 (2 题, 每题 5 分, 共 10 分)

### 21. L1/L2/L∞ 与广义 Lp 范数收敛实验
**答案**: 参考实现与期望输出如下。

```python
import numpy as np

v = np.array([3.0, -4.0, 1.0])

l1  = np.sum(np.abs(v))
l2  = np.sqrt(np.sum(v ** 2))
inf = np.max(np.abs(v))

print(f"L1  = {l1}")
print(f"L2  = {l2:.4f}")
print(f"Linf= {inf}")

print("\np -> Lp   (逐步逼近 Linf = 4.0)")
for p in [1, 2, 5, 10, 50, 100]:
    lp = np.sum(np.abs(v) ** p) ** (1.0 / p)
    print(f"  p={p:>3d}   Lp = {lp:.6f}")
```

**期望输出**:
```
L1  = 8.0
L2  = 5.0990
Linf= 4.0

p -> Lp   (逐步逼近 Linf = 4.0)
  p=  1   Lp = 8.000000
  p=  2   Lp = 5.099020
  p=  5   Lp = 4.174686
  p= 10   Lp = 4.021975
  p= 50   Lp = 4.000000
  p=100   Lp = 4.000000
```

**解析**: $p$ 增大过程中 Lp 单调递减并收敛到 $L_\infty=4$; 因为 $|-4|$ 是绝对值最大的分量, 高次幂使其他分量的贡献趋近 0。评分点: 三种范数计算正确 (2 分)、Lp 循环与幂次写法正确 (2 分)、能指出收敛现象与原因 (1 分)。
**来源**: §1.3 广义 Lp 范数

### 22. 基变换、对偶基构造与正交陷阱验证
**答案**: 参考实现与期望输出如下。

```python
import numpy as np

v = np.array([3.0, 2.0])
P = np.array([[1.0, -1.0],
              [1.0,  1.0]])          # 新基按列堆叠

# 1) 新基下的坐标
coords = np.linalg.solve(P, v)
print(f"v 在新基下的坐标 = {coords}")

# 2) 对偶基 = P^{-1} 的行
P_inv = np.linalg.inv(P)
b1_star, b2_star = P_inv[0], P_inv[1]
print(f"b1* = {b1_star}")
print(f"b2* = {b2_star}")

# (a) 校准: b_i*(b_j) = δ_ij → 应为单位矩阵
calib = P_inv @ P
print(f"P^-1 @ P =\n{calib}")

# (b) 对偶读数 = 坐标
print(f"b1*(v) = {b1_star @ v}   (should equal coords[0] = {coords[0]})")
print(f"b2*(v) = {b2_star @ v}   (should equal coords[1] = {coords[1]})")

# (c) 陷阱: 直接用 b1 . v 读不出坐标 (除非正交归一)
b1 = P[:, 0]
print(f"b1 . v = {b1 @ v}   (WRONG: 5.0, not 2.5 — b1 非单位正交)")
```

**期望输出**:
```
v 在新基下的坐标 = [ 2.5 -0.5]
b1* = [0.5 0.5]
b2* = [-0.5  0.5]
P^-1 @ P =
[[1. 0.]
 [0. 1.]]
b1*(v) = 2.5   (should equal coords[0] = 2.5)
b2*(v) = -0.5   (should equal coords[1] = -0.5)
b1 . v = 5.0   (WRONG: 5.0, not 2.5 — b1 非单位正交)
```

**解析**:
- (a) $P^{-1}P=I$ 就是 Kronecker δ 的矩阵表达, 每把"尺子" $\mathbf{b}_i^\ast$ 在自己的基向量上读 1、在其他基向量上读 0。
- (b) 对偶基作为线性泛函, 输入向量、输出坐标; 坐标"就是"对偶基读数。
- (c) $\mathbf{b}_1\cdot\mathbf{v}=5\ne 2.5$——因为 $\|\mathbf{b}_1\|^2=2$, 直接点积得到的是坐标的 $\|\mathbf{b}_1\|^2$ 倍。只有单位正交基下这个捷径才成立。

评分点: `solve` 求坐标正确 (1 分)、对偶基构造与校准 (a) 正确 (2 分)、(b)(c) 三个验证齐全且结论正确 (2 分)。
**来源**: §1.5 咖啡馆基变换 + 对偶基 + 正交陷阱

## 六、易错点

1. **向量空间公理只管两种运算**: 加法与标量乘法; 点积交换律是内积性质, 不是向量空间公理 (题 1)。
2. **L2 别忘了开平方**: $\|\mathbf{v}\|_2=\sqrt{26}$ 不是 26 (题 5、题 11)。
3. **L1 vs L2 的主导项**: L2 的平方让单一极大差主导距离, L1 分量平权; 选型取决于"想让谁说话大声" (题 8)。
4. **一般基不能直接点积读坐标**: 读数会被 $\|\mathbf{b}_i\|^2$ 放大, 必须用对偶基 $P^{-1}$ 的行; 单位正交基是唯一例外 (题 10、题 19、题 22)。
5. **汉明距离是度量但不是范数导出的**: 卡在齐次缩放性 (题 17)。
6. **叉积反交换、仅 3D**: $\mathbf{a}\times\mathbf{b}=-(\mathbf{b}\times\mathbf{a})$, 平行向量叉积为零向量 (题 7、题 18)。
7. **子空间必过原点**: 取标量 $c=0$ 即强制 $\mathbf{0}\in U$; 实际数据靠中心化满足 (题 3、题 16、题 20)。
