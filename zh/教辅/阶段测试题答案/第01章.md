## 三 · 简答题 (5 题)

### 3.1 范数 3 大公理

**答**:
1. **正定性**: ||x|| ≥ 0, 且 ||x|| = 0 iff x = 0
2. **三角不等式**: ||x + y|| ≤ ||x|| + ||y||
3. **齐次性**: ||αx|| = |α| × ||x||

**反例**:
- ||x|| = -1 (不满足正定性)
- ||x|| = x₁² + x₂² + 1 (在 x=0 时为 1, 不满足正定性)
- ||x|| = x₁² + |x₂| (不满足齐次性, ||2x|| = 4x₁² + 2|x₂| ≠ 2||x||)

### 3.2 L1 vs L2 范数

**L1**: ||x||₁ = Σ|xᵢ|, **稀疏性** (SVM / Lasso), 几何: 菱形
**L2**: ||x||₂ = √(Σxᵢ²), **数值稳定** (Ridge), 几何: 球形

**L1 偏好稀疏解**: 因为 L1 等值面在坐标轴有"尖角", 优化时容易"撞"到稀疏点(某一维 = 0)。

### 3.3 正交基与标准基

**标准基**: e₁=(1,0), e₂=(0,1), **正交但非完备**(只覆盖 ℝ² 的"基本方向")
**正交基**: 任何正交向量组展开空间, 如 Schmidt 正交化结果。

Gram-Schmidt 步骤: 对每个新向量减去它在已有正交基上的投影。

### 3.4 点积的几何与代数

**代数**: u·v = Σ uᵢvᵢ
**几何**: u·v = ||u|| × ||v|| × cos θ
- cos θ = 1: 同向, 最大
- cos θ = 0: 正交
- cos θ = -1: 反向, 最小(最负)
- cos θ = 0.5: 60°
- cos θ = -0.5: 120°

### 3.5 维数公式

**答**: 对线性映射 T: V → W,
```
dim(V) = dim(Ker T) + dim(Im T)
```

**例**: T: ℝ³ → ℝ², dim(Ker)=1, dim(Im)=2 → dim(V)=3 ✓

## 四 · 编程题 (2 题)

### 4.1 向量范数实现

```python
import numpy as np

def l1_norm(x): return np.sum(np.abs(x))
def l2_norm(x): return np.sqrt(np.sum(x**2))
def linf_norm(x): return np.max(np.abs(x))

# 验证范数公理
def verify_norm_axioms(norm_func):
    x = np.random.randn(10)
    assert norm_func(x) >= 0  # 正定
    assert abs(norm_func(0) - 0) < 1e-9
    y = np.random.randn(10)
    assert norm_func(x + y) <= norm_func(x) + norm_func(y) + 1e-9  # 三角
    alpha = np.random.randn()
    assert abs(norm_func(alpha * x) - abs(alpha) * norm_func(x)) < 1e-9  # 齐次
    print(f"{norm_func.__name__} axioms OK")

verify_norm_axioms(l1_norm)
verify_norm_axioms(l2_norm)
```

### 4.2 Gram-Schmidt

```python
def gram_schmidt(vectors):
    ortho = []
    for v in vectors:
        for u in ortho:
            v = v - np.dot(v, u) / np.dot(u, u) * u
        if np.linalg.norm(v) > 1e-10:  # 跳过零向量
            ortho.append(v / np.linalg.norm(v))  # 归一化
    return np.array(ortho)

# 测试
v1 = np.array([1, 1, 0], dtype=float)
v2 = np.array([1, 0, 1], dtype=float)
v3 = np.array([0, 1, 1], dtype=float)
orthonormal = gram_schmidt([v1, v2, v3])
print(orthonormal)
# 验证正交性
print(orthonormal @ orthonormal.T)  # 应该是单位矩阵
```

## 六 · 易错点

1. **范数 vs 距离**: 距离 d(x,y) = ||x-y||
2. **L1 偏好稀疏**: 不等于"鼓励更多稀疏", 而是"等值面尖角"
3. **Schmidt 正交化**: 必须**从前往后**减投影, 顺序影响结果(但张成不变)
4. **零空间 / 行空间**: 列空间 vs 行空间 dim 关系是 dim 相等(秩), 不是同一空间
5. **单位正交基**: 既正交又归一, Gram 矩阵是单位阵
