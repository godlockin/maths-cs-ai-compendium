## 三 · 简答题答案 (5 题)

### 3.1 抖音推荐系统 (8 步)
1. **需求**: 100 万视频库,推 10 个给用户
2. **指标**: CTR / 完播率 / 留存
3. **离线**: AUC;**在线**: CTR + 长期留存
4. **一致性**: 特征对齐 + 实时特征
5. **数据流**: 用户行为日志 → Kafka → Flink → 特征仓库
6. **特征**: 用户(历史/兴趣) + 视频(类目/标签) + 上下文(时间/位置)
7. **模型**: **召回**(双塔/协同过滤) → **精排**(DLRM/DIN) → **重排**(多样性/规则)
8. **监控**: 实时 CTR + 特征分布 + A/B 测试

### 3.2 企业 RAG 知识库
1. **需求**: 100 GB 文档库,答员工问题
2. **指标**: Faithfulness / Answer Relevance / Citation 准确率
3. **离线**: RAGAS 评测集
4. **一致性**: 文档版本 + 权限
5. **数据流**: PDF/Confluence → Loader → Splitter(512 token 重叠 50)→ Embedder(BGE)→ Vector DB(Milvus)
6. **特征**: BM25 + 向量 混合检索
7. **模型**: Claude 4.5 + System Prompt(引用源)+ Re-ranker
8. **监控**: 引用率 + 用户反馈 + 文档更新

### 3.3 LLM 推理服务
1. **需求**: 100 QPS,p99 < 2s
2. **指标**: 延迟 / 吞吐 / 成本(QPS/$)
3. **离线**: throughput benchmark
4. **一致性**: 训练-推理差异
5. **数据流**: HTTP → Load Balancer → API Gateway → Inference Cluster
6. **特征**: 文本 + prompt cache
7. **模型**: **vLLM / SGLang / TensorRT-LLM**,PagedAttention,KV Cache,连续批处理
8. **监控**: 延迟 / GPU 利用率 / 队列长度

### 3.4 离线-在线不一致 3 大原因
1. **特征不一致**: 离线用历史快照,在线用实时特征 → **特征平台(Feast)** 统一
2. **分布漂移**: 用户/数据变化 → **PSI 监控** + **周期性重训**
3. **反馈延迟**: 用户行为延迟 → **实时反馈 + 离线-在线一致性检查**

### 3.5 Offer 谈判 3 大关键
1. **手里有竞争**: 拿 1-2 个其他 offer 当谈判筹码
2. **用数据说话**: 引用市场(levels.fyi / 猎聘)+ 个人贡献(涨收 X%)
3. **不只谈 base**: 谈**签字费 + RSUs + 假期**,总包可能比 base 涨 30%

## 四 · 算法题答案 (2 题)

### 4.1 Top-K Frequent Elements
```python
from collections import Counter
import heapq

def topKFrequent(nums, k):
    count = Counter(nums)
    return heapq.nlargest(k, count.keys(), key=count.get)
```
**复杂度**: O(n log k),优于排序 O(n log n)。

### 4.2 LRU Cache
```python
from collections import OrderedDict

class LRUCache(OrderedDict):
    def __init__(self, capacity):
        self.capacity = capacity
    
    def get(self, key):
        if key not in self:
            return -1
        self.move_to_end(key)
        return self[key]
    
    def put(self, key, value):
        if key in self:
            self.move_to_end(key)
        self[key] = value
        if len(self) > self.capacity:
            self.popitem(last=False)
```
**复杂度**: get/put 都是 O(1)。
