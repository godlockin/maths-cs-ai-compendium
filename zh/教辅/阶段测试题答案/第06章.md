## 一 · 选择题 (10 题)

**1.** B - 逻辑回归输出 $\hat p=\sigma(z)=1/(1+e^{-z})\in(0,1)$，配二元交叉熵 (自然对数下单位 nat)；A 混同线性得分与概率，C 忽略训练目标，D 混淆二分类与多分类。

**2.** B - 残差为 $0.1,-0.1$，$\operatorname{MSE}=(0.01+0.01)/2=0.01$；平方和 $0.02$ 不是 MSE。

**3.** C - 父熵 $H(S)=1$ bit，左节点纯 ($H=0$)、右节点均衡 ($H=1$ bit)，加权子熵 $(2/4)\cdot0+(2/4)\cdot1=0.5$ bit，$\operatorname{IG}=1-0.5=0.5$ bit。

**4.** B - 几何距离 $=1/\|\mathbf w\|_2=1/5=0.2$；$\|\mathbf w\|_2$ 越大间隔越小。

**5.** A - 分母 $P(\mathbf x)$ 对各类相同，比较分子即可：$0.3>0.1$，判 $C_A$ (归一化后验 $0.75$ vs $0.25$)。

**6.** B - Dropout 训练时随机置零部分激活，推理时使用完整网络；反向 Dropout 训练时把保留激活除以保留率 $q$，保持期望尺度不变。

**7.** C - 作为优化目标惩罚项时，$L^1$ 诱导稀疏解，$L^2$ 惩罚大权重使参数变小但不稀疏；正则化同时影响训练目标。

**8.** B - 标准缩放点积注意力为 $\operatorname{softmax}(QK^\top/\sqrt{d_k})V$；缩放因子是 $\sqrt{d_k}$ 不是 $d_k$。

**9.** C - bit 口径下 $\operatorname{PPL}=2^H=2^3=8$；自然对数口径则写 $\exp(H_{nat})$，bit 与 nat 不能混用。

**10.** C - 错误项：AllReduce 规约出平均梯度后，各进程仍须用同一结果更新参数，否则副本分叉；A/B/D 均为同步数据并行的标准口径。

## 三 · 简答题 (6 题)

### 16. Adam 四公式与第 1 步更新

- 一阶矩 $m_t=\beta_1m_{t-1}+(1-\beta_1)g_t$，二阶矩 $v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2$。
- 偏差修正 $\hat m_t=m_t/(1-\beta_1^t)$，$\hat v_t=v_t/(1-\beta_2^t)$。
- 更新 $\theta_t=\theta_{t-1}-\eta\hat m_t/(\sqrt{\hat v_t}+\varepsilon)$。
- 代入 $\beta_1=0.9,\beta_2=0.999,g_1=0.2$：$m_1=0.02$，$v_1=0.00004$，$\hat m_1=0.2$，$\hat v_1=0.04$。
- $\theta_1=1-0.001\cdot0.2/(\sqrt{0.04}+10^{-8})\approx0.999000$ (保留 6 位小数)。

### 17. 缩放点积注意力手算

- $QK^\top=(1,0)$，$d_k=1$ 故 $\sqrt{d_k}=1$，logits 为 $(1,0)$。
- softmax 权重 $\left(e^1/(e^1+1),\,e^0/(e^1+1)\right)\approx(0.7311,0.2689)$，和为 $1.0000$。
- 输出 $(0.7311,0.2689)V=(1.4621,0.5379)$ (用未四舍五入权重计算)。

### 18. 陈述判断与改正

1. **不成立** - $\operatorname{MSE}=(1/n)\sum_i(y_i-\hat y_i)^2$，必须除以样本数；两个平方误差各 $0.01$ 时平方和 $0.02$，MSE 为 $0.01$。
2. **成立** - 对数底决定单位：$\log_2$ 为 bit，$\ln$ 为 nat。
3. **成立** - 本卷 $\beta_1,\beta_2$ 专指 Adam 衰减率，不是回归系数；多义符号按题面标注消歧。
4. **成立** - 分母是 $\sqrt{d_k}$；$d_k=4$ 时为 $2$，不是 $4$。
5. **不成立** - 数据并行每进程保存完整模型副本、处理不同数据分片；"只保存部分层"是模型并行。
6. **不成立** - 经典 Q-Learning 是 off-policy：行为策略可用 $\varepsilon$-greedy，目标用 $\max_{a'}Q(s',a')$ 的贪心价值。

### 19. 三种并行与 AllReduce

- **数据并行**：每进程保存完整模型，输入 batch 分片；各自前向反向后对梯度 AllReduce，更新后副本一致。
- **模型并行**：不同层或张量切到不同设备，单样本前向需跨设备传中间激活，适合模型大于单卡显存。
- **流水线并行**：按层段切分模型，多个 micro-batch 依次过各段，减少设备空闲，但有流水线气泡。
- **AllReduce 数字例**：梯度 $(1,3)^\top$ 与 $(3,5)^\top$ 求和为 $(4,8)^\top$，平均梯度 $(2,4)^\top$，再以 $\theta\leftarrow\theta-\eta\bar{\mathbf g}$ 更新。
- 全局 batch 为各进程 batch 之和且损失按样本平均时，平均梯度保持单机大 batch 的梯度尺度，学习率无需额外放大；若用梯度求和则需按进程数重标定。

### 20. MDP 五元组与 Q-Learning 更新

- MDP $=(\mathcal S,\mathcal A,P,R,\gamma)$：状态集、动作集、转移概率、奖励函数、折扣因子。
- 更新式 $Q(s,a)\leftarrow Q(s,a)+\eta[r+\gamma\max_{a'}Q(s',a')-Q(s,a)]$。
- TD 误差 $\delta=1+0.9\times\max(1.5,2.0)-0.5=1+1.8-0.5=2.3$。
- $Q_{new}=0.5+0.5\times2.3=1.65$。

### 21. 交叉熵、KL 与 VAE 正则项

- 交叉熵 $H(P,Q)=-\sum_xP(x)\log Q(x)$；KL 散度 $D_{KL}(P\|Q)=H(P,Q)-H(P)$，不对称、不能称距离。
- 固定真实分布下 $H(P)$ 为常数，最小化交叉熵等价于最小化 KL。
- $\operatorname{BCE}=-\sum_i[y_i\log\hat y_i+(1-y_i)\log(1-\hat y_i)]$；$\operatorname{CCE}=-\sum_{k=1}^K y_k\log\hat y_k$。
- VAE 损失含重构项与 $D_{KL}(q_\phi(z\mid x)\|p(z))$，约束潜变量后验接近先验；训练框架常用 $\ln$，默认单位 nat。
- 单位数字核验：真类概率 $0.8$ 时 $-\ln0.8\approx0.2231$ nat，而 $-\log_2 0.8\approx0.3219$ bit，单位与数值都须写明。

## 四 · 编程题 (4 题)

### 22. Softmax + 多分类交叉熵 (nat)

```text
[0.665241, 0.244728, 0.090031]
loss=0.407606 nat
```

减最大 logit 不改变 softmax 比值且防指数溢出；$\operatorname{CCE}=-\ln(0.665241)\approx0.407606$ nat。若改用 $\log_2$ 约为 $0.588$ bit，不能与 nat 混写。

### 23. MSE 与偏置一次更新

```text
mse=0.030000
grad_b=-0.133333
b_new=0.013333
new_mse=0.028222
```

误差 $(-0.2,0.2,-0.1)$，平方和 $0.09$，MSE $=0.09/3=0.03$；梯度 $2(-0.1)/3=-0.133333$，负梯度说明整体预测偏低，正向更新偏置。

### 24. Adam 第 1 步

```text
m=0.020000
v=0.000040
m_hat=0.200000
v_hat=0.040000
theta=0.999000
```

$\theta_1\approx0.99900000025$，六位小数为 $0.999000$；初值为 0 造成矩估计低估，偏差修正后 $\hat m_1=0.2$、$\hat v_1=0.04$。

### 25. 最小 RL 环境与 Q-Learning

```text
reward=1: delta=1.000000, Q=0.500000
reward=2: delta=2.000000, Q=1.000000
```

终止状态 bootstrap 项取 0：奖励 1 时 $\delta=1+0.9\times0-0=1$，$Q=0+0.5\times1=0.5$；奖励 2 时 $\delta=2$，$Q=1$。奖励尺度放大 2 倍，首步 TD 误差与 Q 更新同步放大 2 倍；长期任务还受折扣因子 $\gamma$ 影响。
