## 第 1 章 · 基础层 (Ch01-05) — 数学的 5 把钥匙

### 1.1 章节定位

数学是 AI 工程师的"母语"。5 章覆盖:**线性代数 → 矩阵论 → 概率 → 统计 → 贝叶斯**。

### 1.2 章节主线

```
Ch01 线性代数
   ↓ 升维
Ch02 矩阵论 (SVD, 特征分解)
   ↓ 不确定性
Ch03 概率与梯度 (随机变量, 优化)
   ↓ 推断
Ch04 统计 (估计, 检验)
   ↓ 决策
Ch05 贝叶斯与信息论 (先验, 后验, 熵)
```

### 1.3 关键概念地图

| 章节 | 核心公式 | 应用场景 |
|------|---------|----------|
| Ch01 | $\mathbf{Ax} = \lambda \mathbf{x}$ | PCA, 词嵌入, 推荐 |
| Ch02 | $\mathbf{A} = \mathbf{U\Sigma V}^T$ | Transformer 注意力, 推荐 |
| Ch03 | $P(A\|B) = \frac{P(B\|A)P(A)}{P(B)}$ | 医学诊断, 贝叶斯 |
| Ch04 | $\hat{\theta} = \arg\max_\theta \log P(D\|\theta)$ | MLE, MAP |
| Ch05 | $H(X) = -\sum p \log p$ | 交叉熵, KL |

### 1.4 学习路径

- **入门**: 上课 + Gilbert Strang 线性代数
- **进阶**: Bishop PRML Ch1-5
- **应用**: PyTorch `torch.linalg` 实操
