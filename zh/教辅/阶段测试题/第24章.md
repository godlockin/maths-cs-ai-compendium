### 简答

**3.1** Mixed Precision: 权重 / 激活 / 梯度用 FP16 (省内存 + 快), 但**主副本 (master copy) 仍用 FP32** (避免精度损失)。技术:
- **Loss Scaling**: loss × scale (e.g. 65536), 防止 FP16 梯度下溢
- **GradScaler**: 检测 inf/nan, 动态调整 scale
- **关键算子 (Loss/Softmax) FP32 计算**

**3.2**
- **SGD**: 简单, 泛化好, 慢, 需手动调 lr; **适合 CNN/RL**
- **Adam**: 自适应, 快, 泛化略差, 默认首选; **适合 Transformer**
- **L-BFGS**: 二阶近似, 收敛快但内存大, 需小 batch; **适合小数据集 / 经典 ML**
- **Shampoo**: 二阶 preconditioner, 加速 2-3×; **适合大模型**

**3.3** SVM 原始: min (1/2)||w||² s.t. y_i(w·x_i+b)≥1。Lagrangian: L = (1/2)||w||² - Σαᵢ[y_i(w·x_i+b)-1]。对 w,b 求偏导 = 0: w = Σαᵢyᵢxᵢ, Σαᵢyᵢ = 0。代入得对偶: max Σαᵢ - (1/2)ΣΣαᵢαⱼyᵢyⱼ(x_i·xⱼ) s.t. αᵢ≥0。KKT 互补松弛: αᵢ[y_i(w·x_i+b)-1]=0, 即 y_i(w·x_i+b)>1 时 αᵢ=0 (非支持向量), =1 时 αᵢ≥0 (支持向量)。

**3.4**
- **DDP**: 每 worker 完整模型 + AllReduce 梯度。**内存 = 模型 + 优化器**。通信 1 次/步 (AllReduce)。
- **FSDP**: 模型/优化器/梯度都分片。**内存 = 模型/world_size + 优化器/world_size**。通信 2-3 次/步 (AllGather + ReduceScatter)。
- **选 DDP**: 模型 < 1.5B, 显存够
- **选 FSDP**: 模型 > 7B, 单卡放不下

**3.5** 场景:
- **Softmax**: exp(1000) = inf → 全 0
- **CrossEntropy**: log(0) = -inf
- **梯度消失**: 梯度小到 fp16 无法表示
避免: Softmax 减 max / CrossEntropy 内部已含 log_softmax / 用 bfloat16 / Loss Scaling。

### 编程

**4.1** 参考答案:
```python
import numpy as np

def softmax_stable(x):
    x = np.array(x)
    x_shifted = x - np.max(x)  # 关键: 减 max
    exp_x = np.exp(x_shifted)
    return exp_x / np.sum(exp_x)
```

import torch.distributed as dist
from torch.nn.parallel import DistributedDataParallel as DDP

def train_ddp(rank, world_size, model, optimizer):
    # 初始化
    dist.init_process_group("nccl", rank=rank, world_size=world_size)
    torch.cuda.set_device(rank)
    model = model.to(rank)
    ddp_model = DDP(model, device_ids=[rank])
