### 简答

**3.1** Goodhart's Law: "当度量变成目标, 它就不再是好度量"。LLM 中: RM 喜欢长回答 → 模型生成冗长空话 (高 RM 低质量)。检测方法: 同时跟踪 RM 分数和人类/语义质量评分, 当两者相关性低时即 reward hacking。

**3.2** 见 P14 / 本章 §02 总结。核心区别:
- RLHF: RM + PPO, 训练慢 + 不稳定
- DPO: 闭式解, 无 RM, 一次 SFT
- GRPO: 组内相对优势, 无 Critic, 适合 Reasoning

**3.3** Mechanistic = **逆向工程**网络找到具体电路; Explainability = 后处理生成解释。前者更难但更根本 (Anthropic 2024 蓝图), 后者更通用但不可信 (SHAP 不反映模型真实推理)。

**3.4** ORM 只评最终答案对错; PRM 评**每一步推理**是否正确。数学/代码题需要多步推理, 中间错一步就全错, ORM 难以归因, PRM 可精确归因并针对性训练。DeepSeek-R1 / o1 用 PRM 在 AIME 上大幅提升。

**3.5** 4 层防御: ① **输入层** (Prompt 检测 + 长度限制 + 内容审查); ② **检索层** (RAG 内容过滤); ③ **模型层** (Safety Fine-tuning + Constitutional AI); ④ **输出层** (二次 LLM 审查 + 关键词过滤 + 人工兜底)。

### 编程

**4.1** 参考答案:
```python
def detect_reward_hacking(reward_history, quality_history):
    if len(reward_history) < 10:
        return False
    # 计算滑动相关系数
    import numpy as np
    r = np.array(reward_history[-20:])
    q = np.array(quality_history[-20:])
    correlation = np.corrcoef(r, q)[0, 1]
    # RM ↑ 但 Quality ↓ → reward hacking
    recent_r_slope = np.polyfit(range(len(r)), r, 1)[0]
    recent_q_slope = np.polyfit(range(len(q)), q, 1)[0]
    return recent_r_slope > 0.1 and recent_q_slope < -0.05 and correlation < 0.3
```

**4.2** 参考答案:
```python
import re

def detect_jailbreak(prompt: str) -> bool:
    prompt_lower = prompt.lower()
    for pattern in JAILBREAK_PATTERNS:
        if re.search(pattern, prompt_lower, re.IGNORECASE):
            return True
    # 启发式: 检测 Base64 长串 (绕过常见手法)
    if len(re.findall(r"[A-Za-z0-9+/=]{50,}", prompt)) > 0:
        return True
    return False
```
