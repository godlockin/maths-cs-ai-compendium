**要点**:
- 物理对称性是先验
- 强制等变提升数据效率与鲁棒性
- 例: CNN = 平移等变, GNN = 节点置换等变

### B2 (★★★)
**题目**: 推导 GCN 的归一化拉普拉斯 $\tilde L = I - D^{-1/2} A D^{-1/2}$ 特征值范围。

**要点**:
- $\tilde L$ 实对称, 特征值实
- 0 ≤ λ ≤ 2 (因为 $D^{-1/2}AD^{-1/2}$ 谱半径 ≤ 1)

### B3 (★★★)
**题目**: 比较 GCN, GraphSAGE, GIN 三种 GNN 的聚合函数和表达力。

**要点**:
- GCN: 加权平均 (归一化求和)
- SAGE: MEAN / MAX / LSTM, 可学
- GIN: SUM + MLP, WL 最优
- 表达力: GIN > GCN ≈ SAGE (部分场景)

**要点**:

### B5 (★★★)

### B6 (★★★)

- `Adam`, `lr=0.01`
- 期望精度: ~81%

**参考**:
```python
from torch_geometric.datasets import Planetoid
from torch_geometric.nn import GCNConv
import torch.nn.functional as F

dataset = Planetoid(root='/data/Cora', name='Cora')
data = dataset[0]

class GCN(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = GCNConv(dataset.num_features, 64)
        self.conv2 = GCNConv(64, dataset.num_classes)
    def forward(self, data):
        x, edge_index = data.x, data.edge_index
        x = F.relu(self.conv1(x, edge_index))
        x = F.dropout(x, training=self.training)
        x = self.conv2(x, edge_index)
        return F.log_softmax(x, dim=1)

model = GCN()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
```
