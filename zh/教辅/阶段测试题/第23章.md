### 简答

**3.1**
- **ReAct** = Reason + Act 交替, 适合**单步工具调用** (查资料 / 调 API)
- **Reflexion** = 失败反思 + 长期记忆, 适合**多轮调试** (编程 / 调试)
- **Voyager** = 技能库 + 自动课程, 适合**长期开放任务** (游戏 / 探索)

**3.2** MCP 设计动机: LLM 应用中"工具对接"重复劳动 (每个 LLM 厂商一套 API), 需要**跨厂商标准**。组件: Resources (数据) + Tools (函数) + Prompts (模板)。优势: ① 一次开发跨 Claude/Gemini/本地模型; ② 工具市场 (1000+ MCP Server); ③ 标准化错误处理。

**3.3** MemGPT 把 LLM 上下文比作"主存", 把外部存储比作"虚存"。通过**系统指令**让 LLM 主动管理: ① Recall (把虚存中相关数据调入主存); ② Archival (把主存数据持久化到虚存)。突破 Context Window 限制, 实现"无限长期记忆"。

**3.4**
- **Anthropic Computer Use**: 桌面优先 (macOS/Linux), 截图 → 鼠标键盘, Claude 模型, 沙盒
- **OpenAI Operator v2**: 全 OS (桌面+浏览器+移动), GPT-5.6, 1M context, 沙盒 + 权限
共同: 都用视觉 + 工具调用, 都强调安全

**3.5** 架构:
- **Loader**: PDF / Word / Confluence
- **Splitter**: 512 token, 重叠 50
- **Embedder**: BGE-large-zh
- **Retriever**: BM25 + 向量混合 (Hybrid)
- **Generator**: Claude 4.5 + System Prompt (引用源)
- **记忆**: Mem0 存用户偏好
- **反思**: Self-RAG 判断是否需要重检索
- **评估**: RAGAS (Faithfulness / Answer Relevance / Context Relevance)

### 编程

**4.1** 参考答案:
```python
class ReActAgent:
    def __init__(self, llm, tools):
        self.llm = llm
        self.tools = tools
        self.history = []
    
    def run(self, task, max_steps=10):
        self.history = [{"role": "user", "content": task}]
        for step in range(max_steps):
            # Reason
            prompt = f"Task: {task}\nHistory: {self.history}\nNext action (JSON):"
            response = self.llm(prompt)
            action = parse_action(response)  # {"tool": "search", "args": {...}}
            # Act
            if action["tool"] == "finish":
                return action["args"]["answer"]
            result = self.tools[action["tool"]](**action["args"])
            # Observe
            self.history.append({"action": action, "result": result})
        return "Max steps exceeded"
```

from mcp.server import Server
from mcp.types import Tool, TextContent

server = Server("company-tools")

@server.list_tools()
async def list_tools():
    return [
        Tool(
            name="search_db",
            description="搜索企业数据库",
            inputSchema={
                "type": "object",
                "properties": {"query": {"type": "string"}},
                "required": ["query"]
            }
        ),
        Tool(
            name="send_email",
            description="发送邮件",
            inputSchema={
                "type": "object",
                "properties": {
                    "to": {"type": "string"},
                    "subject": {"type": "string"},
                    "body": {"type": "string"}
                },
                "required": ["to", "subject", "body"]
            }
        ),
    ]

@server.call_tool()
async def call_tool(name, arguments):
    if name == "search_db":
        result = db.search(arguments["query"])
    elif name == "send_email":
        result = email.send(arguments["to"], arguments["subject"], arguments["body"])
    return [TextContent(type="text", text=str(result))]
