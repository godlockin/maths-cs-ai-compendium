### 简答

**3.1** BLEU = n-gram Precision (词级别), 不考虑语义; BERTScore = BERT 上下文 embedding 余弦相似度 (语义级)。BERTScore 在**开放式生成 / 摘要 / 翻译**上更接近人类判断, 在数学/代码等需要精确匹配的任务上 BLEU/EM 仍有优势。

**3.2** Construct Validity = Benchmark 测的是它声称测的能力。**例子**: GSM8K 测数学推理, 但模型可能只是**死记**训练数据中相似的题 (Contamination), 高分 ≠ 真推理。检测: 用改写题 (paraphrase) 测试分数是否稳定, 大幅下降说明模型没真推理。

**3.3** Prompt 模板示例:
```
You are evaluating two answers to a question.
Question: {question}
Answer A: {answer_a}
Answer B: {answer_b}

Rate each answer on:
1. Correctness (0-5): 是否正确
2. Reasoning (0-5): 推理过程
3. Clarity (0-5): 表达清晰

Let me think step by step:
[CoT]

Output JSON: {"winner": "A/B/TIE", "scores_a": [...], "scores_b": [...]}
```

**3.4**
- MMLU: 多学科知识 (广度)
- GSM8K: 多步数学 (推理)
- HumanEval: 代码生成 (编程)
- HellaSwag: 常识推理 (日常)
- TruthfulQA: 真实性 (不撒谎)
5 个互补: 知识 + 数学 + 代码 + 常识 + 真实, 全面评估。

**3.5**
- **lm-evaluation-harness** (EleutherAI): 通用 200+ Benchmark, 英文为主, 工业首选
- **OpenCompass** (上海AI Lab): 中文 + 多模态, 国内模型首选

### 编程

**4.1** 参考答案:
```python
def pairwise_judge(judge_llm, answer_a, answer_b, prompt):
    # 第一次: A 在前
    p1 = f"{prompt}\nA: {answer_a}\nB: {answer_b}\nWinner:"
    v1 = judge_llm(p1)  # "A" or "B"
    # 第二次: B 在前 (消除 Position Bias)
    p2 = f"{prompt}\nA: {answer_b}\nB: {answer_a}\nWinner:"
    v2 = judge_llm(p2)
    # 转换 v2 (因为 A/B 角色对调)
    v2_inverse = "A" if v2 == "B" else "B" if v2 == "A" else "TIE"
    if v1 == v2_inverse:
        return v1
    return "TIE"
```

**4.2** 参考答案:
```python
def detect_contamination(train_texts, test_texts, n=13):
    # 提取训练集所有 n-grams
    train_ngrams = set()
    for text in train_texts:
        tokens = text.split()
        for i in range(len(tokens) - n + 1):
            train_ngrams.add(tuple(tokens[i:i+n]))
    # 检测测试集
    contaminated = 0
    for text in test_texts:
        tokens = text.split()
        for i in range(len(tokens) - n + 1):
            if tuple(tokens[i:i+n]) in train_ngrams:
                contaminated += 1
                break
    return contaminated / len(test_texts)
```
