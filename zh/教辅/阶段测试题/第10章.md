## Part C · 简答题 (5 × 6 = 30 分)

### C1 🟢
简述早期融合 vs 晚期融合的优缺点。哪个是当前主流,为什么?

<details><summary>答案模板</summary>

**早期融合**(Early/Feature-level):
- 优点: 跨模态细粒度交互,从输入开始就学到对齐
- 缺点: 输入维度大,需要学对齐分布差异,计算成本高,不适合 LLM 长上下文

**晚期融合**(Late/Decision-level):
- 优点: 可复用单模态预训练,简单,可独立训练各编码器
- 缺点: 学不到低层跨模态信号,只能末期整合

**当前主流:中层融合**(middle),例如:
- Q-Former / Perceiver Resampler 压缩视觉 token
- cross-attention 在 LLM 各层注入
- 兼顾效果和效率

</details>

### C2 🟢
解释 InfoNCE 损失的工作原理。它为什么需要大 batch?

<details><summary>答案模板</summary>

**InfoNCE** 把 N 对正负样本分类:
$$L = -\log\frac{\exp(s(z_i, z_i^+)/\tau)}{\sum_{j=1}^N \exp(s(z_i, z_j)/\tau)}$$

正例是对角线 (一张图配自己文本),其他 N²-N 看作负例。

**为什么需要大 batch**:
- softmax 分母是 N 项,需要足够多负样本才能学到"区分"
- N 太小 → 模型把正例、负例都认为相似 → 学不到对比
- SigLIP 用 sigmoid 损失打破这个限制

</details>

---

### C3 🟡
VQ-VAE 的 codebook collapse 现象是什么?列出 3 种缓解策略。

<details><summary>答案模板</summary>

**现象**: 部分 codebook entry 永远不被选中,有效 codebook size 远小于 K。导致下游任务表征能力下降。

**缓解策略**:
1. **EMA 更新**: codebook 不接受梯度,由编码器输出滑动平均更新(避免 Adam 训死)
2. **Code 重启**: 训练 N 步未使用的 entry, 重置为随机 $z_e$
3. **Gumbel-Softmax**: 加温度噪声做 softmax 近似 argmin,保持一定随机性

**补充**: commitment loss 系数 β 增大也能缓解 (鼓励 $z_e$ 接近 $z_q$ 但不强制一致)。

</details>

### C4 🟡
描述 Stable Diffusion 文生图的完整推理流程(从噪声到图像)。

<details><summary>答案模板</summary>

1. **采噪声**: $x_T \sim \mathcal{N}(0, I)$, T=1000 步
2. **循环去噪** (t = T → 1):
   - 用 UNet $\epsilon_\theta(x_t, t, c)$ 预测噪声; c = CLIP 文本嵌入(经 cross-attn 注入)
   - **CFG 加权**: $\hat\epsilon = (1+w)\epsilon_c - w\epsilon_\emptyset$ (通常 w=7.5)
   - 用 **DDPM/DDIM scheduler** 更新 $x_{t-1}$ (含均值、方差项)
3. **解码** $x_0$ (latent) → 经 VAE 解码器 → 像素图像

**关键工程**:
- DDIM 50 步即可,无需 1000 步
- KV cache 复用节省延迟
- batch 多图同时去噪

</details>

### C5 🔴
对比 BLIP-2 Q-Former / LLaVA 线性投影 / Flamingo Perceiver 三种 VLM 投影方案。哪个最适合边缘部署?

<details><summary>答案模板</summary>

**BLIP-2 Q-Former** (32 query token):
- 压缩率灵活,适合大视觉 patch 数
- 三任务预训练(ITC+ITM+ITG),表征质量高
- 显存大,延迟 80-150ms

**LLaVA 线性投影** (1 层 linear):
- 最简单,计算几乎零开销
- 视觉信息直接给 LLM,几乎无损
- 但 LLM 上下文长度压力大

**Flamingo Perceiver Resampler** (64 token):
- 跨 transformer 块压缩
- few-shot 上下文学习强
- 训练复杂

**边缘部署最佳**: LLaVA 风格线性投影,因为:
- 推理时几乎无额外开销
- INT8 量化友好
- 移动硬件(NPU/DSP)直接支持 linear
- 视觉序列长度可灵活控制

</details>

### D3 🔴
多模态幻觉的根因是什么?列出 4 类缓解技术并举例。

<details><summary>答案要点 (8 分)</summary>

**根因**:
1. **训练数据偏差**: 图文对中图说描述不等于全部内容,模型学"猜"
2. **视觉表征不完备**: ViT 编码丢失细节,LLM 靠文本补全 → 幻觉
3. **缺乏 grounding**: 模型没有强制把每个 token 对应到图像区域
4. **自回归错误传播**: 一个错误 token 影响后续生成

**缓解技术**:
1. **视觉 grounding**: 用 attention map 强制模型 attention 到相关区域 (e.g., LLaVA-grounding)
2. **RLHF / DPO**: 用人类偏好对训练,降低幻觉率
3. **对抗训练**: 故意在图像上加 noise 让模型说"我不知道"
4. **多模型集成**: GPT-4V 先 answer 一个,再用一个 verifier 检测幻觉
5. **检索增强**: 模型回答时检索相关图像区域或文本

**代表工作**: RLHF-V, LLaVA-RLHF, OPERA, Woodpecker。

</details>

```python
def info_nce_loss(image_embeds, text_embeds, tau=0.07):
    # 相似度矩阵 (N, N)
    sim = image_embeds @ text_embeds.t() / tau  # (N, N)
    # 标签是对角线
    labels = torch.arange(sim.shape[0], device=sim.device)
    # 双向 InfoNCE
    loss_i = F.cross_entropy(sim, labels)  # image→text
    loss_t = F.cross_entropy(sim.t(), labels)  # text→image
    return (loss_i + loss_t) / 2
```

**评分要点**:
- 正确计算 NxN 相似度 (2 分)
- 双向对称 (2 分)
- softmax + 交叉熵 (2 分)

## Part F · 跨章综合题 (1 × 6 = 6 分 / 选 1)

### F1 ⭐
**跨章综合**: 用 Ch06 §03 ViT 和 Ch10 §01 解释为什么 ViT 适合作为 CLIP 编码器;再结合 Ch07 §04 Transformer 注意力机制,解释 VLM 中 cross-attention 如何工作。

<details><summary>参考答案</summary>

**ViT 适合 CLIP 的原因** (Ch06 §03 + Ch10 §01):
- ViT 通过 patch 化 + 自注意力,在足够数据下学到的表征比 CNN 更全局、更适合语义
- CLIP 训练目标是对比学习,需要视觉/文本嵌入空间对齐,ViT 输出的 patch feature 自带丰富语义
- 大模型 ViT-L/14 (1024 维特征) 在 ImageNet 22K 上预训练后,可直接 fine-tune 用作 CLIP

**VLM cross-attention 工作** (Ch07 §04 + Ch10 §02):
- LLM 解码器每层有 self-attn + cross-attn 两个子层
- self-attn 处理当前文本 (Q=K=V=文本)
- cross-attn 把视觉信息融入: Q=文本 state, K=V=视觉 patch embedding (经 Q-Former 或线性投影)
- 多个文本 token 都可 attend 到任意视觉 patch
- 实现 "看图说话": 当生成"猫" token 时,该层 cross-attn 高度权重到图像 cat 区域

**组合**: CLIP 提供对齐基础 + VLM 添加 LLM 推理能力 = 现代多模态系统

</details>
