### 8. 🔴【L5 评价】Classifier-Free Guidance 中增大引导强度 w 时?

## 三、简答题（6 × 5 = 30 分）

### 16. 🟡【L2 理解】早期、中期、晚期三种融合策略各有何优缺点? 当前主流是哪种, 为什么?

---

**答案**:

- **早期融合**: 处理前就拼接原始/低层特征, 能学细粒度跨模态交互, 但输入空间大、要硬对齐差异极大的数据类型 (稠密像素 vs 稀疏 token)。
- **晚期融合**: 各模态独立编码到预测层再平均/投票, 简单、可直接复用预训练单模态模型, 但学不到低层跨模态交互。
- **中期融合 (当前主流)**: 各自先编码, 中段用交叉注意力/投影合并 (Flamingo、LLaVA), 在模块化与丰富交互间取得平衡。

**来源**: 01. 多模态表征 §融合策略

### 17. 🟡【L3 应用】解释 InfoNCE 损失, 并说明为什么对比学习受益于大 batch。

---

**答案**: InfoNCE 是 $(K+1)$ 路分类: 让查询与正样本的相似度 (除温度 τ) 高于 $K$ 个负样本, 公式为 $-\log\frac{\exp(q\cdot k^+/\tau)}{\exp(q\cdot k^+/\tau)+\sum_j\exp(q\cdot k_j^-/\tau)}$。它是互信息下界, 负样本越多下界越紧、区分信号越强; 大 batch 提供更多 in-batch 负样本 (CLIP 据此用超大批), SigLIP 则用逐位 sigmoid 解除对全局 batch softmax 的依赖。

**来源**: 01. 多模态表征 §InfoNCE

### 18. 🟡【L3 应用】什么是 VQ-VAE 的码本坍塌 (codebook collapse)? 给出 3 种缓解方法。

---

**答案**: 现象: 训练中只有少数码本条目被反复使用, 其余"死掉", 有效码本远小于设定的 K, 表征能力下降。缓解: ① **EMA 更新码本** (码本不吃梯度, 用分配到的编码器输出滑动平均更新); ② **码本重启/复活** (把长期未用条目重置为当前编码器输出); ③ **Gumbel-Softmax** 软量化增加探索; 此外加大 commitment 系数 β、用量化熵正则也有效。

**来源**: 03. 图像与视频 Token 化 §码本坍塌

### 19. 🔴【L4 分析】描述 Stable Diffusion 文生图从高斯噪声到图像的完整推理流程。

---

**答案**:

1. 文本经 CLIP/T5 文本编码器得到条件嵌入 c;
2. 在潜空间采样 $x_T\sim\mathcal{N}(0,I)$ (潜噪声, 由 VAE 空间维数决定);
3. 从 $t=T$ 到 1 迭代: UNet 预测噪声 $\epsilon_\theta(x_t,t,c)$ (条件经交叉注意力注入); 用 **CFG** 组合有条件/无条件预测 $\hat\epsilon=(1+w)\epsilon_c-w\epsilon_\varnothing$ (典型 w≈7.5); 由 DDPM/DDIM 调度器更新到 $x_{t-1}$ (DDIM 常 20-50 步即可);
4. 把去噪后的潜变量 $x_0$ 经 VAE 解码器还原成像素图像。

**来源**: 04. 跨模态生成 §潜扩散 / §无分类器引导

### 20. 🔴【L4 分析】对比 BLIP-2 Q-Former、LLaVA 线性投影、Flamingo Perceiver Resampler 三种视觉 token 接入 LLM 的方案。

---

**答案**:

- **LLaVA 线性/MLP 投影**: 最简单, 把图块特征映射到 LLM 维度直接拼接, 推理几乎零额外开销、量化友好, 但视觉 token 多、占上下文。
- **BLIP-2 Q-Former**: 32 个可学习查询经交叉注意力压缩成定长 token, 还用 ITC/ITM/ITG 三任务预训练, 表征质量高, 但模块更重。
- **Flamingo Perceiver Resampler**: 64 个学习 token 把可变数量视觉特征压成固定长度, 再经门控交叉注意力 (门 α 初始化为 0) 注入冻结 LM 各层, 支持图文交错与少样本, 训练最复杂。

端侧部署通常偏好 LLaVA 式简单投影 (额外参数少、NPU 友好)。

**来源**: 02. 视觉语言模型 §规模化 / §Q-Former

### 21. 🔴【L4 分析】2026 年图像/视频生成的两个核心竞争力为什么从"单张画质"转向"一致性"与"音画一体"? 结合正文说明。

---

**答案**: 单张生成好看在 2024-2025 已商品化 (commodity), 扩散与流匹配的画质普遍达标; 真正的付费能力转向: ① **跨轮/跨镜头一致性**——同一角色、产品、场景在多图多镜头里保持不变 (Runway Gen-4、Nano Banana 角色一致性、多模态 LLM 原生编辑), 这是影视/电商管线的刚需; ② **音画一体**——Veo 3 首次把对话口型、音效、环境音与画面同步生成, MiniMax H3 (2026-08 开源) 用原生立体声把它带进开源阵营, 省去后期配音。这两点都对应"统一多模态架构"(§05) 相对"独立扩散工具"的结构性优势; Sora 2 的停运还说明产品成败同时取决于算力成本、版权治理与商业模式。

**来源**: 06. 图像与视频生成进展 §一/§二

### 22. 🟡【L3 应用】用 PyTorch 实现 CLIP 风格的对称 InfoNCE 对比损失。

```python
import torch
import torch.nn.functional as F

def clip_loss(image_embeds: torch.Tensor,
              text_embeds: torch.Tensor,
              tau: float = 0.07) -> torch.Tensor:
    """
    image_embeds / text_embeds: (N, D), 已 L2 归一化
    返回对称的图文对比损失 (标量)
    """
    pass  # 实现
```

---

**答案**:

```python
def clip_loss(image_embeds, text_embeds, tau=0.07):
    image_embeds = F.normalize(image_embeds, dim=-1)
    text_embeds = F.normalize(text_embeds, dim=-1)
    logits = image_embeds @ text_embeds.t() / tau   # (N, N)
    targets = torch.arange(logits.shape[0], device=logits.device)
    loss_i2t = F.cross_entropy(logits, targets)          # 图找文
    loss_t2i = F.cross_entropy(logits.t(), targets)      # 文找图
    return (loss_i2t + loss_t2i) / 2
```

要点: L2 归一化、N×N 相似度除以温度、对角线为正样本标签、双向交叉熵取平均。

**来源**: 01. 多模态表征 §CLIP (编程任务 1)

### 23. 🔴【L6 自造场景】给定一段视频, 设计"镜头切分 + 多模态描述"的处理管线。

```python
# 用任意工具/库 (如 decord 抽帧, transformers 调 VLM), 写出步骤与关键调用
def describe_scenes(video_path: str) -> list[dict]:
    """
    返回 [{"start": float, "end": float, "caption": str}, ...]
    """
    pass
```

---

**答案**: 参考管线: ① **VAD/镜头切分**: 用帧间差异或 PySceneDetect 检测镜头边界, 得到 (start,end) 区间 (长视频还可按固定窗口切); ② **关键帧抽取**: 每个镜头取中间帧或多帧; ③ **VLM 描述**: 把帧喂给 Qwen3-VL / InternVL3.5 等开源 VLM (或调 API), prompt 如"用一句话描述这个镜头的主体、动作与场景", 多帧时让模型综合; ④ 可选 ASR 转写对白 (见第 9 章) 与描述合并; ⑤ 汇总成区间-描述列表。2026 年的 Qwen3-VL 已支持数小时视频 + 秒级时间定位, 可省去显式切分, 直接让模型输出带时间戳的镜头描述。

```python
import decord
from transformers import AutoProcessor, AutoModelForVision2Seq  # 示例 API
def describe_scenes(video_path):
    vr = decord.VideoReader(video_path)
    # 1) 每 N 帧抽一帧 (简化; 生产中用镜头检测)
    idxs = list(range(0, len(vr), vr.fps // 2))
    frames = [vr[i].asnumpy() for i in idxs]
    # 2) 调 VLM (伪代码, 具体按所选模型的 chat template)
    results = []
    for j, frame in enumerate(frames):
        t = j * 2.0 / 1.0
        caption = vlm_caption(frame, prompt="一句话描述这个镜头")
        results.append({"start": t, "end": t + 2.0, "caption": caption})
    return results
```
