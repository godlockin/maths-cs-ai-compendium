## Part C 简答 (5 × 6 = 30)

### C1 🟢
简述 SLAM 的前/后端职责分工。

<details><summary>答案</summary>

**前端 (Front-End)**:
- 提取关键帧 + 特征 (如 ORB)
- 计算相机位姿 (视觉里程计/IMU)
- 数据关联

**后端 (Back-End)**:
- 全局 BA / Pose Graph 优化
- 回环检测 (词袋/Sim(3))
- 地图管理

**典型实现**: ORB-SLAM, VINS-Mono, OKVIS, SplaTAM

</details>

### C2 🟡
**Diffusion Policy** 与 **BC (行为克隆)** 的本质区别是什么?

<details><summary>答案</summary>

| 维度 | BC | Diffusion Policy |
|------|----|------------------|
| 训练 | 单步 MSE / MLE | 多步去噪 |
| 多模态 | 弱 (均值) | 强 (表达多解) |
| 长 horizon | 易漂移 | 鲁棒 |
| 数据效率 | 中 | 较低 (需更多数据) |
| 推理速度 | 1 ms | ~50 ms (16 步) |

实测 ManiSkill2 DP 比 BC 强 3-5 倍。

</details>

### C3 🟡
解释 **MPC** 在自动驾驶控制中的具体应用。

<details><summary>答案</summary>

**MPC 思路**: 用车辆动力学模型预测未来 N 步轨迹, 在线求解最优控制序列。

**自动驾驶应用**:
- **车道跟随**: 跟踪规划轨迹, 预测 10 步 (50 ms 周期)
- **避障**: 软约束融入障碍物距离
- **节能**: 用纵向 MPC 优化加减速

**目标函数**:
$$\min_u \sum \|x_{t+k} - x^*\|^2_Q + \|u\|^2_R$$
s.t. 车辆动力学, 速度约束, 加速度约束。

**工程库**: ACADO, CasADi, ACADOS。

</details>

### D1 🔴
**VLA 模型通用化的三大挑战**及解决思路。

<details><summary>答案</summary>

**挑战**:
1. **数据稀缺**: 机器人轨迹成本高,互联网图文数据无法直接使用
2. **异构机器人**: 不同形态(双臂/四足/人形)的动作空间不同
3. **仿真到真实**: sim-to-real gap, 加速度/接触动力学仿真不准

**解决思路**:
1. 数据: Open X-Embodiment 跨机器人数据 + 自我中心相机 + 众包平台
2. 异构: 共享 VLM 视觉/语言编码 + 各机器人专属 action head
3. sim2real: 大模型通用化降低 sim2real gap (因为真实数据参与训练)

**代表工作**: π0 (3B), OpenVLA (7B 开源), RT-2 (55B)。
</details>

## Part E 代码题 (1 × 6)

### E1 🔴
写一个简化 BEV 占据预测的伪代码, 输入为 6 个相机图像, 输出为 256×256×32 占据体素。

<details><summary>答案</summary>

```python
import torch
import torch.nn as nn

class BEVOccupancyNet(nn.Module):
    def __init__(self, n_cams=6):
        super().__init__()
        # 共享视觉编码器
        self.backbone = ViT_L_ImageNet(n_cams=n_cams)
        # BEV 空间转换 + 高度聚合
        self.bev_transform = BEVTransform(in_dim=768, out_dim=128)
        # 3D 占据头部
        self.occ_head = nn.Sequential(
            nn.Conv3d(128, 64, 3, padding=1),
            nn.ReLU(),
            nn.Conv3d(64, 1, 1),  # 输出每个体素占用 0/1
        )

    def forward(self, images):
        # images: (B, 6, 3, H, W)
        feats = self.backbone(images)  # (B, 6, 768, h, w)
        bev = self.bev_transform(feats)  # (B, 128, 256, 256)
        # 假设 32 高度层
        bev_3d = bev.unsqueeze(2).expand(-1, -1, 32, -1, -1)  # (B, 128, 32, 256, 256)
        occ = self.occ_head(bev_3d)  # (B, 1, 32, 256, 256)
        return occ.squeeze(1).sigmoid()
```

**评分点**: BEV 转换正确 (2), 3D 占据输出正确 (2), 多相机融合 (2)。

</details>

### 易错点

- VLA 是 Vision-Language-Action, 不是 Visual
- L4 是"限定 ODD",L5 是"全场景"
- Diffusion Policy 16 步 (不是 1000)
- BA 中是 Levenberg-Marquardt / Schur complement
