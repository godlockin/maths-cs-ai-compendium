## 三、简答题（6 × 5 = 30 分）

### 16. 🟢【L2 理解】简述 SLAM 前端与后端的职责分工。

---

**答案**:

- **前端**: 提取关键帧与特征 (如 ORB)、视觉/视觉-惯性里程计估计局部位姿、数据关联 (特征匹配/跟踪)。
- **后端**: 全局 BA (光束平差) 或位姿图优化、回环检测 (词袋等)、地图管理与一致校正。
- 代表实现: ORB-SLAM、VINS-Mono、SplaTAM (3DGS 系)。

**来源**: 01. 感知 §SLAM

### 17. 🟡【L3 应用】Diffusion Policy 与行为克隆 (BC) 的本质区别?

---

**答案**: BC 用单步监督回归把观测映射到动作, 对多模态动作分布 (同一任务有几种合理做法) 只能回归到均值, 长程任务易漂移; Diffusion Policy 把动作生成建模为多步去噪, 能表达多模态分布、长 horizon 更稳, 代价是推理要 16 步左右迭代 (~50 ms)。实测同类基准上常比 BC 强数倍。

**来源**: 02. 机器人学习 §Diffusion Policy

### 18. 🟡【L3 应用】解释 MPC 在自动驾驶控制中的作用与目标函数结构。

---

**答案**: MPC 用车辆动力学模型向前预测 N 步 (典型 10 步), 在线求解带约束的最优控制序列, 只执行第一步并滚动重算。目标函数形如 $\min_u \sum_k \|x_{t+k}-x^*\|^2_Q + \|u\|^2_R$——跟踪参考轨迹 (Q 权重) 同时惩罚剧烈控制 (R 权重), 约束包括动力学方程、速度/加速度界限、避障距离。工程常用 ACADO/CasADi/ACADOS 求解。

**来源**: 04. 自动驾驶 §MPC

### 19. 🟡【L3 应用】端到端与模块化自动驾驶路线的优劣与代表?

---

**答案**: 模块化 (Waymo): 感知→预测→规划分模块, 可解释、易定位问题、便于安全认证, 但模块间误差累积、信息损失; 端到端 (Tesla FSD v12 起全神经): 原始传感数据直出轨迹, 可联合优化、上限高、数据驱动扩展, 但黑盒难调试、需冗余监控。Wayve 与百度 Apollo 属混合探索派。2025-2026 现实: Waymo 六城商业运营 (年约 1400 万付费行程), Apollo Go 覆盖 20+ 城 (累计 2200 万单), L4 进入单位经济验证阶段。

**来源**: 04. 自动驾驶 §两条路线 / §商业化快照

### 20. 🔴【L4 分析】VLA 通用化的三大挑战与对应解决思路?

---

**答案**:

- **数据稀缺**: 机器人轨迹成本高 (遥操作秒级采集), 比互联网图文少几个数量级 → 跨形态共享数据 (Open X-Embodiment) + 仿真合成 + 从 VLM 预训练迁移表征。
- **异构形态**: 双臂/四足/人形动作空间不同 → 共享 VLM 骨干 + 形态专属动作头/动作专家 (π0 的流匹配专家)。
- **sim-to-real gap**: 接触动力学、执行器摩擦仿真不准 → 域随机化 + 可微仿真 (Newton) + 真实数据微调 (π0.5 用互联网知识兜底开放世界)。

**来源**: 03. 视觉-语言-动作模型 / 02. 机器人学习

### 21. 🔴【L4 分析】NeRF 与 3DGS 在自动驾驶仿真中的作用与对比?

---

**答案**: 两者都从多视角采集数据重建可自由渲染的场景, 用于 corner case 合成与传感器仿真。NeRF 训练慢 (小时级)、渲染慢 (秒级/帧), 适合离线高保真重建; 3DGS (SIGGRAPH 2023) 训练分钟级、渲染 30+ fps, 支持实时视角合成与编辑, 已成为自驾仿真主流 (Street Gaussians、SplaTAM 等)。工程注意: 重建的是"采集时刻的静态世界", 动态目标与光照变化需额外建模; 软件分布现实 (corner case 长尾) 不能只靠重建解决, 还要生成式世界模型补。

**来源**: 01. 感知 / 04. 自动驾驶 §仿真

## 四、编程题（2 × 10 = 20 分）

### 22. 🟡【L3 应用】实现简化 BEV 占据预测网络的伪代码: 输入 6 路相机图像, 输出 256×256×32 占据体素。

---

**答案**:

```python
import torch
import torch.nn as nn

class BEVOccupancyNet(nn.Module):
    def __init__(self, n_cams=6):
        super().__init__()
        self.backbone = ViTEncoder(n_cams=n_cams)          # 共享视觉骨干
        self.bev_transform = BEVTransform(in_dim=768, out_dim=128)  # 2D->BEV
        self.occ_head = nn.Sequential(
            nn.Conv3d(128, 64, 3, padding=1), nn.ReLU(),
            nn.Conv3d(64, 1, 1),                            # 每体素占据 logit
        )

    def forward(self, images):                     # (B, 6, 3, H, W)
        feats = self.backbone(images)              # (B, 6, 768, h, w)
        bev = self.bev_transform(feats)            # (B, 128, 256, 256)
        bev_3d = bev.unsqueeze(2).expand(-1, -1, 32, -1, -1)
        return self.occ_head(bev_3d).squeeze(1).sigmoid()  # (B, 32, 256, 256)
```

评分点: 多相机共享骨干 (2)、几何正确的 BEV 投影 (3)、高度维扩展与 3D 占据头 (3)、sigmoid 输出概率 (2)。

**来源**: 04. 自动驾驶 §BEV
