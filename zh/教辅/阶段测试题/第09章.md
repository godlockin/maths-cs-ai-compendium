## 三、简答题 (6 × 6 = 36 分)

### 16. 🟡【L2 理解】解释 MFCC 比原始波形更适合 ASR

**答案**: 
- 原始波形: 时域, 包含说话人/环境/相位等冗余信息
- MFCC: 频域, **模拟人耳听觉** (Mel 尺度), 压缩低频分辨率, 13 维足够表示语音
- ASR 模型对 MFCC 收敛更快, **WER 降低 30-50%**

**来源**: 01.语音基础 §反例

### 17. 🟡【L3 应用】手算 Viterbi 简单例子

**答案**: 
- 2 状态 HMM, 转移 $a_{12}=a_{21}=0.5$, 输出概率 $b_1(\text{a})=0.8, b_2(\text{a})=0.2$
- 观察序列 "a"
- $\delta_1(1) = b_1(a) = 0.8, \delta_1(2) = b_2(a) = 0.2$
- 最优路径: 状态 1 (概率 0.8 > 0.2)

**来源**: 02.声学模型 §公式

### 18. 🟡【L3 应用】CTC 软对齐与传统硬对齐区别

**答案**: 
- 传统硬对齐 (HMM): 1 帧对应 1 个音素, 需 force-alignment 标注
- CTC 软对齐: 允许 1 帧重复 (如 'a' → 'aa') 或空白 $\epsilon$, 概率自动归并
- **优点**: 无需预标注, 端到端训练
- **缺点**: 输出长度不定, 需去除重复 + 空白 (decoding)

**来源**: 03.端到端ASR §反例

### 19. 🔴【L4 分析】为什么 x-vector 需要统计池化

**答案**: 
- 帧级 (frame-level) 输出变长: 不同音频长度不同
- 统计池化 (均值+标准差): 变长 → 定长, 每段 1024 维 → 拼接 512+512 = 1024 维
- 定长后接全连接 → 512 维 x-vector
- **好处**: 支持任意长度音频, 鲁棒 (均值对噪声鲁棒, 标准差保留动态信息)

**来源**: 04.说话人识别 §公式

### 20. 🔴【L4 分析】TTS 三代模型演化

**答案**: 
- **拼接合成 (2000s 前)**: 从大语料库挑音素片段拼接, 死板
- **参数合成 (2010s)**: WaveNet 等自回归, MOS 4.0, 但慢
- **端到端神经 TTS (2017+)**: Tacotron 2 + WaveNet 声码器, MOS 4.5
- **非自回归 TTS (2020+)**: FastSpeech 2, 速度 50x, MOS 4.4
- **VAE+GAN 端到端 (2021+)**: VITS, MOS 4.4 单模型, 真人音色

**来源**: 信息图 §SOTA 进展

### 21. 🔴【L5 评价】为什么 Conformer 比纯 Transformer ASR 准确率高

**答案**: 
- 纯 Transformer: 仅有**全局** self-attention, 局部声学细节 (mfcc 共振峰、辅音) 捕获弱
- Conformer: CNN 提取**局部**声学特征 + Transformer 全局上下文, 互补
- 数字: LibriSpeech test-clean, Conformer WER 1.9% vs Transformer WER 2.6% (降 0.7 个百分点)
- **反例**: 纯 CNN 不能建模长程依赖, 纯 Transformer 不能建模短时声学, 单独用都退化

**来源**: 03.端到端ASR §反例

### 22. 🟡【L3 应用】用 librosa 提取 MFCC 并画图

```python
import librosa
import librosa.display
import matplotlib.pyplot as plt

y, sr = librosa.load("speech.wav", sr=16000)
mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=13, n_fft=400, hop_length=160)
print(mfcc.shape)  # (13, T) — 13 MFCC × T 帧
librosa.display.specshow(mfcc, x_axis="time", sr=sr, hop_length=160)
plt.colorbar()
plt.title("MFCC")
plt.show()
```

**期望输出**: 13 维 MFCC, 帧数 = 时长×采样率/hop_length ≈ 时长×100  
**来源**: 01.语音基础 §公式
