## 三 · 关键流程 (4 步)

### 流程 A: Git Flow

1. `git checkout -b feature/x`
2. 开发 + commit
3. `git push` + 开 PR
4. Review → merge → 删分支

### 流程 B: Docker 部署

1. 写 `Dockerfile`
2. `docker build -t myapp:v1`
3. `docker run -d -p 8000:8000 myapp`
4. 推 `docker push` 到 registry

### 流程 C: CI/CD

1. Push → 触发 GitHub Actions
2. 跑 lint + test
3. build Docker 镜像
4. 部署到 staging → 生产

### 流程 D: LLM 服务化

1. FastAPI 包装模型
2. vLLM 推理引擎
3. Docker 镜像
4. K8s 部署 + autoscaling
