## 三 · 关键流程 (4 步)

### 流程 A: 实时推荐

1. 用户事件 → Kafka
2. Flink 实时特征
3. 在线推理 (TensorFlow Serving)
4. 返回结果

### 流程 B: 离线训练

1. 数据湖 (S3) → Spark 处理
2. 特征工程 (离线)
3. 训练 (PyTorch + DDP)
4. 模型注册 (MLflow)

### 流程 C: 在线服务

1. 用户请求 → API Gateway
2. 在线特征 (Redis)
3. 模型推理 (vLLM)
4. 监控 (Prometheus)

### 流程 D: 模型更新

1. 新数据回流
2. 触发重训
3. 评估 (A/B test)
4. 灰度发布
