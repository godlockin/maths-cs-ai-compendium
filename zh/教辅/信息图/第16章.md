## 三 · 关键流程 (4 步)

### 流程 A: SIMD 优化

1. **Profile**: `perf` 找热点
2. **向量化**: 用 AVX intrinsics
3. **数据对齐**: 32 / 64 字节
4. **验证**: 数值一致性

### 流程 B: CUDA Kernel

1. **分配**: `cudaMalloc` / `cudaMemcpy`
2. **启动**: `kernel<<<grid, block>>>(...)`
3. **同步**: `cudaDeviceSynchronize`
4. **取结果**: `cudaMemcpy` 回 host

### 流程 C: Triton 编程

1. 定义 `@triton.jit` 函数
2. 自动向量化 / 调优
3. 编译为 PTX
4. 调用执行

### 流程 D: 量化部署

1. FP32 → FP16 / BF16
2. PTQ (训练后量化)
3. QAT (量化感知训练)
4. 部署到边缘 (INT4)
