## 三 · 关键流程 (4 步)

### 流程 A: 哈希表查找

1. **哈希函数**: $h(\text{key}) \to [0, m)$
2. **冲突**: 链地址 (chaining) 或开放定址 (probing)
3. **查找**: 平均 $O(1)$, 最坏 $O(n)$
4. **扩容**: rehash, 装填因子 > 0.7 触发

### 流程 B: Dijkstra 最短路

1. **初始化**: dist[start] = 0, 其他 = ∞
2. **优先队列**: 弹出最小 dist 节点
3. **松弛**: 更新邻居
4. **终止**: 所有节点访问完

### 流程 C: 红黑树插入

1. 标准 BST 插入
2. 修复: 变色 / 旋转
3. 满足 5 性质 (黑高一致等)
4. 树高 $O(\log n)$

### 流程 D: LRU Cache

1. **哈希表**: key → 链表节点
2. **双向链表**: 维护访问顺序
3. **访问**: 移到链表头
4. **淘汰**: 链表尾 (最久未用)
