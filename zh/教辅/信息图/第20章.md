## 三 · 关键流程 (4 步)

### 流程 A: 量子 ML

1. 编码数据 (amplitude / angle)
2. 设计量子电路
3. 测量结果
4. 经典后处理

### 流程 B: 神经形态

1. spike 编码
2. SNN 网络
3. 异步事件驱动
4. 低功耗推理

### 流程 C: 太空数据中心

1. 太阳能板发电
2. 辐射加固服务器
3. 真空环境散热
4. 激光 / RF 通信

### 流程 D: 脑机接口

1. 神经信号采集 (电极 / EEG)
2. 特征提取
3. ML 解码 (意图)
4. 反馈 (机器 / 显示)
