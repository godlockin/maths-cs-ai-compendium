## 三 · 关键流程 (4 步)

### 流程 A: AI 药物发现

1. **靶点**: 选定蛋白 (e.g., 受体)
2. **生成**: Diffusion / RL 生成分子
3. **筛选**: docking + QED
4. **优化**: 合成 + 测试

### 流程 B: LLM Agent

1. **任务**: 用户给目标
2. **规划**: LLM 拆分子任务
3. **执行**: 调工具 / 检索 / 写代码
4. **验证**: 检查结果, 循环

### 流程 C: 蛋白结构预测

1. **MSA**: 多序列比对
2. **Pair representation**: 残基对
3. **Evoformer**: 推理
4. **Structure module**: 3D 输出

### 流程 D: 量化交易

1. **数据**: K 线 / 财报 / 新闻
2. **特征**: 技术指标 / NLP
3. **模型**: LSTM / Transformer
4. **回测**: 策略验证
