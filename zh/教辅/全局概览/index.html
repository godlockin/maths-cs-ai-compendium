    全局概览 · AI 全领域地图 (跨 25 章)¶

    一句话总纲: 本套书覆盖数学基础 → 机器学习 → 深度学习 → 多模态 → 应用 → 工程 → 前沿 → 对齐评估 → Agent → 面试, 25 章构成 AI 工程师"从理论到落地到面试"的完整地图。本文档是跨章学习路径 + 领域全景。
