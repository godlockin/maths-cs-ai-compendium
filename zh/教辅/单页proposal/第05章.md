# Ch05 概率论：把不确定性算清楚

## 30 秒锚点

生日悖论: 23 个人聚在会议室, 任两人生日撞上的概率就已经过 50% — 直觉上"得 366 人吧", 算完才 23。设 23 人两两生日独立, 撞上的概率 = $1 - 365/365 \times 364/365 \times \cdots \times 343/365 \approx 0.507$。这一章要算的就是这类"独立事件的累积概率", 顺便给后续所有 ML 模型的噪声、数据采样、参数不确定性一个**带公理的口径**。

## 为什么学

- **AI 数学底层**: 测度论三件套 (Ω, F, P) 是现代概率论的严格起点; 公理不立, 后续"独立""条件概率"全站不住。
- **ML 全部模型的母语**: Bernoulli / Binomial (分类损失)、Poisson (计数与事件流)、Normal (噪声 + VAE 重参数化)、Exponential / Gamma / Beta (先验与共轭)、Dirichlet (主题模型) — Ch05 一节把这一族全部过完。
- **贝叶斯接入点**: 条件概率、全概率公式、Bayes 公式构成现代 AI 的核心 — 从朴素贝叶斯分类器到语言模型微调, 一条线穿下来。

## 学完能干什么

- 🟢 **L2 我能**用样本空间 Ω、事件域 F、概率测度 P 三件套定义一个简单随机实验 (如掷两次骰子, 显式列出 Ω 与事件)。
- 🟢 **L3 我能**在 ≤3 步内算完一个二项/泊松/正态分布的具体问题 (例: $n=10, p=0.3$ 时 $P(X=3) = \binom{10}{3}(0.3)^3(0.7)^7 \approx 0.267$)。
- 🟡 **L4 我能**区分 PMF (Σ) 与 PDF (∫) 的语义, 解释"PDF 值大于 1 合法"的来源 (密度不是概率, 面积才是)。
- 🟡 **L4 我能**用全概率公式做至少一次"分情形合并"和用 Bayes 公式做至少两次**后验更新** (疾病检测 + 二次检测)。
- 🟡 **L4 我能**陈述大数定律与中心极限定理, 并验算"n=30 时样本均值近似正态"。
- 🔴 **L5 我能**说出 PDF 与 PMF 在测度论下的统一 (Radon-Nikodym 导数), 并指出"连续 vs 离散"本质是**对哪种测度取密度**。
- 🔴 **L5 我能**用 KL 散度 $D_{KL}(P\|Q) = \sum p \log(p/q)$ 计算两分布差异, 并解释 softmax / cross-entropy 损失与它的关系。

## 1 分钟核心内容

- **测度论三件套**: 样本空间 Ω (所有可能结果)、事件域 F (Ω 上的 σ-代数, 必须含 Ω 且对补集与可列并封闭)、概率测度 P (满足 K1 非负 / K2 规范化 / K3 可列可加)。K1/K2/K3 三件套与 Ch04 同源, 这里进测度论的**严格版**。几何直觉: 把 Ω 想象成一块质量 1 的橡皮泥, 事件就是切下来的一块, P 告诉你这块有多重。
- **PMF vs PDF 的核心差异**: 离散用 PMF, $P(X=x)$ 直接给概率, 全部加起来 = 1; 连续用 PDF, $f(x)$ 是**密度不是概率**, 单点 $f(x)$ 可大于 1 (例: $U(0, 0.5)$ 在 $x=0.1$ 处 $f=2$), 概率要看面积 $\int_a^b f(x)\,dx$。离散 (Σ) vs 连续 (∫) 的区别全靠上下文。
- **常见分布族完整版**: 离散 — Bernoulli / Binomial / Poisson / Geometric / Negative Binomial; 连续 — Uniform / Normal / Exponential / Gamma / Beta / χ² / Student-t / Dirichlet。每一族都有 PMF/PDF、支撑集、均值、方差四件套, 数字例 ≤3 步可验。
- **条件概率与独立性**: $P(A|B) = P(A \cap B) / P(B)$ (P(B)>0); 独立 iff $P(A|B) = P(A)$。常见踩坑: 不代表"两事件无关联"而是"知不知道 B 不影响 A 的判断"。
- **全概率 + Bayes 公式**: $P(B) = \sum P(B|A_i) P(A_i)$ (分情形合并); $P(A_i|B) = P(B|A_i) P(A_i) / P(B)$ (已知 B 反推 $A_i$)。Bayes 公式的分母就是全概率公式。
- **大数定律 (LLN)**: $\bar X_n \to \mu$ 几乎必然 — 频率派"长期相对频率"的数学根据; **中心极限定理 (CLT) 严格版**: i.i.d. 变量和的标准化收敛到 $N(0,1)$, Berry-Esseen 界给出收敛速度, Lindeberg 条件给"哪些分布族成立"的判别。
- **信息论入门**: 自信息 $I(x) = -\log p(x)$; 熵 $H(X) = -\sum p\log p$ (分布不确定性的平均度量); KL 散度 (见下, **先给数例再给公式**); 互信息 $I(X;Y) = H(X) - H(X|Y)$。

  - **KL 散度**: **先给例** — 取 $P=(0.5,\,0.5)$, $Q=(0.9,\,0.1)$, 则 $D_{KL}(P\|Q) = 0.5\log_2(0.5/0.9) + 0.5\log_2(0.5/0.1) \approx \mathbf{0.737}$ bit (单位 bit, 因取 $\log_2$)。**再给公式** — $D_{KL}(P\|Q) = \sum_x P(x)\log_2[P(x)/Q(x)] = H(P,Q) - H(P) \ge 0$。三性质: 非负、$P=Q$ 时为 0、**不对称** $D_{KL}(P\|Q)\ne D_{KL}(Q\|P)$。
- **AI/ML 对接**: softmax 归一化 = 离散分布归一化; GMM = 多高斯加权; VAE 重参数化 = 把采样从 N(μ,σ²) 移到 N(0,1) 再仿射; 语言模型 perplexity = $2^{H(P)}$; KL 散度正则 = 约束生成分布不离先验太远; cross-entropy 损失 = $-\sum p\log q$。
