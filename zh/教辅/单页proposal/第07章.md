# Ch07 计算语言学：从字符序列到大语言模型

## 30 秒锚点

ChatGPT 全球月活跃用户 2024 年年中跨过 2 亿，背后的整套机理——分词、子词合并、词嵌入、自注意力、下一 token 预测、对齐——全部在 5 节里装完。打开任意一段英文输入："The cat sat on the mat"，进 BPE 后切成 ["The", "cat", "sat", "on", "the", "mat"]，每个 token 映射成 768 维向量，过 96 层 Transformer 块，输出下一个 token 的概率分布。本章要算的就是从这条字符串出发，经过哪些数学机制，才能在 0.5 秒内续出像人话一样的下文。

## 为什么学

- **现代 AI 的主战场**: 大语言模型（LLM）是 2024 年工业界最大的一笔投入（OpenAI、Anthropx、智谱、Qwen），其核心数学骨架只占 Ch07 的 5 节，其余全是对外延（提示工程、对齐、检索增强）。
- **Ch06 机器学习 + Ch05 概率论的具象落地**: Transformer 注意力 = Ch06 缩放点积，CLM 训练目标 = Ch05 负对数似然，perplexity = $2^{H(P)}$ 接 Ch05 信息论。
- **跨章接口枢纽**: Ch08 计算机视觉用同一套 Transformer 处理图像 patch（ViT），Ch12 图神经网络把它搬到了图上，Ch17 推理优化要管 KV-cache，Ch21 对齐讨论 RLHF——全部从这里分叉。

## 学完能干什么

- 🟢 **L2 我能**用 Levenshtein 动态规划手算 "kitten" → "sitting" 的编辑距离：$D[6][7]=3$，三步（k→s、e→i、插入 g），每步都在状态转移表里查到。
- 🟢 **L3 我能**写 BPE 合并算法：起始词表 = 26 字母 + 词边界；从 4 词语料开始，统计相邻对频率、合并 "es" 频率=9 的对、再合并 "est"，最终产出混合词表（"newest"、"widest" 整词 + "est"、"lo" 子词）。
- 🟡 **L4 我能**用 Skip-gram 负采样解释类比 $v_{\text{king}} - v_{\text{man}} + v_{\text{woman}} \approx v_{\text{queen}}$：收敛后点积近似 $\text{PMI}(w, c) - \log k$，"皇室"方向是大致线性的向量平移；PMI = Ch05 §05 信息论里的逐点互信息。
- 🟡 **L4 我能**手算多头注意力的形状链路: $X \in \mathbb{R}^{B \times T \times d_\text{model}}$, $Q = XW_Q \in \mathbb{R}^{B \times T \times d_\text{model}}$，拆成 $h$ 头后每头 $d_k = d_\text{model}/h = 64$（$d_\text{model}=512, h=8$）, $\text{softmax}(QK^\top/\sqrt{d_k})V$ 输出再 reshape 回 $B \times T \times d_\text{model}$，残差 + LN + FFN 接住。
- 🟡 **L4 我能**写缩放律 (Ch07 §04): $\text{loss} \propto N^{-\alpha_N}$，Chinchilla 修正为 $N_\text{opt} \propto C^{0.5}$、$D_\text{opt} \propto C^{0.5}$；经验上每参配 20 token 量训练（DeepSeek-V3 ≈ 700 亿参 × 14T token 训练）。
- 🔴 **L5 我能**陈述 RLHF 三步流程并解释 KL 惩罚 $\beta D_\text{KL}(\pi_\theta \| \pi_\text{SFT})$ 的作用：防止策略飘离基座、堵住奖励黑客（reward hacking）；$\beta$（KL 系数）≠ Ch04 二类错误率 $\beta$，$\pi_\theta$ 是策略网络，区别于 Ch01 的向量 $\pi$。
- 🔴 **L6 我能**指出 Chatbot Arena Elo 评分 $R_A' = R_A + K(S - P(A \succ B))$ 与 Ch07 §04 §05 的评测协议：位置偏差通过交换顺序减半、冗长偏差靠长度控制胜率纠正、数据污染靠金丝雀字符串。

## 1 分钟核心内容

- **01 语言学五层**: 音系 → 形态 → 句法 → 语义 → 语用；分布假说（Firth 1957）"看一个词就看它跟谁一起出现"是词嵌入的根。Geometric 直觉: 把"语义"想成三维空间里的点阵，词邻词。
- **02 经典 NLP 流水线**: 文本规范化 → 分词（BPE 合并高频相邻对、WordPiece 走 PMI 打分）→ TF-IDF 稀疏特征 → n-gram 语言模型 → POS/NER 序列标注（HMM 给出 $\hat{t}_{1:n} = \arg\max \prod P(w_i|t_i)P(t_i|t_{i-1})$）。
- **03 词嵌入 + 序列模型**: Word2Vec（CBOW/Skip-gram + 负采样）学稠密向量；GloVe 在全局共现矩阵上做加权最小二乘 $w_i^\top \tilde w_j + b_i + \tilde b_j = \log X_{ij}$；RNN/LSTM/GRU 用隐藏状态 $h_t$ 压历史；seq2seq + Bahdanau 注意力破固定向量瓶颈。
- **04 Transformer 与语言模型**: 缩放点积注意力 $\text{softmax}(QK^\top/\sqrt{d_k})V$（Ch06 已讲，这里接 RoPE 相对位置 + pre-norm + FFN）；三大范式: 仅编码器（BERT, MLM）、仅解码器（GPT, CLM）、编解码器（T5, span corruption）；PEFT（LoRA $W' = W + BA$, $r \ll d$）+ 缩放律（Chinchilla）+ MoE 路由 + 多层评测（BLEU → BERTScore → LLM 当裁判 + Elo）。
- **05 高级文本生成**: 文本扩散（D3PM、MDLM）绕开自回归串行，迭代去噪同时精炼所有 token；RLHF 三步（SFT → RM → PPO+KL 惩罚）；DPO 直接偏好优化绕过 RM；RAG 把外部检索段落塞进 prompt；推测解码用小模型起草大模型验证，2-3 倍吞吐。
- **跨章共同数学机制**: 注意力、词嵌入、扩散去噪全部走"内积 + 加权/归一化"这条主干；具体是 softmax 归一化把相似度变概率分布，线性层把分布投影回向量。<!-- FIX: P0-1: 跨章同源点必配具体机制 -->

## 前置知识 & 后置章节

**前置**: Ch05 概率论（逐点互信息 PMI、熵 $H(P)$、KL 散度 $D_\text{KL}$、交叉熵 + 负对数似然）；Ch06 机器学习（缩放点积注意力 $\text{softmax}(QK^\top/\sqrt{d_k})V$、残差 + LN、BCE 交叉熵、Adam 优化器、PPO 截断策略优化）。

**符号表 (跨章契约 v2, Ch07 专用)**:
- $d_\text{model}$ — **Transformer 隐藏维度**（例 768/1024/4096），符号 $d$ 一律指此；与 Ch06 $d_k$（注意力键维度，$d_k = d_\text{model}/h$）区分
- $\mathcal{M}$ — **掩码位置集合**（BERT MLM 损失中 $\mathcal{L}_\text{MLM} = -\sum_{i\in\mathcal{M}} \log P(w_i | w_{\backslash\mathcal{M}})$）；与 Ch05 测度空间 $\mathcal{M}$、Ch06 掩码张量 $M$ 区分
- $\beta$ — **Ch07 里以三种身份出现**：(1) KL 系数 $\beta D_\text{KL}(\pi_\theta \| \pi_\text{SFT})$；(2) LoRA 缩放 $\beta = \alpha/r$；(3) ROUGE/ChrF/METEOR 中精确率-召回率权重 $\beta^2$。**逐节必须标注 "$\beta$ (KL 系数)" 等**；严禁与 Ch04 二类错误率 $\beta$、Ch05 Beta 分布参数 $\beta$ 混用
- $\pi_\theta$ — **Ch07 策略网络**（RLHF/PPO 的 $\pi$）；与 Ch01 向量 $\pi$、Ch05 置换 $\pi$ 区分
- $h$ — **注意力头数**（$d_k = d_\text{model}/h$, 必须整除）
- $d_k$ — **每头键向量维度**（例 64），$Q, K \in \mathbb{R}^{n \times d_k}$
- $N, D, C$ — **缩放律三件套**：参数量 / 数据 token 数 / 算力 FLOPs；公式 $N_\text{opt} \propto C^{0.5}$
- $r$ — **LoRA 秩**（4-64 常见），区别于 Ch02 矩阵秩 $\text{rank}(A)$
- $R_A, R_B$ — **Chatbot Arena Elo 评分**（初始 1000 上下）；区别于 Ch04 R²、Ch05 风险率 $R(t)$

**后置**: Ch08 计算机视觉（ViT 把同一套注意力搬到图像 patch；CLIP 文本-图像对齐）；Ch09 音频与语音（Whisper 用 Transformer 做 ASR）；Ch17 AI 推理（KV-cache、PagedAttention、推测解码的理论基础来自 Ch07 §05）；Ch21 对齐安全与可解释性（RLHF/DPO 详化 + 红队评估）；Ch23 AI Agent（Function calling、ReAct、工具使用都基于 Ch07 LLM）。

## 时长 & 难度评级

阅读与手算 **150–210 分钟**（5 节，每节 30-42 分钟），编程练习（Colab JAX）**120 分钟**；难度 **🟡 中等偏高**，三道门槛：①负采样梯度推到 PMI 矩阵分解；②RoPE 旋转角度的几何直觉 $q'^\top k' = q^\top R_{m-n} k$；③RLHF 三步各自的损失函数与数据格式。⭐ 文本扩散 (D3PM) 闭式解、MDLM 掩码调度、专家并行 all-to-all 通信分析可跳读。

> **金句**: 语言模型不是理解了语言，而是在高维空间里把"接下来该说什么"算成了概率 — 学完 Ch07, 你至少能自己推一遍 perplexity 不是从天上掉下来的。
