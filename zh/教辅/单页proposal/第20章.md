## 选题 1: 量子-经典混合的 LLM 推理

**TL;DR**: 用 VQE 替代 LLM attention 中的部分矩阵运算, 探索量子优势。

### 核心问题
- 当前量子硬件规模小 (~100 qubit)
- LLM 推理需要大量线性代数
- VQE + LLM 混合架构是否可行?

### 目标
- 设计混合架构
- 在小模型 (Llama 1B) 测试
- 评估量子优势

### 关键公式
$$A_{\text{hybrid}} = \alpha A_{\text{quantum}} + (1-\alpha) A_{\text{classical}}$$

### 创新点
- 量子-经典接口
- 误差缓解
- 混合优化

### 参考
- IBM Qiskit
- Google Cirq
- PennyLane (Xanadu)

## 选题 2: 神经形态芯片部署 SNN LLM

**TL;DR**: 把 LLM 转 SNN, 在 Intel Loihi 上推理, 功耗降低 100×。

### 核心问题
- LLM 推理耗电 (70B 模型 ~700W)
- SNN 事件驱动节能
- SNN LLM 精度损失?

### 目标
- Llama 3 8B 转 SNN
- Loihi 2 推理
- <7W 功耗

### 关键公式
$$E_{\text{SNN}} = N_{\text{spikes}} \times C_{\text{per-spike}}$$
$$\text{Speedup} = \frac{E_{\text{ANN}}}{E_{\text{SNN}}}$$

### 创新点
- Spike 编码
- 时间步优化
- 替代激活

### 参考
- SNN 工具: Nengo, Norse, snnTorch
- Intel Loihi 2
- 清华天机芯

## 选题 3: 太空数据中心原型

**TL;DR**: 在低地球轨道 (LEO) 部署 GPU 集群, 24h 太阳能 + 真空散热, 太空 AI。

### 核心问题
- 地面数据中心耗电大
- 太空太阳能 24h
- 辐射 / 散热 / 通信挑战

### 目标
- LEO 60 GPU 集群
- 验证 AI 训练 / 推理
- 商业化路径

### 关键公式
$$P_{\text{solar}} = A_{\text{panel}} \times 1361 \text{ W/m²}$$
$$T_{\text{orbit}} = 90 \text{ min}$$

### 创新点
- 辐射加固 GPU
- 真空液冷
- 激光通信 (Starlink)

### 参考
- Google Project Suncatcher
- Starcloud / Lumen Orbit
- SpaceX

## 选题 4: 去中心化模型市场 (BitTensor)

**TL;DR**: 在区块链上构建模型市场, 模型贡献者获奖励, 类似 AI 版 Airbnb。

### 核心问题
- 中央化 AI 平台垄断
- 模型贡献者无激励
- 区块链 + AI 协同

### 目标
- 智能合约实现
- 100 个模型贡献者
- 激励机制设计

### 关键公式
$$\text{Reward}_i = f(\text{Quality}_i, \text{Rank}_i)$$

### 创新点
- 共识机制
- 推理验证
- 抗作弊

### 参考
- BitTensor (Bittensor)
- NEAR AI
- Ritual

## 选题 5: 脑机接口 + LLM (脑控 AI)

**TL;DR**: 用 BMI 信号解码意图, 让 LLM 帮人写邮件 / 控制机器人。

### 核心问题
- BMI 信号解码困难
- 实时性要求高
- LLM 输出长

### 目标
- EEG 解码 → text
- 50ms 延迟
- 准确率 > 90%

### 关键公式
$$\text{text} = \text{LLM}(\text{decoded\_intent})$$
$$T_{\text{end2end}} = T_{\text{decode}} + T_{\text{LLM}}$$

### 创新点
- 多模态 (EEG + EMG + EOG)
- Few-shot 适应
- 实时推理

### 参考
- Neuralink
- Synchron
- Meta BCI
