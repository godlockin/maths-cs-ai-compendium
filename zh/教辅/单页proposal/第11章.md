## 选题 1: 改进 Diffusion Policy 在长 horizon 任务中的稳定性

**TL;DR**: Diffusio Policy 用 16 步去噪生成动作,但在长 horizon 任务中容易漂移/抖动。本选题探索 horizon-hierarchical 方案:粗粒度规划 + 细粒度去噪。

### 核心问题
- 扩散策略在 ManiSkill2 上 short-horizon (3-5 步) SOTA
- Long-horizon (50-100 步) 累积误差大
- 时序一致性缺失

### 目标
- 设计 horizon-hierarchical 扩散策略: 顶层规划关键 sub-goals, 底层扩散生成 16 步动作
- 在 5 个 long-horizon 操作任务上评测
- 单 GPU 训练, 3 GPU 日完成

### 关键公式
$$\mathcal{L}_{hier} = \mathcal{L}_{diff}(\tau_{coarse}) + \alpha \cdot \mathcal{L}_{diff}(\tau_{fine})$$

### 创新点
- Goal-conditioned action chunking
- 用 VLM 生成 sub-goal (替代人工设计)
- 与 Transformer Memory 集成

### 参考
- Chi et al., "Diffusion Policy", RSS 2023
- Bousmalis et al., "RT-2", 2023
- π0 / OpenVLA, 2024-2025

## 选题 2: VLA 模型小型化到 1B 参数部署到边缘

**TL;DR**: 当前 VLA (RT-2 12B, π0 3B) 太大跑不动边缘。本选题训 1B VLA 用 pruning + knowledge distillation。

### 核心问题
- 边机器人 (家庭/工厂/医疗) 受算力限制
- VLM 80% 参数对动作预测冗余
- Pruning + Distillation 可压 5x

### 目标
- base: π0 (3B), student: 1B VLA
- 在 5 个真机任务 + 3 个仿真任务评测
- 边缘部署 (Jetson Orin) inference ≤ 50 ms

### 关键公式
$$\mathcal{L}_{distill} = \mathcal{L}_{task} + \alpha \cdot \mathcal{L}_{KL}(p_s \| p_t)$$

### 创新点
- 动态 token pruning (空间/时间维度)
- Mixture-of-Experts (MoE) 在 VLA 中的应用

### 参考
- π0 / OpenVLA papers 2024-2025
- DistilBERT, TinyBERT 系列

## 选题 3: BEV 占据网络 + Diffusion 预测未来轨迹

**TL;DR**: 当前 BEV 占据只输出占用 0/1, 不预测运动。本选题把占据预测升级为动态占用 (DOF) + 扩散预测 3s 轨迹。

### 核心问题
- Tesla FSD v12 占据预测只到 t+0 帧
- Waymo 用 LSTM 单独做 motion prediction
- 二者没融合

### 目标
- 设计 3D 时空 Diffusion 占据预测网络
- 在 nuScenes + Waymo Open 上评测 motion mAP
- 5 GPU 日完成

### 关键公式
$$p(o_{t+k} | o_t) = \mathcal{N}(\mu_\theta, \Sigma_\theta), \text{ via DDPM}$$

### 创新点
- 把占据预测与轨迹预测联合优化
- Diffusion 替代 LSTM 后端

### 参考
- Tesla AI Day 2022
- Waymo 2023 MotionLM, MTR
- OccNet 系列 (OccFormer, TPVA)

## 选题 4: 端到端 vs 模块化自驾的混合架构

**TL;DR**: 不做端到端也不做纯模块化,而是基于 Vision-Language 的混合架构,可解释 + 高性能。

### 核心问题
- 端到端 (Tesla) 性能上限高但黑盒难调试
- 模块化 (Waymo Classic) 易调试但有组合误差
- 现没人做 hybrid: VLM 中间层 + RL 端模块

### 目标
- VLM 输出意图 (lane change / yield / accelerate)
- 下层 RL 输出轨迹 + 控制
- 可解释: 每步 VLM 生成自然语言理由
- nuScenes open-loop eval, 5 GPU 日

### 关键公式
$$\pi_{hybrid}(a|s) = \sum_z \pi_{rl}(a|s, z) p_{vlm}(z|s)$$

### 创新点
- VLM 引入 CoT 推理 (类似 GPT-4o)
- 决策链可审计

### 参考
- DriveVLM (Wayve 2024)
- LMDrive (HKUST 2023)
- GPT-Driver (Stanford 2023)

## 选题 5: 太空机器人 (Mars 2020) 的鲁棒 RL 训练

**TL;DR**: 太空环境下 sim-to-real gap 巨大。本选题用 domain randomization + 鲁棒 RL 训练太空机械臂。

### 核心问题
- NASA Mars 直升机的低密度空气 + 高延迟
- 难以重建物理仿真
- Domain randomize 是常用解决

### 目标
- 用 Isaac Sim + PhysX 建立火星重力 + 空气仿真
- 训练 PPO 域随机化策略
- 在真机或高精度仿真评测

### 关键公式
$$\pi^* = \arg\max_\pi \mathbb{E}_{\xi \sim \mathcal{U}}\left[\mathbb{E}_{s,a}\left[R(s,a)\right]\right]$$

### 创新点
- 物理引擎参数从 NASA 数据校准
- Failure modes 收集 + adversarial training

### 参考
- NASA Mars 2020 Ingenuity (Aung et al., 2021)
- Robust RL (Pinto & Gupta, ICRA 2017)
- Domain Randomization (OpenAI 2017)
