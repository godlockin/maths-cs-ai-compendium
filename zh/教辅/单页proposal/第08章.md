# Ch08 计算机视觉：从像素网格到视觉 Transformer

## 30 秒锚点

手机拍一张 4032×3024 的照片，存成 RGB 张量后是 $(3024, 4032, 3)$ ≈ **3900 万个像素**，每个像素一个 $[0,255]$ 的整数。把这张图丢给 YOLOv8-nano，在 MacBook GPU 上**实时（≥30 FPS）**检出图里有几只猫、几个行人、车牌号位置；丢给 ViT-B/16 一张 $224\times224$ 的图，被切成 196 个 $16\times16$ patch 后过 12 层 Transformer — 26M 参数足以把 ImageNet 1000 类分对 84.4% top-1。本章要算的就是，从一格像素到"看见世界"，到底要经过哪些数学机制。

## 为什么学

- **数据规模**: ImageNet 拥有约 **1400 万张**标注图、2 万类，1400 万 / 1000 ≈ 1.4 万张/类，是训练视觉模型的常用训练集；COCO 1170 万 8.5 万标签,YOLO、Mask R-CNN、Faster R-CNN、ViT、EfficientNet、扩散模型(Diffusion)、CLIP 都从这两个数据集中某一个起步。
- **同一套数学骨架已在 Ch06 出现**: 卷积神经网络 (CNN) 的卷积 + 池化 + 全连接 + 交叉熵 = Ch06 §03 深度学习；视觉 Transformer (ViT) 的多头自注意力 = Ch07 §04 Transformer；任何"分块 → 嵌入 → 序列模型"在 ImageNet 上训出来的 ViT, 都可以零样本切到 Ch10 多模态。
- **全栈接口枢纽**: Ch04 描述性度量 + Ch05 概率论跑 IoU/mAP 评估指标；Ch11 自主系统用 Ch08 实例分割当感知前端；Ch14 数据结构与算法里 K-D 树 + RANSAC 直接给 Ch08 §05 SLAM 用；Ch21 对齐里 CLIP 文本-图像对齐、DALL·E 安全过滤也接 Ch08。

## 学完能干什么

- 🟢 **L2 我能**写出 RGB→灰度的 BT.601 公式 $L = 0.299R + 0.587G + 0.114B$, 当 $R=200, G=100, B=50$ 时 $L = 124.2$ ≈ 124（每通道 8 位, 256³=1677 万色, 三通道组合）。
- 🟢 **L3 我能**手算 3×3 拉普拉斯卷积核 $$
K = \tfrac{1}{8}\begin{pmatrix}-1&-1&-1\\-1&8&-1\\-1&-1&-1\end{pmatrix}
$$, 核内元素和=0 (用作边缘检测, 经一像素亮点 6 邻域全 0 时输出 1, 全 100 时输出 0, 因为核和为 0)。
- 🟡 **L3 我能**写出卷积输出尺寸公式 (PyTorch `nn.Conv2d` 官方文档 2024)：$\text{out} = \left\lfloor\frac{\text{in} + 2p - d(k-1) - 1}{s}\right\rfloor + 1$；$k=3, p=1, s=1, d=1 \Rightarrow \text{out}=\text{in}$ (same 卷积, VGG 用此规则保尺寸)。
- 🟡 **L4 我能**画清楚 YOLOv8 三尺度输出 (输入 640×640): 步长 32 → 20×20 网格 (检大目标)，步长 16 → 40×40 (检中目标)，步长 8 → 80×80 (检小目标)；总计 $20^2+40^2+80^2=8400$ 个 anchor-free 中心点, 每个点 3 个 anchor, 共 25200 个候选框，配合 NMS 后保留 ≥30 FPS。
- 🟡 **L4 我能**解释 Faster R-CNN 两阶段流程: RPN 用 3×3 卷积在共享特征图上滑窗，预测 objectness + 3 比例 3 长宽比 9 个 anchor（=9 × W × H 候选框）；再 RoI Pooling 把候选框切成 7×7 网格，每格做 max-pool，二阶段做 box regression + 类别分类（IOU 阈值 0.7 判正, 0.3 判负）。
- 🟡 **L4 我能**写出 ViT-B/16 的 patch 划分: 输入 $224\times224$ RGB, 被切成 $(224/16)^2 = 196$ 个 $16\times16\times3$ patch（$196\times768=150528$ 维展平向量），加 1 个 [CLS] token = 197 个 token，过 12 层 Transformer（多头 $h=12, d_k=64$）。
- 🔴 **L5 我能**解释 CLIP 文本-图像对齐的 InfoNCE loss $L = -\frac{1}{N}\sum_i \log\frac{\exp(\cos(\mathbf{I}_i,\mathbf{T}_i)/\tau)}{\sum_j\exp(\cos(\mathbf{I}_i,\mathbf{T}_j)/\tau)}$, $\tau$ 温度可学, 直推图→文/文→图对齐任务零样本迁移 ImageNet 准确率 76.2%。
- 🔴 **L6 我能**为扩散模型 DDPM 写数学骨架: 前向加噪 $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$, $\epsilon\sim\mathcal{N}(0,I)$，反向预测噪声 $\epsilon_\theta(x_t, t)$ 用 L2 损失逼近 $\epsilon$；训练 1000 步调度, 推理 50 步 DDIM 可采样一张 $256\times256$ 图。

## 1 分钟核心

- **01 图像基础**: RGB 三通道 $(H,W,3)$, 8 位/通道 = 1677 万色；HSV/YCbCr/LAB 按任务选；图像即二维离散信号, $f:\mathbb{Z}^2\to\mathbb{R}^3$; 卷积 $\to$ 滤波器 (高斯模糊、Sobel 梯度、Canny 边缘)；SIFT/ORB/Harris 角点是深度学习时代前的"手工特征"。
- **02 卷积网络**: 6 要素 — 卷积核 $k$、步长 $s$、填充 $p$、膨胀 $d$、通道 $C$、激活 (ReLU)；堆叠 + 下采样 = 感受野指数扩张；架构演进 LeNet(60K) → AlexNet(60M) → VGG-16(138M) → ResNet-50(25M, 残差) → EfficientNet-B0 (复合缩放, $\phi=88$); 训练技巧 = 数据增强 + BatchNorm + Dropout2D + Label Smoothing。
- **03 检测与分割**: 两阶段 (Faster R-CNN = RPN + RoI Head) 精度高, 单阶段 (YOLO、SSD、FCOS) 速度快；语义分割 FCN/UNet/DeepLab (空洞卷积 ASPP)；实例分割 Mask R-CNN = 检测 + 像素分类；评估用 mAP@0.5 / mAP@[.5,.95] / IoU; COCO test-dev mAP@[.5,.95] 截至 2024: DINO SOTA ≈ 63.0。
- **04 ViT 与生成**: ViT 把图像分 patch → 线性嵌入 → [CLS] token → Transformer (Encoder) → MLP Head; 变体 Swin (层次化窗口注意力)、DeiT (蒸馏)、MAE (掩码自编码)；检测 DETR (无 anchor, 100 object query)；扩散模型 (DDPM/DDIM/Stable Diffusion) = 逐步去噪, 训练简单, 生成多样；文生图 (CLIP + Diffusion) / 文生视频 (Sora / CogVideoX) 在此奠基。
- **05 视频与 3D**: 视频 = 图像序列 + 时间维, 光流 (TV-L1) 估像素运动；NeRF 用 MLP 学 5D 辐射场 $\sigma(\mathbf{x}), c(\mathbf{x},\mathbf{d})$, 体渲染 $C(\mathbf{r})=\int T(t)\sigma(\mathbf{r}(t))c(\mathbf{r}(t),\mathbf{d})dt$, 重建新视角；3D Gaussian Splatting (3DGS) 用 3D 高斯做实时辐射场渲染；SLAM 用 ORB-SLAM3 闭环, 视觉里程计 + BA 优化 + 回环检测。
- **跨章共同数学机制**: 视觉任务的共同点都是"把像素/特征投影到能比较的空间" — 分类是到 1000 维 logits, 检测是到 (中心+尺寸+类别) 向量, 分割是到每个像素的类别概率, 3D 是到体积渲染权重。具体形式是"线性层 + softmax/sigmoid"为主, 卷积/注意力为特化结构。<!-- FIX: P0-1: 跨章同源点必配具体机制 -->

## 前置知识 & 后置章节

**前置**: Ch04 统计学（描述性度量 / 假设检验），Ch05 概率论（高斯过程/熵/InfoNCE 损失里的归一化常数 = softmax 的分母），Ch06 机器学习（CNN 已是 Ch06 §03 深度学习主干，卷积操作 = 滑动窗口点积，CrossEntropyLoss = Ch04 统计 + Ch05 信息论交叉熵），Ch07 计算语言学（Transformer 注意力 = Ch07 §04, 是 ViT/DETR/MAE 的核心）。

**符号表 (跨章契约 v2, Ch08 专用)**:
- $H, W, C$ — **图像张量形状**（Height 高度 / Width 宽度 / Channel 通道数）；RGB 三通道图 $C=3$
- $k, s, p, d$ — **卷积四件套**: 核大小 / 步长 / 填充 / 膨胀率（公式 $\text{out}=\lfloor(\text{in}+2p-d(k-1)-1)/s\rfloor+1$）
- $\alpha$ — **Ch08 里两种身份**：(1) BachNorm 中的可学缩放 $\gamma$（笔记沿用 $\gamma$，但 Ch04 t-检验里的显著性也用 $\alpha$）；(2) DDPM 噪声调度参数 $\bar\alpha_t = \prod_{s=1}^t(1-\beta_s)$。**逐节必须标注 "$α$ (DDPM 噪声调度)" 等**；严禁与 Ch04 显著性水平 $\alpha$、Ch06 学习率别名 $\alpha$ 混用
- $\beta$ — **Ch08 里是 DDPM 方差调度**（$\beta_s$ 从 $10^{-4}$ 线性增到 $0.02$，即 $\bar\alpha_t = \prod_{s=1}^t(1-\beta_s)$）；区别于 Ch04 二类错误率 $\beta$、Ch05 Beta 分布参数 $\beta$、Ch07 回归系数 $\beta$
- $\epsilon_\theta$ — **DDPM 噪声预测网络**；区别于 Ch06 探索噪声 $\epsilon\sim\mathcal{N}(0,I)$ 的同一记号
- $\tau$ — **CLIP 温度参数**（$\tau$ 可学, 通常初始化 $0.07$）；区别于 Ch07 时间步 $t$、Ch03 时间常数 $\tau$
- $\sigma, c(\mathbf{x},\mathbf{d})$ — **NeRF 体积密度 + 颜色**（区别于 Ch04 标准差 $\sigma$、Ch07 sigmoid 输出 $\sigma$）；方向向量 $\mathbf{d}$ 区别于 Ch05 KL 散度的 $d$ 与 Ch01 维度符号 $d$
- $\mathbf{r}(t)$ — **相机射线参数化** $\mathbf{r}(t)=\mathbf{o}+t\mathbf{d}$, $t$ 是沿射线距离（非时间）
- mAP — **mean Average Precision**（COCO 评估指标, IoU 阈值 0.5 的 AP 叫 AP@0.5, .5到.95步长0.05 共10个阈值的均值叫 mAP@[.5,.95]）；区别于 Ch04 平均精度（精度均值）

## 时长 & 难度评级

阅读与手算 **150–210 分钟**（5 节，每节 30–42 分钟），编程练习（PyTorch + torchvision）**150 分钟**；难度 **🟡 中等偏高**, 三道门槛：①卷积四件套 $k/s/p/d$ 输出尺寸公式不混淆；②YOLO 中心点 + 尺度 + NMS 三个分离机制在脑里合并;③DDPM 前向 $\bar\alpha_t$ 调度 / 反向 $\epsilon_\theta$ 预测 / 采样 $x_{t-1}\sim\mathcal{N}(\mu_\theta,\Sigma_\theta)$ 之间的衔接。⭐ 视频光流 TV-L1 推导、NeRF 体渲染 $\int$ 推导、SLAM 后端 BA 优化可跳读。
