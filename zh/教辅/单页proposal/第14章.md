## 选题 1: LLM KV Cache 哈希表优化

**TL;DR**: 用自定义哈希表替代 vLLM 的 PyTorch tensor 索引, 把 KV cache 查找从 $O(\log n)$ 降到 $O(1)$。

### 核心问题
- vLLM 用 RadixAttention, 但序列 hash 查找仍是瓶颈
- KV cache 大小动态变化, 频繁 rehash
- 长上下文 (128K) 时哈希碰撞严重

### 目标
- 设计 sequence-aware 哈希函数 (token + position)
- Cuckoo hashing 实现
- vLLM 集成, 推理吞吐 +15%

### 关键公式
$$T_{\text{lookup}} = O(1) \text{ avg, } O(n) \text{ worst (cuckoo)}$$
$$\text{Throughput} \propto \frac{1}{T_{\text{lookup}} + T_{\text{decode}}}$$

### 创新点
- 哈希函数对 token embedding 敏感
- 开放定址 + 双重哈希
- 集成到 vLLM block manager

### 参考
- vLLM, "PagedAttention", SOSP 2023
- Piranha, USENIX 2024
- SGLang RadixAttention

## 选题 2: 图算法在 GNN 大规模训练

**TL;DR**: 用近似 Dijkstra + Union-Find 实现 GraphSAINT 子图采样, 训练加速 3×。

### 核心问题
- GNN 大图 (OGB-ppa 38M 节点) 邻居爆炸
- Cluster-GCN 切分, 但边界节点邻居不全
- 子图采样是 $O(V+E)$ 但随机

### 目标
- 用 BFS 采样保证连通性
- 集成 Union-Find 避免重复
- PyG / DGL 实现

### 关键公式
$$T_{\text{sample}} = O(V + E) \text{ with BFS}$$
$$\text{Speedup} \approx 3 \times \text{ (vs random)}$$

### 创新点
- 重要性采样 (PageRank 权重)
- 缓存采样结果
- 多 GPU 流水线

### 参考
- GraphSAINT, ICLR 2020
- Cluster-GCN, ICML 2019
- Ch12 §03 GNN

## 选题 3: 优先队列在 RL 经验回放

**TL;DR**: 用堆 (heap) 实现优先级经验回放 (PER), 比 random sampling 训练快 2×。

### 核心问题
- DQN 经验回放 uniform 采样
- 但 TD-error 大的样本更值得学
- SumTree 实现复杂

### 目标
- 简化 heap 实现 PER
- 在 Atari / MuJoCo 评测
- PyTorch 集成

### 关键公式
$$P(i) = \frac{p_i^\alpha}{\sum_k p_k^\alpha}$$
$$T_{\text{sample}} = O(\log n) \text{ heap}$$

### 创新点
- 双堆 (max + min) 加速
- Lazy update
- GPU 兼容

### 参考
- PER, Schaul et al., ICLR 2016
- Ape-X, Distributional 2018
- Ch06 §04 DQN

## 选题 4: KD-Tree 加速 Transformer Attention

**TL;DR**: 用 KD-Tree 把 full attention $O(n^2)$ 变成 sparse $O(n \log n)$, 长序列加速。

### 核心问题
- 长序列 Transformer (32K+ tokens) attention $O(n^2)$ 太贵
- Longformer / BigBird 用 sliding window 但不够灵活
- KD-Tree 找 top-k 邻居 attention

### 目标
- KD-Tree 分桶 attention
- 在 LRA (Long Range Arena) 评测
- 5× 加速, 精度保留 95%

### 关键公式
$$T_{\text{KD-Tree build}} = O(n \log n)$$
$$T_{\text{attention}} = O(n \log n) \text{ sparse}$$

### 创新点
- 学习 hash (L2H / REFORMER)
- Hierarchical attention
- 与 Flash Attention 集成

### 参考
- Linformer, Facebook 2020
- Performer, ICML 2020
- Reformer, ICLR 2020

## 选题 5: 排序算法在分布式训练 Shuffle

**TL;DR**: 改进分布式 Shuffle 用基数排序替代比较排序, 加速 2×。

### 核心问题
- 分布式训练数据 Shuffle 是 IO 密集
- 当前用 sort-based shuffle, $O(n \log n)$ 比较
- 大规模 (TB 级) 排序慢

### 目标
- Radix sort 分布式版
- PyTorch DataLoader 集成
- 1 TB 数据 shuffle < 5 min

### 关键公式
$$T_{\text{radix}} = O(nk), k = \text{位长度}$$
$$T_{\text{merge}} = O(n \log n)$$

### 创新点
- 多机 Radix shuffle
- 与 DDP 集成
- GPU 加速

### 参考
- PyTorch DistributedDataParallel
- Horovod, Uber 2018
- Ch13 §04 MapReduce
