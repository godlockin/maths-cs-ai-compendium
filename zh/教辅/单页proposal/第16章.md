## 选题 1: Flash Attention 3 在 H100 上的极致优化

**TL;DR**: 改进 Flash Attention 3 在 H100 上的 warp specialization + TMA, 目标超过 cuDNN attention。

### 核心问题
- 当前 Flash Attention 3 在 H100 上 ~75% 理论 FLOPS
- cuDNN 已 80%+, 但闭源
- 想做开源 SOTA

### 目标
- warp specialization (producer / consumer)
- TMA (Tensor Memory Accelerator)
- 在 H100 上 A/B test
- 5-10% 加速

### 关键公式
$$T_{\text{attn}} = O(n^2 d) \text{ FLOPs}$$
$$T_{\text{mem}} = O(n^2) \text{ bytes}$$

### 创新点
- 异步 copy
- Register reuse
- Persistent kernel

### 参考
- Flash Attention 2/3, Dao et al.
- CUTLASS, NVIDIA
- Ch07 §04 Transformer

## 选题 2: Triton DSL 自动调优框架

**TL;DR**: 改进 Triton autotune, 加入 ML-based 预测, 加速 kernel 选择 10×。

### 核心问题
- Triton autotune 耗时, 大模型多算子
- 启发式搜索慢
- 期望 ML 预测最佳 config

### 目标
- 训练 model 预测 best config
- 集成 Triton
- 开源 benchmark

### 关键公式
$$T_{\text{tune}} = N_{\text{configs}} \times T_{\text{compile}}$$

### 创新点
- 特征: 输入 shape + 算子
- 模型: GBDT 或小型 NN
- 在线学习

### 参考
- Triton autotune
- Ansor (TVM)
- Helion (PyTorch)

## 选题 3: 异构 GPU 集群 (CUDA + ROCm + TPU)

**TL;DR**: 设计跨平台算子库, 一份代码跑 NVIDIA / AMD / Google。

### 核心问题
- 当前算子针对单平台
- 跨平台需重写
- AI 公司成本 / 可用性需求

### 目标
- Triton 风格的统一 DSL
- CUDA / ROCm / TPU 后端
- 性能差距 < 5%

### 关键公式
$$\text{Speedup}_{\text{cross}} = \frac{T_{\text{native}}}{T_{\text{portable}}}$$

### 创新点
- 自动降级
- 平台感知调度
- 开放算子库

### 参考
- Triton
- XLA
- Helion (PyTorch 2024)

## 选题 4: 量化 (INT4) + 稀疏化 联合优化

**TL;DR**: 量化与稀疏化结合, 让 70B 模型跑在 24GB GPU。

### 核心问题
- LLM 太大
- 单纯量化损失精度
- 单纯稀疏化硬件支持差

### 目标
- GPTQ + 2:4 稀疏
- 在 Llama 70B 评测
- 24GB 单卡推理

### 关键公式
$$\text{Memory} = N_{\text{params}} \times 0.5 \text{ bytes (INT4)}$$
$$\text{Speedup} = \frac{T_{\text{dense}}}{T_{\text{sparse}}}$$

### 创新点
- 混合精度
- 稀疏感知 kernel
- 量化感知稀疏

### 参考
- GPTQ, AWQ
- SparseGPT
- cuSPARSELt

## 选题 5: RISC-V + 边缘 LLM (Llama 3 8B)

**TL;DR**: RISC-V 嵌入式部署 Llama 3 8B (量化), <10W 功耗。

### 核心问题
- 边缘 LLM 部署难
- ARM / x86 功耗高
- RISC-V 开放 + 可定制

### 目标
- 量化 Llama 3 8B 到 INT4
- RISC-V + SIMD 加速
- <10W 功耗, >5 tok/s

### 关键公式
$$\text{Power} = V \times I \times f$$
$$\text{TPS} = \frac{1}{T_{\text{token}}}$$

### 创新点
- 自定义 RISC-V 扩展
- 量化矩阵乘
- 内存层级优化

### 参考
- SiFive RISC-V
- 平头哥玄铁
- Llama.cpp
