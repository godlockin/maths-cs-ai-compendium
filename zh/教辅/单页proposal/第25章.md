# 第25章 · AI 系统实战面试指南 · 单页 Proposal

## 一句话定位
> **面试地图**: 系统设计 (40%) + 算法编程 (30%) + 项目深挖 (20%) + 行为面 (10%)。从"能干活"到"能讲出来"。

## 为什么学这一章
- AI 工程师 / 算法岗面试 2024-2026 **题库大改**: LLM 系统 / Agent / RAG / 推理优化 成主流
- 不会讲 = **做了 80% 准备但面试过不了**
- 不学 = "做得好但讲不出来", 错失 offer

## 学什么 (7 节)
1. **面试全景与准备心法** (STAR 法 / 8 步系统设计 / 反向提问)
2. **ML 系统设计 8 步框架** (需求澄清 / 指标 / 离线-在线 / 数据流 / 模型 / 部署 / 监控)
3. **典型题演练 · 推荐-搜索-排序** (召回 / 精排 / 重排 / DLRM)
4. **典型题演练 · 反欺诈-风控-异常检测** (GNN / 时序 / 标签稀缺)
5. **典型题演练 · 对话与 LLM 系统** (RAG / Agent / KV Cache)
6. **算法与编程面试实战** (Top-K / LRU / Trie / DP / 红黑树)
7. **行为面 + 项目讲述 + Offer 谈判** (STAR / 电梯演讲 / 薪资博弈)

## 学完后能做什么
- 用 **8 步框架** 应对任何系统设计题
- 讲清 **推荐 / 风控 / LLM 系统** 3 大典型题
- 答出 **Top-20 算法题** 的最优解
- 写出 **STAR 项目故事** (3-5 个深度项目)
- 在 Offer 谈判中 **拿到 +20% 涨幅**

## 5 大关键词
**系统设计 / RAG / Agent / STAR / 算法**

## 推荐入门路径
```
入门: §01 (面试全景 + STAR)

题海: §03-§05 (推荐 / 风控 / LLM 3 大题)
算法: §06 (持续刷 LeetCode)
收尾: §07 (行为面 + Offer)
```
