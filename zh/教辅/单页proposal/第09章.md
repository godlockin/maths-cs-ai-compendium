# Ch09 音频与语音：从声波到听得懂的机器

## 30 秒锚点

打开手机，对 Siri 喊一声"嘿 Siri, 帮我定个 8 点的闹钟" — 全球 Siri 月活早在 2024 年已突破 **5 亿** (Apple 公开披露); OpenAI 用 Whisper 模型在 **100 万小时**多语种音频上训练, GitHub 仓库 radis/librispeech 等公开数据集加在一起约 **1 亿小时**标注语音 (Whisper 论文表 1)。这些数字背后的整套流水线——采样、FFT、梅尔频谱图、对数梅尔、Conformer 编码器、CTC/RNN-T 解码、声码器 WaveNet/HiFi-GAN、x-vector 说话人嵌入、Conv-TasNet 源分离——全部装在这一章的 5 节里。本章要算的就是, 从一格声波到"听懂 + 会说 + 分得清谁在说话", 到底经过哪些数学机制。

> **符号契约 (Ch09 专用, 跨章)**:
> - $f_s$ — **采样率** (Hz, 例 CD 44100/电话 8000/语音 16000)
> - $N$ — **FFT 帧大小** (例 512/1024/2048); 与 Ch06 样本数 $N$、Ch08 像素维度 $N$ 上下文区分
> - $M$ — **梅尔滤波器组通道数** (例 40/64/80), 不同于 Ch05 转移矩阵 $M$、Ch06 大 $M$ 测试常数
> - $\beta$ — **Ch09 里两种身份**: (1) CTC 空白折叠逆温度 $\beta$ 在 RNN-T joint 网络 softmax 里; (2) 倒谱系数加权 $\beta$ 在 MFCC DCT 矩阵里; 与 Ch04 二类错误率 $\beta$、Ch05 Beta 分布参数 $\beta$、Ch07 KL 系数 $\beta$ 严格区分
> - $\sigma$ — **sigmoid 激活** (RNN-T 联合网络 $\sigma$); 区别于 Ch04 标准差 $\sigma$、Ch08 NeRF 体密度 $\sigma$
> - $E$ — **短时能量** $\sum_{n=0}^{N-1} x[n]^2$ (Ch09 §01 定义域 $\mathbb{R}$), 区别于 Ch05 期望算子 $E[\cdot]$
> - $\mu$ — **mu-law 压扩常数** (256 级量化), 区别于 Ch05 高斯均值 $\mu$

## 为什么学

- **数据规模触顶**: LibriSpeech (960 小时朗读英语) + Common Voice (80+ 语种, 累计 **数千小时**) + GigaSpeech (1 万小时) + Whisper 训练语料 68 万小时 (OpenAI 2022 论文表 1) — 音频已是继文本/图像之后第三大数据模态; Ch09 与 Ch07、Ch08 共称多模态三件套, Ch10 多模态学习直接接 Whisper/CLIP/VALL-E 接口。
- **同一套数学骨架已出现在前 8 章**: 卷积 (Ch06) 提取梅尔频谱; 缩放点积注意力 $\text{softmax}(QK^\top/\sqrt{d_k})V$ (Ch06/Ch07) 是 Conformer/Whisper 编码器的核心; CTC 前向-后向算法 = HMM 前向-后向算法 (Ch05 §05) 的连续版; KL 散度 (Ch05) 是 RNN-T joint 网络 softmax 的来源; 梯度下降 (Ch06) 是神经声码器 WaveNet/VITS 训练的基础。
- **全栈接口枢纽**: Ch04 描述性度量在 ASR 上就是 WER/CER; Ch05 信息论在 TTS 上是 mel-spectrogram 重建损失 + SI-SDR; Ch06 优化器 (Adam $\beta_1=0.9, \beta_2=0.999$) 是所有神经 TTS/ASR 默认; Ch07 Transformer 直接被 Whisper 拿来用 (Whisper-large 1550M 参数, 32 层 Conformer); Ch10 多模态在 Ch09 之后接 VALL-E 神经编解码语言模型 + AudioPaLM。

## 学完能干什么

- 🟢 **L2 我能**算奈奎斯特频率并解释混叠: $f_s = 16000$ Hz 时 $f_{\text{Nyquist}} = 8000$ Hz; 一个 15 kHz 音在 16 kHz 采样下混叠成 $16 - 15 = 1$ kHz (Ch09 §01 锚点例, 验算通道 Pyodide 已沉淀)。
- 🟢 **L3 我能**写 STFT 输出尺寸公式: $\text{帧数} = \lfloor (L - N) / \text{hop} \rfloor + 1$, 例 $L = 16000$ (1 秒 16 kHz), $N = 512$, $\text{hop} = 160$ (10 ms 步长) ⇒ $\lfloor (16000 - 512) / 160 \rfloor + 1 = 97$ 帧, 每帧 $|X[k]|^2$ 共 $N/2+1 = 257$ 个频点, 输出 $97 \times 257$ 矩阵 (实数)。
- 🟡 **L4 我能**算梅尔滤波器组的尺度变换: $\text{mel} = 2595 \log_{10}(1 + f/700)$, $f=1000$ Hz ⇒ $\text{mel} = 2595 \log_{10}(1 + 1000/700) \approx 999.99 \approx 1000$; $f=8000$ Hz ⇒ $\text{mel} = 2595 \log_{10}(1 + 8000/700) \approx 2840$; 80 通道梅尔滤波器把 0-8000 Hz 线性切成 80 段, 每段用三角带通加权 — 这就是 mel-spectrogram。
- 🟡 **L4 我能**写 CTC loss 公式并解释空白折叠: $P(\mathbf{y}|\mathbf{x}) = \sum_{\boldsymbol{\pi}\in\mathcal{B}^{-1}(\mathbf{y})} \prod_{t=1}^{T} p(\pi_t|\mathbf{x})$, 其中 $\mathcal{B}$ 把空白 `-` 与重复字符折叠; 例 "cat" 可由 "--cc-aa-t--" 折叠得到; 前向-后向算法把 $O(T \cdot |\mathbf{y}|)$ 复杂度从指数级压下来 (与 Ch05 HMM 前向-后向同构)。
- 🟡 **L4 我能**解释 Whisper-large 编码器-解码器: 80 通道 mel-spectrogram (30 秒片段, $80 \times 3000 = 240000$ 特征) 过 32 层 Conformer 编码器 (每一层 $d_\text{model}=1280, h=20$ 头, $d_k = 64$), 产出隐藏状态; 解码器为 32 层 Transformer 解码器 (同样维度), 自回归输出 BPE token; 总参数 1550M (1.55B); 训练集 68 万小时多语种音频。
- 🔴 **L5 我能**陈述 RNN-T joint 网络的 softmax 来源: $p(y|t,u) = \text{softmax}(W \cdot \tanh(W_\text{enc} \mathbf{h}_t^\text{enc} + W_\text{pred} \mathbf{h}_u^\text{pred} + b))$, 解释为什么这种"加性 tanh + 线性 softmax"结构等价于把编码器与预测网络的隐状态投影到同一 logits 空间; $\sigma$ (sigmoid) 在此处不直接出现, 但可用 $\text{softmax} = \sigma \cdot \text{归一化}$, 与 Ch06 sigmoid 单元区分。
- 🔴 **L6 我能**区分 VALL-E 与传统 TTS 的核心机制: VALL-E 是神经 **编解码语言模型**, 用 Encodec (75 Hz 残差向量量化, 8 个 codebook, 每本 1024 entry) 把音频编码为离散 token, 再用 LM (类似 Ch07 Chinchilla 风格) 自回归预测; 3 秒 prompt 音频 + 文本 → 完整语音; 与传统端到端 TTS (Tacotron + WaveNet) 共享 mel-spectrogram 中间表示, 但推理框架是离散 LM 而非连续回归。

## 1 分钟核心内容

- **01 数字信号处理**: 声波 = 压力波, 振幅/频率/相位; 采样 $f_s \ge 2f_\text{max}$ (奈奎斯特); 量化 $n$ bit ⇒ $2^n$ 电平; **STFT** $X[t,k] = \sum_n x[n] w[n-t\cdot\text{hop}] e^{-j2\pi kn/N}$ 把 1D 波形变成 2D 时频图; 梅尔滤波器组按人耳感知刻度切 80 通道; **MFCC** = DCT 压缩梅尔对数谱。<!-- FIX: P0-2: STFT 公式必标 hop/N -->
- **02 自动语音识别**: 经典 ASR = 声学模型 + 发音词典 + 语言模型 + WFST 解码; 端到端 ASR = CTC / RNN-T / LAS / Conformer / Whisper; CTC 用空白折叠解决对齐, 条件独立 (需外接 LM); RNN-T 加预测网络, 取消条件独立, 流式 (Google Pixel 用); Conformer = 卷积 (局部) + 自注意力 (全局), 4 模块三明治; Whisper = 编码器-解码器 Transformer, 训练 68 万小时多语种, 参数量 39M-tiny / 74M-base / 244M-small / 769M-medium / 1550M-large。
- **03 文本到语音**: TTS 流水线 = 文本归一化 → G2P (字素到音素) → 声学模型 → 声码器; 声学模型 Tacotron2 输出 mel-spectrogram, FastSpeech 用 duration predictor 并行; 声码器 WaveNet 自回归 (1 秒 24 kHz 需 24000 次串行); HiFi-GAN 用 GAN + 多周期/多尺度判别器把合成加速 1000 倍; VALL-E 走神经编解码语言模型路线。
- **04 说话人与音频分析**: 说话人验证 (1:1, "Hey Siri 是本人吗?") vs 说话人识别 (1:N, 是哪个人?); x-vector = TDNN + 统计池化 + 全连接, 输出 512 维嵌入; 余弦相似度 + 阈值 $\theta$ 判接受; EER (等错误率) < 1% 在 VoxCeleb1; PLDA 显式分离说话人/信道; 说话人分离 (diarisation) = "谁在什么时候说话"; VAD 用能量 + ZCR + 神经分类器。
- **05 源分离与降噪**: 鸡尾酒会问题 = 多源混合 + 噪声; 时频掩码 IRM = $|S_c|^2 / \sum_j |S_j|^2$ 软分离; ICA 求解混矩阵 $W \approx A^{-1}$, 要求源非高斯独立; NMF $V \approx WH$ (非负, 频谱字典 × 时间激活); Conv-TasNet 用 encoder-decoder + 分离 + decoder, 时域端到端; SepFormer 用双路径 Transformer 捕捉全局依赖; 自适应降噪 (LMS, NLMS) 在线更新滤波器权重。
- **跨章共同数学机制**: 音频任务的共同点是"时域信号 ↔ 频域表示 ↔ 序列模型" — 频域靠 STFT/FFT (Ch02 矩阵分解), 序列模型用 Transformer (Ch07 注意力) 或 RNN-T (Ch05 HMM 连续版), 输出空间是离散 token (CTC/VALL-E) 或 mel-spectrogram (Tacotron); 具体形式是"特征提取 → 编码 → 解码 → 重建", 与 Ch08 视觉"图像 → CNN → 检测头"共享编码-解码骨架。<!-- FIX: P0-1: 跨章同源点必配具体机制 -->

## 前置知识 & 后置章节

**前置**: Ch05 概率论 (HMM 前向-后向 = CTC 雏形 + 信息论 SI-SDR/BLEU + KL 散度); Ch07 计算语言学 (Transformer 注意力 + BPE 分词 + 缩放律 — Whisper = Ch07 Transformer 在音频上的直接应用); Ch08 计算机视觉 (3D Conv 提取对数梅尔频谱的时间模式 + Conv-TasNet encoder-decoder = Ch06 CNN 在音频上的特化); Ch06 机器学习 (CTC/RNN-T 损失的反向传播 + Adam 优化器 $\beta_1=0.9, \beta_2=0.999$ + 注意力 $\sqrt{d_k}$ 防饱和)。

**后置**: Ch10 多模态学习 (VALL-E 神经编解码 + AudioPaLM 音频-文本联合 LM + 音频对话系统); Ch11 自主系统 (车载语音助手 + 远场麦克风波束成形); Ch17 AI 推理 (Whisper TensorRT 量化 + KV-cache 加速解码); Ch21 对齐安全 (语音克隆滥用检测 + 说话人匿名化 + 音频深度伪造 (deepfake) 检测); Ch23 AI Agent (Function calling 语音输入/输出)。

## 时长 & 难度评级

阅读与手算 **150–210 分钟** (5 节, 每节 30–42 分钟), 编程练习 (PyTorch + torchaudio + Hugging Face Transformers) **120 分钟**; 难度 **🟡 中等偏高**, 三道门槛: ①STFT 输出尺寸 (帧数 × 频点数) 与 mel-spectrogram 80 通道 × 100 帧/秒的形状约定不混淆; ②CTC 空白折叠与 RNN-T 联合网络的 softmax 出口分清楚; ③x-vector 余弦相似度 + 阈值与 EER 评估的统计含义。⭐ 倒谱均值方差归一化 (CMVN) 数值细节、自适应 LMS 滤波器收敛性、VALL-E 神经编解码量化可跳读。
