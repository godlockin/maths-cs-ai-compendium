# 第24章 · 数值分析与凸优化补遗 · 单页 Proposal

## 一句话定位
> **数值优化 = ML 工程的"地基"**: 浮点误差 / 病态矩阵 / 凸性 / 收敛性, 任一都会让训练失败。本章 = 工程师的"避坑手册"。

## 为什么学这一章
- 训练崩溃 80% 原因在 **数值稳定性 + 优化器选择**
- 大模型训练 (Ch17) 离不开 **二阶方法 / 分布式优化**
- 系统设计面试必问: **Adam vs SGD / L-BFGS vs Newton / 同步 SGD**
- 不学 = 训练"卡住"时无从下手

## 学什么 (7 节)
1. **浮点与数值稳定性** (IEEE 754 / bfloat16 / Kahan / Softmax Trick)
2. **迭代法与稀疏线代** (CG / GMRES / CSR / COO / 预条件子)
3. **凸集与凸函数** (凸判别 / 强凸 / 平滑 / Lipschitz)
4. **对偶与 KKT** (Lagrange / 强对偶 / Slater / KKT 4 条件)
5. **二阶方法** (Newton / BFGS / L-BFGS / Trust Region / K-FAC)
6. **内点法与约束优化** (Barrier / 投影梯度 / Frank-Wolfe / SQP / ADMM)
7. **分布式与随机优化** (Async SGD / Hogwild! / AllReduce / FedAvg)

## 学完后能做什么
- 诊断并修复 **数值不稳定** (梯度爆炸 / 损失 NaN)
- 选 **正确的优化器** (SGD / Adam / L-BFGS / Shampoo)
- 实现 **分布式训练** (DDP / FSDP / ZeRO)
- 推导 **SVM / 逻辑回归 / Softmax** 的对偶形式
- 在面试中讲清 **为什么 L-BFGS 比 Adam 适合小数据集**

## 5 大关键词
**数值稳定性 / 凸优化 / 二阶方法 / 分布式优化 / KKT**

## 推荐入门路径
```

进阶: §05-§06 (二阶 + 约束)
```
