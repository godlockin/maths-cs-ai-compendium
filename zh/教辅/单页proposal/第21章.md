# 第21章 · 对齐、安全与可解释性 · 单页 Proposal

## 一句话定位
> **AI 系统的"安全三角"**: 让 AI 做人类想要的事 (对齐) + 不做人类不想让它做的事 (安全) + 让我们能理解它为何这么做 (可解释性)。

## 为什么学这一章
- 大模型已渗透生产, **幻觉 / 越狱 / 奖励黑客** 三大风险每周都有事故
- 监管 (EU AI Act / 美 AI Bill of Rights) 强制要求 **可审计 / 可解释**
- **不学 = 工程师会"部署出一个无法控制的系统"**

## 学什么 (6 节)
1. **什么是对齐** — 目标错配 / 规范博弈 / Goodhart's Law
2. **RLHF-DPO 深入** — RLHF 三阶段 + DPO + GRPO + RLAIF
3. **对抗攻击与越狱** — Prompt Injection / Jailbreak / Red Teaming
4. **机制可解释性入门** — 电路 / Sparse Autoencoder / Feature
5. **可解释性工具** — TransformerLens / Logit Lens / 注意力可视化
6. **AI 治理与前沿** — EU AI Act / RSP / Scalable Oversight

## 学完后能做什么
- 设计带 **Constitutional AI + RLAIF** 的训练 pipeline
- 给生产 LLM 加 **Input/Output 防护栏** (Guardrails)
- 解释 LLM **为什么会拒绝/出错** (Mechanistic)
- 撰写 **Model Card + Risk Card** 合规文档
- 在面试中讲清楚 **RLHF vs DPO vs GRPO** 差异

## 5 大关键词
**Alignment / Safety / Interpretability / RLHF / Jailbreak**
