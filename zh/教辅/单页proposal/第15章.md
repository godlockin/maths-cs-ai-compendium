## 选题 1: LLM 推理服务的 K8s 自动扩缩容

**TL;DR**: 基于 QPS + 显存 + KV cache 利用率, 设计 HPA (Horizontal Pod Autoscaler) 策略, 让 LLM 服务成本 -30%。

### 核心问题
- LLM 推理延迟 + 显存需求难预测
- 当前 HPA 仅看 CPU/QPS, 不准
- 突发流量浪费资源

### 目标
- 自定义指标 (KV cache 利用率)
- KEDA 集成
- 在 8 GPU 节点集群 A/B test

### 关键公式
$$\text{Replicas} = \lceil \text{Current} \cdot \frac{\text{TargetMetric}}{\text{CurrentMetric}} \rceil$$
$$T_{\text{cold}} \approx 30 \text{s (模型加载)}$$

### 创新点
- 预热 (warm pool)
- 主动扩容 (look-ahead traffic)
- 模型分层 (小模型先, 大模型 fallback)

### 参考
- KEDA (Kubernetes Event-Driven Autoscaling)
- vLLM, "PagedAttention", SOSP 2023
- Anthropic, "Scaling Laws for Inference"

## 选题 2: MLOps 平台 (模型版本管理)

**TL;DR**: 用 DVC + MLflow + Git 搭建端到端 ML 实验追踪与版本管理。

### 核心问题

- 团队协作困难

### 目标
- DVC 管数据, MLflow 管实验

### 关键公式
$$\text{Reproducibility} = \frac{\text{Reproduced}}{\text{Total}}$$

### 创新点
- 自动实验对比
- 模型 registry + A/B test 集成
- 数据 lineage 追踪

### 参考
- DVC (dvc.org)
- MLflow (mlflow.org)
- Weights & Biases

## 选题 3: 端到端 ML 流水线 CI/CD

**TL;DR**: 把"数据 → 训练 → 评估 → 部署"做成 GitOps 流水线。

### 核心问题
- ML 流水线手工, 易错
- 模型发布周期长
- 难以 rollback

### 目标
- GitHub Actions + Argo Workflows
- 自动化数据验证 + 模型评估
- 金丝雀发布

### 关键公式
$$T_{\text{deploy}} = T_{\text{train}} + T_{\text{eval}} + T_{\text{canary}}$$

### 创新点
- 模型质量门禁 (accuracy threshold)
- 自动 rollback (基于 metrics)
- 影子流量测试

### 参考
- Argo Workflows
- Kubeflow Pipelines
- Meta MLRobin

## 选题 4: 测试驱动的 AI 代码

**TL;DR**: 在 LLM 服务代码中引入 property-based testing + mutation testing。

### 核心问题
- AI 代码难测 (随机性)
- 边界 case 难覆盖
- 回归测试不足

### 目标
- Hypothesis (property-based)
- 覆盖率 95%+
- CI 集成 mutation testing

### 关键公式
$$\text{Mutation score} = \frac{\text{Killed mutants}}{\text{Total mutants}}$$

### 创新点
- AI 模型确定性 (seed 锁定)
- 数据 fixture 库
- 性能回归检测

### 参考
- Hypothesis (Python property-based)
- mutmut (Python mutation)
- Ch14 §04 测试

## 选题 5: 边缘部署 (Edge AI)

**TL;DR**: 在 Jetson / Raspberry Pi 上部署轻量 LLM (Phi-3 / Llama.cpp)。

### 核心问题
- 边缘设备资源有限
- 模型过大无法本地跑
- 网络延迟不可接受

### 目标
- 量化 (INT4) + 蒸馏
- Llama.cpp 推理
- 端到端延迟 < 100ms

### 关键公式
$$\text{Latency} = T_{\text{load}} + T_{\text{tokenize}} + T_{\text{inference}}$$
$$\text{Memory} = N_{\text{params}} \cdot 0.5 \text{ bytes (INT4)}$$

### 创新点
- 自适应算子 (CPU/GPU 切换)
- 模型并行 (split)
- 离线优先 + 云端 fallback

### 参考
- Llama.cpp
- NVIDIA Jetson
- Phi-3 / TinyLlama
