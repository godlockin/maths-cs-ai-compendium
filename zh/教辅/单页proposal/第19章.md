## 选题 1: AI 量化交易系统 (A 股 / 美股)

**TL;DR**: 用 Transformer + 强化学习, 在 A 股或美股实现年化 Sharpe > 1.5 的策略。

### 核心问题
- 传统因子模型不够
- 深度学习 + RL 提升
- 实时信号 + 风控

### 目标
- Transformer 价格预测
- RL 仓位管理
- A 股 / 美股回测

### 关键公式
$$\text{Annual Return} = \prod (1 + r_i) - 1$$
$$\text{Sharpe} = \frac{R - R_f}{\sigma}$$

### 创新点
- 多因子融合
- 强化学习仓位
- 风险约束

### 参考
- WorldQuant 101 Formulaic Alphas
- Alpha-GPT
- DeepLOB

## 选题 2: 蛋白设计 (Functional Protein Design)

**TL;DR**: 用 RFdiffusion / Chroma 等扩散模型设计新功能蛋白, 验证湿实验。

### 核心问题
- 天然蛋白受限
- 新功能 (结合 / 催化) 设计难
- 湿实验成本高

### 目标
- 选定功能 (e.g., 结合特定配体)
- 生成 100 候选
- 合成 10 + 验证

### 关键公式
$$\text{pLDDT} > 70, \text{TM-score} > 0.5$$
$$\text{Affinity} = K_d < 100 \text{ nM}$$

### 创新点
- 多目标 (结构 + 动力学 + 功能)
- 主动学习
- 闭环湿实验

### 参考
- RFdiffusion (Watson et al., Nature 2023)
- Chroma (Generate Biomedicines)
- ProteinMPNN

## 选题 3: LLM Agent 在企业自动化 (RAG + Tool Use)

**TL;DR**: 构建企业 Agent, 自动处理工单 / 数据查询 / 报告生成, 节省 50% 人力。

### 核心问题
- 重复劳动多
- LLM 单兵能力不足
- Agent 协调难

### 目标
- 3-5 个典型场景
- 准确率 > 90%
- 节省工时评估

### 关键公式
$$\text{Saving} = 1 - \frac{T_{\text{agent}}}{T_{\text{human}}}$$
$$\text{Accuracy} = \frac{N_{\text{correct}}}{N_{\text{total}}}$$

### 创新点
- 工具编排
- 长期记忆
- 反馈学习

### 参考
- LangChain / LangGraph
- Anthropic MCP
- AutoGen

## 选题 4: AI 药物发现端到端平台

**TL;DR**: 整合靶点 → 生成 → docking → ADMET → 合成, 平台化, 缩短药物发现周期。

### 核心问题
- 流程分散
- 多个模型拼接难
- 端到端评估

### 目标
- 选定靶点
- 生成 1000 候选
- 选出 10 个 lead

### 关键公式
$$\text{Hit Rate} = \frac{N_{\text{hits}}}{N_{\text{total}}}$$
$$\text{ADMET} = \text{QED} + \text{LogP} + \text{Solubility}$$

### 创新点
- 多目标优化
- 主动学习
- 闭环湿实验

### 参考
- AlphaFold / ISMRD
- DiffDock
- RoseTTAFold All-Atom

## 选题 5: 联邦学习 + 医疗影像

**TL;DR**: 多医院联合训练癌症检测模型, 不共享原始数据, 符合 HIPAA / GDPR。

### 核心问题
- 医疗数据隐私
- 多中心数据散落
- 中央化训练违规

### 目标
- 5 家医院
- 肺结节检测
- 不传原始数据

### 关键公式
$$\theta_{t+1} = \theta_t - \eta \nabla L_{\text{local}}$$
$$\text{Privacy} \epsilon < 1$$

### 创新点
- 差分隐私
- 安全聚合
- 同态加密

### 参考
- NVIDIA Clara
- FedML
- Owkin
