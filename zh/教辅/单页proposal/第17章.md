## 选题 1: 自适应量化的 LLM 推理引擎

**TL;DR**: 推理时根据 layer 重要性动态选择 INT8 / INT4, 比全局 INT4 精度 +5%。

### 核心问题
- 全局量化统一精度
- 部分 layer (e.g., attention) 更敏感
- 动态选择可平衡精度 / 速度

### 目标
- 量化策略自适应
- Llama 70B 评测
- < 5% 精度损失

### 关键公式
$$\text{Quantization} = f(\text{importance}, \text{hardware})$$

### 创新点
- 重要性度量 (梯度 / Hessian)
- 在线切换
- 硬件感知

### 参考
- AWQ / SmoothQuant
- LLM.int8()
- Outlier Experts

## 选题 2: Speculative Decoding 改进

**TL;DR**: 改进 draft 模型, 用小型非自回归模型, 加速 2-3×。

### 核心问题
- 当前 draft 模型也是自回归
- 慢, 不能并行
- 长序列边际效益低

### 目标
- 非自回归 draft
- 在 Llama 3 8B/70B 评测
- 2-3× 加速

### 关键公式
$$T_{\text{decode}} = \frac{N_{\text{tokens}}}{T_{\text{step}} \times P_{\text{accept}}}$$

### 创新点
- Medusa (multi-head)
- EAGLE (轻量)
- Layer-skip draft

### 参考
- SpecDec
- Medusa (TensorRT-LLM)
- EAGLE (NeurIPS 2024)

## 选题 3: Edge LLM 编译器

**TL;DR**: 端到端编译 Llama 3 8B 到 Llama.cpp + 量化 + SIMD, 在手机 <10W 跑 5 tok/s。

### 核心问题
- 边缘 LLM 部署难
- 功耗 + 内存限制
- 量化损失与加速平衡

### 目标
- 编译器自动优化
- 手机 (8 GB RAM) 跑
- <10W 功耗

### 关键公式
$$T_{\text{token}} = T_{\text{load}} + T_{\text{forward}}$$
$$P_{\text{wall}} = V \times I$$

### 创新点
- 算子融合
- KV cache 量化
- 异步 pipeline

### 参考
- Llama.cpp
- MNN / NCNN
- 阿里 MNN

## 选题 4: 推理服务 GPU 利用率优化

**TL;DR**: 改进 vLLM 的 continuous batching, 让 GPU 利用率从 70% 到 95%。

### 核心问题
- vLLM 70% 利用率
- 突发流量浪费
- 资源调度难

### 目标
- 改进调度算法
- 长度感知 chunked prefill
- A/B test

### 关键公式
$$\text{Utilization} = \frac{\text{Active SMs}}{\text{Total SMs}}$$

### 创新点
- 优先级队列
- KV cache 复用
- 跨节点调度

### 参考
- vLLM
- SGLang RadixAttention
- TGI

## 选题 5: 推理路由 (Model Routing)

**TL;DR**: 根据 query 难度路由到不同大小模型, 节省 50% 算力。

### 核心问题
- 简单 query 用大模型浪费
- 难 query 用小模型答错
- 路由决策难

### 目标
- 训练 router (small model)
- Llama 3 8B/70B 双模型
- 50% 算力节省

### 关键公式
$$\text{Saving} = 1 - \frac{N_{\text{hard}} C_{\text{large}} + N_{\text{easy}} C_{\text{small}}}{N C_{\text{large}}}$$

### 创新点
- 难度预测
- 成本-精度权衡
- 自适应阈值

### 参考
- RouteLLM (ICLR 2024)
- FrugalGPT
- OpenAI 路由
