# 第23章 · AI Agent 与工具使用 · 单页 Proposal

## 一句话定位
> **AI Agent = LLM + 工具 + 规划 + 记忆 + 反思**: 从"对话"到"行动"的范式跃迁, 2024 是 MCP 协议年, 2025 是 Operator + Multi-Agent 年, 2026 工业化。

## 为什么学这一章
- **Agent 是 LLM 商业化主战场** (Anthropic Computer Use / OpenAI Operator / Devin)
- **MCP / A2A / ANP** 三大协议是新基础设施
- **不学 Agent = 错过 2024-2027 LLM 最大的应用层机会**
- 面试 + 创业 + 转型 **必备**

## 学什么 (10 节 + 2 实战专题)
1. 什么是 AI Agent + LLM-to-Agent 跃迁
2. Prompt-based 推理与规划 (CoT / ReAct / ToT / Reflexion)
3. 工具使用与函数调用 (Function Calling / Toolformer / Gorilla)
4. **MCP** 模型上下文协议 (Anthropic 标准)
5. **Multi-Agent** 编排 (AutoGen / CrewAI / LangGraph)
6. Agent 生产落地 (评估 / 监控 / 调试 / thread_id)
7. 前沿方向 (虚拟世界 → 真实电脑)
8. **A2A + ANP** 协议
9. **Agent 记忆与自进化** (Mem0 / Letta / Voyager / AlphaEvolve)
10. **Computer Use / Operator** (Anthropic / OpenAI / Browser-Use)

## 学完后能做什么
- 设计 **MCP Server** 给 LLM 接入任何工具
- 实现 **Multi-Agent 协作** 系统 (AutoGen / CrewAI)
- 构建 **有记忆的 Agent** (Mem0 / HippoRAG / Letta)
- 部署 **Computer Use Agent** (Anthropic Computer Use / Skyvern)
- 在面试中讲清 **ReAct vs Reflexion vs Voyager 区别**

## 5 大关键词
**Agent / MCP / Multi-Agent / Memory / Computer Use**
