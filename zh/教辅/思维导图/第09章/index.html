    第09章 音频与语音 · 思维导图¶

    一句话总结: Ch09 把物理声波 (Ch03 傅立叶) + 概率 (Ch05 KL/EM) + Transformer (Ch07 §04) + 频谱图当图像 (Ch08 §05) 转译成"听得见 + 听得懂 + 说得出 + 分得开"的全栈音频 AI, 主干覆盖数字信号处理、ASR、TTS、说话人分析与源分离, 数字例 ≤3 步可核验, 单位 bit / dB / Hz / kHz 严格标注.

    承接 Ch05: 信息论 (Ch05 §05) → 交叉熵损失 (CTC, RNN-T 训练目标); 熵 → perplexity → Whisper 语言模型困惑度; KL 散度 → NMF 源分离目标 / VITS 后验对齐; EM 算法 → GMM-HMM 声学模型训练 (Baum-Welch); Viterbi 解码 → 状态对齐搜索.

    承接 Ch07: 自注意力 (Ch07 §04 QK^T/√d_k V) → Conformer 多头自注意力 + SepFormer 块内/块间注意力; Transformer 编码器-解码器 → Whisper ASR 与 VALL-E 编解码语言模型; BPE 词片 → Whisper 字节级 BPE; KL → DPO/RLHF 偏好对齐 (与 ASR/TTS 训练正交).

    承接 Ch08: ViT 16×16 patch (Ch08 §05) → AST 音频频谱图 Transformer; ResNet 残差 → x-vector / ECAPA-TDNN 残差块 + WaveNet 膨胀因果卷积; 对比学习 InfoNCE (Ch08 §05 CLIP) → wav2vec 2.0 对比损失; U-Net 编码-解码 (Ch08 §04) → Conv-TasNet 编码-分离-解码三段式.

    跨章桥接: DFT 矩阵 (Ch02 矩阵分解 + Ch03 傅立叶级数) → 频域变换; 矩阵分解 NMF (Ch02) → 经典源分离; 链式法则 (Ch03) → 自回归 WaveNet 训练; 测度/期望 (Ch05) → SI-SDR 评估指标; 后续 Ch10 (多模态音频-文本融合), Ch21 (语音隐私与水印).

    常见误区¶

    • 把 STFT 当成"时域+频域"两套独立信息 — 实际受 Gabor 极限约束, 时频分辨率乘积有下界
    • 期望 WaveNet 实时推理 — 自回归 1 秒 24 kHz 要 24000 步, 必须用 HiFi-GAN / VITS 替代
    • 把 MFCC 当过时的"老古董" — 对数梅尔频谱 (跳过 DCT) 才是现代 NN 输入, MFCC 仍活跃于小模型
    • 把 Conformer 当"Conv + Transformer 简单拼" — 实际是 FFN/MHSA/Conv/FFN 严格四段马卡龙, 半步残差权重是关键
    • 以为 wav2vec 2.0 一定要 53k 小时 — 实际可在不同规模上缩放, 关键是量化码本 + 掩码预测组合
    • 把 VALL-E 当"传统 TTS 加点新意" — 实际是把语音生成重定义为离散 token 上的语言建模, 借用 LLM 缩放红利
    • 把说话人验证 EER <1% 当"已解决" — 跨信道/跨语种/短时 (1-2 秒) 仍是开放问题
    • 把 ICA 当万能分离器 — 假设源非高斯且独立, 现实混响 + 源多于麦即失效, 现代深度方法更稳
    • 以为 NMF 就是非负 SVD — 实际代价函数 (Frobenius / KL) 和更新规则完全不同
    • 以为 SI-SDR 和 SDR 一样 — SI-SDR 对尺度不变, 移除绝对音量影响, 单独评价分离质量
