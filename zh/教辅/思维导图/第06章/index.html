    第06章 机器学习 · 思维导图¶

    一句话总结: Ch06 把概率/信息论 (Ch05) 转译成"可优化的目标函数", 用闭式解或梯度方法拟合参数; 主干覆盖经典 ML、梯度学习、深度学习、分布式与强化学习, 全程以 MSE / BCE / 交叉熵 / KL / perplexity 为主线, 复算 ≤ 3 步可见.

    承接 Ch05: 互信息 → 决策树信息增益; KL 散度 → 交叉熵损失 + VAE KL 正则; 熵 → 语言模型 perplexity = 2^H; LLN + CLT → SGD 收敛理论; Bayes → 朴素贝叶斯; 正态分布 → Xavier/He 初始化与 BatchNorm; Gamma/Poisson → Dropout / 噪声模型.

    跨章桥接: 距离/内积 (Ch01) → SVM / kNN; 矩阵求逆 (Ch02) → 正规方程; 链式法则 (Ch03) → 反向传播; 测度/期望 (Ch05) → 经验风险最小化; 后续 Ch07 (NLP perplexity), Ch08 (CV 损失), Ch12 (假设检验接 p 值).

    常见误区¶

    误区 错在哪 修正
    L1 范数稀疏友好 范数本身不诱导稀疏 L1 是作为优化目标里的正则项才把解推到坐标轴上
    Adam 默认学习率 1e-3 万能 不同任务差距大 实际常需 [1e-5, 1e-3] 网格; Transformer 一般 1e-4 ~ 5e-4
    dropout 测试时记得缩放 漏了一步 实际用反向 dropout, 训练时已经把激活除以 (1-p), 测试不变
    Adam = SGD + momentum + RMSprop 略去偏差修正 Adam 必须除以 (1-β₁ᵗ) 与 (1-β₂ᵗ), 否则前几步全偏零
    REINFORCE 用梯度下降 方向反了 策略梯度要做梯度上升; 想用优化器就把损失写成 -∇logπ·G_t
    策略梯度 ∇logπ = π - e_a 顺序反了 softmax 策略下 ∇logπ(a) = e_a - π; 写成 π - e_a 训练崩
    ε-greedy ε=0.1 永远不变 探索前期浪费 ε 通常从 0.5/1.0 指数衰减到 0.01; 后期纯利用
    perplexity 越低越好 (跨模型比) 不公平 PPL 只在同分词器下可比; 跨词表要用 BPB (每字节比特)
    Transformer 注意力 O(n²) 不可解 老黄历 FlashAttention-2/3 用 SRAM 块化在 H100 上 700+ TFLOPs
    BatchNorm 在所有场景都好用 批小就垮 RNN / Transformer / 小 batch 一律换 LayerNorm
    正态 = 万能初始化 忽略激活函数 tanh 用 Xavier (2/(d_in+d_out)); ReLU 用 He (2/d_in); 混用就崩
    数据并行 = 加速 N 倍 通信成本 通信开销吃掉了 10-30% 加速; 真要把 batch 扩到 N·B, 还得调学习率
    MSE 越小越好 忽略泛化 训练 MSE→0 是过拟合信号, 验证 MSE 才反映泛化
    Q-learning 总是比 SARSA 好 任务相关 悬崖漫步: SARSA 走安全路, Q-learning 走险路, 反而 SARSA 实际奖励高
    MoE 推理快 参数量≠计算量 MoE 总参数大但激活小, FLOPs ≈ 稀疏化; 显存仍大, 部署吃紧
    PPO 一定要做 KL 惩罚 与 PPO-clip 二选一 原始 PPO 用裁剪目标就够, KL 惩罚是 PPO-penalty 变体
