# 第07章 计算语言学 · 思维导图

> **一句话总结**: Ch07 把语言学 (Ch01 线性代数 + Ch02 矩阵 + Ch03 链式法则) 转译成"自然语言的可计算表示与生成", 主干覆盖语言学层级、经典 NLP、词嵌入与序列模型、Transformer 语言模型、高级文本生成, 全程以词袋 / TF-IDF / 困惑度 (perplexity) / 交叉熵 为主线, 数字例 ≤3 步可核验.
>
> **承接 Ch05**: 互信息 → 词嵌入 (Word2Vec 隐式分解 PMI); KL 散度 → 蒸馏损失 + DPO 偏好对齐 + RLHF 奖励正则; 熵 → 困惑度 $\text{PPL}=2^H$; HMM → POS 标注 / CRF → NER; 大数定律 → BLEU / ROUGE / METEOR 期望估计.
>
> **承接 Ch06**: 反向传播 (autograd) → Transformer 训练; Softmax + 交叉熵 → L_CLM 训练目标; Adam 优化器 → 大模型预训练标配; PPO 截断目标 → RLHF 基础算法 (DPO = PPO 闭式解); perplexity (Ch06) → 语言模型评估指标.
>
> **跨章桥接**: 距离/内积 (Ch01) → 余弦相似度文档检索; 矩阵分解/SVD (Ch02) → GloVe 词共现矩阵分解 + LSA; 链式法则 (Ch03) → softmax + cross-entropy 反向梯度; 测度/期望 (Ch05) → BLEU/ROUGE 语料级期望; 后续 Ch08 (CV 视觉编码器)、Ch09 (语音音素)、Ch21 (联邦 LLM).

## 常见误区

| 误区 | 错在哪 | 修正 |
|---|---|---|
| **Word2Vec 嵌入学过同义词表** | 模型只看到分布 | 只学"上下文相似"的近邻; 同义/反义是涌现属性, 不是监督目标 |
| **困惑度跨模型可比** | 词表和分词不同 | PPL 只在**同分词器**下可比; 跨词表用 **BPB** (每字节比特) |
| **BPE 越大越好** | 词表与序列长度的权衡 | 词表大 → embedding 大, 序列短; 实际 30k-100k; 中文常用 6w+ |
| **BPE 是 NLP 自创** | 不是 | **数据压缩算法 (1994)**; Sennrich 2016 搬到子词分词 |
| **WordPiece = BPE** | 算法不同 | BPE 按原始频率合并, WordPiece 按 PMI 风格打分 freq(AB)/[freq(A)·freq(B)] |
| **CRF = HMM** | 生成 vs 判别 | HMM 建模 P(x,y), CRF 建模 P(y\|x); CRF 直接判别式, 转移特征可任意 |
| **BLEU 越高翻译越好** | 忽略召回率 + 句子级差 | BLEU 只算 n-gram 精确率 + BP 惩罚; 句子级与人工相关性差 |
| **ROUGE 是召回率** | 名字"Recall-Oriented"误导 | ROUGE-N 是召回, ROUGE-L 是 LCS; 但都只看表层 n-gram |
| **度量指标钻空子无害** | metric gaming | 模型可以专攻 BLEU/PPL, 输出安全通用但脱离真实质量 |
| **DPO 与 RLHF 不同源** | 同源数学 | DPO 是 RLHF 带 KL 约束目标的**闭式最优策略**; 数学上等价 |
| **温度参数 w 越大越好** | 多样性坍塌 | CFG w 大 → 死磕条件, 多样性崩塌, 重复; 典型 w=1.5-3 |
| **prefix tuning = prompt tuning** | 发生空间不同 | prefix 改激活空间, prompt 改嵌入空间; prefix 通常更强 |
| **RoPE 支持任意长上下文** | 单纯 RoPE 不行 | 需配合 ABF 调基础频率 (5e5/1e6) 或 YaRN 低频插值 |
| **MoE 总参数 = 推理算力** | 显存 vs 激活 | MoE 总参大但激活少, FLOPs ≈ 稀疏; 显存仍按总参占 |
| **BLEURT 是无监督指标** | 已被微调过 | BLEURT 在合成扰动 + 人类评分上微调过 BERT |
| **CTC 不要 blank token** | 重复字符塌缩 | 没有 blank, "Hello" 的 "ll" 与单 "l" 无法区分 |
| **beam=1 = greedy** | 等价 | 束宽 k=1 时退化为贪心解码; 默认 k=4-10 |
| **语言模型只算交叉熵** | 缺单位 / 缺 bit 标 | 必须明示 bit 或 nat, bit/nat 比 ≈ ln2 ≈ 0.693 |
| **困惑度低即落地** | 评估漏了 | 困惑度只测流畅; 事实性 / 指令遵循 / 安全另需评估 |
| **CKA / OT 对齐无损** | 蒸馏常掉点 | 学生即便有 KL 蒸馏, 复杂任务仍掉 1-3 个百分点 |
