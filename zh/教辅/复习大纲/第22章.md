- 决定 LLM-as-Judge 公正性

- 3 大挑战: Contamination / Saturation / Construct Validity

- **BLEU**: n-gram Precision, 翻译
- **ROUGE**: Recall, 摘要
- **METEOR**: 同义词 + 词干
- **chrF**: 字符级
- **BERTScore**: 上下文 embedding
- **PPL**: 语言模型不确定度
- **WER**: 词错误率, ASR

### §03 现代 Benchmark
- **知识**: MMLU / MMLU-Pro / GPQA
- **数学**: GSM8K / MATH / MATH-500
- **代码**: HumanEval / MBPP / LiveCodeBench / SWE-Bench
- **综合**: BBH / BIG-Bench / HellaSwag
- **中文**: C-Eval / CMMLU
- **实时**: LiveBench / FrontierEval
- **完整**: HELM 7×16
- **真实性**: TruthfulQA / HaluEval

### §04 竞技场
- **LMSYS Arena**: 真实投票
- **Bradley-Terry 模型**: 偏好概率
- **Elo Rating**: K-factor 更新
- **TrueSkill**: (μ, σ) 不确定性

### §05 LLM-as-Judge
- **3 模式**: Single-Point / Pairwise / Reference
- **4 大 Bias**: Position / Verbosity / Self-Bias / Anchoring
- **最佳实践**: Few-shot + CoT + JSON

### §06 Contamination
- **检测**: n-gram / Membership / 行为
- **缓解**: 私有 / 定期 / 模糊 / 时间戳
- **历史争议**: GPT-4 HumanEval

### §07 双轨 Eval
- Capability: 推理/代码/数学

- 5 大支柱

## 二、重点公式

### BLEU 简化
$$\text{BLEU} = \text{BP} \cdot \exp\left(\sum_{n=1}^{N} w_n \log p_n\right)$$

BP = Brevity Penalty, $p_n$ = n-gram precision

### Bradley-Terry
$$P(A \succ B) = \frac{e^{r_A}}{e^{r_A} + e^{r_B}}$$

### Elo 更新
$$R_{\text{new}} = R_{\text{old}} + K(S - P_{\text{pred}})$$

K=32 (Arena), S ∈ {0, 0.5, 1}, P_pred = $\frac{1}{1+10^{(R_B-R_A)/400}}$

### BERTScore
$$\text{BERTScore} = \frac{1}{|x|}\sum_{x_i \in x} \max_{y_j \in y} \text{sim}(\mathbf{x}_i, \mathbf{y}_j)$$

### Perplexity
$$\text{PPL}(x) = \exp\left(-\frac{1}{N}\sum_{i=1}^N \log p_\theta(x_i | x_{<i})\right)$$
