- JD 解读三步

### §02 ML 系统设计 8 步
1. **需求澄清**: 业务 / QPS / 延迟 / 成本
2. **指标定义**: 离线(AUC/NDCG) + 在线(CTR/时长/留存)
3. **离线-在线一致性**
4. **数据流**: Kafka / Flink / Spark / Feast
5. **特征工程**: 离线 + 在线 + Embedding
6. **模型选择**: baseline → SOTA
7. **部署**: K8s + GPU + A/B
8. **监控**: PSI / AUC / 延迟 / 反馈循环

### §03 推荐-搜索-排序
- **召回**: 双塔 / Faiss / ScaNN (100万 → 1000)
- **精排**: DLRM / DeepFM / DIN (1000 → 100)
- **重排**: 多样性 / 规则 (100 → 10)
- **冷启动**: Look-alike / Bandit
- **案例**: 抖音 / YouTube DNN / Amazon 协同过滤

### §04 反欺诈-风控-异常
- **3 类异常**: 统计(Z-score/IForest) / 距离(KNN/DBSCAN) / 深度(AE/LSTM-AE)
- **GNN 风控**: 团伙欺诈 / 设备指纹
- **标签稀缺**: PU Learning / 半监督 / 主动学习
- **不平衡**: Focal Loss / SMOTE / PR-AUC
- **决策**: 阈值 + 二次验证

### §05 对话与 LLM 系统
- **RAG**: 文档加载 / 分块 / Embedding / 向量 DB / Hybrid / Re-rank / Generator
- **Agent**: MCP / Function Calling / Multi-Agent / Memory / Computer Use
- **性能优化**: KV Cache / Speculative Decoding / Prompt Caching / Continuous Batching / 量化
- **容量规划**: QPS × tokens → GPU 数
- **监控**: TTFT / TPOT / 成本 / CSAT

### §06 算法与编程
- **Top-K**: 堆 O(n log k) / 快选 O(n) / LeetCode 347
- **LRU/LFU**: 哈希 + 双向链表 / LeetCode 146
- **Trie**: 单词搜索 / 自动补全 / 路由匹配
- **并查集**: 路径压缩 / Kruskal / 朋友圈
- **二分**: 4 变体 / 旋转数组 / 二分答案
- **DP**: 5 大类 / 编辑距离 / 区间 / 树形
- **图**: BFS/DFS / 拓扑排序 / Dijkstra / 最短路
- **红黑树/B 树**: Linux 内核使用

### §07 行为面 + Offer 谈判
- **STAR 项目讲述**: 3-5 个深度项目 + 量化
- **失败项目**: 诚实 + 反思 + 学习
- **团队冲突**: 数据说话 + 妥协共识

- **Offer 谈判**: Base + RSUs + 签字费 / 多 Offer 博弈 / levels.fyi / 反 PUA

## 二、重点公式

### 双塔召回相似度
$$\text{sim}(u, v) = \langle \mathbf{e}_u, \mathbf{e}_v \rangle = \cos(\theta)$$

### NDCG
$$\text{NDCG@k} = \frac{\text{DCG@k}}{\text{IDCG@k}}$$
$$\text{DCG@k} = \sum_{i=1}^k \frac{2^{rel_i} - 1}{\log_2(i+1)}$$

### AUC
$$\text{AUC} = P(f(x^+) > f(x^-))$$

### TTFT (Time To First Token)
$$\text{TTFT} = T_{\text{prefill}} = T_{\text{attn}} \cdot N_{\text{tokens}}$$

### TPOT (Time Per Output Token)
$$\text{TPOT} = T_{\text{decode-step}}$$

### 容量估算
$$\text{GPU 数} = \frac{\text{QPS} \times \text{tokens/req}}{\text{throughput/GPU}}$$
