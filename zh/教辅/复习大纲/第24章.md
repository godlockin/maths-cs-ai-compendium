## 一、知识地图(7 大模块)

### §01 浮点与数值稳定性
- **IEEE 754**: FP32 (1+8+23) / FP16 (1+5+10) / BF16 (1+8+7) / FP8 / FP4 / 1.58-bit
- **Machine Epsilon**: FP32 = 1.19e-7, FP16 = 9.77e-4, BF16 = 7.81e-3
- **误差类型**: 舍入 / 截断 / Catastrophic Cancellation
- **算法**: Kahan 求和 / Softmax 减 max / BatchNorm / Loss Scaling

### §02 迭代法与稀疏线代
- **矩阵分解**: LU / QR / SVD / Cholesky
- **迭代法**: CG / GMRES / BiCGSTAB
- **稀疏存储**: CSR / COO / ELL / Block Sparse
- **预条件子**: Jacobi / ILU / AMG

### §03 凸集与凸函数
- **凸集**: 定义 / 凸包 / 凸锥 / 仿射集
- **凸函数**: 一阶条件 / Hessian 半正定 / 强凸 / 平滑
- **Lipschitz 梯度**: ||∇f(x) - ∇f(y)|| ≤ L||x-y||
- **共轭**: f*(y) = sup_x {yᵀx - f(x)}

### §04 对偶与 KKT
- **Lagrange**: L(x,λ,ν) = f(x) + λg(x) + νh(x)
- **弱对偶**: g ≤ f(x*)
- **强对偶**: Slater 条件 + 凸
- **KKT 4 条件**: Stationarity / Primal Feasibility / Dual Feasibility / Complementary Slackness

### §05 二阶方法
- **Newton**: 二次收敛, O(n³)
- **BFGS**: 秩 2 修正, 超线性
- **L-BFGS**: O(mn) 内存
- **Trust Region**: 比 Line Search 稳健
- **K-FAC / Shampoo**: 实用化二阶, 训练加速 2-3×

### §06 约束优化
- **Interior Point**: Barrier Method
- **投影梯度**: 简单约束
- **Frank-Wolfe**: 凸包优化
- **SQP**: 强约束
- **ADMM**: 分布式

### §07 分布式与随机优化
- **同步 SGD**: AllReduce (Ring, NCCL)
- **异步 SGD / Hogwild!**: 无锁
- **Parameter Server**: 超大规模
- **FedAvg**: 联邦学习
- **EA-SGD**: 弹性平均 + 拜占庭鲁棒

## 二、重点公式

### IEEE 754 FP32
$$x = (-1)^s \times 2^{e-127} \times (1.m)$$

### Kahan 求和
$$y = a - c; \quad t = b + y; \quad c = (t - b) - y; \quad \text{sum} = t$$

### Softmax 减 max(数值稳定)
$$\text{softmax}(x_i) = \frac{e^{x_i - \max x}}{\sum_j e^{x_j - \max x}}$$

### 凸函数 Hessian 判别
$$\nabla^2 f(x) \succeq 0, \quad \forall x$$

### 强凸 + 平滑 → 线性收敛
$$\frac{L}{\mu} = \kappa \text{(条件数)}$$

### KKT Stationarity
$$\nabla f(x^*) + \sum \lambda_i \nabla g_i(x^*) + \sum \nu_j \nabla h_j(x^*) = 0$$

### L-BFGS 更新
$$s_k = x_{k+1} - x_k; \quad y_k = \nabla f_{k+1} - \nabla f_k; \quad \rho_k = \frac{1}{y_k^T s_k}$$

### AllReduce Ring
$$T_{\text{Ring}} = 2(N-1) \times \frac{M}{N}$$
