    二、考点详解¶

    🔴考点 1 · 测度版三件套 (Ω, F, P) — 难度 🟢 L1¶

    母版出处: zh/教辅/STATISTICS_AXIOMS_TEMPLATE.md (Ch04 应用层 → Ch05 测度论)

    样本空间 Ω: 一次实验所有可能结果的集合 — 抛硬币 \(\{H,T\}\), 掷骰子 \(\{1,2,3,4,5,6\}\), 连续区间 \([0,1]\)。

    事件域 (σ-algebra) F: Ω 的子集族, 满足 - \(\varnothing, \Omega \in \mathcal{F}\) - \(A \in \mathcal{F} \Rightarrow A^c \in \mathcal{F}\) - \(A_1, A_2, \ldots \in \mathcal{F} \Rightarrow \bigcup_i A_i \in \mathcal{F}\)

    大白话: F 是"可测"的集合族, 概率只能定义在 F 的元素上, 不能定义在任意子集上 (否则 Banach-Tarski 悖论)。

    最小例 (Ω={1,2,3}): 教学最常用。 - 平凡 σ-代数: \(\mathcal{F}=\{\varnothing,\Omega\}=\{\varnothing,\{1,2,3\}\}\) (仅 2 个元素, 仍满足三条性质)。 - 全幂集 (最常用): \(\mathcal{F}=2^\Omega=\{\varnothing,\{1\},\{2\},\{3\},\{1,2\},\{1,3\},\{2,3\},\Omega\}\) 共 \(2^3=8\) 个子集。 - 条件: \(\mathcal{F}\) 必须含 \(\varnothing\) 与 \(\Omega\)、对补集封闭、对可列并封闭 — 这是抽象 σ-代数的"教学黄金例"。

    概率测度 P: \(\mathcal{F} \to [0,1]\), 满足 K1/K2/K3。

    K1 非负性: \(\forall A \in \mathcal{F}, P(A) \ge 0\) - 大白话: 概率像长度, 不能为负 - 反例: P(A) = −0.3, 不合法

    K2 规范化: \(P(\Omega) = 1\) - 大白话: 整个样本空间概率 = 1 - 反例: PMF 总和 = 0.8 ≠ 1, 不合法

    K3 可列可加性: 互不相交 \(A_1, A_2, \ldots\) ⇒ \(P(\bigcup_i A_i) = \sum_i P(A_i)\) - 大白话: 互不相交事件可加 (无限个也行) - 反例: P(A)=0.6, P(B)=0.5, A∩B=∅, P(A∪B)=0.8 ≠ 1.1, 不合法

    派生定理 (从公理推): 单点 ≤ 1; 补集公式; 互斥可加; 容斥; P(∅)=0。

    易错: 把派生定理当公理写 — 三件套是公理, 其他都是定理/推论。

    🔴考点 2 · 离散 vs 连续: PMF / PDF / CDF — 难度 🟢 L1¶

    函数 适用 数学 几何含义
    PMF \(p(x)\) 离散 \(P(X=x)\) 柱状图柱子高度 (本身就是概率)
    PDF \(f(x)\) 连续 \(P(a \le X \le b)=\int_a^b f(x)\,dx\) 曲线下面积才是概率
    CDF \(F(x)\) 通用 \(F(x)=P(X \le x)\) 累积, 单调不减, \(F(-\infty)=0, F(\infty)=1\)
    • 离散求和 → 连续积分 的统一原则: 期望 \(E[X]\) 离散 \(\sum x\,p(x)\), 连续 \(\int x\,f(x)\,dx\)。
    • 反例陷阱: "PDF 值 > 1 也合法" ❌ — 密度 ≠ 概率! PDF > 1 表示该区域概率集中, 但 PDF 单点值的"概率"是 0 (连续单点概率为 0)。
    • 典型题型: 验合法 PMF (K1+K2); 求 CDF; 求 PDF 由 CDF 求导; 连续单点 \(P(X=a)=0\)。

    🔴考点 3 · 条件概率 \(P(A|B)\) — 难度 🟢 L2¶

    \[P(A|B) = \frac{P(A \cap B)}{P(B)}, \quad P(B) > 0\]
    • 大白话: 把样本空间从 Ω 缩到 B, 再问 B 中有多大部分也属于 A。
    • 数字例: 抽牌, \(P(\text{king}|\text{red}) = P(\text{king} \cap \text{red})/P(\text{red}) = (2/52)/(26/52) = 1/13\)
    • 反例陷阱: \(P(A|B) = P(A)\) 不一定推出独立 — 仅当对所有 B 都成立才独立, 单次相等不算。
    • 典型题型: 算条件概率; 验独立; 全概率公式铺垫。

    🔴考点 4 · 独立 vs 不相关 — 难度 🟡 L3¶

    独立: \(P(AB) = P(A)P(B)\), 或等价地 \(P(A|B) = P(A)\) - 数字例: 抛两枚独立硬币, \(P(H_1 \cap H_2) = 0.25 = 0.5 \times 0.5\) - 正态等价: 对联合正态 X, Y, 独立 ⟺ 不相关 (充要); 对一般分布, 只 "独立 ⟹ 不相关", 反之不成立。 - 反例: \(X \sim U(-1,1)\), \(Y = X^2\) ⇒ \(\text{Cov}(X,Y)=0\) 但显然相关 (Y 由 X 完全决定) - 典型题型: 判独立 vs 不相关; 给场景选独立性假设 (朴素贝叶斯就用它)。

    🔴考点 5 · 全概率公式 — 难度 🟡 L2¶

    \[P(B) = \sum_i P(B|A_i) P(A_i)\]

    其中 \(\{A_i\}\) 是 Ω 的一个划分 (互斥且穷举)。

    • 大白话: 用各种"原因" \(A_i\) 把 \(B\) 拆开加权求和 — 是 Bayes 分母。
    • 数字例: 工厂 A 出 50%, 次品率 2%; B 出 30%, 次品率 3%; C 出 20%, 次品率 5%。\(P(\text{次}) = 0.5 \times 0.02 + 0.3 \times 0.03 + 0.2 \times 0.05 = 0.029\)
    • 易错: 划分必须是 Ω 的完备集 (覆盖整个样本空间); 漏项直接错。
    • 典型题型: 给 P(Ai), P(B|Ai) 求 P(B); 给场景构造划分。

    🔴考点 6 · Bayes 公式 (深度版) — 难度 🟡 L3¶

    \[P(A|B) = \frac{P(B|A) P(A)}{P(B)} = \frac{P(B|A) P(A)}{\sum_i P(B|A_i) P(A_i)}\]

    四要素: - 先验 \(P(A)\): 看到数据前的信念 - 似然 \(P(B|A)\): 给定 A, 数据 B 出现概率 - 证据 \(P(B)\): 全概率展开的分母 - 后验 \(P(A|B)\): 看到数据后更新的信念

    数字例 1 (假阳性): 患病率 1%, 检测灵敏度 95%, 假阳率 5% $\(P(\text{患}|\text{阳}) = \frac{0.95 \times 0.01}{0.059} \approx 16.1\%\)$ 反直觉: 检测阳性, 实际患病仍只有 16% — base rate 极低时, Bayes 后验小。

    数字例 2 (多条件 + 后验更新): 工厂 ABC (见考点 5), 抽到次品, 来自 A 的概率: $\(P(A|\text{次}) = \frac{0.5 \times 0.02}{0.029} \approx 0.345\)$

    数字例 3 (连续更新): 抛硬币先验 Beta(2,2), 观测 3 正 1 反 → 后验 Beta(5,3); 再观测 1 正 1 反 → 后验 Beta(7,4); 后验众数随观测更新。

    • 易错: 分母漏全概率展开; 误读为因果 (\(P(A|B) \ne\) "A 导致 B")。
    • 典型题型: 假阳性; 多事件 Bayes; 共轭更新。

    🔴考点 7 · 期望 \(E[X]\) — 难度 🟢 L1¶

    • 离散: \(E[X] = \sum_x x\,p(x)\)
    • 连续: \(E[X] = \int_{-\infty}^{\infty} x\,f(x)\,dx\)
    • 数字锚点: 公平骰子 \(E[X] = (1+2+3+4+5+6)/6 = 3.5\)
    • 性质: \(E[aX+b] = aE[X] + b\) (线性, 不要求独立!)
    • 反例陷阱: "期望 = 单次结果" ❌ — 期望是长期平均。
    • 承 Ch03: 多变量期望 \(E[\mathbf{X}] = \int \mathbf{x}\,f(\mathbf{x})\,d\mathbf{x}\), Jacobian 用于变量替换 (Ch03 §02)。
    • 典型题型: 算期望; 算函数期望 \(E[g(X)]\); 用线性性简化。

    🔴考点 8 · 方差 \(\text{Var}(X)\) — 难度 🟢 L2¶

    • 定义: \(\text{Var}(X) = E[(X-E[X])^2] = E[X^2] - (E[X])^2\) (后者易算)
    • 数字锚点: 公平骰子 \(E[X^2] = 91/6\), \(\text{Var} = 91/6 - 12.25 = 35/12 \approx 2.92\)
    • 性质: \(\text{Var}(aX+b) = a^2 \text{Var}(X)\) (平移不变, 缩放平方)
    • 加性陷阱: \(\text{Var}(X+Y) = \text{Var}(X) + \text{Var}(Y) + 2\text{Cov}(X,Y)\), 仅独立时 \(= \text{Var}(X) + \text{Var}(Y)\)
    • 期望 vs 方差的独立性: \(E\) 永远线性 (无论独立), \(\text{Var}\) 仅独立时加性。
    • 典型题型: 算方差; 用 \(E[X^2] - (E[X])^2\); 判独立再用加性。

    🔴考点 9 · 协方差与相关系数 — 难度 🟡 L2¶

    \[\text{Cov}(X,Y) = E[(X-E[X])(Y-E[Y])] = E[XY] - E[X]E[Y]\]
    \[\rho_{XY} = \frac{\text{Cov}(X,Y)}{\sigma_X \sigma_Y}, \quad |\rho| \le 1\]
    • 独立 vs 不相关: \(X \perp Y \Rightarrow \text{Cov}=0\); \(\text{Cov}=0 \not\Rightarrow X \perp Y\) (一般分布, 仅正态等价)。
    • 存在性陷阱: Cauchy 分布无均值, 故 \(\text{Cov}\) 无定义 — 算前先验 \(E[X]\) 存在。
    • 数字例: \(X \sim U(-1,1)\), \(Y=X^2\): \(\text{Cov}(X,Y)=E[X^3]-E[X]E[X^2]=0\) (奇函数), 但显然相关。
    • 典型题型: 算 \(\text{Cov}\); 判 ρ 强度; 解读 ρ=0。

    🔴考点 11 · 矩母函数 (MGF) — 难度 🟡 L3¶

    \[M_X(t) = E[e^{tX}]\]
    • 性质: \(M_X^{(n)}(0) = E[X^n]\), 一阶导=均值, 二阶导=\(E[X^2]\)
    • 判定唯一性: MGF 唯一确定分布 (在有限邻域内存在)
    • 和的 MGF: \(M_{X+Y}(t) = M_X(t) M_Y(t)\) (若独立)
    • 数字例: Poisson(λ) 的 MGF = \(\exp(\lambda(e^t-1))\); Normal(μ,σ²) 的 MGF = \(\exp(\mu t + \sigma^2 t^2/2)\)
    • 典型题型: 由 MGF 求矩; 由 MGF 判分布; 独立和的 MGF 拆分。

    🔴考点 12 · 大数定律 (LLN) — 难度 🟡 L3¶

    陈述 (弱大数定律): 若 \(X_1, X_2, \ldots\) i.i.d. 且 \(E[|X_i|] < \infty\), 则 $\(\bar X_n = \frac{1}{n} \sum_{i=1}^n X_i \xrightarrow{P} \mu\)$

    强大数定律 (Kolmogorov): 在更弱条件下, \(\bar X_n \to \mu\) 几乎必然 (a.s.)。

    • 大白话: 频率 → 概率; 样本均值 → 期望。
    • 数字锚点: 公平骰 \(n=10000\), 实测 \(\bar X \approx 3.5\) ✓ (模拟可验)
    • 关键: 不要求原分布是什么, 只要均值存在。
    • 典型题型: 用 LLN 解释频率收敛; 区分弱/强大数。

    🔴考点 13 · 中心极限定理 (CLT) 严格版 — 难度 🔴 L4 ⭐¶

    经典 CLT: \(X_1,\ldots,X_n\) i.i.d., \(E[X]=\mu\), \(\text{Var}(X)=\sigma^2<\infty\), 则 $\(\frac{\sqrt{n}(\bar X_n - \mu)}{\sigma} \xrightarrow{d} \mathcal{N}(0,1)\)$

    • 几何直觉: 测度比 — 把总和看成"面积", 标准化后比值收敛到正态密度。
    • 数字例: \(X \sim \text{Exp}(\lambda=1)\), \(n=30\), \(\bar X\) 近似 \(\mathcal{N}(1, 1/30)\), 模拟 10000 次验证 ✓
    • 不变量: 不管原分布形状 (均匀/指数/Bernoulli), \(\bar X\) 的极限都是正态 — 这是正态的核心地位来源。

    Lindeberg-Feller 条件 (进阶 ⭐): 独立但不必同分布情形下 CLT 成立的充要条件族: $\(\forall \varepsilon>0, \quad \frac{1}{s_n^2} \sum_{i=1}^n E[X_i^2 \mathbf{1}_{|X_i|>\varepsilon s_n}] \to 0\)$ 其中 \(s_n^2 = \sum \text{Var}(X_i)\)。

    Berry-Esseen 界 (进阶 ⭐): 给收敛速率 $\(\sup_x |F_n(x) - \Phi(x)| \le \frac{C \rho}{\sigma^3 \sqrt{n}}\)$ 其中 \(\rho = E[|X-\mu|^3]\) 是三阶绝对矩, \(C \approx 0.4748\)。

    • 典型题型: 用 CLT 近似 \(\bar X\) 分布; 三角阵 CLT 应用; 给收敛速率上界。

    🔴考点 14 · 条件独立 — 难度 🟡 L3¶

    \[X \perp Y \mid Z \iff P(X,Y|Z) = P(X|Z) P(Y|Z)\]
    • 大白话: 给定 Z 后, X 和 Y 互不影响。
    • 数字例: 抛两枚硬币 X, Y, 给定总数 Z=X+Y 后, X|Z 与 Y|Z 不独立 (总和定了, 单个概率变了)。
    • ML 角色: 朴素贝叶斯的核心假设 = 特征条件独立 给定类别 — 这就是它"朴素"的来源。
    • 典型题型: 判条件独立; 朴素贝叶斯公式推导; HMM 中观测独立假设。

    🔴考点 15 · 信息论入门 — 难度 🟡 L3 (AI/ML 桥梁)¶

    自信息 (surprisal): \(I(x) = -\log_2 p(x)\) - 数字例: 公平硬币正面的自信息 = \(-\log_2 0.5 = 1\) 比特; 概率 1/8 事件 = 3 比特 - 大白话: 概率越低的事件, 自信息越大 (越意外)。

    熵 (entropy): \(H(X) = E[I(X)] = -\sum_x p(x) \log_2 p(x)\) - 数字例: 公平硬币 \(H=1\) 比特; 偏心 \(p=0.9\), \(H \approx 0.469\) 比特; 必然事件 \(H=0\)。 - 最大熵原理: \(n\) 个等可能结果的熵最大 \(= \log_2 n\)。 - 压缩下界: Shannon 信源编码定理 — 无损压缩极限 = 熵率。

    微分熵: \(h(X) = -\int f(x) \log f(x)\,dx\) - 数字例: \(X \sim \mathcal{N}(0,\sigma^2)\), \(h = \frac{1}{2}\log_2(2\pi e \sigma^2)\) - 关键性质: 等方差分布中, 正态微分熵最大 — 这就是正态在建模中常见的原因。

    交叉熵: \(H(p,q) = -\sum_x p(x) \log_2 q(x)\) - 数字例: 单标签 \(c\) 的样本, \(\mathcal{L} = -\log \hat{y}_c\) - ML 应用: 分类标准损失 = 交叉熵损失 (BCE / CCE)。

    KL 散度 (相对熵): \(D_{KL}(p\|q) = \sum_x p(x) \log \frac{p(x)}{q(x)} = H(p,q) - H(p) \ge 0\) - 数字例: \(p = \mathcal{N}(0,1)\), \(q = \mathcal{N}(0,2)\), \(D_{KL}(p\|q) = \frac{1}{2}\log(4) + \frac{1}{2}(1/4-1) = \log 2 - 3/8 \approx 0.318\) (用 \(\log_2\) 单位为 bit, 用 \(\ln\) 单位为 nat) - ⛔ 不对称: \(D_{KL}(p\|q) \ne D_{KL}(q\|p)\), 这是 KL 与距离的根本区别。

    KL 三性质 (考点 🔴): 1. 非负 \(D_{KL}(P\|Q) \ge 0\) (Jensen 不等式证明); 2. \(P=Q\) 时为 0 \(D_{KL}(P\|P)=0\) (等号当且仅当 \(P=Q\)); 3. 不对称 \(D_{KL}(P\|Q) \ne D_{KL}(Q\|P)\) (KL 不是距离)。

    互信息: \(I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = \sum_{x,y} p(x,y) \log_2 \frac{p(x,y)}{p(x)p(y)}\) - 数字例: \(X \perp Y \Rightarrow I(X;Y) = 0\) - ML 应用: 决策树信息增益 = \(I(X_{\text{split}}; Y)\); 特征选择度量。

    • 典型题型: 算熵/KL/互信息; 验不对称; 判 ML 损失对应。

    🟡考点 16 · 排列组合与二项系数 — 难度 🟢 L1¶

    • 加法法则: 互斥情形相加

    🟡考点 17 · 几何分布与无记忆性 — 难度 🟢 L2¶

    \(P(X=k) = (1-p)^{k-1} p\), \(k=1,2,\ldots\)

    • 无记忆: \(P(X > s+t | X > s) = P(X > t)\)

    🟡考点 18 · 指数分布与无记忆性 — 难度 🟢 L2¶

    \(f(x) = \lambda e^{-\lambda x}\), \(E[X] = 1/\lambda\), \(\text{Var}(X) = 1/\lambda^2\)

    • 无记忆: \(P(X > s+t | X > s) = P(X > t)\)
    • 数字例: 灯泡寿命 Exp(λ=1/1000 小时), 已用 500 小时还能再用 1000 小时的概率 = \(P(X>1000)\) — 与已用多久无关。
    • Poisson 联系: Poisson 过程相邻事件间隔 ~ Exponential(λ)。
    • 典型题型: 算概率; 验无记忆; 联系 Poisson 过程。

    🟡考点 19 · \(\chi^2\) 与 t 分布 — 难度 🟡 L3¶

    • \(\chi^2(k)\): \(k\) 个独立标准正态平方和 — 均值 \(k\), 方差 \(2k\)
    • Student \(t(\nu)\): \(\nu\) 自由度 — 尾部比正态重, \(\nu \to \infty\) 收敛到 \(\mathcal{N}(0,1)\)

    🟡考点 20 · 共轭先验 — 难度 🟡 L3¶

    Beta-Binomial: 先验 \(p \sim \text{Beta}(\alpha,\beta)\), 数据 \(k\) 成功 \(n-k\) 失败 \(\Rightarrow\) 后验 \(p|D \sim \text{Beta}(\alpha+k, \beta+n-k)\)

    Gamma-Poisson: 先验 \(\lambda \sim \text{Gamma}(\alpha,\beta)\), 数据 \(k\) 个事件 \(\Rightarrow\) 后验 \(\lambda|D \sim \text{Gamma}(\alpha+k, \beta+n)\)

    • 数字例: Beta(1,1) 先验 (均匀), 观测 3 正 1 反 \(\Rightarrow\) Beta(4,2); 后验众数 \(= (\alpha-1)/(\alpha+\beta-2) = 3/4 = 0.75\)
    • 意义: 后验 = 同一族 = 解析上可继续更新; 是 Bayes 推断的"主力"。
    • 典型题型: 验共轭; 多步更新; 选先验参数 (\(\alpha=1, \beta=1\) 是无信息先验)。

    🟡考点 21 · 极大似然估计 (MLE) — 难度 🔴 L4¶

    • 似然: \(L(\theta) = \prod_i p(x_i|\theta)\)
    • 对数似然: \(\ell(\theta) = \sum_i \log p(x_i|\theta)\)
    • MLE: \(\hat\theta_{\text{MLE}} = \arg\max \ell(\theta)\)
    • 数字例: \(n\) 次 Bernoulli, \(k\) 次成功 \(\Rightarrow \hat p = k/n\) (单步可验)
    • 数值法: 闭式不存在时, 用 Ch03 §05 Newton/GD 迭代
    • 典型题型: 求 MLE; 对数似然; 数值解; Fisher 信息计算铺垫。

    🟡考点 22 · MAP 估计 — 难度 🟡 L3¶

    \[\hat\theta_{\text{MAP}} = \arg\max_\theta P(\theta|D) = \arg\max_\theta \left[ \log P(D|\theta) + \log P(\theta) \right]\]
    • 数字例: 10 次全正面, MLE 给 \(\hat p=1\); Beta(2,2) 先验下, MAP 给 \(\hat p = 9/12 = 0.75\) (有先验修正)
    • 与 MLE 关系: MAP = MLE + 先验; 先验 → 0 时 MAP → MLE
    • 典型题型: 给先验求 MAP; 与 MLE 对比; 共轭下 MAP 闭式。

    🟡考点 23 · Jensen 不等式 — 难度 🟡 L3¶

    • 数字例: \(\log\) 凸, 故 \(\log E[X] \ge E[\log X]\); 故 \(E[\log X] \le \log E[X]\)
    • 应用: KL 散度非负性 (\(D_{KL} \ge 0\)); 信息不等式; EM 算法推导。

    🟢考点 24 · 测度论严格公理化 (Ω, F, P) — 难度 🔴 L5 ⭐¶

    🟢考点 26 · 充分统计量与 Rao-Blackwell — 难度 🔴 L5 ⭐¶

    🟢考点 27 · EM 算法 — 难度 🔴 L5 ⭐¶

    五、识别他人错误陈述题型 (L5, 6 题)¶

    5.1 密度当概率 — 学生说 "某连续分布在 \(x=2\) 处的密度是 2.5, 所以 \(P(X=2)=2.5\)"。 - 错: \(f(2)=2.5\) 不是概率, 仅是密度。\(P(X=2) = \int_2^2 f(x)\,dx = 0\)。 - 正: 密度 > 1 完全合法; 单点概率恒为 0; 概率是面积。 - 修: 看 \(f(x)\) 与 \(F(x)\) 的关系: \(F'(x) = f(x)\), \(F\) 才是概率。

    5.2 独立 = 不相关 — 学生对正态之外的 \(X,Y\) 说 "\(\text{Cov}=0\) 所以独立"。 - 错: 一般 \(\text{Cov}=0 \not\Rightarrow\) 独立; 反例 \(Y=X^2\), \(X\sim U(-1,1)\)。 - 正: 仅联合正态下独立等价不相关。 - 修: 改说"\(\text{Cov}=0\) 只能排除线性相关, 不能排除非线性相关"。

    5.3 KL 对称 — 学生写 \(D_{KL}(p\|q) = D_{KL}(q\|p)\)。 - 错: KL 不对称, \(D_{KL}(p\|q) \ne D_{KL}(q\|p)\)。 - 正: 数字例 \(p=\mathcal{N}(0,1)\), \(q=\mathcal{N}(0,2)\): \(D_{KL}(p\|q) = \frac{1}{2}\log 4 - 1/2 + 1/8\), 而 \(D_{KL}(q\|p) = \frac{1}{2}\log(1/4) - 1 + 2 = -\log 2 + 1\) — 不等。 - 修: 用 Jensen 证明 \(D_{KL} \ge 0\), 但不证明对称。

    5.4 MLE = MAP — 学生认为先验不影响估计。 - 错: MLE 无先验; MAP 带先验。 - 正: 数字例 10 次全正面, MLE 给 \(\hat p=1\); Beta(2,2) 先验下 MAP 给 \(9/12=0.75\)。 - 修: 写 MAP = \(\arg\max [\log P(D|\theta) + \log P(\theta)]\)。

    5.5 条件独立 = 独立 — 学生写 "朴素贝叶斯假设特征独立"。 - 错: 朴素贝叶斯假设特征给定类别 \(Y\) 后条件独立, 不是无条件独立。 - 正: 写 \(P(X_1, X_2, \ldots, X_d | Y) = \prod_i P(X_i | Y)\)。 - 修: 特征之间仍可能相关 (边缘), 仅条件独立。

    5.6 λ 三义混淆 — 学生写 \(\lambda = 5\) 时不标语境。 - 错: λ 在不同章节含义不同。 - 正: 标 "λ (Poisson 率)" 或 "λ (Ch03 乘子)"。 - 修: 每次首现写符号表, 持续到不再歧义。
