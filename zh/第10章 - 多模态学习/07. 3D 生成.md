# 3D 生成 (3D Generation)

> **补充说明**: 本节为中文版扩展内容，英文原书无对应章节。快照日期 2026-09。注意本节讲"生成 3D 资产/场景"，与第 05 节"用 GNN 学习 3D 点云表示"互补。

> **一句话总结**：3D 生成在 2024-2026 年从"学术 demo"跨进"生产管线"——以**前馈大重建模型** (如 TripoSR 谱系) 解决"快"、以**原生 3D 扩散/流匹配** (如腾讯 Hunyuan3D 系、微软 TRELLIS) 解决"好"，以**可交互世界场景** (World Labs Marble，见第 20 章世界模型) 解决"大"；游戏、影视、电商、机器人的资产管线正在被重写。

## 一 · 为什么 3D 生成比 2D 难

- **表示未定**：2D 生成只需要像素网格；3D 要先选表示——网格 (mesh)、体素、符号距离场 (SDF)、NeRF、**3D 高斯溅射 (3D Gaussian Splatting, 3DGS)**。表示决定"能不能导出到游戏引擎/能不能拓扑/能不能渲染得快"。
- **数据稀缺**：互联网的 2D 图片近乎无限，配对好的 3D 资产 (Object/材质/拓扑) 以百万计——比 2D 数据少三个数量级。
- **一致性维度多**：几何、拓扑 (流形)、UV、材质 (PBR)、多视角一致、物理合理 (能站住、能动画)，任何一项不及格都进不了生产管线。

## 二 · 三条技术路线 (2026-09 快照)

### 路线 A：前馈大重建模型 (图生 3D 的"秒级"路线)

- **思想**：不逐样本优化，训练一个 Transformer 直接回归 3D 表示——本质是把 NeRF/3DGS 的"逐场景拟合"换成第 6 章的"端到端监督学习"。
- **谱系**：LRM (2023) → **TripoSR** (Stability AI × Tripo, 2024，单图 3D 秒出) → **Stable Point Aware 3D (SPAR3D)**、TRELLIS 的快速模式等。2026 年它们已是电商/预览管线的默认引擎。
- **优点**：快 (秒级)、可扩展；**缺点**：细节与拓扑仍弱于逐样本优化，"像不像"有了，"能不能直接进 Maya"还差工序。

### 路线 B：原生 3D 生成模型 (扩散/流匹配吃 3D)

- **思想**：把第 04 节的扩散/流匹配搬到 3D 潜空间——先训 3D VAE 把资产压成结构化潜码 (几何 + 表面 + 纹理)，再训扩散模型生成潜码。这与"LLM 在离散 token 上学分布"同构，只是 token 换成了**结构化 3D 潜变量**。
- **代表**：
  - **腾讯 Hunyuan3D 2.x / 2.5 (2025)**：开源生态里最完整的"形状 + 纹理"两阶段系统 (Hunyuan3D-DiT 生成形状 + Paint 生成纹理)，2.5 代把几何细节与 PBR 材质推到接近商用资产；2.1 起开源含训练代码，社区复现活跃。
  - **微软 TRELLIS (2024-12)**：**结构化潜变量 (SLAT)** 表示——把 3DGS/网格统一进一个可编辑潜空间，支持变体生成 (同形异材质/同材质异形)，开源后成为研究界事实基线之一。
  - **Tripo / Rodin (Deemos) / Meshy** 等商用平台：把上述研究打包成"上传图 → 下载可导入 Blender/Unity 资产"的产品，主打游戏/影视外包管线。
- **2026 分水岭**：**拓扑与 UV 可用性**。生成"好看的 mesh"已解决，生成" game-ready 的 mesh" (干净拓扑、合理 UV、PBR 贴图) 仍是主要差距，各家 2.5 代产品都在攻这一项。

### 路线 C：可交互场景与 4D (从资产到世界)

- 单资产之上是**场景与世界**：World Labs **Marble** (图/文 → 可导出 3D 场景，已商业化)、**Genie 3** 类实时交互世界 (第 20 章世界模型路线)、以及视频驱动的 **4D 生成** (时序一致的动态 3D，服务影视预演与仿真)。
- 这条路线与第 20 章的物理 AI 合流：机器人仿真需要无限"可交互场景"，3D 生成正在成为**仿真资产的自助工厂**。

## 三 · 工程选型口诀 (2026-09)

| 需求 | 建议 |
|------|------|
| 电商/预览，秒级出模型 | 路线 A：TripoSR 系 / SPAR3D |
| 游戏资产，质量优先、可开源自部署 | 路线 B：Hunyuan3D 系 / TRELLIS |
| 商用外包管线 (要交付保证) | Tripo / Rodin / Meshy 平台 |
| 整个可交互场景 | Marble / 世界模型路线 (第 20 章) |
| 动态/4D | 视频驱动 4D (尚在快速演化，谨慎压注单家) |

## 四 · 通用提示：把 3D 生成当"多阶段流水线"读

所有 2026 年的 3D 生成系统，拆开都是同一副骨架——这与本书反复出现的"分阶段+每阶段可替换"思想一致：

$$\text{输入 (图/文)} \xrightarrow{\text{多视角/几何先验}} \text{粗几何} \xrightarrow{\text{细节化}} \text{精细几何} \xrightarrow{\text{纹理/材质}} \text{PBR 资产} \xrightarrow{\text{后处理}} \text{可导入资产}$$

论文对比时先问三件事：**用的什么 3D 表示？每阶段是前馈还是优化？评测用的资产级指标还是渲染级指标？**——答完这三问，大部分"又快又好"的宣传都能放进同一坐标系。

## 📌 本节要点

- **3D 生成的三大难点**：表示未定 (mesh/SDF/3DGS/NeRF)、数据稀缺 (比 2D 少三个量级)、一致性维度多 (几何/拓扑/UV/材质/物理)。
- **三条路线**：前馈大重建 (快，TripoSR 谱系)、原生 3D 扩散/流匹配 (好，Hunyuan3D/TRELLIS)、可交互场景 (大，Marble/世界模型)。
- **2026 分水岭是"拓扑与 UV 可用性"**：从"像"到"game-ready"，是研究到生产的最后一公里。
- **方法论骨架统一**：粗几何 → 细节 → 纹理 → 后处理的多阶段流水线；读论文先问表示、前馈/优化、评测口径。
- **与本书的连接**：3D VAE + 扩散 = 第 04 节；端到端回归 = 第 06 章；可交互场景 = 第 20 章世界模型；机器人仿真数据 = 第 11 章。
