# 图像与视频生成 · 2025-2026 进展

> **补充说明**: 本节为中文版扩展内容，英文原书无对应章节。承接第 04 节 (GAN/VAE/扩散/流匹配) 与第 05 节 (统一架构)；快照日期 2026-09，具体产品规格以官方发布为准。

> **一句话总结**：图像生成在 2025-2026 完成了"扩散 → 自回归/流匹配混合 + 原生多模态"的换代 (GPT-4o 原生图像、Google Nano Banana 系、FLUX 系)，视频生成分辨率/时长/可控性三线并进 (Sora 2、Veo 3、可灵 Kling 等，中国模型在赛道上位居第一梯队)，且生成正在从"工具"变成"交互媒介"。

## 一 · 图像生成：三代同堂的 2026

- **第一代 (2022-2023, 扩散 UX 时代)**：Stable Diffusion XL、DALL·E 3、Midjourney v5-v6——"写咒语 → 抽卡"。仍是教科书范式 (第 04 节)，但已非体验前沿。

- **第二代 (2024-2025, 指令编辑时代)**：
  - **GPT-4o 原生图像生成** (2025-03)：图像生成第一次被放进**自回归多模态 LLM** 里——不是外挂一个扩散模型，而是让 LLM 直接"画" (自回归 + 扩散解码器混合)。核心突破是**指令式编辑**与**文字渲染**："把这张图的猫换成狗，其余别动"首次可靠。
  - **FLUX 系 (Black Forest Labs)**：流匹配 (第 04 节) 的工业化样板；**FLUX.1 Kontext** (2025-05) 把上下文编辑做成模型能力，**FLUX.2** (2025-11) 进一步统一生成/编辑，开源阵营的画质天花板。
  - **Google Nano Banana / Gemini 原生图像** (2025-08 起)：Gemini 多模态家族内置的图像生成与编辑，**角色一致性** (multi-turn 里同一人物不变) 是招牌；2025-11 "Nano Banana Pro" 把生成拉进 4K 与"图形设计可用"区间。
  - **Midjourney v7** (2025-04)：审美先发优势的延续，视频能力 (V1) 同步上线。
  - **中国梯队**：字节 **Seedream 4.0** (2025-09)、阿里 **Qwen-Image** (2025-08，开源) 等在权威评测榜单上与美系旗舰互有胜负，中文文字渲染是显著长板。

- **2026 年的关键词：一致性经济**。生成单张好看的图已是 commodity；付费能力集中在**跨轮一致性** (同一角色/产品/场景反复出现)、**精准排版** (海报级文字)、**编辑可靠性** (改一处不动全局)。这恰是"多模态 LLM 原生生成"相对"独立扩散工具"的结构性优势 (与第 05 节统一架构论呼应)。

## 二 · 视频生成：从"能动"到"可控可拍"

- **Sora 2 (OpenAI, 2025-09/10)**：分辨率/时长/物理合理性的整体跃升，配 **Sora app** (信息流 + 二创) 让生成视频第一次有了消费级社交产品形态；**cameos** (把真人形象授权给生成场景) 引发"人格权 vs 生成媒介"的治理讨论 (第 21 章议题)。
- **Veo 3 / 3.1 (Google DeepMind, 2025-05 起)**：**同步音轨生成** (对话口型 + 音效 + 环境音一起出) 是差异化里程碑——"视频 + 声音一体生成"从此成为旗舰标配。
- **可灵 Kling (快手) / 海螺 (MiniMax) / Vidu (生数) / 通义万相 (阿里)**：中国梯队整体处于第一梯队，其中可灵在迭代速度与商业化规模上被广泛认为与美系旗舰并肩；**Wan 2.x 系 (阿里)** 提供开源权重，是开源视频生成的主力。
- **Runway Gen-4 (2025-03)**：把**角色/场景一致性引用** (reference-consistent generation) 做成工业管线，影视工作流向靠拢。

- **技术趋势 (对应第 04/05 节理论)**：
  1. **DiT + 全量缩放**成为视频底座 (第 04 节 DiT 的放大版)，训练算力比同参数 LLM 更烧。
  2. **流匹配/整流** 逐步替换 DDPM 采样，少步数 (第 8 章 "5-20 步") 成为标配。
  3. **自回归+扩散混合** (时间维自回归、空间维扩散) 统一了"长视频"与"高画质"的矛盾。
  4. **音视频联合生成**：联合 token 化 (第 03 节的延伸)。
  5. **世界模型接管"可控性"**：相机轨迹、物体交互级的控制，正来自第 20 章世界模型的动作条件化——视频生成与世界模型的边界在变模糊。

## 三 · 对读者的定位建议

- **学理论**：第 04 节的扩散/流匹配数学 + 第 05 节统一架构观点，到 2026 仍是全部产品的骨架，没有过时。
- **追产品**：图像看"编辑可靠性与一致性"，视频看"音画一体与可控性"，把具体型号当快照而非知识本体。
- **选型口诀 (2026-09)**：开源可控选 FLUX 系 / Wan 系；一致性编辑选 Gemini 原生图像；影视管线选 Runway/Veo；社交娱乐看 Sora 系；中文文字渲染优先中国梯队。

## 📌 本节要点

- **图像生成换代**：从"独立扩散工具"转向"多模态 LLM 原生生成" (GPT-4o 图像、Gemini/Nano Banana 系)——指令编辑、文字渲染、跨轮一致性取代单张画质成为竞争力核心；FLUX 系是开源流匹配的工业化样板。
- **视频生成第一梯队**：Sora 2 (产品化+物理感)、Veo 3 (音画一体)、可灵/海螺等中国梯队 (第一梯队)、Wan 系 (开源主力)；Runway 把一致性做成工作流。
- **五大技术趋势**：DiT 缩放、流匹配少步采样、自回归+扩散混合、音视频联合、与世界模型合流。
- **与教材的关系**：第 04/05 节的扩散/流匹配/统一架构理论是这些产品的共同骨架；具体型号是快照，方法是本体。
