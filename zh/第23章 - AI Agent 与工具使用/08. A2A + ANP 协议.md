## 一 · 一句话总览

> **Agent 协议 2025 = 4 大演进**: **MCP (Anthropic 2024-11, 工具协议)** → **A2A (Google 2025-04, Agent-to-Agent)** → **ANP (Agent Network Protocol, 2025, 跨域互联)** → **IBM ACP (2025, 通信标准)**。LLM 进入"协议化"时代。

---

## 二 · 心智模型

把 Agent 协议想成"互联网协议"演进:
- **HTTP** (1990) = 文档传输
- **REST API** (2000) = 资源访问
- **GraphQL** (2015) = 灵活查询
- **MCP** (2024) = LLM 工具访问
- **A2A** (2025) = Agent 协作
- **ANP** (2025) = Agent 网络

**每一层都建立在上一层之上**。

### 第 2 段 · MCP (Anthropic 2024-11) (10 分钟)

**全称**: Model Context Protocol

**核心思想**: 把 LLM 与外部工具 / 数据**标准化连接**。

**架构**:
```
LLM ←→ MCP Client ←→ MCP Server ←→ 工具 / API / DB
```

**3 大组件**:
- **MCP Host**: Claude Desktop / IDE
- **MCP Client**: 与 server 通信
- **MCP Server**: 暴露工具 (Python / TS 实现)

**协议特性**:
- JSON-RPC 2.0
- stdio / HTTP+SSE / Streamable HTTP
- 三种原语: Tool / Resource / Prompt

**示例**:
```python
# MCP Server
from mcp.server import Server

app = Server("weather")

@app.tool()
async def get_weather(city: str) -> str:
    return f"Weather in {city}: sunny"

# MCP Client
from mcp.client import Client

client = Client(app)
result = await client.call_tool("get_weather", {"city": "Beijing"})
```

**Ch23 §04 已覆盖**, 本节扩展。

### 第 3 段 · A2A (Google 2025-04) (10 分钟)

**全称**: Agent-to-Agent Protocol

**核心思想**: 解决 **Agent 之间**通信, 不只是 LLM 调用工具。

**与 MCP 区别**:
- **MCP**: LLM ↔ Tool (工具调用)
- **A2A**: Agent ↔ Agent (协作)
- **MCP 解决"如何访问工具"**
- **A2A 解决"如何与其他 Agent 协作"**

**关键概念**:
- **Agent Card**: JSON 描述 Agent 能力 (类似 OpenAPI)
- **Task**: 任务对象 (state, message, artifact)
- **Push Notifications**: 异步事件
- **Streaming**: 长任务流式传输

**协议栈**:
- HTTP + JSON-RPC 2.0
- Server-Sent Events (SSE)
- gRPC / WebSocket (TBD)

**示例**:
```json
// Agent Card
{
  "name": "Research Agent",
  "description": "Performs web research and analysis",
  "url": "https://research-agent.example.com",
  "skills": [
    {"id": "web_search", "description": "Web search"},
    {"id": "summarize", "description": "Summarize text"}
  ],
  "auth": {"type": "oauth2"},
  "version": "1.0"
}
```

**2025-07 状态**:
- 50+ 公司支持 (Google / AWS / Microsoft / Salesforce / Atlassian)
- 7+ 框架集成 (LangGraph / AutoGen / CrewAI / Strands / Genkit)
- Linux Foundation 治理

### 第 4 段 · ANP (Agent Network Protocol, 2025) (8 分钟)

**核心思想**: 解决 **跨域 / 跨组织** Agent 互联。

**与 A2A 区别**:
- **A2A**: 同一信任域内 Agent 协作
- **ANP**: 跨域 / 跨组织 Agent 网络 (类似 HTTP + DNS)

**核心特性**:
- **去中心化**: 基于 DID (Decentralized Identifier)
- **协商**: 自动 Agent 发现 (类似 DNS)
- **加密**: 端到端加密通信
- **互操作**: 跨协议转换

**架构**:
```
Agent A  ←→  ANP Gateway  ←→  Agent B
             ↓
           DID (身份)
             ↓
           VCA (能力描述)
```

**适用场景**:
- 跨企业 Agent 协作
- 跨云 Agent 实例互通
- 跨国 / 跨监管 Agent 协作

### 第 5 段 · IBM ACP + 统一趋势 (5 分钟)

**IBM Agent Communication Protocol (2025-06)**:
- 工业级 Agent 通信
- 与 Kafka / MQTT 集成
- 强 SLA + 监控

**OpenAI Agents SDK (2025-07)**:
- OpenAI 推 Agent 标准
- 紧跟 MCP + A2A
- Handoffs / Sessions / Guardrails

**统一趋势**:
- **协议融合**: MCP + A2A + ANP → 单协议
- **Registry 标准化**: Agent Registry 类似 npm
- **全双工**: 双向流式 + 双向认证
- **多模态**: 文本 / 语音 / 视频统一

**2026 预测**:
- 单一 Agent 协议标准 (类似 LSP 之于 IDE)
- Agent Discovery (DNS-like)
- 跨厂商 Agent 协作生产化
