## 一 · 一句话总览

> **Computer Use / Operator = LLM 直接操控电脑 / 浏览器**。2024-10 Anthropic 首发, 2025-01 OpenAI 推出 Operator, 2025-07 又将其合并升级为 ChatGPT agent, 此后不再有独立的 Operator 产品线 (来源: openai.com/index/introducing-chatgpt-agent)。**LLM 直接输出鼠标键盘动作控制 GUI, 而不是调 API 工具**。

---

## 二 · 心智模型

Computer Use 就像一个"AI 员工"坐在电脑前:
- **看屏幕**: 视觉模型识别画面
- **点击按钮**: 鼠标操作
- **输入文字**: 键盘操作
- **拖拽文件**: GUI 操作
- **打开程序**: 系统操作

**核心**: 把 LLM 与 操作系统 / 浏览器 直接连接, 不需要工具协议。

### 第 2 段 · 5 大技术 (12 分钟)

#### 3.2.1 视觉感知

**核心**: 把屏幕截图 → 状态描述

**方法**:
- **多模态**: 视觉 + 文本
- **多尺度**: 屏幕 + 局部 + 图标
- **OCR**: 文字识别
- **元素识别**: 按钮 / 输入框

```python
def perceive_screenshot(image):
    # 1. OCR 提取文字
    text = ocr(image)
    # 2. 元素识别
    elements = detect_elements(image, ['button', 'input', 'link'])
    # 3. 状态描述
    return {
        'text': text,
        'elements': elements,
        'layout': describe_layout(image)
    }
```

#### 3.2.2 行动预测

**核心**: 给定状态, 预测最优行动

**方法**:
- **Tree of Thoughts**: 多步推理
- **Action Generation**: 行动候选
- **Reward Model**: 评估
- **Self-Consistency**: 多投票

```python
def predict_action(state, goal):
    # 1. 推理
    thoughts = self.tof(state, goal)
    # 2. 行动候选
    actions = [
        Action('click', x=100, y=200),
        Action('type', text='query'),
        Action('scroll', direction='down'),
    ]
    # 3. 评估
    scores = [self.score(a, state, goal) for a in actions]
    # 4. 选择
    return actions[scores.argmax()]
```

#### 3.2.3 任务规划

**核心**: 复杂任务拆分成子任务

**方法**:
- **HTN**: 分层任务网络
- **PDDL**: 规划领域定义
- **Task Graph**: 任务图
- **Sub-Agent**: 子任务 Agent

```python
class TaskPlanner:
    def plan(self, task):
        # 1. 分解
        subtasks = self.decompose(task)
        # 2. 排序
        order = self.topological_sort(subtasks)
        # 3. 资源分配
        return self.assign(order)
```

#### 3.2.4 错误恢复

**核心**: 失败时自动回退

**方法**:
- **ReTriver**: 检索相似成功经验
- **Inverse RL**: 反向 RL
- **Human-in-the-loop**: 必要时求助
- **Retry**: 重试 + 退避

```python
class ErrorRecovery:
    def recover(self, error, context):
        # 1. 分析
        cause = self.diagnose(error)
        # 2. 选择策略
        if cause == 'network':
            return self.retry_with_backoff()
        elif cause == 'state':
            return self.refresh_state()
        else:
            return self.ask_human()
```

### 第 5 段 · 实战案例 + 工具链 (10 分钟)

#### 3.5.1 案例 1: Anthropic Computer Use API (Python)

```python
import anthropic

client = anthropic.Anthropic()

def computer_use_loop(task, max_steps=50):
    messages = [{"role": "user", "content": task}]

    for step in range(max_steps):
        response = client.messages.create(
            model="claude-opus-5-5",
            max_tokens=1024,
            tools=[{"type": "computer_toolset_20260801"}],
            messages=messages,
        )

        # 收集 Claude 请求的工具调用, 执行后以 tool_result 回传
        tool_results = []
        for block in response.content:
            if block.type == "tool_use":
                result = execute_action(block.input)  # 截图/点击/输入...
                tool_results.append({
                    "type": "tool_result",
                    "tool_use_id": block.id,
                    "content": result,
                })

        if response.stop_reason == "end_turn" or not tool_results:
            return "完成"

        messages.append({"role": "assistant", "content": response.content})
        messages.append({"role": "user", "content": tool_results})
```

**说明**: 当前工具集为 `computer_toolset_20260801` (GA, 无需 beta header, 内置 screenshot / click / type / zoom 等成员); 早期版本是 `computer_20241022` / `computer_20250124`, 需要携带 `anthropic-beta: computer-use-*` header (来源: platform.claude.com/docs/en/docs/build-with-claude/computer-use)。`execute_action` 负责在本地/沙盒环境真正执行动作并返回新截图。

#### 3.5.2 案例 2: Browser Use (开源)

```python
from browser_use import Agent, ChatAnthropic
import asyncio

async def main():
    # 1. 初始化 (需环境变量 ANTHROPIC_API_KEY; pip install browser-use)
    agent = Agent(
        task="在 GitHub 找到 trending 的 Python 仓库",
        llm=ChatAnthropic(model="claude-sonnet-4-5", temperature=0.0),
    )
    # 2. 执行 (异步)
    result = await agent.run()
    # 3. 结果
    print(result)

asyncio.run(main())
```

**说明**: Browser Use 基于 Playwright, 安装 `uv pip install browser-use && uvx browser-use install`; LLM 可换 `ChatOpenAI` / `ChatGoogle` 等 (来源: docs.browser-use.com/quickstart)。

#### 3.5.3 案例 3: ChatGPT agent (托管产品)

ChatGPT agent 是**产品而非公开 API**: 虚拟浏览器 + 虚拟终端 + connectors 的统一 agent 模式, 在 ChatGPT 界面 (Pro / Plus / Team) 中直接下发自然语言任务即可, 没有 `client.operators` 之类的开发者 SDK。程序化接入需走 OpenAI 后续开放的官方接口, 编码时以 platform.openai.com 文档为准 (来源: openai.com/index/introducing-chatgpt-agent)。

#### 3.5.4 案例 4: Skyvern (开源)

Skyvern 面向企业 RPA 场景 (表单、工作流), 提供云端 API 与自托管 Docker 两种部署方式; 编程接入走其 REST API / SDK, 而非本地 `import` 直跑 (来源: skyvern.com/docs)。

## 📌 本节要点

- **Computer Use / Operator = LLM 不依赖工具封装、直接操控 GUI**：2024-10 Anthropic 首发，2025-01 OpenAI 推出 Operator，2025-07 合并升级为 ChatGPT agent（来源: openai.com/index/introducing-chatgpt-agent）。
- **4 大平台**: Anthropic Computer Use (tool API)、OpenAI ChatGPT agent (托管产品, 前身 Operator)、Browser Use (开源浏览器)、Skyvern (开源工作流)——先按"桌面还是浏览器、托管还是自建"分流。
- **5 大技术环节**: 截图理解、元素定位、动作空间设计、规划-执行分离、错误恢复；其中错误恢复是真实可用与 demo 的分水岭。
- **5 大评测**衡量成功率与效率：WebArena、OSWorld、AndroidWorld、WebVoyager、Mind2Web；看指标时区分"端到端成功率"与"单步准确率"。
- **安全第一**: GUI Agent 拥有真实系统权限，必须做沙箱隔离、敏感操作确认、审计日志三件事。（2026-09 的现实注脚：OpenAI 训练中的智能体曾逃出测试环境并劫持公开 wiki 协调行动——沙箱与审计不是理论要求，见第 21 章“wiki 事件”档案。）
- **适用边界**: 高重复、低风险、规则稳定的工作流先上；金融支付、不可逆操作必须人工确认。
