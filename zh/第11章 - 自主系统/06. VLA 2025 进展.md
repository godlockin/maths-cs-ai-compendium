## 二 · 心智模型

把 VLA 想象成"机器人界的 LLM":
- **2023**: RT-2 (第一种 VLA, 闭源)
- **2024**: OpenVLA / π0 (开源 + 跨形态)
- **2025**: Gemini Robotics / π0.5 / LeRobot (通用 + 普及)

**核心趋势**: 通用化 + 开源化 + 推理增强 + 高效微调

## 三 · 章节主线 (5 段)

### 第 1 段 · Gemini Robotics (Google 2025) (8 分钟)

**发布时间**: 2025-03 (Gemini Robotics) + 2025-04 (Gemini Robotics-ER)

**核心**: Gemini 2.0 + 机器人动作输出

**架构**:
- 基座: Gemini 2.0
- 输入: 图像 + 文本指令 + 机器人状态
- 输出: 动作 token (类似 RT-2)
- 训练: 互联网视频 + 真实机器人 + 仿真

**性能**:
- ALOHA 模拟: 70%+ 任务
- 真实机器人: 50%+ 任务
- 零样本泛化: 强

**Gemini Robotics-ER**:
- 加入"具身推理" (Embodied Reasoning)
- 4 倍推理增强
- 理解场景 + 规划路径

**开源**: 提供 SDK, 模型权重 API

### 第 2 段 · π0 → π0.5 (Physical Intelligence, 2024-2025) (8 分钟)

**π0 (2024-10)**:
- 3B 参数
- 22 种机器人验证
- 流式动作输出
- 通用性强

**π0.5 (2025-04)**:
- 跨形态泛化
- 长时任务 (10+ 步)
- 指令微调 SFT
- 性能堪比专家

**架构**:
- PaliGemma VLM 基座
- 动作专家 (action expert)
- 流式输出 (50 Hz)
- 延迟 50ms

**训练**:
- 多形态机器人数据
- 互联网预训练
- 任务微调

**应用**:
- 折衣服
- 整理桌子
- 装配零件
- 烹饪 (与人类协作)

### 第 3 段 · LeRobot (HuggingFace, 2024-) (6 分钟)

**项目**: HuggingFace 开源机器人基座

**目标**:
- 开源机器人数据 (Open X-Embodiment)
- 开源模型 (SmolVLA)
- 开源硬件 (ALOHA / Koch v1.1)

**SmolVLA (2025)**:
- 450M 参数
- 适配消费级 GPU
- 训练 50 小时即可
- 教学友好

**数据集**:
- Open X-Embodiment (2024, 22 机构合作)
- 60+ 机器人类型
- 2M+ 演示

### 第 4 段 · VLA-CoT 推理增强 (2025) (6 分钟)

**问题**: VLA 缺推理, 复杂任务易失败。

**方案**: 借鉴 LLM CoT, VLA 引入推理链。

**代表**:
- **HiRT** (2024): 视觉 + 推理 + 动作分层
- **VLA-CoT** (2025): 显式推理步骤
- **Embodied-CoT** (Google 2024): 3D 场景推理

**架构**:
```
图像 → VLM 场景理解 → LLM 推理 → 动作分解 → 低层控制器
```

**效果**:
- 长时任务 +30%
- 失败恢复 +25%
- 解释性增强

### 第 5 段 · OpenVLA-OFT + 部署 (6 分钟)

**OpenVLA (2024)**:
- 7B 开源 VLA
- 在 OpenVLM 基础上
- 单 GPU 训练

**OpenVLA-OFT (2025)**:
- 优化微调 (Optimized Fine-Tuning)
- 速度 5×
- 性能 10%+
- 适配更多硬件

**部署难点**:
- **延迟**: 实时性 (< 50ms)
- **安全**: 失败兜底
- **硬件**: CPU 推理难
- **能耗**: 长时间工作

**部署栈**:
- 模型量化 (INT8 / FP16)
- Edge 推理 (TensorRT / ONNX Runtime)
- 安全层 (碰撞检测 + 急停)
- 冗余 (主备切换)

## 八 · 2026 年中增补 · VLA/机器人基础模型新格局 (快照 2026-09)

> 本节为译者扩展增补（2026-09），前文主体是 2025 快照，保留作对照。

### 1. 三强格局定型：GR00T / Gemini Robotics / π 系

- **NVIDIA Isaac GR00T**: 2025-03 发布 **N1**（开源人形 VLA 基础模型，双系统架构：快系统 ~120Hz 真机动作 + 慢系统 VLM 推理）；2025 年内迭代 **N1.5**；**N1.7 (2026) 附带商业许可**——从研究开源走向"可以拿去卖钱的产品"，这是 VLA 商业化的关键一步。配套 **GR00T 参考人形** (基于宇树硬件，2026 年底) 把"模型 + 硬件 + 数据管线"打包成标准件。
- **Google DeepMind Gemini Robotics**: 2025 的初代之后，**Gemini Robotics 2** 与 **Gemini Robotics On-Device 2** (轻量版，跑在机载硬件上) 已发布——演示能力从抓放进化到系垃圾袋结、拧灯泡等高灵巧任务。双产品线 = 云端大模型 + 端侧小模型，与 LLM 的云/端分工同构。
- **Physical Intelligence π 系**: π0 → π0.5 的跨形态泛化路线继续；开源开放权重策略与 LeRobot 生态共同构成"非大厂阵营"的基础设施。

### 2. 关键变化：数据飞轮与标准化

- **遥操作数据平民化**：LeRobot 生态把 SO-10x 等低成本臂 + 数据工具链标准化，实验室级 VLA 复现门槛从"千万美元"降到"数千美元"。
- **仿真合成数据成为主粮**：NVIDIA Isaac/Cosmos 世界模型系 (见第 20 章世界模型一节) 把"仿真生成数据 → 真机微调"变成默认管线，缓解真实机器人数据永远不够的根本瓶颈。
- **本体的标准化**：NVIDIA 参考人形 + 宇树/Figure/1X 等硬件批量交付，让"同一套 VLA 权重跨本体迁移"有了现实载体。

### 3. 2026 年的开放问题

- **本体感知短板**：社区讨论指出相当比例的人形系统对自身身体状态 (proprioception) 的建模仍不可靠——"知道自己身体在哪"仍是未完全解决的问题。
- **可靠性长尾**：演示视频成功率 ≠ 产线成功率；连续运行数天的 MTBF (平均无故障时间) 是 2026 年商用化的真正门槛。
- **评测未统一**：VLA 没有"ImageNet 时刻"——各家用自家任务集，跨论文比较仍然困难。

### 4. 本节要点增补

- **GR00T N1.7 商业许可 + 参考人形** = VLA 供应链标准化的信号；**Gemini Robotics 2 双产品线** = 云端+端侧分工的信号。
- 世界模型 (Cosmos/Genie 系) 与 VLA 正在合流：世界模型管"想象/合成数据"，VLA 管"动作"——这是 2026 最重要的架构趋势 (见第 20 章世界模型)。

## 📌 本节要点

- **2025 VLA 四大主线**: Gemini Robotics (通用 VLA)、π0.5 (Physical Intelligence, 跨形态)、LeRobot (HuggingFace, 开源生态)、VLA-CoT (推理增强)；"通用化 + 开源化"双轨并进。
- **Gemini Robotics 的意义**: 把 Gemini 的多模态理解直接接到机器人控制，证明"互联网级预训练 → 物理动作"的迁移可行。
- **π0.5 的关键是跨形态**: 同一套模型适配不同机器人本体 (交叉形态训练)，数据规模与多样性决定泛化。
- **LeRobot 降低了入场门槛**: 开源模型 + 数据集 + 硬件参考设计，让实验室能复现 VLA 基线。
- **VLA-CoT / OpenVLA-OFT 代表两个改进方向**: 推理增强 (先思考再动作) 与高效微调 (低秩适配降低部署成本)。
- **2026 商用化落地中**: 从 demo 到产线，可靠性、安全认证与成本是三道门槛（2026 增补见下）。
