## 一 · 一句话总览

> **2025 VLA 进展 = 5 大方向**: **Gemini Robotics (Google 2025, 通用 VLA)** + **π0.5 (Physical Intelligence, 跨形态)** + **LeRobot (HuggingFace, 开源)** + **VLA-CoT (推理增强)** + **OpenVLA-OFT (高效微调)**。VLA 进入"通用化 + 开源化"双轨。

---

## 二 · 心智模型

把 VLA 想象成"机器人界的 LLM":
- **2023**: RT-2 (第一种 VLA, 闭源)
- **2024**: OpenVLA / π0 (开源 + 跨形态)
- **2025**: Gemini Robotics / π0.5 / LeRobot (通用 + 普及)

**核心趋势**: 通用化 + 开源化 + 推理增强 + 高效微调

## 三 · 章节主线 (5 段)

### 第 1 段 · Gemini Robotics (Google 2025) (8 分钟)

**发布时间**: 2025-03 (Gemini Robotics) + 2025-04 (Gemini Robotics-ER)

**核心**: Gemini 2.0 + 机器人动作输出

**架构**:
- 基座: Gemini 2.0
- 输入: 图像 + 文本指令 + 机器人状态
- 输出: 动作 token (类似 RT-2)
- 训练: 互联网视频 + 真实机器人 + 仿真

**性能**:
- ALOHA 模拟: 70%+ 任务
- 真实机器人: 50%+ 任务
- 零样本泛化: 强

**Gemini Robotics-ER**:
- 加入"具身推理" (Embodied Reasoning)
- 4 倍推理增强
- 理解场景 + 规划路径

**开源**: 提供 SDK, 模型权重 API

### 第 2 段 · π0 → π0.5 (Physical Intelligence, 2024-2025) (8 分钟)

**π0 (2024-10)**:
- 3B 参数
- 22 种机器人验证
- 流式动作输出
- 通用性强

**π0.5 (2025-04)**:
- 跨形态泛化
- 长时任务 (10+ 步)
- 指令微调 SFT
- 性能堪比专家

**架构**:
- PaliGemma VLM 基座
- 动作专家 (action expert)
- 流式输出 (50 Hz)
- 延迟 50ms

**训练**:
- 多形态机器人数据
- 互联网预训练
- 任务微调

**应用**:
- 折衣服
- 整理桌子
- 装配零件
- 烹饪 (与人类协作)

### 第 3 段 · LeRobot (HuggingFace, 2024-) (6 分钟)

**项目**: HuggingFace 开源机器人基座

**目标**:
- 开源机器人数据 (Open X-Embodiment)
- 开源模型 (SmolVLA)
- 开源硬件 (ALOHA / Koch v1.1)

**SmolVLA (2025)**:
- 450M 参数
- 适配消费级 GPU
- 训练 50 小时即可
- 教学友好

**数据集**:
- Open X-Embodiment (2024, 22 机构合作)
- 60+ 机器人类型
- 2M+ 演示

### 第 4 段 · VLA-CoT 推理增强 (2025) (6 分钟)

**问题**: VLA 缺推理, 复杂任务易失败。

**方案**: 借鉴 LLM CoT, VLA 引入推理链。

**代表**:
- **HiRT** (2024): 视觉 + 推理 + 动作分层
- **VLA-CoT** (2025): 显式推理步骤
- **Embodied-CoT** (Google 2024): 3D 场景推理

**架构**:
```
图像 → VLM 场景理解 → LLM 推理 → 动作分解 → 低层控制器
```

**效果**:
- 长时任务 +30%
- 失败恢复 +25%
- 解释性增强

### 第 5 段 · OpenVLA-OFT + 部署 (6 分钟)

**OpenVLA (2024)**:
- 7B 开源 VLA
- 在 OpenVLM 基础上
- 单 GPU 训练

**OpenVLA-OFT (2025)**:
- 优化微调 (Optimized Fine-Tuning)
- 速度 5×
- 性能 10%+
- 适配更多硬件

**部署难点**:
- **延迟**: 实时性 (< 50ms)
- **安全**: 失败兜底
- **硬件**: CPU 推理难
- **能耗**: 长时间工作

**部署栈**:
- 模型量化 (INT8 / FP16)
- Edge 推理 (TensorRT / ONNX Runtime)
- 安全层 (碰撞检测 + 急停)
- 冗余 (主备切换)
