## 一 · 一句话总览

> **2025 端侧 NPU 推理 = 4 大突破**: **Apple ANE (M4 38 TOPS)** + **高通 Hexagon (8 Gen 3)** + **联发科 APU (天玑 9300+)** + **WebLLM (浏览器 GPU)**。LLM 已能在 4GB 内存设备上跑 7B 模型。

---

## 二 · 心智模型

把 NPU 想象成"汽车发动机":
- **CPU**: 普通汽油机 (通用)
- **GPU**: 柴油机 (并行)
- **NPU**: 电动机 (AI 专用, 高效能)

**NPU 优势**:
- 5-10× 效率比 GPU
- 低功耗
- 实时响应
- 端侧隐私

## 三 · 章节主线 (5 段)

### 第 1 段 · Apple ANE + MLX (5 分钟)

**M4 Max ANE**:
- 38 TOPS
- 5× M1 速度
- 专用矩阵单元

**MLX / MLX-LM**:
- Apple Silicon 优化
- Unified Memory (CPU+GPU+ANE 共享)
- 与 PyTorch 互操作

**部署**:
```python
from mlx_lm import load, generate

model, tokenizer = load("mlx-community/Meta-Llama-3-8B-Instruct-4bit")
response = generate(model, tokenizer, prompt="hello", max_tokens=100)
```

**Mac Studio 跑 70B 4-bit**:
- M2 Ultra: ~6 tokens/sec
- M4 Max: ~12 tokens/sec

### 第 2 段 · 高通 Hexagon + 端侧 SDK (8 分钟)

**Snapdragon 8 Gen 3 NPU**:
- 12 TOPS
- 45% 性能提升 vs Gen 2
- 8-bit 量化原生

**Snapdragon X Elite (PC)**:
- 45 TOPS NPU
- 微软 Copilot+ 认证
- 笔记本本地 LLM

**QUALCOMM AI Hub**:
- 一键模型转换
- 100+ 预训练模型
- 端到端优化

**部署**:
- Llama 3 8B 4-bit
- 持续对话
- 离线翻译

### 第 3 段 · 联发科 APU + 国产芯片 (6 分钟)

**天玑 9300+ APU**:
- 12 TOPS
- 端侧 Stable Diffusion
- LLM 推理

**国产 NPU**:
- **华为达芬奇**: 麒麟 9000s / 9100
- **寒武纪 MLU**: 端侧 MLU220
- **壁仞 BR104**: 算力 1024 TFLOPs

**国产框架**:
- **MindSpore Lite** (华为)
- **寒武纪 CNRT** (寒武纪)
- **MegEngine** (旷视)

### 第 4 段 · WebLLM + 浏览器推理 (6 分钟)

**WebLLM 项目** (MLC AI, 2024):
- 浏览器内 LLM 推理
- WebGPU 加速
- 无需服务器

**支持**:
- Llama 3 (8B / 70B)
- Phi-3
- Qwen 2
- Mistral

**部署**:
```js
import { CreateMLCEngine } from "@mlc-ai/web-llm";

const engine = await CreateMLCEngine("Llama-3-8B-Instruct-q4f16_1-MLC");
const response = await engine.chat.completions.create({
  messages: [{ role: "user", content: "Hello" }]
});
```

**优势**:
- 零成本
- 隐私 (本地)
- 离线可用
- 跨平台

**局限**:
- 大模型首加载慢
- 浏览器限制
- 长上下文慢

### 第 5 段 · 树莓派 5 + LLM + 实时应用 (6 分钟)

**树莓派 5 (8 GB)**:
- ARM Cortex-A76 × 4
- 16 TOPS (RP 5 + Hailo)
- $80 完整 LLM 设备

**Phi-3 Mini 3.8B 跑树莓派 5**:
- 量化 INT4
- 1-2 tokens/sec
- 持续对话

**应用**:
- 智能家居
- 机器人控制
- 离线翻译
- 智能音箱

**实时语音**:
- Moshi 200ms 延迟
- Phi-3 + Whisper
- 端侧完整对话

**PhoneLLM**:
- 旗舰手机端 LLM
- 0.5-1.5B 模型
- 30-50 tokens/sec
- 自动语音助手

1. **LLM Studio** (UI, 端侧)
